# generators — 曲のブロックが使う振る舞い

曲（`pieces/`）のブロックは、ここの生成器を奏者と既定値で呼ぶ（[`../docs/architecture.md`](../docs/architecture.md) の「曲」）。
生成器を直すと、使っている曲が全部書き直される（プレビューが動いていれば保存したとき）。

どれも曲の動機（`ctx.material.motif`）とセクションの中心（`ctx.centre`）から音を作る。

| 生成器 | すること |
| --- | --- |
| [`statement`](./statement.ts) | 1 人が動機を述べる。そのまま・動機の音程に沿った反復（sequence）・紡ぎ出し（spin out: 圧縮、頭だけ、尻尾を伸ばしたカデンツ）・ブロック全体に引き伸ばす（fill: 定旋律） |
| [`halo`](./halo.ts) | 動機の音高クラスの和音を数人で保つ。一人ずつずれて息づく。動機の道筋どおりに動く、または元の調へ戻る。前のノードの音から共通音で入る |
| [`imitation`](./imitation.ts) | 動機の頭を人から人へ。入りごとに動機の道筋を 1 歩進み、P と I（か 4 形）を交互に。入りの間隔と速さは直線や流れに従う（ストレッタ、縮小） |
| [`field`](./field.ts) | 動機の音を 16 分などの細胞にして、人ごとに違う音から回し、何拍かごとにずらす。和声は動機の道筋を動機のリズムで進む（同じブロック長の fill と一緒に動く） |
| [`strike`](./strike.ts) | 全員で動機の和音を一撃。低音は動機の最初の音、一番上は選んだ音（ピボットにつながる） |
| [`pivot`](./pivot.ts) | 1 人が 1 音を継ぎ目の向こうまで保つ。既定は前のノードの一番上の音 |
| [`liquidation`](./liquidation.ts) | 動機を何度も繰り返し、毎回 1 音ずつ短く、遅く、弱く、最後の 1 音を保つ |
| [`bells`](./bells.ts) | ハープや鍵盤打楽器が、始まり・終わり・小節ごと・和声の変わり目・隣の旋律の段（親から渡された印）で動機の和音を鳴らす |

共通の道具は [`common.ts`](./common.ts): 楽器の楽な音域、奏者の選び方と順、声部の進め方（共通音を保ち、残りは近くへ）、動機のリズムでブロックを区切ること。
