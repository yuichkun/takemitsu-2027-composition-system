# 弦の16分 — ジャギジャギと弓を返して進む

- 状態: 試し中
- 作るもの: [`sketch.ts`](./sketch.ts)。値はプレビュー右のつまみで動かせる（`values.json` に残る）
- 奏法（staccato / spiccato）もつまみの 1 つ

## 問い

弦 4 セクション（Vn I、Vn II、Va、Vc）だけで、16分の一定のリズムを短く切って弓を返しながら進むパッセージはどう鳴るか。

## 余湖さんの注文（2026-09-27）

- 16分、一定のリズム、スタッカートのように短く切る
- 4 セクションは、全部が重なる瞬間があってもいいが、少し重なりながら互い違いになる
- 最後に向けてフーガのクライマックスのように全部重なる
- 最後は駆け上がって終わる

## 形（僕が置いたもの）

| 小節 | 起きること |
| --- | --- |
| 1–8（A） | Vc → Va → Vn II → Vn I の順に 1 小節おきに入る。各 1 小節半なので、隣と半小節ずつ重なる |
| 9–14（B） | 半小節おきに入る。常に 3 セクションが重なり、1 セクションが休む。短三度上 |
| 15–18（C） | 8分ずつずらして全員が入り、そのまま全員で弾き続ける。三全音上 |
| 19（D） | 全員が自分の基音から 2 オクターブ駆け上がる。拍頭にアクセント |
| 20 | 頂点の音を短くアクセントで 1 つ。fff |

## つまみ（意図ごと）

| グループ | つまみ | 何を決めるか | 仮の値 |
| --- | --- | --- | --- |
| Sound | Tempo | 16分の速さ | ♩=144 |
| Sound | Stroke | 弓の返し方。staccato（点だけ、弦の上）/ spiccato（点に spicc.、弾ませる） | staccato |
| Pitch | Scale | 全部の音を取る音の集合（1 オクターブ内の半音）。2 つの音型も駆け上がりもここから取る | 八音音階 0 1 3 4 6 7 9 10 |
| Pitch | Transpose | 全体の高さ。0 で Vc D3、Va A3、Vn II D4、Vn I A4 に立つ | 0 |
| Pitch | Lift per stage | 段階ごとに上げる幅（B は A の、C は B の上） | 3 半音 |
| Form | Hand-off | A（1 声ずつ受け渡す）の小節数 | 8 |
| Form | Overlap | 受け渡しで、次が入ってから前が弾き続ける長さ | 16分 8 個 |
| Form | Three voices | B（半小節おきに入り、常に 3 声）の小節数 | 6 |

つまみにしていないもの（変えるなら言葉で）: 入りの順（下から）、音型の使い分け（A は楔 4 回のあと槌、B は交互、C は楔）、
音型そのものの形（楔: 基音と音階を交互に登る、槌: 連打に音階の次の音を混ぜる）、アクセントの位置（各入りの頭、駆け上がりの拍頭、最後の音）、
最後の音も点で短く切ること（BBC SO の弦には短いマルカートがなく、点がないと長いマルカートの頭で鳴るため）

余湖さんが保存した組「a」は、つまみを意図ごとに組み直す前のもの。テンポ、奏法、各段の小節数は今のつまみにそのまま効く。ほかは今のつまみに無いので、仮の値に戻る

## 奏法の書き方

- staccato の点だけ: この速さなら奏者はふつう弓を弾ませて弾く（spiccato / sautillé）。BBC SO は「Short Staccato」で鳴る（弦に付いた硬めの短い音）
- 点に spicc. を添える: BBC SO は「Short Spiccato」で鳴る（弾んだ軽い音）
- 弦に付けたまま噛ませたいなら、譜面には「on the string」などと書くのが正確（まだ入れていない）

## 事実

- 音域: 全音が BBC SO の各セクションの音域内。最高音は Vn I の A6
- 測った音量（つまみにする前の版。強弱を途中で 3 回折っていた）: 1 小節目 −37 dB から 19 小節目 −16 dB まで上がる。ピークは −3 dBFS
- 1 音ずつの切れ（16分ごとの音量の谷）: 薄い所で 6〜12 dB、全員の所で 5〜7 dB。残響で谷が浅くなる
