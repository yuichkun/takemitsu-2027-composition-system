# A · 一つずつ遅れる

- 作るもの: [`sketch.ts`](./sketch.ts)

## 仕組みと聴こえ方

10 の撥弦・打鍵の楽器が和音の一音ずつを受け持ち、それぞれ一つだけの間で打ち続ける（パルス）。間は低い音の楽器から順に atom 一つずつ長い（5 連 16 分で 40、41、42…）。回ごとに崩れ方が広がり（0 → 1.8 → 3.6 → 5.4 → 7.2 拍）、5 回目には 8 拍の中に 10 音が順に並ぶ

## 楽器

グロッケンシュピール、ヴィブラフォン、マリンバ、ハープ I、チェレスタ（起点の格子）、ハープ II とピアノ（四分音低く調弦、ずれた格子）、ヴァイオリン・ヴィオラ・チェロのピッツィカート（どちらの格子も）

## つまみ

Chord（和音を積む間）、Anchor、Between（いちばん低い音の間）、Family（atom）、Bars、Tempo（仕組みを決めるものだけ。札はなし）
