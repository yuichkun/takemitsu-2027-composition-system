## 仕組みと聴こえ方

10 の管が和音を打つ。一回の打ちの中で、楽器どうしの鳴り始めの間を時間のセットから組合せで取り出す。セットは {0 0 0 0} から始まり、一つずつ atom 一つ広がって {2 3 3 4} に着く。和音はひびが入り（3、4、7 か所）、ロールになり、受け渡される線になる。打つたびに最初に鳴る楽器が一人ずつ回る。時間の間の 0（原則では未決）を使っている唯一のスケッチ
