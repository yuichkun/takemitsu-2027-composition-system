# 縦の線と横の線 — 8 本のスケッチ

- 状態: 試し中（2026-09-29）。計画は Artifact「縦の線と横の線」
- 余湖さんの注文: 「縦の線が横の線になる（逆でもいい）」を、A（時間）と B（音程）で。つまみで変化を出すのではなく、仕組みそのものが違うスケッチを複数
- 共通のコード: [`common.ts`](./common.ts)（和音を積む、格子と音域で楽器に配る、規則の流れ、4/4 の楽譜）

## 見方（Claude の読み）

二つの音のあいだには、時間の間（鳴り始めの間隔）と音程の間がある。
**縦の線は時間の間が 0 の並び、横の線は音程の間が 0 の並び。** A は時間の間を 0 から開く。B は音程の間を 0 へ閉じる。

## A（時間の間を開く）

| スケッチ | 仕組み | 楽器 |
| --- | --- | --- |
| [`a-late-by-one`](./a-late-by-one/README.md) | どの楽器も一つだけの間で打ち続け、その間が低い音から順に atom 一つずつ長い。差が積もって和音が線に倒れる | 鍵盤打楽器、ハープ 2（1 台は四分音低く）、チェレスタ、ピアノ（四分音低く）、弦のピッツィカート |
| [`a-zero-opens`](./a-zero-opens/README.md) | 一回の打ちの中の時間の間を、0 ばかりのセットから atom 一つずつ開く。誰から鳴るかは一人ずつ回る | 木管 5、金管 5 |
| [`a-families-part`](./a-families-part/README.md) | 全員が拍ごとに鳴るが仲間（2・3・5）がばらばら。一人ずつ間を atom 一つ動かし、出会いが遠のく | 弦のピッツィカート、ハープ 2、マリンバ、ヴィブラフォン |
| [`a-peel-off`](./a-peel-off/README.md) | 和音を繰り返すたびに一人が抜け、和音の後ろに遅れの間ぶん並ぶ | 金管 10 |

## B（音程の間を閉じる）

| スケッチ | 仕組み | 楽器 |
| --- | --- | --- |
| [`b-narrowing`](./b-narrowing/README.md) | 上行のセットの間を、段ごとに全部四分音ひとつずつ狭めて 0 へ | 独奏ヴァイオリン |
| [`b-zeros-spread`](./b-zeros-spread/README.md) | 間の大きさはそのまま、0 を一つずつ足していく。最後は 0 だけ | フルートとクラリネット（交互） |
| [`b-ceiling`](./b-ceiling/README.md) | 天井を越える一歩は天井で切られ、着いた声は 0 だけを引く | 木管 3、弦 4 部 |
| [`b-hand-off`](./b-hand-off/README.md) | 音程は 0 へ閉じるが、次に鳴らす楽器の順は回り続ける（最後は音色の線） | 10 色 |
