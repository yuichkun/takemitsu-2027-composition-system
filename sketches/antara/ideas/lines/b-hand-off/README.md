# B · 同じ音を受け渡す

- 状態: 試し中（2026-09-29）。8 本の並びと見方は [`../README.md`](../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 仕組みと聴こえ方

上行の線を 10 の楽器が一音ずつ受け渡す。音程の間は b-narrowing と同じく段ごとに四分音ずつ閉じるが、次に鳴らす楽器の順（色の遠い順）は回り続ける。ずれた格子の音は、ヴィブラフォンとハープを飛ばす。最後は C5 一音が色だけを替えて受け渡される

## 楽器

フルート、オーボエ、クラリネット、ホルン、弱音器付きトランペット、ヴィブラフォン、ハープ、独奏ヴァイオリン（flautando）、独奏ヴィオラ（sul tasto）、独奏チェロ

## つまみ

Rising set、Start、Notes per stage、Rhythm、Tempo（仕組みを決めるものだけ。札はなし）
