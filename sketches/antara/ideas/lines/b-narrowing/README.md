## 仕組みと聴こえ方

独奏ヴァイオリンが上行のセット {1.5 2.5 3.5} で前の音から続けて歩く。段ごとにセットの間が全部四分音ひとつ狭くなる（.5 付きの段と付かない段が交互に来るので、格子を渡る歩みと留まる歩みも交互になる）。上り方が小さくなり、最後は一つの音（G♯6）の反復。リズムは時間のセットから取り出し続ける
