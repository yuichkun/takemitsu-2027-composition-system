# 冒頭の案 · 響きが触れると、つながる（rings）

- 状態: 案（2026-09-30）。場面と 4 つの案の比べ方は [`../README.md`](../README.md)、共通のコードは [`../common.ts`](../common.ts)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 仕組み

- **チェレスタ**: 一つの音（F♯5）を打ち続ける。間はセット {29 37 48}（16 分音符の数）から、毎回一つずらす規則で取り出し、セット全体は時間とともに縮む（17 秒ごとに半分）
- **響き**: 打った音が鳴っている長さ（Ring）。1.25 秒を、16 分音符の整数個（4 つ、1.15 秒）にして数える。チェレスタの音が消えるまでの長さの見込み（推測。聴いて決める）
- **ハープ 1**: 前の打ちがまだ響いているうちに来た打ち（間が響きより短い）で、同じ音を弾く。二つの音がつながった所に、二つ目の名前が付く
- **ハープ 2**: 二つ前の打ちまでまだ響いているうちに来た打ち（三つの音が同時に鳴っている）で、ハープ 1 と同じ弦を弾く（四分音低く鳴る）。最初の音程
- **保たれた響き**: ハープ 2 の付いた打ちが続くあいだ、第 1 ヴァイオリン（二つに分け、flautando）が二つの音（F♯5 と、その四分音下）を無から保ち、最後の打ちの響きが終わる所で無へ戻る。
  打ちがつながりきると、響きは止まらなくなり、最初の音程が保たれた音になる
- **地鳴り**: 音の高さのない、ロールだけ（バスドラム、タムタム）。音の高さのある音は、チェレスタから生まれるものだけ

## 構成（既定の値）

♩ = 52、22 小節、1:42。チェレスタ 86 打。

| 時刻 | 小節 | 起きること |
| --- | --- | --- |
| 0–9 秒 | 1–2 | ロールだけ |
| 9 秒 | 3 | チェレスタの最初の一打 |
| 9–63 秒 | 3–14 | 間が 8.4 → 1 秒あまり。響きはまだ触れない |
| 64 秒 | 14（A） | ハープ 1 が初めて。72 秒ごろからは、ほとんどの打ちに付く |
| 83 秒 | 19（B） | ハープ 2 が初めて。第 1 ヴァイオリンが二つの音を保ち始める（83–87 秒、87–100 秒） |
| 83–101 秒 | 19–22 | 同音連打に、二台のハープと、保たれた四分音の二音 |

## 聴きどころ

- ハープ 1 が、打ちの間が響きより短くなる所で入ること。前後で、点の並びが、つながった線に変わるか
- 最後の 18 秒の、保たれた四分音の二音（ヴァイオリン）。次のセクション two-grids のガラスの和音に近い響き
- 地鳴りに音の高さがないので、音の高さの世界がチェレスタ一つから広がるように聴こえるか

## 事実

- `check.ts` で警告 0。1:42、22 小節、7 パート、197 音（チェレスタ 86、ハープ 1 が 64、ハープ 2 が 41）
- ハープ 1 の最初の打ち: 63.5 秒（14 小節）。ハープ 2 の最初の打ち: 83.1 秒（19 小節）
- 第 1 ヴァイオリン（78 と 77.5、flautando）: 83.1–86.5 秒、87.4–100.1 秒

## 作曲の段で考える点（いまは狭めない）

- ハープ 1 は、生まれるとすぐに、ほとんどの打ちに付く（つながったら、つながったまま）。「たまに」の時間は 64〜72 秒だけ
- 保つのを第 1 ヴァイオリンの flautando にした。倍音（フラジオレット）にすると、BBC SO の録音が 79 からなので 77.5 が出ない。弦のほかの組（ヴィオラの倍音など）や、音を一つ上にずらすことも
- 共通の点は [`../README.md`](../README.md) の「作曲の段で考える点」
