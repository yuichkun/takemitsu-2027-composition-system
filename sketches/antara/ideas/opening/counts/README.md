# 冒頭の案 · 数えると、頭ができる（counts）

- 状態: 案（2026-09-30）。場面と 4 つの案の比べ方は [`../README.md`](../README.md)、共通のコードは [`../common.ts`](../common.ts)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 仕組み

- **チェレスタ**: 一つの音（F♯5）を打ち続ける。間はセット {29 37 48}（16 分音符の数）から、毎回一つずらす規則で取り出し、セット全体は時間とともに縮む（17 秒ごとに半分）。間はいつも 16 分音符の整数個
- **数え始め**: 打ちと打ちの間が初めて 1.75 秒を切った所から、打ちを数え始める。それより離れた打ちは別々の出来事として聴かれるので、まとまりにできない
- **まとまりと頭**: 数えた打ちを、長さ {3 4 5 7}（打ちの数。毎回一つずらす）のまとまりに分ける。まとまりの最初の打ちが**頭**。
  最初の頭は、最初のまとまりを数え終えた次の打ち
- **ハープ 1**: 頭で、チェレスタと同じ音を弾く
- **ハープ 2**: 頭をまた {2 3 4}（頭の数）で数え、そのまとまりの頭で、ハープ 1 と同じ弦を弾く（四分音低く鳴る）。最初の音程
- **いちばん遅い段**: ハープ 2 の頭を同じ {2 3 4} で数え、そのまとまりの頭で、タムタムを柔らかく一度打つ。地面がいちばん遅い段を受け持つ（そのぶん地鳴りのロールはバスドラムだけ）
- **地鳴り**: 低い 6 声とバスドラムのロール。最後まで残り、最後の 2 拍で消える
- 小節線ではなく、数えることから、何段もの拍子（頭、頭の頭、その頭）が出てくる。まとまりの長さが不ぞろいなので、拍子も不ぞろい

## 構成（既定の値）

♩ = 52、22 小節、1:42。チェレスタ 86 打。

| 時刻 | 小節 | 起きること |
| --- | --- | --- |
| 0–9 秒 | 1–2 | 地鳴りだけ |

| 9–48 秒 | 3–11 | 間が 8.4 → 2 秒 |
| 48.5 秒 | 11 | 間が初めて 1.75 秒を切る。ここから数える |
| 54 秒 | 12（A） | ハープ 1 が初めて（数え始めた打ちから 3 打を数えた、次の打ち） |
| 54–67 秒 | 12–15 | ハープ 1 だけが、3〜7 打おきに |
| 67 秒 | 15（B） | ハープ 2 が初めて |
| 67–101 秒 | 15–22 | 同音連打へ。ハープ 1 は 16 回、ハープ 2 は 4 回（67、80、90、95 秒） |
| 90 秒 | 20 | タムタムの一打（ハープ 2 の 3 回目と同時） |

## 聴きどころ

- 同音連打の上に、ハープの色で、不ぞろいなまとまりが聴こえるか（拍子のように聴こえるか、たまに重なる色に聴こえるか）
- ハープ 2 が、ハープ 1 のうちの少しだけに付くこと。四分音の二音は 4 回しか鳴らない
- 最後のタムタムが、いちばん遅い段として聴こえるか、ただの一打に聴こえるか
