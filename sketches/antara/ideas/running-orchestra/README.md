## 仕組み

弦の音列（元の running と同じ）:

- 弦 4 部（チェロ → ヴィオラ → 第 2 → 第 1 ヴァイオリン）が、同じ規則をカノンで走る。各部の一本の音列を、その部の4群で受け渡す
- 時間は二層の足し算: 刻み（いまの系の単位ごとに一打。3 連系 → 16 分系 → 5 連系と替わる）と、組の頭（アクセント）。
  組の長さ（刻みの数）はセット {2 4 4 4} から組合せで取り出す。聴こえる拍子はここから生じる
- 一つの組が一つの音程の組を弾く: 頭は立ち位置の音、残りの刻みにセット A {−1.5 2 5} から取り出した間を足していく（決まった順に、一つずつずらして）
- 立ち位置: one（全部が D3 のオクターブ違い）→ split（A の最初の組の音に分かれる）→ walk on（前の音から歩き続ける）
- 変化は下の部から 3 拍ずつ遅れて上へ伝わる。伝わっているあいだは、部ごとに違う系で走り、出会うのは拍だけ
- 最後は全部の部が 25 小節目の頭で、split の和音に着く

### 弦のフレーズの受け渡し

- 元の音高・打点・音価・アクセントをすべて保ち、誰が弾くかだけを分ける。格子による分担はしない。各群は両方の格子の音を弾く。調弦は変えない
- 重なり込みで一群は最大10音。1〜10音目、8〜17音目、15〜24音目…と7音ごとに4群が順に受け持つ。一つのフレーズの中は連続して弾き、休みはフレーズとフレーズのあいだにまとめる
- 前の群は次のフレーズの最初の3音まで一緒に弾く。同じ音を同じ時刻に重ねるだけで、音を伸ばして別の音と和音にしない
- 既定値では10音の句を3連系で約1.67秒、16分系で1.25秒、5連系で1秒弾き、次の出番まで約1.8〜3秒休む。末尾の断片は短くなる。手渡しは元の組の頭に限定せず、アクセントは元の位置を保つ。各群の途中に休符は入らない
- 人数は第1ヴァイオリン4・4・4・4、第2ヴァイオリン4・4・3・3、ヴィオラ3・3・3・3、チェロ3・3・2・2。25小節目の最後の一打は全員に戻る
- Strings の Sharing で全員版と切り替える。Chunk は重なりも含めた一群の最大音数、Overlap は手渡しで一緒に弾く音数（Chunk の半分以下）
- 休みは準備時間を作るが、弾いている間の速さ（最速毎秒10音）や運指の難しさは変わらない。分奏で一音あたりの人数が減るため、厚さと他楽器とのバランスは試聴で確認する

## 事実

- 楽譜が書き出せて、警告 0。0:50、25 小節、51 パート、3328音（弦の全員版2743音に、受け渡しで重ねる585音を加えたもの）
- 曲では series のあと、106小節目から。曲全体は10:28、189小節、100パート、警告0
- 弦の元の音がすべて残ること、各群のフレーズ内に抜けがないこと、同時に重なるのは最大2群であることを確認。ハープの高速パッセージ336音を外した際には、最後の一打と全ての他パートの内容が変更前と一致することを確認
- Chunk 8・10・24音 × Overlap 0・3・4音でも、音の保存・連続句の最大音数・次の群までの進み幅・人数制約を確認。不正な重複数はエラーにする
- 区切りの候補（`seams`）: 弦は組の頭（アクセントの付いた刻み）と分奏の句の入り、ほかは音の頭

## 作曲の段で考える点（いまは狭めない）

- 最後の全員の和音の配り方（いまは和音の音を楽器に順に配っただけ）
