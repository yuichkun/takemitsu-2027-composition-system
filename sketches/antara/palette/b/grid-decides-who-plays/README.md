## 何をしたか

言葉は、下の「仕組みと聴こえ方」の「言葉」でまとめて定義する。ここでは短く書く。

A の仕組みはこうだった。一本の間の流れ（規則がセットから取り出す、音と音のあいだ〈間〉の列）を三つの声で歩く。全部の声は流れの間を全部取り、付かない声は .5 の付かない間（半音の整数個）だけ、付く声は .5 の付く間（四分音の端数がある間）だけを取る。取らない声は、その音を保つ。

四分音の格子は、四分音ずれた二つの半音の格子でできている。起点（三声が始める音）が乗る方を「起点の格子」、もう一方を「ずれた格子」と呼ぶ。.5 の付く間は音をずれた格子へ移し、付かない間は同じ格子に置く。

ここでは、この三つの声の性質（どちらの格子に立つか）を、**どの楽器が弾けるか**の理由にした。

- 付かない声は、起点の格子を一度も出ない。だから、ふつうに調律された固定の音の楽器（ハープ I とヴィブラフォン）がいつも弾ける、ただ一つの声になる
- 付く声は、動くたびに格子を替える。だから、その声が動いたときに打つ楽器は、ふつうの調律の楽器と、四分音低く調律した楽器（ハープ II とピアノ）とを、一歩ごとに行き来する
- 全部の声は両方の格子を使うので、固定の音の楽器では弾けない。木管と Vn I が持つ

そして、流れを作るセットを、段ごとに変えていく。**六つの間の全部に .5 が付いたセットから始めて、一段に一つずつ .5 を外して 0 個まで行き、また一つずつ付けて 6 個に戻る。**
始めは付かない声（チェロ）が起点に留まり、付く声（ヴィオラ）が全部の声とユニゾンで動く。真ん中の .5 が 0 個の所では、ヴィオラが留まり、チェロが全部の声と平行に動く。終わりはまたチェロが留まり、ヴィオラが全部の声と平行に動く。

前提の二つ目（名前は、立つ位置で変わる）に沿った B。同じ一本の線の同じ一歩が、格子の上の立ち位置によって、ある声の一歩にも別の声の一歩にもなり、どの楽器がその音を打つかまで決まる。打つ楽器の調律は、その音が立つ格子の名前になっている。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだの幅。半音単位で書き、四分音は .5。上へは +、下へは −。四分音は間の atom（それ以上は割らない単位）
- **二つの格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。起点が乗る方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ。
  .5 の付く間（四分音の奇数個）は音をずれた格子へ移し、.5 の付かない間（半音の整数個）は同じ格子に置く。
  ここでは起点が 63 なので、起点の格子は半音の整数の音（63、64 …）、ずれた格子は .5 の付く音（63.5 …）
- **固定の音の楽器**: 奏者が音の高さを変えられない楽器（ハープ、ピアノ、ヴィブラフォン）。調律した一つの格子の音しか出ない。
  ふつうの調律なら起点の格子だけ、**四分音低く調律**すれば（すべての弦・鍵を四分音下げる）ずれた格子だけを出す。弦・木管・金管は両方を出せる
- **セット**: どの間を、いくつずつ持つか。ここでは 6 つの間を、書いた順で持つ
- **規則**: セットから、次にどの間を取り出すか。ここでは書いた順に取り出し、6 つを一回ずつ取り終える（**一巡**）ごとに、次は一つ後ろから読み始める。
  この規則が取り出す間の列を「一本の流れ」と呼ぶ
- **段**: セットが同じでいるひと続き。一段で規則は一巡する（6 歩）。段が替わっても、規則は読み始めの位置をそのまま引き継ぐ
- **鳴り始め**: どれかの声が新しい音を弾く時点。起点の一つと、流れの一歩ごとに一つ
- **部分和（起点からの距離）**: 声が今までに取った間の合計
- **縦の間**: 同時に鳴る二つの声のあいだの間
- **平行**: 二つの声が、同じ間で一緒に動き、縦の間が変わらないこと。縦の間が 0 の平行がユニゾン
- **打ち**: 付かない声か付く声が動いた鳴り始めで、その新しい音を、その音の格子の固定の音の楽器が一度だけ打つこと。次の打ちまで響かせる
- **atom**: 時間を数えるいちばん小さな単位。ここでは 3 の仲間の atom（3 連 8 分の長さ。3 つ足すと 1 拍になる）

### 三つの声（A のまま）

三声とも起点 63 から同時に始め、取った間を自分の直前の音に足していく（オクターブで折り返さない）。

- **全部の声**: 流れの間を全部取る。一本の流れをそのまま歩く線なので、以下では「線」とも呼ぶ
- **付かない声**: .5 の付かない間だけを取る。付く間のあいだは、音を保つ
- **付く声**: .5 の付く間だけを取る。付かない間のあいだは、音を保つ

どの一歩でも、ちょうど二声が同じ間で動き（全部の声と、付かない声か付く声のどちらか）、一声が保つ。どちらが動くかは、その間に .5 が付くかどうかだけで決まる。

全部の声の距離は、付かない声の距離と付く声の距離の和になる。そこから、次のことが結果として起こる。どれも置いたものではない。

- 付かない声は起点の格子を出ない
- 全部の声と付く声の縦の間は、付かない声の距離に等しい（半音の整数個なので、二声はいつも同じ格子にいる）
- 全部の声と付かない声の縦の間は、付く声の距離に等しい

### ここで足したもの: 格子が配器を決める

- **全部の声**: 両方の格子が要る。バス・フルート、コーラングレ、クラリネット 2、Vn I（16 人）のユニゾン。すべての鳴り始めで新しい音を弾き、次の鳴り始めまで伸ばす
- **付かない声**: チェロ（10 人）。動くときだけ新しい音を弾き、次に動くまで伸ばす
- **付く声**: ヴィオラ（12 人）。付かない声と同じく、動くときだけ弾いて伸ばす
- **打ち**: 付かない声か付く声が動いた鳴り始めで、その新しい音（同じ高さ）を、その音の格子の楽器が打つ
  - 起点の格子の音 → ハープ I とヴィブラフォン（モーターなし）
  - ずれた格子の音 → 四分音低く調律したハープ II とピアノ（楽譜は実音で書いてある）
  - 全部の声は、どちらの格子の楽器にも弾けないので、打ちを持たない

だから、チェロが動いた歩ではいつもハープ I とヴィブラフォンが打つ。ヴィオラが動いた歩では、ヴィオラが動くたびに格子を替えるので、打つ楽器が四分音低いハープ II とピアノ、ハープ I とヴィブラフォンのあいだで、一回ごとに入れ替わる。
どの楽器が打つかを、作曲者は選んでいない。音の格子から決まる。

始めの鳴り始め（0:00）では、チェロとヴィオラが起点 63 で入るので、ハープ I とヴィブラフォンが 63 を打つ。最初の一歩（0:00.6）は +1.5 で、線とヴィオラが 64.5（ずれた格子）へ動き、ハープ II とピアノが打つ。

### 物語: セットの .5 の間の個数

### 仮の値をなぜ選んだか

- **最初のセットの大きさ 1.5〜6.5**: 0 でない半音の整数のうち、小さい方から六つ（1〜6）を、それぞれ四分音一つ広げたもの。大きさが全部違うので、段で動かす間の順（狭い方から）がいつも一つに決まる
- **全部の間に .5 を付けて始める**: 四分音は最初から格子に入れる。最初の一歩（0:00.6）で線とヴィオラがずれた格子へ移り、四分音低いハープ II とピアノが打つ。
  物語は、一方の端（.5 が 6 個）から始まり、もう一方の端（0 個）を真ん中で通って、また 6 個へ戻る。.5 の数は一方向に増えも減りもせず、0 から 6 までのどの数も通る（0 は一度、ほかは二度）。
  ヴィオラが動くたびに格子を替えるので、真ん中の段（.5 が 0 個）に着くまでのヴィオラの動く数（6 + 5 + 4 + 3 + 2 + 1 = 21、奇数）が、そこでヴィオラの立つ格子を決める。21 は奇数なので、ヴィオラはずれた格子で止まり、真ん中の段でも二つの格子が声の中で鳴り続ける
- **向き**: 奇数の大きさ（1.5、3.5、5.5）は上、偶数の大きさ（2.5、4.5、6.5）は下。前の版と同じ六つの間（前の版の +1, −2, +3, −4, +5, −6 を、それぞれ四分音広げたもの）。一巡の和は −3（段によって −3 と −3.5 を行き来する）
- **書いた順 +1.5, −4.5, +5.5, −2.5, +3.5, −6.5**: 上と下を交互に置いた（一巡の中では、線が一歩ごとに折り返す。前の版と同じ。巡の継ぎ目では読み始めが一つずれるので、同じ向きが二歩続く。事実を参照）。向きが大きさの奇数・偶数で決まっているので、交互に置くと、奇数と偶数の大きさが交互に並ぶ。
  その並べ方のうち、大きさが一つ違いの間どうし（4.5 と 5.5、2.5 と 3.5 など）が隣り合う所がいちばん少ないもの（二か所。一巡の継ぎ目も含めて数え、これより少なくはできない）を取った。条件を満たす並びは、この一つとその逆行だけ。
  前の版は大きさの順（一つ違いの隣どうしが五か所）で、どこから読み始めても、一巡の継ぎ目のほかは一歩ごとに大きさが一つずつ増えて、上下に開いていく形（くさび）になっていた。いまは、大きさが続けて一方向に増えるのは三つ組が二つ（1.5, 4.5, 5.5 と 2.5, 3.5, 6.5）だけで、増え方も揃っていない
  - ただし、残った一つ違いの隣どうし（−4.5 → +5.5 と −2.5 → +3.5）は、どちらも二歩の和が +1 で、一巡の中で続けて並ぶ。だから、上がる歩で着く音（線の一つおきの音）が、半音ずつ二回上がる（1 段なら 64.5、65.5、66.5。そのあいだの下がる歩で着く音は 60 と 63 を行き来する）。
    上と下の交互と、奇数を上・偶数を下にする約束のもとで一つ違いの隣どうしを二か所にすると、この二つの和はどちらも +1 になる（逆行でも同じで、そのときは下がる歩で着く音の方が上がる）。
    曲の中では、1 段と 13 段の頭で 3 音、6 段の途中から 7 段の終わり近くまで（0:32.7〜0:41.8）は巡の継ぎ目（同じ向きが二歩続く所）をまたいで 6 音、半音ずつ上がる。くさびの片側が残った形で、値を選んだあとに鳴る音の並びを数えて分かった（事実を参照）
  - 逆行（+1.5, −6.5, +3.5, −2.5, +5.5, −4.5）ではなくこちらにしたのは、三声がそろって起点の格子だけに立つ時間（ヴィオラが起点の格子にいて、声の中にずれた格子の音がない時間）が、最後の一歩までで最長 2.4 秒と、逆行の 5.5 秒より短いから（どちらも計算で確かめた）
  - 書き始めは、いちばん狭い +1.5 にした
- **段の進め方（狭い方から一つずつ、大きさの一周を二回）**: 一段で .5 の有無がちょうど一つ替わる。どの間も、続けて 6 段だけ .5 が外れる（1 は 2〜7 段、2 は 3〜8 段 … 6 は 7〜12 段）。一巡の和は 0.5 しか動かない。
  段で変わるのは「どの間が格子を替えるか」だけで、線の形はほとんど変わらない。二周目で .5 を戻すときに 0 から離す向きにしたので、外すときの四分音をそのまま戻すことになり、最後の段は最初の段と同じセットになる
- **一段に一巡（6 歩）**: どの間も一段に一度ずつ取られるので、チェロとヴィオラの動く数が段の .5 の数とちょうど合う（0/6、1/5 … 6/0 … 0/6）。13 段で 78 歩。
  もう一つの理由は、ヴィオラの動く数の偶奇。一巡なら真ん中の段の前に 21 回（奇数）で、ヴィオラはずれた格子に止まる。二巡にすると 42 回（偶数）で、真ん中の段の 12 歩のあいだ三声とも起点の格子にそろう（計算で確かめた）
- **起点 63**: 帯 55〜72 のほぼまん中（下へ 8、上へ 9）。半音の整数の音なので、付かない声（チェロ）の格子はふつうの調律の楽器の格子になる
- **帯 55〜72**: 下の端 55 は Vn I のいちばん低い音で、全部の声はこれより下へ行けない。幅 17 は、いちばん広い間 6.5 の二倍（13）より広い。一つの声だけなら、外へ出る間は逆向きに取れば必ず帯に入る

## つまみ

- **First set**: 最初の段のセット（半音、− は下向き、.5 は四分音）。書いた順がそのまま規則の順になる。段の数は、間の数の二倍と最初の段（仮の値では 13 段）。最後の段は最初の段と同じセットになる
- **Rounds per stage**: 一段で規則がセットを何巡するか
- **Standpoint**: 起点。三声がここから一緒に始める。付かない声（チェロ）はこの音の格子を出ない
- **Band**: 声が歩く音域。外へ出る間は逆向きで取る（仕組みの外の足し物）
- **Time set**: 時間のセット（atom の数）。音程の間一つに一つずつ
- **Family**: 時間の atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- **Tempo**: テンポ

First set は、目盛りのつまみ（間のセットのつまみ）ではなく、文字で書くつまみにした。目盛りのつまみは間を大きさの順に並べ替えてしまい、書いた順を保てないため。
