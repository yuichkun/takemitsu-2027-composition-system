## 見直しで変えたこと

見直しで出た疑い: 前の版は、A を三つ時間をずらして重ね、起点を保続しただけだった。
A はすでに大きさ 2 の組で一巡している。前の版で足した「育つ」は、大きさ 1 の短い一巡を前に付けただけで、組の大きさを半分で止めたので一段しかなかった。
A の二巡目（逆の順で上へ出る弧）は落としたので、歩く人はいつも下へ出るだけだった。

変えたこと（「組を一巡ごとに育てる」という方法はそのまま）:

- 組の大きさを、半分で止めずにセット全体まで育てる。半分を越えた大きさは、A の二巡目と同じ逆の順で取り出す。すると歩く人は、それまでと同じ遠さを起点の上側に出る。
  最後の大きさ（セット全体、組は一つ）では、二人が同じ線を弾く
- だから一つの対の中で、出来事の種類が変わっていく。組が一巡ごとに一つ長くなって頭が間遠になり、歩く人は下、上、戻る人と一つ、と移る
- 三つの対の間の数を 5、4、3 にした（前は 5、4、5）。一巡の数と長さが対ごとに違い、最後に入るチェロは、ほかの二対の途中で自分の全部の段を通り抜ける
- 仮の値のうち、フルートのセット・起点・リズム、チェロのセット・起点・リズム、テンポ（48 → 60）を変えた。理由は「仮の値の理由」

残っている疑い（作り直したあとで、書かれた楽譜を数えて分かったこと）:

- 一つの対の中では、出来事の種類が変わるようになった。けれど、間が 5 つと 4 つでは、歩く人のいる側の並びが同じ（下、下、上、上、同じ線）で、フルートとクラリネットはこの並びをほぼ揃って進む。
  二対が両方鳴っている 83.8 秒のうち 73.3 秒（87%）は、二対が同じ側の一巡にいる。側が分かれるのは 0:32.8〜0:42.3（フルートが上、クラリネットが下）と 1:27〜1:28 だけで、一巡の替わり目も 1:06.0 と 1:06.3、1:27 と 1:28 でほぼ重なる。
  ほかの対と違う側にいるのは、19 秒のチェロ（0:23.75〜0:32.8 に上、ほかの二対は下）だけ。対どうしで見ると、同じ育ち方が二つ、ほぼ揃って重なっている
- 0:52〜1:40 は、独奏の平均の高さ、人数、頭の頻度、遠さが、おおむねそろって下がり、同じ線に収まって消える。一方向にそろう終わり方に聴こえないか

## 何をしたか

前提の二点目（その名前は、立つ位置で変わる）を、中編成で試す。

使った A「戻る人と歩く人」では、一本の間の列を二人が同じ時に弾く。一人（戻る人）は組ごとに起点へ戻り、もう一人（歩く人）は戻らずに足し続ける。
二人の違いは立ち位置だけで、二人のあいだの縦の間が、歩く人の立ち位置のずれそのものになる。

ここでは、その二人組（対）を三つ、フルート、クラリネット、独奏チェロで走らせる。足したのは三つ。

1. **組の大きさを一巡ごとに一つ大きくし、セット全体まで育てる。** 大きさが半分より小さいうちは辞書順（A の一巡目の順）で、歩く人は下へ出る。
   半分を越えると逆の順（A の二巡目の順）で、歩く人は同じ遠さを上へ出る。最後はセット全体を一つの組にして、二人が同じ線を弾く
2. **対を一つずつ遅らせて入れる。** 前の対が最初の一巡を終えて起点に戻ったその瞬間に、次の対が入る
3. **弦が、入った対の起点だけを保つ。** 戻る人が組ごとに帰ってくる音で、糸が結ばれている所。弦はこのほかの音を持たない

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだ。半音単位で数え、四分音は .5 と書く。− は下へ
- **セット**: どの間を、いくつずつ持つか。**間の数**は、セットが持つ間の個数
- **起点（立ち位置）**: 間を足し始める音
- **組と組の大きさ**: セットから間をいくつか取り出したまとまりを組と呼ぶ。一つの組が持つ間の数を、組の大きさと呼ぶ
- **組の和**: 組の間を全部足したもの。一つの組を弾き終えると、歩く人の立ち位置はこれだけ動く
- **残りの組**: セットから、ある組の間を除いたもの。大きさ 2 の組の残りは、間が 5 つのセットなら大きさ 3 の組
- **規則（組合せ）**: 大きさの決まった組を、セットから取り出せるだけ全部取り出して並べる。
  **辞書順**は、セットを小さい順に並べ、一つ目の間が小さい組から。一つ目が同じなら二つ目が小さい組から。組の中も小さい順。**逆の順**は、辞書順をうしろから並べたもの（A の二巡目の順）
- **一巡**: ある大きさの組を全部、決まった順に一度ずつ弾き終えるまで
- **頭**: 一つの組は、はじめの鳴り始め（頭）と、組の間を一つずつ足した鳴り始めでできている。大きさ 1 の組は鳴り始めが二つ、大きさ 2 の組は三つ、大きさ 5 の組は六つ
- **最後の組**: セット全体を一つにした組。その大きさの一巡は、この組一つだけ
- **対、戻る人、歩く人**: 同じ楽器の二人を対と呼ぶ。1 番（戻る人）は頭で必ず起点を弾き、組の間を順に足す。2 番（歩く人）は頭で直前の音をもう一度弾き（動く間は 0）、そこから同じ間を足す。二人はまったく同じ時に鳴る
- **縦の間**: 同じ瞬間に鳴っている、対の二人の音のあいだの間（歩く人 − 戻る人）。組の中では二人が同じ間で動くので変わらず、頭でだけ替わる。
  その値は、それまでの組の和を全部足したもの。歩く人の立ち位置が起点からどれだけ離れたか、そのもの
- **遠さ**: 一巡のあいだの縦の間の大きさ（− を外した値）のいちばん大きなもの。歩く人がその一巡でどこまで出たか
- **二つの格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。ふつうの半音の並び（60、61、62…）を**ふつうの格子**と呼ぶ。縦の間に .5 が付くと、対の二人は別々の格子に立つ
- **atom と仲間**: 時間を数えるいちばん小さな一粒。素数の仲間ごとに一つある。2 の仲間は 16 分、3 の仲間は 3 連 8 分、5 の仲間は 5 連 16 分。鳴り始めの間は、その何個分かで数える
- **保続音**: 弦が保つ音。それまでに入った対の起点だけでできている

### 対の中で起きること（A と同じ）

- 頭では、戻る人だけが起点へ跳び、歩く人はその場に留まる。だから縦の間は頭でだけ替わる
- セットの間の和が 0 なら、一巡の終わりで歩く人は起点に戻る。一巡ではどの間も同じ回数ずつ使われるので、歩く人が一巡で動く量はセットの和のその回数倍になり、和が 0 なら 0 になる。組の大きさがいくつでも同じ
- 戻った所では、二人が同じ音（起点）を弾く。次の一巡の最初の組のあいだ、二人は同じ音で動く

### 組の大きさが育つ

- 大きさ 1 から始め、一巡ごとに一つ大きくし、セット全体（大きさ = 間の数）で終わる
- ある大きさの組と、その残りの組は、一つずつ対応する。セットの和が 0 なので、残りの和は元の組の和の正負を逆にしたもの
- 辞書順に並べると、残りの組は、元の組のちょうど逆の順に並ぶ。だから大きい方の一巡を辞書順で弾くと、歩く人は小さい方の一巡と同じ縦の間を、同じ側で逆にたどるだけになる（前の版が半分で止めた理由）
- ここでは、半分を越えた大きさの一巡を逆の順で弾く。すると何番目の組も、小さい方の一巡の同じ番目の組の残りになり、縦の間は小さい方と同じ順で、正負だけが逆になる。
  歩く人は、同じ遠さを起点の上側に出る。この順は A の二巡目の順そのもの
- 大きさがちょうど半分（間の数が偶数のとき）の組は、残りも同じ大きさで、同じ一巡の中にある。だからこの大きさは、辞書順と逆の順の両方で一巡ずつ弾く。これは A の形そのもの（一巡目で下、二巡目で上）
- 最後の大きさはセット全体で、組は一つ。和が 0 なので、縦の間は 0 のまま。二人は同じ線を弾き、起点から出て起点に戻る。これが対の最後の音になる
- 辞書順では下向きの間を含む組が先に来るので、半分までの一巡では縦の間がすべて 0 以下、半分を越えた一巡ではすべて 0 以上になる（下の「事実」）
- 一つの対の中で変わっていくもの:
  - 組の長さ: 大きさが一つ増えるたびに、組の鳴り始めが一つ増える。頭（縦の間が替わる所）が一巡ごとに間遠になる
  - 歩く人のいる側: 戻る人の下 → 上 → 戻る人と同じ線
  - 保続音（起点）との関係: はじめは歩く人の上にある音、次は下にある音、最後は同じ音
- 間の数ごとの一巡の並び（括弧の中は歩く人のいる側）:
  - 5 つ（フルート）: 大きさ 1（下）、2（下）、3（上）、4（上）、5（同じ線）
  - 4 つ（クラリネット）: 大きさ 1（下）、2（下）、2（上）、3（上）、4（同じ線）
  - 3 つ（チェロ）: 大きさ 1（下）、2（上）、3（同じ線）

| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| フルート 2 | −4、−3、+0.5、+1、+5.5 | 79.5 | 5 | 3、4、4、4、4、5、5 | 0:00 | 5 | 111 | 0:00〜1:31.8 |
| クラリネット 2 | −5.5、−1、+2.5、+4 | 65 | 3 | 3、3、4、5、5 | 0:08（フルートが最初に戻った所） | 5 | 65 | 0:08〜1:40 |

- **リズム**: 鳴り始めの間を、セットの小さい順に繰り返し取る（セットはどう書いても小さい順に並ぶ）。組や一巡の区切りとは関係なく読み続ける（A と同じ）
- **入り**: 前の対の最初の一巡が終わる時刻（前の対が起点に戻った頭）に入る。三つの仲間の格子が重なるのは拍の上なので、その時刻が拍の上にないときは次の拍で入る。
  仮の値では、戻る時刻がちょうど拍の上に来る（下の「仮の値の理由」）
- **終わり**: 各対の最後の音は、最後の組の終わりの音で、二人とも起点。弦の保続音と同じ音。
  フルートとチェロは、その音を自分のリズムの次の間の長さだけ伸ばしながら消え、あとは休む。いちばん最後に着く対（クラリネット）は、それを曲の終わりまで伸ばし、保続音といっしょに消える
- **保続音**: 対が入った瞬間に、その対の起点が弦に加わり、終わりまで続く。加わるのは起点だけで、保続音には自分のセットも規則もない。
  チェロの対が消えたあとも、44 は弦に残る。その対の糸が結ばれていた所として

### 仮の値の理由

- **三つのセットとも和が 0**: 値の演出ではなく、この仕組みで歩く人が戻ってくるための性質そのもの。戻ることが、終わり方を後から選んだ結果ではなく、セットの性質になる（A と同じ）
- **間の数 5、4、3**: 間の数が一巡の並びと長さを決める。5 つなら一巡が 5 つで鳴り始め 111、4 つなら半分の大きさを両方の順で弾くので一巡が 5 つで 65、3 つなら一巡が 3 つで 19。
  三つの対に違う数を配ったので、一巡の数と長さは対ごとに違う。いちばん短い 3 を最後に入るチェロに置いたので、チェロは、クラリネットが下の一巡にいて、フルートが下から上へ移るあいだに、下、上、同じ線を通り抜ける。
  ただし 5 つと 4 つでは歩く人のいる側の並びが同じ（下、下、上、上、同じ線）で、仮の値ではフルートとクラリネットがこの並びをほぼ揃って進む（上の「残っている疑い」）
- **クラリネットのセットは A と同じ**（−5.5、−1、+2.5、+4）: 間が 4 つなので、大きさ 2（半分）の一巡を辞書順と逆の順で一つずつ弾く。この二巡は A の二巡と同じ組、同じ縦の間（0、−6.5、−9.5、−11、−9.5、−6.5 と、その正負を逆にしたもの）。
  起点が 2 高く（A は 63）、リズムが違う（A は 3、4、4、5）。クラリネットの真ん中が A そのものなので、どの A を使ったかを耳でたどれる
- **フルートのセット −4、−3、+0.5、+1、+5.5**: 歩く人が上にも出るようになったので、下と上の両方の端が楽器の音域に入らないといけない（前のセットでは歩く人の届く幅が 46 になり、フルートの音域 60〜96 の 36 を越える）。
  次の条件をすべて満たすセットの中で、歩く人の届く幅がフルートの音域いっぱい（36）になるのは、このセットだけ。遠さもいちばん大きい（16.5）
  - 和が 0。下向き 2 つと上向き 3 つ（前の版と同じ配置）
  - .5 の付く間が偶数個（和が 0 になるのに要る。ここでは +0.5 と +5.5 の 2 個）
  - 五つの間の大きさがどれも違う
  - クラリネットのセットと同じ間を持たない（大きさだけなら、+1 と +5.5 はクラリネットの −1、−5.5 と同じで向きが逆）
  - 2・5・7 を仮の値に置かない
- **チェロのセット −4.5、−3.5、+8**: 前のセットの形（小さな下向きがいくつかと、大きな上向き一つ）を、間 3 つで保った。
  - 前の上向き +7.5 をそのまま残したかったが、7.5 を二つの下向きに分けるどの分け方も、ほかのセットと同じ間を持つか、2・5・7 を含むか、三つの間が 1.5 の倍数にそろう（−6、−1.5、+7.5）。
    1.5 の倍数にそろうと、線は 1.5 ごとの格子の上だけを歩き、ふつうの格子の上では減七の四音にしか乗らない（名前の側に落ちる）ので、使わなかった
  - そこで上向きを 7.5 にいちばん近い 8 にした。前の版に近いことは構造の理由ではないので、8 は仮。8 を分ける分け方のうち、条件を満たすのは −4.5 と −3.5、−6.5 と −1.5、−7.5 と −0.5 の三つ
  - 上向きが 8 だと、どの分け方でも、ふつうの格子の上に来る音は起点と起点 ± 8（36、44、52）だけになる。1.5 の倍数の案を退けたのと同じ種類の偏り（ふつうの格子の上の音が、等しい間隔の少数の音にそろう）が、三つの音の形で残っている。
    違いは、ほかの四つの音（39.5、40.5、47.5、48.5）が、ふつうの格子から四分音ずれた格子にあること
  - その中で、二つの下向きの大きさがいちばん近いものを選んだ。大きさ 1 の一巡の頭で縦の間が 0 → −4.5 → −8 と替わり、どの頭でも 3.5 以上替わる（−7.5 と −0.5 だと、二つ目の頭で 0.5 しか替わらない）
- **三つのセットの違い**: 和が 0 であることだけを共有させ、ほかは互いに変えた
  - 向きの配置: フルートが下 2・上 3（上向きは 0.5 と 1 の小さな二つと、5.5 の大きな一つ）、クラリネットが下 2・上 2、チェロが下 2・上 1
  - .5 の付く間は三つとも 2 個
  - 三つのセットに共通の間は一つもない
  - どのセットも、間を四分音の数で数えると、公約数が 1（四分音より大きな単位ではそろわない）
- **起点**: 各対の歩く人のいちばん低い所が、その楽器のいちばん低い音にちょうど着くように置いた（A と同じ理由）。
  楽器のいちばん低い音は 60、50、36（フルートは C の足部管の最低音。三つとも BBC SO に音がある範囲の下端と同じ）。歩く人のいちばん低い所は、起点から −19.5、−15、−8。だから起点は 79.5、65、44。
  結果として、フルートの歩く人は 60〜96 でフルートの音域の端から端まで届く。戻る人の音域は三つの対で重ならない（チェロ 36〜52、クラリネット 58.5〜71.5、フルート 72.5〜86.5）。起点どうしの間は 21 と 14.5
- **仲間 5、3、2**: 三つの対に違う仲間を一つずつ割り当てた（クラリネットは A と同じ 3）。どの対も一つの仲間のまま替えない
- **リズムの値の数**: 組の頭がリズムの中のいつも同じ場所に来ないように、値の数を、組が占める間の数（大きさ + 1）のどれとも公約数を持たない数にした（A で値を 4 つにしたのと同じ理由）。
  組が二つ以上ある大きさだけを数える（最後の組は一つなので数えない）
  - フルート: 大きさ 1〜4 の組は間を 2〜5 個占める。そのどれとも公約数を持たない、1 より大きいいちばん小さな数は 7
  - クラリネット: 大きさ 1〜3 で 2〜4 個。5
  - チェロ: 大きさ 1、2 で 2、3 個。5
- **リズムの値**:
  - 一周の和が拍の整数倍にならないようにした。そうすると句の頭が拍や小節の頭にそろわない。一周はフルート 29 atom = 5.8 拍、クラリネット 20 atom = 6⅔ 拍、チェロ 21 atom = 5¼ 拍

## つまみ

「Flutes (enter first)」「Clarinets (enter second)」「Cellos (enter last)」の三つのグループに、同じ三つのつまみがある。

- **Set**: その対の間のセット（半音、.5 は四分音、− は下へ）。和が 0 なら、一巡ごとに歩く人が戻る。組の大きさは 1 からセット全体まで育つ。
  間の数を増やすと鳴り始めが急に増える（間が 3、4、5、6 つで 19、65、111、335）
- **Anchor**: 起点。二人が始める音、戻る人が頭ごとに戻る音、最後の音、弦が保つ音。二人のどちらかが楽器の音域を出るとエラーになる
- **Rhythm**: 鳴り始めの間（その対の仲間の atom の数）。小さい順に繰り返し、組や一巡の区切りとは関係なく読み続ける

ほかに **Tempo**。仲間はつまみにしていない（フルート 5、クラリネット 3、チェロ 2 に固定）。
