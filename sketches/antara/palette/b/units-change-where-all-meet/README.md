# B · 全員が起点に立つ所でだけ、単位が替わる

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)
- 使っている A: [`pitch-one-count-three-units`](../../a/pitch-one-count-three-units/README.md)（一つの数え、三つの単位）。仕組みはこのフォルダの `sketch.ts` に写し、変えずに使っている

## 何をしたか

A の「一つの数え、三つの単位」は、間を四分音の何個分かという「数え」として持ち、何本かの線が同じ数えの列を、それぞれの「単位」で読む方法。単位は、数え 1 を四分音いくつ分として読むかを決める整数で、− の単位は形を上下に裏返し、0 の単位は起点から動かない。数えは関係の側にあり、音の高さは、単位が決まって初めて付く名前になる。

これを四群（群は、一本の線を受け持つ楽器の組）の管弦楽で使い、一つの決まりを足した。**単位を替えてよいのは、全員が起点（全員が最初に鳴らす音。ここでは MIDI 番号の 60）に立っている所だけ。**
全員が起点に立つ所では、どの単位で読んでも名前（音の高さ）が同じになり、線どうしの区別がなくなる。区別がなくなる所でだけ、区別の付け方（単位）を替える。
時間の軸で、線が鳴り始めの間隔を数える単位（仲間。16 分、3 連 8 分、5 連 16 分の三つ）を替えてよいのは、仲間どうしの目盛りが重なる所（拍、小節線）だけ、という決まりと同じ形。

前提の一点目（関係が先にあり、項は後から付く名前である）と二点目（その名前は、立つ位置で変わる）を一つの場面にした。数えが関係、単位はその線が数えをどれだけの大きさで、どちら向きに読むか、高さは単位が後から付ける名前。

単位は書いた順に一つずつ入り、また一つずつ 0 へ戻る。そのため、場面の中で出来事の種類が替わっていく。
起点の保続（動かない群が 60 を伸ばし続けること）の上の細い線 → 反進行（逆向きに動く二本）の対 → 三本、四本の比例した線（同じ形を、単位の比の大きさと向きで描く線。保続が消える）→ 線が一本ずつ保続へ戻る → 大きな一本 → 起点だけ。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間と数え**: 間は二つの音のあいだ。大きさは四分音（間の atom。それ以上は割らない一粒）の何個分かで数える。この「何個分か」を数えと呼ぶ。上へは +、下へは −
- **セットと規則**: セットは、どの数えを持つか。規則は、セットから次にどの数えを取り出すか。ここでは書いた順に読み、セットを読み終えるたびに、次は一つ後ろから読み始める（一巡ごとに一つずらす）
- **巡**: セットの 4 つの数えを一回ずつ読み終えるまでの一回り
- **起点**: 全員が始める音。60
- **部分和**: 始めからその時点までに読んだ数えの合計
- **単位**: 数えを高さの差に直すときの一目盛り。整数で、数え 1 が四分音いくつ分になるか。単位 1 なら数え 1 が四分音一つ（0.5 半音）、単位 2 なら半音、単位 3 なら四分音三つ（1.5 半音）。
  − の単位は形を上下に裏返し、単位 0 は起点から動かない
- **線の高さ**: どの鳴り始めでも「起点 + 部分和 × 単位 ÷ 2」半音。数えは一度だけ取り出し、四本の線は同じ数えを読む。オクターブで折り返さない
- **出会い**: 部分和が 0 の鳴り始め。どの単位で読んでも高さが 60 になり、四本とも起点に立つ
- **群**: 一本の線を受け持つ楽器の組。組の中のパートは同じ音を同じ強さで弾く。四群ある
- **窓**: 一つの巡のあいだ、四群が持っている単位の組
- **保続**: 単位 0 の群が、弾き直さずに 60 を伸ばし続けること
- **格子**: 四分音まで数えると、高さの目盛りは、四分音ずれた二つの半音の目盛りでできている。60 が乗る方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ
- **時間の間と仲間**: 時間の間は鳴り始めの間隔で、atom の何個分かで数える。atom は仲間（素数 2・3・5 の系統）ごとに一つあり、ここでは 2 の仲間（16 分音符）だけを使う

### 仕組み

1. 数えは一本の流れで、四群とも同じ数えを読む。一つの数えにつき鳴り始めが一つ
2. 四群の単位は、始めはどれも 0
3. 出会いのたびに、一つの群だけが次の単位を受け取る。受け取る群は、ヴィオラの群 → チェロの群 → 金管の群 → ヴァイオリン II の群 → ヴィオラの群 … と順に回る。
   最初の鳴り始め（0:00）も出会いで、ここでヴィオラの群が最初の単位を受け取る
4. 受け取る単位は、書いた列 +1、−2、+3、−1、+2、−3 のあと、0 が 4 つ（各群に一つずつ）。四群とも 0 に戻った出会いで終わる
5. 単位が 0 でない群は、数えのたびに弾き直す。単位 0 の群は 60 を保ち、弾き直さない。単位が 0 になった群は、60 に着いたその音をそのまま伸ばす
6. 一つの巡のあいだ窓は変わらないので、動いている線は一つの形を、単位の比の大きさと向きで描く。和音はいつも「部分和 ÷ 2 × 単位の組」を 60 に足したもので、部分和が変わるたびに、同じ形のまま広がったり縮んだり、上下が裏返ったりする
7. 最後の出会いのあと、全員が 60 を時間の間二つぶん（4 拍）保って消える

### 仮の値と、その理由

- **数えのセット {+1, −3, +8, −6}（書いた順）**
  - 和が 0 なので、一巡を読み終えるたびに部分和が 0 に戻り、全員が 60 に立つ。この並びでは、どこから読み始めても巡の途中で部分和が 0 にならないので、出会いは巡の終わりだけになる
  - 4 つの大きさはすべて違う
  - 単位 1〜3 のどれで読んでも一歩が 2・5・7 半音にならない数えだけを使った（手引きの決まり: 2・5・7 を仮の値に置かない）。そういう数えは 1、3、6、8、9、11、12、13
  - これらで作れる 4〜6 個の組（和 0、大きさがすべて違う、どの巡の途中でも部分和が 0 にならない）を全部並べると、部分和のいちばん大きい所がいちばん小さくなるのは 4 個の組で 8（5 個と 6 個の組では 11）。これで単位 3 の線が 60 ± 12 の中に収まる
  - 最大 8 になる並べ方は、読み始めの位置と上下の裏返しを除くと二通り（+1 −3 +8 −6 と +1 −6 +8 −3）。+1 の次に −3 と −6 のどちらを置くかの違いで、小さい方の −3 を置く方を取ったのは仮。読み始めを +1 にした（最初の一歩がいちばん小さい）のも仮
- **単位の列 +1、−2、+3、−1、+2、−3**
  - A の三つの単位（四分音 1・2・3 個分）を、上向きと下向きで一度ずつ使う
  - 向きは交互にした。入ってくる線は、いつも直前に入った線と逆を向く
  - 大きさは 1・2・3 と回した。続けて入る二つが同じ大きさにならない
  - 同じ大きさで逆向きの二つ（+1 と −1 など）は、列の中で 3 つ離れている
- **群の数 4**: 窓は、直前の出会い 4 回で配られた単位からなる。列で 3 つ離れた二つが同時に窓に入る、いちばん小さい幅が 4。これで ±1、±2、±3 の対が、それぞれ一つの巡でだけ揃う（群が 3 なら、どの対も揃わない）
- **起点 60**: 音域で絞った。四群の帯は起点から ±8、±12、±12、±4 半音（起点 60 なら 52〜68、48〜72、48〜72、56〜64）。これを群の楽器の音域の中で出せる起点は、四分音の目盛りで 59、59.5、60 の三つだけ（下はヴァイオリン II の下端 55、上はトロンボーンの上端 72 で決まる。起点を替えて走らせて確かめた）。三つのうち A と同じ 60 を取ったのは仮
- **単位 0 の群は弾き直さない**: 単位 0 では一歩がいつも 0 で、新しい名前が生まれないから。鳴り始めは、どこかの線が数えに名前を付けた所だけになる
- **時間のセット {7, 9, 10}（2 の仲間）、一巡ごとに一つずらす**
  - 時間の間が 3 つ、数えが 4 つなので、巡ごとのリズムが揃わない（9 つの巡のリズムはすべて違う）
  - 時間の一巡の和は 26 atom（6.5 拍）で、拍（4 atom）にも小節（16 atom）にも揃わない
  - 7・9・10 という具体の数と、2 の仲間にしたことは仮
- **テンポ ♩ = 54**: 仮。長さが B の幅（1〜2 分）に入る
- **強さ**: 動く線は p、保続は pp。60 に着いて保続へ戻る群は、次の鳴り始めまでに p から pp へ下がる。出会いには印を付けない。p と pp という段は仮

### 手引きの落とし穴に照らして

- **和音が 12 半音を等分する目盛りに乗る（名前の側に落ちる）**: 和音はいつも「60 + 部分和 ÷ 2 × 単位」なので、四本はいつも、60 から「部分和の半分」半音ずつの目盛りの上に立つ。
  - 部分和が偶数なら、四本とも起点の格子に立つ。部分和 ±6 では 3 半音ずつ、±8 では 4 半音ずつの目盛りで、どちらも 12 半音を等分する目盛り（名前の付いた響き）になる。出会いを除く 27 の和音のうち 9 がこれに当たり、いちばん広い和音（20 半音）4 つはすべて ±8 の側
  - 部分和 ±2 では 1 半音ずつ（5 つ）、奇数の部分和では 0.5・1.5・2.5 半音ずつの目盛り（13）で、奇数の単位の線はずれた格子へ移る
  - これは A の仕組み（高さ = 部分和 × 単位）と、上の数えの条件から来る。部分和が ±4〜±14 の偶数なら、どれも 12 半音を等分する目盛りか、5 半音・7 半音ずつの目盛りになる。そして上の条件を満たす数えのセット（4〜6 個。並べ方まで数えて 26544 通り）は、どれもそういう部分和を通る（全部を数えて確かめた。あらましの理由は次の二つ）
    - 一巡ごとに一つずらす規則では、どの数えも、どこかの巡の最初の部分和になる。偶数の数え（6、8、12）は、それだけで 3、4、6 半音ずつの目盛りを作る
    - 奇数の数えだけのセットでは、隣り合う二つの数えの和も、どこかの巡の二つ目の部分和になる。和が ±2 になる二つは、大きさ 1 と 3、9 と 11、11 と 13 の組（逆向き）だけで、どの数えも両隣とこの組を作る輪は、同じ大きさを二度使わないと閉じない。だから ±2 でない偶数の部分和が必ず出る
  - 値を替えれば減らせる。その候補は「作曲の段で考える点」に書いた
- **同じ大きさの間が続く和音**: 4 巡目（単位 +1、−2、+3、−1）は、単位を並べると間が 1・2・2 なので、四本の和音の間は、同じ大きさが二つ続き、端に半分の大きさが一つ付く。この巡の部分和はどれも負なので、下の二つの間が同じ大きさ（6・6、5・5、8・8）で、その上に半分の大きさ。37 の和音のうち、同じ大きさの間が二つ続くのはこの 3 つだけ
- **半音だけの線**: 単位 2 の線（2〜5 巡目のチェロの群、5〜8 巡目のヴィオラの群）は、半音の整数だけで歩き、起点の格子から出ない。単位が四分音の偶数個であることの結果で、狙ったものではない。
  立つ高さは 52〜68 の 13 通り（53、56、64、67 を通らない）。オクターブ違いを同じと数えると半音の 12 の位置をすべて通り、決まった音階の形にはならない
- **12 半音の跳び**: 単位 3 で数え 8 を読む所で、12 半音跳ぶ（8 回）。オクターブだからという理由で避けてはいない。和音の中の 12 半音も避けていない
- **形の反復**: 数えの和が 0 なので、形を移していく反復進行にはならない。ただし数えの巡は 4 巡ごとに同じ輪郭に戻る（1・5・9 巡目、2・6 巡目、3・7 巡目、4・8 巡目）。そのときの窓は毎回違う。
  また、群の数と数えの個数がどちらも 4 なので、ある群が次の単位を受け取るのは、読み始めがちょうど一回りした所になる。そのためヴィオラの群とチェロの群は、同じ 16 の数えの列を、二つの単位で二度弾く（ヴィオラの群は 1 倍のあと 2 倍、チェロの群は −2 のあと −3）。リズムは二度とも違う。
  同じ数えが単位を替えて戻ることは、この場面の課題そのものでもある
- **句の頭と拍・小節**: 句の頭にあたる出会い 10 のうち、拍の上は 6（0:00、0:28.9、0:38.9、0:47.8、0:57.8、1:26.7）、小節の頭は 2（0:00 と 0:57.8）。巡の長さは 8〜9.5 拍で揃わない。鳴り始め 37 のうち拍の上は 11、小節の頭は 3。拍を刻むものはどこにもない
- **盛り上げの型、一方向の偏り**: 人数（26 人）と強さの段は最初から最後まで同じ。動く線の数は巡ごとに 1、2、3、4、4、4、3、2、1 で、弾き直しの数（4〜16）もそれに付いて増えて減る。
  和音のいちばん広い所は巡ごとに 3、7.5、20、20、15、15、20、20、9 半音で、中ほどの一か所ではなく 3・4・7・8 巡目に散らばる。四本の平均の高さは、どの鳴り始めでも 57.75〜62 で、上がりも下がりもしない。
  前半の 3 巡は、動く線の数と和音の幅が一緒に増える。後半では、幅が最大のまま動く線が減る。全体は一つの音から開いて一つの音へ閉じる弧になる
- **外形が似ているもの**: 一つの音から開いて一つの音へ閉じる弧は、[「0 で遅れ、0 で待つ」](../zeros-fan-and-gather/README.md)の外形に近い。こちらは開き方が単位（大きさと向き）で、毎巡同じ 60 に戻る点が違う。
  一つずつ替わっていく進み方は、[「全部の順番を一度に」](../every-order-at-once/README.md)の段の進み方にも似る。こちらは値が入って、また 0 へ出ていく窓で、値が溜まっていかない
- **B の展開**: 出来事の種類は、保続の上の一本 → 反進行の対 → 三本 → 保続のない四本 → 三本 → 対 → 大きな一本 → 起点、と替わる（鳴り始めごとの違う高さの数は、巡ごとに 2、3、4、4、4、4、4、3、2）

## 聴きどころ

- 始めは四群が 60 を一緒に鳴らす。ヴィオラとクラリネットの線（単位 1、一歩 0.5〜4 半音）だけが 60 から出て、また 60 へ戻る。ほかの三群は 60 を pp で保つ
- 全員が 60 に戻るたびに、一つの群だけが単位を替える。次に入るのは逆向きで 2 倍の線（チェロとファゴット、0:09.7）、その次は 3 倍の線（ホルンとトロンボーン、0:19.2）
- 0:28.9〜0:57.8 は保続が消え、四本すべてが動く。60 は出会いの所でだけ鳴る。同じ大きさで逆向きの対が、±1（0:28.9〜）、±2（0:38.9〜）、±3（0:47.8〜）と一つずつ揃い、60 をはさんだ反進行になる
- 0:38.9 と 0:47.8 は、線が出入りせず、線の大きさだけが替わる所。ヴィオラの群の一歩が 2 倍に、チェロの群の一歩が 1.5 倍になる。ヴィオラの群は 1〜4 巡目と同じ数えの列を、チェロの群は 2〜5 巡目と同じ数えの列を、新しい単位でもう一度読む
- 一つの巡のあいだ、和音の形（単位の組）は変わらない。数えにつれて変わるのは、形の大きさと上下の向きだけ。形が替わるのは、全員が 60 に立った直後だけ
- 0:57.8 から、群が一つずつ 60 に着いて保続へ戻る。1:17.5 からはチェロとファゴットの大きな線（単位 −3、一歩 1.5〜12 半音）だけが動き、1:26.7 に 60 へ戻って、全員が 60 で消える
- **耳で判断してほしい点**
  - 単位が替わったことが、同じ数えの形の大きさ・向きの替わりとして聴こえるか。それとも、ただ線が一本ずつ出入りするように聴こえるか
  - 部分和 ±6、±8 の和音（12 半音を等分する目盛りの上。いちばん広い 4 つを含む）が、名前の付いた響きとして立ちすぎないか
  - 約 10 秒ごとの 60 と、全体の 76% のあいだ鳴っている 60 が、区切りや中心として立ちすぎないか

## 楽器

四群。一群が一本の線を受け持ち、群の中のパートは同じ音を同じ強さで弾く（8 パート、26 人）。どの群の楽器も、その群が受け取る単位が必要とする音域で選んだ。
四本は 60 で重なり、互いに交差するので、群ごとに違う組み合わせにして、同じ高さでも線を聴き分けられるようにした。

- ヴィオラの群（単位 +1 と +2、52〜68）: クラリネット 1・2（2 人で一パート）、ヴィオラ 6 人
- チェロの群（単位 −2 と −3、48〜72）: ファゴット 1・2（2 人で一パート）、チェロ 5 人
- 金管の群（単位 +3、48〜72）: ホルン 3・4（2 人で一パート）、トロンボーン 1・2（2 人で一パート）
- ヴァイオリン II の群（単位 −1、56〜64）: コーラングレ、ヴァイオリン II 6 人

すべて持続音で、アクセント、スラー、グリッサンド、奏法の指定はない。

## つまみ

- **Counts**（Pitch のグループ）: 数えのセット（四分音の個数、0 でない整数、− は下向き）。書いた順がそのまま規則の順になる。和が 0 でないと出会いが戻らないので、スケッチはエラーで止まる
- **Units**: 出会いで配る単位の列（整数、− は裏返し、0 は保続）。配り終えたあと、各群に 0 が一つずつ配られ、四群とも 0 になった出会いで終わる
- **Standpoint**: 起点。オクターブで折り返さないので、楽器の音域を出る線があるとエラーで止まる
- **Time set**（Time のグループ）: 時間の間のセット（atom の数）。一巡ごとに一つずらして読む
- **Family**: 時間の atom の仲間
- **Tempo**（Form のグループ）

Counts と Units は、目盛りのつまみ（間のセットのつまみ）ではなく文字で書くつまみにした。目盛りのつまみは値を大きさの順に並べ替えてしまい、書いた順（規則）を保てないため。

固定（仕組みの一部）: 群の数 4 と単位を受け取る群の順、単位 0 の群は弾き直さないこと、最後の出会いのあとの時間の間二つぶんの保続。
固定しているが仕組みではないもの（仮）: 強さの段（p と pp）、楽器の割り当てと人数。
