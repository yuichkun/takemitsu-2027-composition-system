# B · 0 から開いて 0 へ閉じる切れ目

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)
- 使っている A: [`../../a/pitch-half-moves`](../../a/pitch-half-moves/README.md)（半分ずつ動く和音）と [`../../a/texture-leaf-gates`](../../a/texture-leaf-gates/README.md)（葉が開け閉めする和音）。どちらの規則も、このフォルダの `sketch.ts` に写して使っている。
  高さは「半分ずつ動く和音」、いつ新しい高さを読むかは「葉が開け閉めする和音」と、役割を分けた

## 何をしたか

前提の二点を、一つの仕組みで試す。

一つ目（関係（切れ目）が先にあり、項は後から付く名前である）。和音を「立ち位置に三つの間を足すか足さないか」の全部の組み合わせとして持つと、どの間も和音を二つの半分に分ける切れ目になる（半分ずつ動く和音）。
ここでは三つの間に大きさ 0 を持たせた。大きさ 0 の間は分けない切れ目で、その両側の半分が同じ高さに立つ。
曲は、三つの間がすべて 0（8 声が一つの高さ）の所から始まる。間が一つずつ開いて 8 つの高さになり、半分ずつ動く和音の順で大きさを替え、最後に一つずつ 0 へ閉じて一つの高さへ戻る。
切れ目が先に開き、その両側の高さ（項）は後から付く。

二つ目（その名前は、立つ位置で変わる）。各声は、葉が開け閉めする和音のように、自分の周期で鳴っては休む。いまの間の大きさを読むのは、自分が鳴り始める時だけ。
だから間の大きさが替わっても、その間を足した 4 声は一斉には動かない。それぞれが次に鳴り始める時に、一人ずつ新しい高さで入る。同じ時刻でも、声ごとに読んでいる状態が違いうる。
高さが替わった入りにだけ管が重なり、どの声がいつ新しい高さへ移ったかを色で示す。

原則の言葉で言い直す。音程の軸では、和音は時間の間が 0 の並びで、立ち位置に、セット（三つの間）から選んだ間の和を、選び方の全部について足したもの。
セットの物語は、三つの間が 0 から開き、一つずつ大きさを替え、0 へ閉じること。時間の軸では、各声は自分の仲間の atom で数えた同じ開閉を繰り返し、開く所でだけセットを読む。
セットが替わる時刻そのものには、何も鳴らない。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだ。半音単位で書き、四分音は .5。四分音は間の atom（それ以上は割らない単位）。0（同じ高さ）も間。− は下向き
- **立ち位置**: 何も足さない声の高さ。ここでは 58（B♭3）。以下 s と書く。この声は最初から最後まで一度も動かない
- **三つの間と 8 声**: 三つの間を a、b、c と呼ぶ。各声は、s に a、b、c のそれぞれを足すか足さないかを決めた音で、組み合わせは 8 通り:
  s、s+a、s+b、s+a+b、s+c、s+a+c、s+b+c、s+a+b+c。声の名前は何を足したかで付け、高さの順では付けない
- **切れ目と半分**: どの間も、8 声を、それを足した 4 声と足していない 4 声に分ける。この 4 声ずつを「半分」と呼ぶ。
  間の大きさが替わると、それを足した半分だけが、替わった幅だけ同じ向きに動き、もう半分は動かない
- **大きさ 0 の間**: 足しても足さなくても同じ高さになる。二つの半分が同じ高さに重なり、切れ目は何も分けない
- **三つの大きさ**: 各間は 0 と、符号つきの二つの大きさを持つ。a は 0、+3、+5.5。b は 0、−5.5、−8.5。c は 0、+11、+17.5。0 に近い方を一つ目の大きさ、遠い方を二つ目の大きさと呼ぶ。
  一つ目と二つ目の差を「替わる幅」と呼ぶ（a 2.5、b 3、c 6.5）
- **状態**: 三つの間がいまどの大きさにあるか。a、b、c の順に 0・1・2（0、一つ目、二つ目）で書く。例えば 211 は、a が二つ目（5.5）、b と c が一つ目（−5.5 と 11）
- **格子**: 四分音の目盛りは、四分音ずれた二つの半音の目盛りでできている。s（58）が乗る方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ。
  動く幅が四分音の奇数個（.5 付き）なら、動いた声はもう一方の格子へ移る。偶数個なら同じ格子に留まる
- **atom と仲間**: atom は時間を数えるいちばん小さな単位。素数の仲間ごとに一つある。2 の仲間は 16 分（1 拍に 4 つ）、3 の仲間は 3 連 8 分（1 拍に 3 つ）、5 の仲間は 5 連 16 分（1 拍に 5 つ）。一つの声は、最初から最後まで一つの仲間で数える
- **開と閉**: 開は声が鳴っている長さ、閉は休んでいる長さ。どちらも自分の仲間の atom の数で数える。全部の声で開 12、閉 5。開と閉を一度ずつ通ったもの（17 atom）を一周と呼ぶ
- **読む**: 声が開く（鳴り始める）時に、その時刻の状態から自分の高さを決めること。開いているあいだはその高さのまま。途中で状態が替わっても、次に開くまでは前の高さを鳴らし続ける
- **入り**: 声が開くこと。前の開と違う高さで開くことを「新しい高さで入る」と言う

### 高さの規則: 状態の道すじ

15 の状態、14 回の替わり。一度に一つの間だけが替わる。

1. **開く**: a、b、c の順に、0 から一つ目の大きさへ。000 → 100 → 110 → 111。違う高さの数は 1 → 2 → 4 → 8
2. **替える**: 半分ずつ動く和音と同じ順（a、b、a、c、a、b、a、c）で、一つ目と二つ目のあいだを行き来する。111 → 211 → 221 → 121 → 122 → 222 → 212 → 112 → 111。
   三つの間の二つの大きさの組み合わせ 8 通りを、ちょうど一度ずつ通って戻る
3. **閉じる**: c、b、a の順に 0 へ。111 → 110 → 100 → 000

最後に開いた c が最初に閉じるので、最後の 4 つの状態は、最初の 4 つを逆に並べたものになる（高さの上で。時間の上では同じにならない。「事実」を参照）。
間が替わる回数は、a が 6 回（開く 1、替える 4、閉じる 1）、b と c が 4 回ずつ。声が動く回数は、その声が足した間の替わる回数の和で、s 0、s+a 6、s+b 4、s+c 4、s+a+b 10、s+a+c 10、s+b+c 8、s+a+b+c 14（合計 56）。

**c で分けた二つの半分の形**: a は上向き、b は下向きなので、c を足していない半分（s、s+a、s+b、s+a+b）のいちばん上は s+a、c を足した半分のいちばん下は s+b+c。
だから c と、a と b の開き（a − b）の大小で、二つの半分は「離れる」（s+b+c が s+a より上）、「接する」（同じ高さ）、「入り組む」（下）のどれかになる。

### 時間の規則: 開閉と、読む時

- **仲間**: 声が s から何本の切れ目を越えているか（足した間の数）で決める。1 本（s+a、s+b、s+c）は 2 の仲間、2 本（s+a+b、s+a+c、s+b+c）は 3 の仲間、
  0 本と 3 本（s と s+a+b+c。すべての切れ目を挟んで向かい合う二声）は 5 の仲間
- 同じ開 12・閉 5 atom が、仲間ごとに違う長さになる（♩ = 66、1 拍 0.91 秒）

| 仲間 | 開 12 atom | 閉 5 atom | 一周 17 atom |
| --- | --- | --- | --- |
| 2 | 3 拍 | 1¼ 拍 | 4¼ 拍（3.9 秒） |
| 3 | 4 拍 | 1⅔ 拍 | 5⅔ 拍（5.2 秒） |
| 5 | 2.4 拍 | 1 拍 | 3.4 拍（3.1 秒） |

- **ずらし**: 同じ仲間の声は、一周の中に等しく散らして始める。s+a は 0、s+b は 6、s+c は 11 atom 目に最初に開く。s+a+b は 0、s+a+c は 6、s+b+c は 11。s は 0、s+a+b+c は 8。最初に開くまでは黙っている
- **読む時**: 声は開くたびに、その時刻の状態を読み、その高さで pp で弾き直す。閉じるとそこで止める（弱めて消すのではなく止める）
- **状態が替わる時刻**: 3 の仲間の atom で数える。最初の替わりは 20 atom 目。そのあとは時間のセット {20, 22, 25} を、一巡ごとに読み始めを一つずらして取り出す（20 22 25、22 25 20、25 20 22、…）
- **終わり**: 最後の替わり（000 へ戻る）のあと、各声はもう一度だけ開いて s（58）を鳴らし、もう開かない。最後の声が閉じた所で終わる

### 色

- **弦**: 8 声を弦の分奏（一つのセクションを部に分けて別々の音を弾かせる）で鳴らす。各声が通る音域の真ん中が低い順に、低いセクションから割り当てた。
  各部はセクションのおよそ 4 分の 1 の人数（3〜4 人）。arco、senza vib.、pp
- **管**: 声が前の開と違う高さで入るときだけ、その開を同じ長さで重ねる。p で入り、1 拍かけて pp へ。どの声がどの管かは、その声が通る音域で決めた。
  s は一度も高さが替わらないので管がない

### 仮の値をなぜ選んだか

- **替わる幅（a 2.5、b 3、c 6.5）**: a と c は四分音の奇数個（5 個と 13 個）なので、替えると動いた半分はもう一方の格子へ移る。b は偶数個（6 個）で、同じ格子に留まる。
  いちばんよく替わる a（行き来の 8 回のうち 4 回）の幅がいちばん小さく、2 回しか替わらない b と c の幅は大きい。回数と幅を逆にしたのは、半分ずつ動く和音と同じ関係。
  構造で決めたのは奇偶と大小の順までで、幅の大きさそのもの（2.5、3、6.5）は仮。A の幅（1.5、2、4.5）は使っていない。2 は仮の値に置かない値なので
- **向き（a と c は上、b は下）**: 0 から開くときに和音が上へだけ広がると、高さと違う高さの数が一緒に増える。b を下へ開くので、開く段で和音のいちばん下は 58 から 52.5 へ下がる
- **c の一つ目の大きさ 11**: a の二つ目の大きさ 5.5 と、b の一つ目の大きさ 5.5 の和。c で分けた二つの半分の形は c と a − b の大小で決まる（上の「c で分けた二つの半分の形」）。
  a − b は 8.5、11、11.5、14 の四つをとるので、c = 11 のあいだに半分は「離れる」（111）、「接する」（211）、「入り組む」（221、121）のすべてを通る。
  c の二つ目の大きさ 17.5 は a − b のどの値よりも大きく、c = 17.5 のあいだはいつも離れる
- **a と b の一つ目の大きさ（3 と 5.5）**: 上の条件を決めると、残る自由はこの二つだけ。満たしている条件は、小さい方から開くこと（a の一つ目 < b の一つ目の大きさ）、
  どの管も自分の声の高さを出せること（クラリネット 1 が s+a+c のいちばん上 ≦ 94、ホルンが s+b+c のいちばん上 ≦ 77）、どの大きさにも 2・5・7 を置かないこと。
  この二つには構造の理由がなく、仮の値。
  依頼の段では、条件を満たす組の中から、格子ごとの声が三和音の形になる数や、隣どうしに 5・7・四分音一つが出る数がいちばん少ない組として選ばれていた。
  それは名前の物差しで値を選ぶこと（三和音の形を避ける操作）なので、選んだ理由にはしない。値は依頼のまま置き、三和音の形は「事実」で数えるだけにした。
  この値の結果として、a の二つ目（+5.5）と b の一つ目（−5.5）が逆向きの同じ大きさになる。だから状態 211 では、0 でない二つの間 a と b を足した間が 0 になり、
  s+a+b が s と、s+a+b+c が s+c と同じ高さに立つ（c で分けた二つの半分が接することと合わせて、8 声が 5 つの高さに立つ）。5.5 が多いのも、この結果
- **立ち位置 58**: 音域だけで決めた。s+a と s+c は最後に s へ戻り、そこへオーボエが重なる。58 はオーボエの最低音なので、オーボエを使う限りこれより下には置けない。8 声（49.5〜81）はどれも割り当てた弦の音域に入る
- **開 12・閉 5（一周 17 atom）**: 17 は 3・4・5（仲間ごとの 1 拍の atom の数）のどれとも公約数を持たないので、開く位置は拍にそろわない（仲間どうしが出会うのは 17 拍ごとだけ）。
  閉 5 は、同じ仲間の 3 声の閉を一周の中に重ならずに並べられるいちばん長い値（5 × 3 = 15 は 17 に収まり、6 × 3 = 18 は収まらない）。
  だから全員が一度開いたあとは、2 の仲間から 2 声、3 の仲間から 2 声、5 の仲間から 1 声が少なくとも鳴っていて、常に 5 声以上が鳴る
- **仲間の決め方**: s から越えた切れ目の本数で分けた。0 本と 3 本の二声は、すべての切れ目を挟んで向かい合うので同じ仲間にした。本数と仲間の対応のさせ方（1 本 → 2、2 本 → 3、0・3 本 → 5）は仮
- **替わる時刻（{20, 22, 25}、3 の仲間）**: どの値も、いちばん長い一周（3 の仲間の 17 atom）より長い。だからどの状態も、8 声全員に一度は読まれてから次へ移る。最初の状態の長さも同じセットから取った（いちばん短い 20）。
  一巡の和 67 atom は 22⅓ 拍で、拍にも小節にもそろわない。規則（一巡ごとに一つずらす）は三巡で元に戻り、その長さは 67 拍。67 は 4（小節）でも 17（開閉がそろって元に戻る拍数）でも割り切れないので、あとの替わりが、前の替わりと同じ開閉の位置に来ることはない
  - 依頼の値は {20, 23, 25} だった。三巡が 68 拍 = 17 小節 = 開閉の 4 周になり、10 回目と 12 回目の替わりが、1 回目と 3 回目とそっくり同じ開閉の位置に来ていた
    （c が閉じる替わりが、c が開く替わりと同じ 4 声に、同じ順、同じ遅れ（1、3、3⅔、5⅓ 拍）で届く）。手引きの「時間の和が小節にそろう」に当たるので、23 を 22 にした（比べた数は「事実」）
- **テンポ 66**: 約 1 分 40 秒にするための値。構造の理由はない
- **弦の人数（各部 3〜4 人）**: どの声もほぼ同じ重さにするため。また、p の独奏の管が pp の弦に埋もれないようにするため（手引きの「楽器の重さ」）

## 聴きどころ

- 始めの 7 秒は 58 の一つの高さだけ。3 声が一緒に入り、そこから 3.3 秒のあいだに残りの 5 声が一人ずつ入る。どの声も自分の周期で弾き直しと休みを繰り返すので、変わるのは厚さ（鳴っている声の数）だけ
- 切れ目が開くたびに、その半分の 4 声が一人ずつ、自分が開く時に新しい高さで入る。その入りにだけ管が重なる。0:07〜0:22 で、違う高さは 1 → 2 → 4 → 8
- 出来事の種類が段ごとに替わる
  - 開く段: 動いた声は、同じ高さに残っている声から分かれて出る（12 回の入りのうち 10 回、前の高さをほかの声がまだ鳴らしている）
  - 中ほど: 8 つの高さを持つ和音の中で、4 声だけが新しい高さへ移る。32 回の入りのうち 29 回は、そのとき誰も鳴らしていない高さへ入る
  - 閉じる段: 動いた声が、すでに鳴っている高さへ入って重なる（12 回のうち 9 回）。最後は 58 一つを、閉じた声から順に止めて終わる
- 替わるたびに、4 声は 2〜5 拍（1.8〜4.5 秒）に散らばって新しい高さへ移る。二声が同じ時刻に新しい高さへ入ることは一度もない
- 0:27 から一声ずつ重なり、0:31〜0:34 の状態 211（a 5.5、b −5.5、c 11）は、5 つの高さ（52.5 58 63.5 69 74.5）が 5.5 ずつの等しい間に並ぶ。c で分けた二つの半分が接する所で、三組の声が同じ高さに立つ（s と s+a+b、s+a と s+b+c、s+c と s+a+b+c）。0:34 からの次の状態で入り組む
- 1:20 から切れ目が閉じていき、半分ずつ同じ高さに重なって 58 一つへ戻る。1:36.4 からは 58 だけが鳴り（最後の管の入りは 1:37.9、ファゴット 2 の 58）、閉じた声から順に止む。s の声（ヴィオラ 3）は最初から最後まで 58 のまま
- **耳で判断してほしい点**
  - 管の色で、どの声が動いたかが聴こえるか。同じ楽器が二声ずつ受け持つ所がある（オーボエが s+a と s+c、クラリネットが s+a+c と s+a+b+c、ファゴットが s+b と s+a+b）ので、色で分かるのは楽器の組まで
  - 替わりが一人ずつ散って届くことが、「和音がゆっくり替わる」ではなく「声ごとに違う状態を読んでいる」ことに聴こえるか。二つの状態が同時に鳴っている時間は全体の 32%
  - 中ほどの和音は 8 つの高さを持つが、一度に鳴っているのは多くの時間 5〜6 声で、8 声がそろうのは合わせて 1.5 拍だけ。開閉のたびに鳴っている部分が替わる。8 つの高さの和音として聴こえるか
  - 開閉の模様（どの声がいつ弾き直して休むか、鳴っている声の数の移り変わり）は、17 拍（15.5 秒）ごとにまったく同じ形で戻る。一周 17 atom は、2 の仲間では 4¼ 拍、3 の仲間では 5⅔ 拍、5 の仲間では 3.4 拍で、三つとも 17 拍でちょうど元の位置に戻るから（葉が開け閉めする和音の性質）。
    曲の中で約 6 回半繰り返す。その区切り（0:00、0:15.5、0:30.9、0:46.4、1:01.8、1:17.3、1:32.7）にだけ三声（s、s+a、s+a+b）が同時に弾き直し、ほかに二声以上が同時に弾き直す所はない。
    高さの状態は 6⅔〜8⅓ 拍ごとに替わるので同じ響きは戻らないが、弾き直しの模様が 15.5 秒の繰り返しとして聴こえないか
  - 5.5 が多い。211（0:31〜0:34）は 5.5 だけの 5 音、222 と 212（0:54〜1:07）にも隣どうしの 5.5 が 4 つずつある（a の二つ目と b の一つ目の大きさがどちらも 5.5 で、c の一つ目がその和であることの結果）。
    5.5 は半音の格子に乗らないので平均律の音名には乗らないが、等しい間の積み重ねとして耳に付くか。111（0:19 と 1:13）は 3 と 2.5 が交互に並ぶ 8 音
  - 0:50〜0:57（状態 122 と、そこから抜けるまで）、起点の格子の 61・67・70 が、音名で見ると減三和音の形になる。三和音の形の数は値を選ぶ理由にしない（「仮の値をなぜ選んだか」）ので、狙いも避けもせず、そのまま置いた
  - 高さの幅は 0 → 31.5 → 0 の山になる（切れ目が開いて閉じることそのもの）。人数・強さ・管の入りの密度は山にならない（「事実」）。山の形が盛り上げとして聴こえないか
  - 仲間を切れ目の本数で決めたことは、声ごとの息つぎの速さの違いとしては聴こえるが、本数との対応まで聴こえるかはわからない（推測）

## つまみ

- a / b / c: 各間の、0 以外の二つの大きさ（半音、.5 は四分音、− は下向き）。0 に近い方が一つ目。a が最初に開き、いちばんよく替わり、最後に閉じる
- Standpoint: 立ち位置 s
- Open / Closed: 開と閉の長さ（自分の仲間の atom の数）。全部の声で同じ
- Between changes: 状態が替わる時間のセット（3 の仲間の atom）。最初の替わりはいちばん短い値のあと、そのあとは一巡ごとに一つずらして取り出す
- Tempo: テンポ

コードの中で決めてあるもの: 状態の道すじ（開く a b c、替える a b a c a b a c、閉じる c b a）、切れ目の本数から仲間への対応、ずらし（一周の中に等しく散らす）、どの声にどの管が重なるか、弦の人数（セクションのおよそ 4 分の 1）。
