# B · 0 で打楽器が線を継ぐ

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)
- 使っている A: [`ideas/lines/b-hand-off`](../../../ideas/lines/b-hand-off/README.md)（同じ音を受け渡す）。間の閉じ方は、同じ lines の [`ideas/lines/b-narrowing`](../../../ideas/lines/b-narrowing/README.md)（間が四分音ずつ縮む）と同じ

## 何をしたか

「同じ音を受け渡す」の仕組みを、無音程の打楽器が線に入ってくる入り口として使った。

- **間**は二つの音のあいだ。四分音の何個分かで数え、ここでは半音を 1、四分音を 0.5 と書く。0（同じ音）も間
- **線**は、起点（最初の音、立ち位置）に、規則がセット（間の集まり）から取り出した間を足していったもの。「同じ音を受け渡す」では、上行する線を楽器が一音ずつ受け渡す。段ごとにセットの間が全部四分音ずつ狭まり、最後は一つの音になる
- どの楽器が鳴らすかを、ここでは**色**と呼ぶ。次にどの色が鳴らすか（受け渡しの**輪**）は、音程とは別の規則で回り続ける
- **無音程の打楽器**は、音程の間のセットに 0 しか持てない楽器と見る（音の原則の表の一行目「セットが {0} だけ」の、音程の側）。これと、起点の音を打つだけの Vn II の col legno を合わせて、**0 の色**と呼ぶ（7 つ）
- 線のセットの間が全部 0 に閉じた所では、音程を持つ楽器と持たない楽器を分けるものが何もない。だからそこで、受け渡しの輪に 0 の色 7 つが加わる。0 の色は有音程の色のあいだにできるだけ均等に散らして入れ、音の高さのない一打が、有音程の楽器の起点の音と同じ列で、一つずつ順番に鳴る
- 線が 0 から開き直すと、0 しか持てない色は付いていけない。0 の色は 0 のまま、自分の時間（有音程の線とは別の格子）で自分の線を続け、一本だった線が、音程の間が開いていく線と、0 のままの色の線の二本に分かれる。0 の色の線は、セットに 0 が残っているあいだ続き、0 がなくなった段で止む

前提の二点目（同じ間 0 が、立つ側で「同じ音」とも「音程なし」とも呼ばれる）と、三点目（どの項も立たない切れ目で、新しいもの、ここでは色の線が定義される）を、「セットが {0} であるあいだだけ打楽器が輪に入り、セットに 0 が残るあいだだけ自分の線を持つ」という一つの関係で聴く。

## 仕組みと聴こえ方

### 段

- **段**は、起点から、セットの四つの間を書いた順（小さい順）に足した 5 音。段が替わるたびに起点へ戻る。段の最後の音が、その段のいちばん上の音
- 段を 0 から数えると、段 k の間は、セットの各間 b から四分音 k 個ぶん（0.5k）を引いたもの（0 より小さくはしない）
- 上行のセット {0.5 3 3.5 4}: .5 の付く間が二つ（0.5 と 3.5）、付かない間が二つ（3 と 4）。段が一つ進むたびに、0 でない間は全部 .5 の有無が入れ替わる（次の段は 0 2.5 3 3.5）。だから線はどの段でも二つの格子（四分音ずれた二つの半音の格子）を行き来する。いちばん広い 4 は四分音 8 つなので、閉じるのに 8 段、開くのに 8 段
- いちばん小さい間を atom（それ以上割らない最小の間）の 0.5 にした理由: 段のいちばん上の音は、起点に四つの間の和を足した所。0 でない間が四つあるあいだは、段ごとに和が四分音 4 つずつ減るので、いちばん上の音は起点と同じ格子の上を 2 ずつ歩く。0.5 は段 1 で 0 に閉じるので、段 1 から段 5 までは 0 でない間が三つになり、いちばん上の音は段ごとに四分音 3 つ（1.5）ずつ下がって、二つの格子を交互に踏む（72 → 70 → 68.5 → 67 → 65.5 → 64 → 62.5 → 61.5）。段の中の一歩一歩と同じく、段のいちばん上の音どうしも格子を渡る
- 同じ理由で、セットに 0 が残っている段は段 1 から段 7 まで（0.5 が段 1 で 0 になり、そのまま）。0 が一つもないのは段 0 だけ。これが開く区間で 0 の色の線が続く長さを決める（下の「0 の色の線」）
- 最初に置いた値 {1.5 2 3.5 4} では、いちばん上の音が 72 → 70 → 68 → 66 と、起点と同じ格子の上を 2 ずつ四つ並び（手引きの落とし穴「一歩が偶数個の四分音だと、線が 12 平均律の音階に乗る」が、段のいちばん上の音の列で起こる）、段 2 ではふつうの格子に立つ音が起点・+4・+7 になった。和・個数・.5 の有無・いちばん広い間は同じなので、Rising set に入れれば聴き比べられる
- 起点 C♯4（61）: 12 の有音程の色がどれも出せる帯は 61〜72（下はチューブラーベルの録音の下端 61、上はトロンボーンの上端 72）。帯の幅 11 はセットの和（0.5 + 3 + 3.5 + 4）と同じなので、帯の下端から始めると、いちばん広い段がちょうど帯を満たす（61 → 72）。段ごとに起点へ戻るので、線はこの帯から出ない

### 三つの区間

1. **閉じる**（0:00〜0:27、40 音）: 段 0 から段 7 まで。有音程の 12 色だけが輪で回る。線の登りが段ごとに四分音ずつ縮む
2. **0**（0:27〜0:44、24 音）: 段 8 ではセットの間が全部 0 になる。この段を 24 音にのばしたのが 0 の区間で、音はすべて起点の 61。輪は 19 色（有音程 12 のあいだに 0 の色 7 を散らしたもの）。有音程の色は 61 を次の鳴り始めまでのばし、0 の色は一打（16 分音符 1 つ）。col legno は 61 を打つ
3. **開く**（0:44〜、40 音）: 段 7 から段 0 まで、閉じた順を逆にたどる。有音程の 12 色の輪が、開いていく線を一本の時間の線の上で鳴らす。同じ 0:44 から、0 の色は 0 の色 7 つだけの輪で、自分の時間の線を打つ。セットに 0 が残っている段 7〜段 1 のあいだ続き、段 0（1:07〜）の前で止む。段 0 は有音程の線だけで 61 から 72 まで登り、最後の 72（クラリネット）が 4 拍のびて消える

### 受け渡しの輪

- 次の音は、輪の次の色へ行く。輪の一巡は書いた順で、次の一巡は一つ後の色から始める（一巡ごとにずらす）
- チューブラーベルとヴィブラフォンは、ふつうの半音の格子の音しか出せない。四分音ずれた格子の音（.5 の付く音）が来ると、その色を飛ばして次の色へ行く（飛ばした分も輪は進む。「同じ音を受け渡す」と同じ）
- 0 に入る所では、有音程の 12 色と 0 の色 7 つを一つの輪にする。19 の場所に 0 の色 7 つを、できるだけ均等に置く（0 の色どうしのあいだが 2 か 3、つまり有音程の色が 1 つか 2 つ挟まる）。二つの群はそれぞれ書いた順のまま。いまの値では、輪は バス・クラリネット、チェロ、**col legno**、ホルン、ベル、**大太鼓**、オーボエ、トロンボーン、**トライアングル**、ヴィブラフォン、**タムタム**、フルート、ヴィオラ、**ウッドブロック**、トランペット、クラリネット、**シンバル**、ファゴット、**テナードラム**（太字が 0 の色）
- 輪が替わる所（0 に入る所、開き直す所）では、次に来るはずだった色から新しい輪を始める。開き直す所では、有音程の輪は次に来るはずだった有音程の色から、0 の色の輪は次に来るはずだった 0 の色から始める
- 0 の区間の 24 音 = 19 色の一巡 + 5 音。開き直しが輪の切れ目ではなく途中で始まる（開くのは段の規則、誰が鳴らすかは輪の規則で、二つは別）

### 0 の色の線

- 開き直してからの 0 の色は、有音程の線とは別の時間の線を打つ。時間の間は、一本の時間の線と同じセット {2 3 3 4} を同じ規則（二つずつの組、辞書順）で取り出し、組の二つの間を足して一つの間にしたもの。組は 2 3 / 2 4 / 3 3 / 3 4 なので、間は 5 6 6 7 の繰り返し
- 時間の間を数える atom（単位）は、音の原則の 5 の仲間（5 連 16 分音符。2 の仲間は 16 分、3 の仲間は 3 連 8 分で、有音程の線は 2 の仲間）。5 6 6 7 は 1・1.2・1.2・1.4 拍で、一巡 4.8 拍。16 分の格子と 5 連 16 分の格子が重なるのは拍の上だけなので、二本の線が同じ瞬間に鳴るのは、どちらも拍の上に来た所だけになる
- 始まり: 線が仲間を替えてよいのは格子の重なる所（拍）だけなので、開き直しの最初の音か、そのあとの最初の拍から打ち始める。いまの値では開き直しの最初の音がちょうど 13 小節の頭にあるので、二本はそこで同時に始まり、そこから別々の格子に分かれる
- 終わり: セットに 0 が一つでも残っているあいだ続け、0 がなくなった段の最初の音の前で止む。0 の色が輪に入るのは「セットが 0 だけのとき」、自分の線を持つのは「セットに 0 があるあいだ」、止むのは「0 が一つもなくなったとき」で、三つとも同じ関係（セットの中の 0）で決まる

### 仮の値

- 有音程 12 の順（書いた順）: バス・クラリネット、独奏チェロ、ホルン、チューブラーベル、オーボエ、トロンボーン、ヴィブラフォン、フルート、独奏ヴィオラ、弱音器のトランペット、クラリネット、ファゴット。隣り合う色がなるべく別の楽器の族（木管・弦・金管・金属の打楽器）になるように並べ（「同じ音を受け渡す」と同じ考え方）、一つの格子しか出せないベルとヴィブラフォンのあいだには 2 色を置いた（.5 の音で二つが続けて飛ばされない）。ただし、クラリネット → ファゴット → バス・クラリネット（一巡の終わりから次の一巡の頭へ）は木管が続く
- 0 の色 7 の順（書いた順）: Vn II の col legno、大太鼓、トライアングル、タムタム、ウッドブロック、サスペンデッド・シンバル、テナードラム。明るさや大きさでは並べていない。この順に構造の理由はまだない（仮）。col legno は、有音程の楽器が間 0 で打つ音で、二つの群の橋になる
- 0 の区間の輪の混ぜ方: 前の版は、有音程 12 のあとに 0 の色 7 をつなげた一列で、0 の色が 7 打続けて来て、有音程の 61 が 11 音続いた。聴こえるのは「管の 61 の列」と「打楽器だけの一節」の交代で、「一打と 61 が一本の線に聴こえるか」の答えを並べ方が先に決めていた。19 の場所に 7 つをいちばん均等に置けば（あいだ 2 か 3）、どちらの群もまとまらず、二つの群は数の比（12 対 7）どおりに混ざる
- 時間: 16 分音符を atom（時間の間を数える単位。音の原則の「2 の仲間」）にして、時間の間のセット {2 3 3 4} から、組合せ（二つずつの組を辞書順に並べる）で取り出す。組は 2 3 / 2 4 / 3 3 / 3 4 なので、鳴り始めの間隔は 2 3 2 4 3 3 3 4（16 分いくつ分か）の繰り返しになる。「同じ音を受け渡す」と同じセットと規則。一巡（8 音）の和は 24 atom。「同じ音を受け渡す」の 3 連 8 分で数えるとちょうど 2 小節になり、句の頭が小節の頭にそろうので、16 分で数えた（一巡 6 拍）。閉じる・0・開くの有音程の線は、同じ一本の時間の線
- 0 の色の線の仲間を 5 にした理由: 3 の仲間（3 連 8 分）だと、0 の色の線の一巡（5 + 6 + 6 + 7 = 24 atom）がちょうど 2 小節になり、一巡の頭がいつも小節の頭に来る（上と同じ落とし穴）。5 の仲間なら一巡は 4.8 拍で、小節とずれる（小節の頭に戻るのは 5 巡ごと、6 小節ごと）。2 の仲間のままでは格子が同じで、前の版と同じく有音程の鳴り始めに重なりやすい
- 組の二つを足して一つの間にした理由: 0 の色の線の鳴り始めは平均 1.2 拍おきになり、有音程の線（平均 0.75 拍おき）の 6 割ほどの数になる。加わった線が、開いていく線より多く鳴らない。前の版は、開く区間の鳴り始めすべてで一打が加わって一つの鳴り始めの音が 1 から 2 に増え、段のいちばん上の音が 61.5 から 72 へ上がるのと同じ向きに量が増えていた（手引きの落とし穴「一方向の偏り」）。セットと規則は同じで、組を一つの間として使うだけなので、新しい値は持ち込んでいない
- 強弱: 全部 p、アクセントなし、クレッシェンドなし。打楽器の加入と二本への分かれが、盛り上げに聴こえないように
- テンポ ♩ = 66（「同じ音を受け渡す」と同じ）

## 聴きどころ

- 前半（0:00〜0:27）: 上行の線が一音ずつ色を替えながら、段ごとに登りが四分音ずつ縮み、一つの音 61 になる。段のいちばん上の音は 72 → 70 → 68.5 → 67 → 65.5 → 64 → 62.5 → 61.5 と下がる（オーボエと弱音器のトランペットが交互に取る）
- 0:27〜0:44（8〜12 小節）: 線は 61 だけになる。クラリネットの 61 のすぐあとにシンバル（0:28）、ファゴットの 61 のあとにテナードラム、と、0 の色が有音程の 61 の一つか二つおきに一つずつ来る（一打が続く所はない。一打どうしは 1.25〜2.5 拍おき）。音の高さのない一打が、管や弦の 61 と同じ輪の順番で鳴る
- 0:44（13 小節の頭）: 有音程の線はホルンの 61 から開き直しの段に入り、同じ瞬間に Vn II の col legno（61）が 0 の色の線を打ち始める。ここから 0 の色は 5 連 16 分の格子の上で 1〜1.4 拍おきに打ち、有音程の鳴り始めと同じ瞬間に鳴るのは、このあと 19 小節の頭の一度だけ。線が一本から二本になる所
- 0:45〜0:46: 有音程の線が四分音一つ（0.5、フルートの 61.5）で 61 を離れる。直前のトロンボーンの 61 とこのフルートのあいだに、トライアングルの一打が入る
- 1:06〜1:07: 0 の色の線はタムタムの一打（1:06）で止む。次の段 0 はセットに 0 がないので、61 から 72 まで有音程の線だけで登り、クラリネットの 72 が消えていく
- 耳で判断してほしい所: 0 の区間で、打楽器の一打と管の 61 が同じ一本の線として聴こえるか（そうなら「音程なし」と「同じ音」は同じ関係の二つの名前。いまは一打がまとまらないので、並べ方ではなく関係で判断できる）。開き直しで、別の格子に乗った二本に分かれたと聴こえるか、打楽器が伴奏に落ちて聴こえるか。最後の段で打楽器が止むのが、セットから 0 がなくなったこととして聴こえるか

## つまみ

- Rising set: 最初の段で線が登る間のセット。段ごとに全部が四分音ずつ 0 へ狭まり、また同じだけ開く。いちばん小さい間が、開く区間で 0 の色の線が続く長さも決める
- Standpoint: 起点。どの段もここから始まり、線はここへ閉じる（col legno もこの音を打つ）
- Zero notes: 間が全部 0 のまま起点にいる音の数。0 の色が輪に入っているのは、ちょうどこの区間。輪は一巡ごとに一つずらして始まるので、長くすると一巡の継ぎ目で 0 の色どうしが近づく（いまの順では 58 以上で、一打が二つ続く所が一か所できる）
- Rhythm: 一本の時間の線の間（16 分、組合せ二つずつ）。開いてからの 0 の色の線は、同じ組の二つを足して一つの間にし、5 連 16 分で数える
- Pitched order: 有音程の色の輪の順（bcl vc hn bells ob tbn vib fl va tpt cl bsn から、書いた順）
- Colours of 0: 0 の色の輪の順（vn2 bd trgl tt wb cym td から、書いた順）。0 の区間では、この順のまま有音程の色のあいだに均等に散らして入る
- Tempo
