# B · 0 で打楽器が線を継ぐ

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)
- 使っている A: [`ideas/lines/b-hand-off`](../../../ideas/lines/b-hand-off/README.md)（同じ音を受け渡す）。間の閉じ方は、同じ lines の [`ideas/lines/b-narrowing`](../../../ideas/lines/b-narrowing/README.md)（間が四分音ずつ縮む）と同じ

## 何をしたか

「同じ音を受け渡す」の仕組みを、無音程の打楽器が線に入ってくる入り口として使った。

- **間**は二つの音のあいだ。四分音の何個分かで数え、ここでは半音を 1、四分音を 0.5 と書く。0（同じ音）も間
- **線**は、起点（最初の音、立ち位置）に、規則がセット（間の集まり）から取り出した間を足していったもの。「同じ音を受け渡す」では、上行する線を楽器が一音ずつ受け渡す。段ごとにセットの間が全部四分音ずつ狭まり、最後は一つの音になる
- どの楽器が鳴らすかを、ここでは**色**と呼ぶ。次にどの色が鳴らすか（受け渡しの**輪**）は、音程とは別の規則で回り続ける
- **無音程の打楽器**は、音程の間のセットに 0 しか持てない楽器と見る（音の原則の表の一行目「セットが {0} だけ」の、音程の側）。これと、起点の音を打つだけの Vn II の col legno を合わせて、**0 の色**と呼ぶ（7 つ）
- 線のセットの間が全部 0 に閉じた所では、音程を持つ楽器と持たない楽器を分けるものが何もない。だからそこで、受け渡しの輪に 0 の色 7 つが加わる。音の高さのない一打が、有音程の楽器の起点の音と同じ列で、順番に鳴る
- 線が 0 から開き直すと、0 しか持てない色は付いていけない。0 の色は 0 のまま自分の線を続け、一本だった線が、音程の間が開いていく線と、0 のままの色の線の二本に分かれる

前提の二点目（同じ間 0 が、立つ側で「同じ音」とも「音程なし」とも呼ばれる）と、三点目（どの項も立たない切れ目で、新しいもの、ここでは色の線が定義される）を、「セットが {0} であるあいだだけ打楽器が輪に入る」という一つの関係で聴く。

## 仕組みと聴こえ方

### 段

- **段**は、起点から、セットの四つの間を書いた順（小さい順）に足した 5 音。段が替わるたびに起点へ戻る。段の最後の音が、その段のいちばん上の音
- 段を 0 から数えると、段 k の間は、セットの各間 b から四分音 k 個ぶん（0.5k）を引いたもの（0 より小さくはしない）
- 上行のセット {0.5 3 3.5 4}: .5 の付く間が二つ（0.5 と 3.5）、付かない間が二つ（3 と 4）。段が一つ進むたびに、0 でない間は全部 .5 の有無が入れ替わる（次の段は 0 2.5 3 3.5）。だから線はどの段でも二つの格子（四分音ずれた二つの半音の格子）を行き来する。いちばん広い 4 は四分音 8 つなので、閉じるのに 8 段、開くのに 8 段
- いちばん小さい間を atom（それ以上割らない最小の間）の 0.5 にした理由: 段のいちばん上の音は、起点に四つの間の和を足した所。0 でない間が四つあるあいだは、段ごとに和が四分音 4 つずつ減るので、いちばん上の音は起点と同じ格子の上を 2 ずつ歩く。0.5 は段 1 で 0 に閉じるので、段 1 から段 5 までは 0 でない間が三つになり、いちばん上の音は段ごとに四分音 3 つ（1.5）ずつ下がって、二つの格子を交互に踏む（72 → 70 → 68.5 → 67 → 65.5 → 64 → 62.5 → 61.5）。段の中の一歩一歩と同じく、段のいちばん上の音どうしも格子を渡る
- 最初に置いた値 {1.5 2 3.5 4} では、いちばん上の音が 72 → 70 → 68 → 66 と、起点と同じ格子の上を 2 ずつ四つ並び（手引きの落とし穴「一歩が偶数個の四分音だと、線が 12 平均律の音階に乗る」が、段のいちばん上の音の列で起こる）、段 2 ではふつうの格子に立つ音が起点・+4・+7 になった。和・個数・.5 の有無・いちばん広い間は同じなので、Rising set に入れれば聴き比べられる
- 起点 C♯4（61）: 12 の有音程の色がどれも出せる帯は 61〜72（下はチューブラーベルの録音の下端 61、上はトロンボーンの上端 72）。帯の幅 11 はセットの和（0.5 + 3 + 3.5 + 4）と同じなので、帯の下端から始めると、いちばん広い段がちょうど帯を満たす（61 → 72）。段ごとに起点へ戻るので、線はこの帯から出ない

### 三つの区間

1. **閉じる**（0:00〜0:27、40 音）: 段 0 から段 7 まで。有音程の 12 色だけが輪で回る。線の登りが段ごとに四分音ずつ縮む
2. **0**（0:27〜0:44、24 音）: 段 8 ではセットの間が全部 0 になる。この段を 24 音にのばしたのが 0 の区間で、音はすべて起点の 61。輪は 19 色（有音程 12 のあとに 0 の色 7）。有音程の色は 61 を次の鳴り始めまでのばし、0 の色は一打（16 分音符 1 つ）。col legno は 61 を打つ
3. **開く**（0:44〜、40 音）: 段 7 から段 0 まで、閉じた順を逆にたどる。鳴り始めごとに、有音程の輪の次の色が開いていく線を鳴らし、0 の色の輪の次の色が一打を同じ瞬間に鳴らす。最後の 72（フルート）が 4 拍のびて消え、打楽器も同じ鳴り始めで終わる

### 受け渡しの輪

- 次の音は、輪の次の色へ行く。輪の一巡は書いた順で、次の一巡は一つ後の色から始める（一巡ごとにずらす）
- チューブラーベルとヴィブラフォンは、ふつうの半音の格子の音しか出せない。四分音ずれた格子の音（.5 の付く音）が来ると、その色を飛ばして次の色へ行く（飛ばした分も輪は進む。「同じ音を受け渡す」と同じ）
- 輪が替わる所（0 に入る所、開き直す所）では、次に来るはずだった色から新しい輪を始める
- 0 の区間の 24 音 = 19 色の一巡 + 5 音。開き直しが輪の切れ目ではなく途中で始まる（開くのは段の規則、誰が鳴らすかは輪の規則で、二つは別）

### 仮の値

- 有音程 12 の順（書いた順）: バス・クラリネット、独奏チェロ、ホルン、チューブラーベル、オーボエ、トロンボーン、ヴィブラフォン、フルート、独奏ヴィオラ、弱音器のトランペット、クラリネット、ファゴット。隣り合う色がなるべく別の楽器の族（木管・弦・金管・金属の打楽器）になるように並べ（「同じ音を受け渡す」と同じ考え方）、一つの格子しか出せないベルとヴィブラフォンのあいだには 2 色を置いた（.5 の音で二つが続けて飛ばされない）。ただし、クラリネット → ファゴット → バス・クラリネット（一巡の終わりから次の一巡の頭へ）は木管が続く
- 0 の色 7 の順（書いた順）: Vn II の col legno、大太鼓、トライアングル、タムタム、ウッドブロック、サスペンデッド・シンバル、テナードラム。明るさや大きさでは並べていない。この順に構造の理由はまだない（仮）。col legno は、有音程の楽器が間 0 で打つ音で、二つの群の橋になる
- 時間: 16 分音符を atom（時間の間を数える単位。音の原則の「2 の仲間」）にして、時間の間のセット {2 3 3 4} から、組合せ（二つずつの組を辞書順に並べる）で取り出す。組は 2 3 / 2 4 / 3 3 / 3 4 なので、鳴り始めの間隔は 2 3 2 4 3 3 3 4（16 分いくつ分か）の繰り返しになる。「同じ音を受け渡す」と同じセットと規則。一巡（8 音）の和は 24 atom。「同じ音を受け渡す」の 3 連 8 分で数えるとちょうど 2 小節になり、句の頭が小節の頭にそろうので、16 分で数えた（一巡 6 拍）。三つの区間とも同じ一本の時間の線
- 強弱: 全部 p、アクセントなし、クレッシェンドなし。打楽器の加入と二本への分かれが、盛り上げに聴こえないように
- テンポ ♩ = 66（「同じ音を受け渡す」と同じ）

## 聴きどころ

- 前半（0:00〜0:27）: 上行の線が一音ずつ色を替えながら、段ごとに登りが四分音ずつ縮み、一つの音 61 になる。段のいちばん上の音は 72 → 70 → 68.5 → 67 → 65.5 → 64 → 62.5 → 61.5 と下がる（オーボエと弱音器のトランペットが交互に取る）
- 0:27〜0:44（8〜12 小節）: 線は 61 だけになる。クラリネットとファゴットの 61 のあと、col legno（61 を打つ）、大太鼓、トライアングル、タムタム、ウッドブロック、シンバル、テナードラムの 7 打が続けて来る（0:28〜0:33。そのあいだ管の 61 は鳴らない）。そのあと 61 が有音程の 11 色を回り（0:33〜0:40）、また col legno、大太鼓、トライアングル、タムタムの 4 打（0:41〜0:43）。音の高さのない一打が、管や弦の 61 と同じ輪の順番で鳴る
- 0:46（13 小節）: 有音程の線が四分音一つ（0.5、オーボエの 61.5）で 61 を離れる。直前のチューブラーベルの 61 がまだ響いている上に鳴る。その少し前（0:44）から、打楽器は有音程の 61 と同じ鳴り始めの上で、0 のまま続いている。線が一本から二本になる所
- 開ききった最後の 72（フルート）で有音程の線が終わり、打楽器（テナードラム）も同じ打ちで止まる
- 耳で判断してほしい所: 0 の区間で、打楽器の一打と管の 61 が同じ一本の線として聴こえるか（そうなら「音程なし」と「同じ音」は同じ関係の二つの名前）。開き直しで、二本に分かれたと聴こえるか、打楽器が伴奏に落ちて聴こえるか

## つまみ

- Rising set: 最初の段で線が登る間のセット。段ごとに全部が四分音ずつ 0 へ狭まり、また同じだけ開く
- Standpoint: 起点。どの段もここから始まり、線はここへ閉じる（col legno もこの音を打つ）
- Zero notes: 間が全部 0 のまま起点にいる音の数。0 の色が輪に入っているのは、ちょうどこの区間
- Rhythm: 一本の時間の線の間（16 分、組合せ二つずつ）
- Pitched order: 有音程の色の輪の順（bcl vc hn bells ob tbn vib fl va tpt cl bsn から、書いた順）
- Colours of 0: 0 の色の輪の順（vn2 bd trgl tt wb cym td から、書いた順）
- Tempo

## 事実

- 長さ 1:16（21 小節、♩ = 66）。`check.ts` は OK、警告 0。19 パート、144 音。`vp check` もエラー 0
- 鳴り始め 104（閉じる 40、0 が 24、開く 40）。すべて 16 分音符の格子の上（格子を外れる鳴り始め 0）。三つの区間で同じ一本の時間の線
- 段ごとの間: 閉じる 8 段と開く 8 段、計 16 段の四つの間が、すべて「各間 − 0.5k（0 で止まる）」どおり（食い違い 0）。どの段も起点 61 から始まる
- 段のいちばん上の音: 閉じる区間で 72, 70, 68.5, 67, 65.5, 64, 62.5, 61.5（下がり幅は 2 のあと 1.5 が五回、最後が 1）。開く区間はその逆順
- 0 の区間: 24 の鳴り始めがすべて 61、音程の間はすべて 0。有音程の音 13、0 の一打 11（同時に鳴る所 0）。7 つの 0 の色がどれも 1 回以上（col legno 2、大太鼓 2、トライアングル 2、タムタム 2、ウッドブロック 1、シンバル 1、テナードラム 1）。輪が 12 色のあとに 7 色を並べたものなので、0 の色は 7 打続けて来る（0 の区間の 3 音目から 9 音目、終わりの 4 音でもう一度）
- 閉じる区間の一打は 0（打楽器は、セットが {0} になるまで入らない）
- 開く区間: 40 の鳴り始めすべてで、有音程 1 音と 0 の色 1 打が同じ瞬間に鳴る（ずれ 0）
- 受け渡し: 連続する二音が同じ楽器に来る回数 0（一本の区間、開く区間の二本それぞれ、つなぎ目とも）
- ベルとヴィブラフォンに .5 の音 0。飛ばした回数はベル 3、ヴィブラフォン 1。有音程の音 93 のうち .5 の音 30
- 最初に 61 を離れる一歩 = 0.5（開き直しの最初の段の 4 歩目、13 小節目）
- 輪の規則をもう一度別に書いて楽譜と突き合わせた: 104 の鳴り始めすべてで、鳴らす楽器が一致
- 有音程の音が同じ楽器の族どうしで続くのは 92 回のうち 13 回（クラリネット → ファゴット 7、ファゴット → バス・クラリネット 6）
- 時間の間は 2 が 26 回、3 が 52 回、4 が 25 回。小節の頭に鳴り始めがあるのは 20 小節のうち 7。段の頭（起点へ戻る音）16 のうち、小節の頭に来るのは 2
- 音域: 線は 61〜72 の帯の中だけ。打楽器どうしが同じ瞬間に打つのは最大 2（開く区間で、ベルかヴィブラフォンと無音程の一打が重なる所、7 回）
- 強弱: 全パートが p。最後のフルートの 72 だけが 4 拍で niente へ
