## 何をしたか

前提の三点目（どの項も立っていない切れ目は、欠けではなく、新しいものが定義される場所になる）を、音の高さで使う。誰も弾けない中心が、輪の生まれる場所になる。

使った仕組みは「中心は誰も弾けない」。四分音の格子をつくる二つの半音の格子の、ちょうど真ん中に、どの楽器も出せない一点がある。そこを中心にして、中心から同じ距離の上と下に立つ二声の組が、空いている幅（二声のあいだの間）へ動く。中心は一度も鳴らない。

ここでは、その組を「輪」として使った。A から変えたこと、足したことは五つ。

1. **向きを外だけにした**: 輪は中心のすぐそば（二声が中心をはさんで立てる、いちばん狭い幅 0.5）で生まれ、外へ一歩ずつ広がり、いちばん広い幅で一周期たつと消える。A の規則「空いている幅へ移る」を、外へだけ、前を行く輪（一つ外の輪）に届かない所までに限った。届くなら待つ。輪どうしは触れず、追い越さない
2. **一歩の大きさをセットから取り出し、輪ごとに順をずらした**: 一歩で一声が動く量のセットは 1、1.5、2、2.5、3、3.5、4 半音。どの輪もこの七つを一回ずつ使うので、生まれる幅（0.5）と消える前の幅（35.5）はどの輪も同じで、あいだの幅は取り出す順で決まる。順は、七つを大きい方から並べ、輪ごとに一つ先から始める（毎回一つずらす規則）。だから最初の七つの輪は、どれも別々の幅の並びを通る
3. **生まれる時（滴）を時間の間のセットと規則にした**: 滴と滴の間のセットは 3、3、12 拍。これも毎回一つずらす規則で取り出す。3 拍の間が続く所で滴が群れになり、12 拍が群れと群れを分ける。10 滴で、群れは 3 滴、2 滴、2 滴、3 滴
4. **輪の速さは仲間だけで違う**: 時間の間は、素数の仲間（2・3・5）ごとに決まった一粒（atom）の何個分かで数える。どの輪も「自分の仲間の atom 11 個ごと」に動くが、仲間が違うので速さが違う。速い輪は、前を行く遅い輪に追いつくと、その後ろで待つ
5. **強さと色**: 強さは中心からの距離（外ほど弱い）。生まれる瞬間に、ハープが一台ずつ交互に、生まれた組の二音のうち自分の格子の方の一音を鳴らす（つまみで、前の版と同じ二台同時にもできる）

展開は、出来事の種類が変わることで作った。初めの群れで、何もない所に輪が三つ続けて生まれ、三つ目の滴は中心が空くのを待つ。そのあとは 3〜4 の輪が重なったまま、群れが来るたびに新しい輪が内側に入り、外では輪が一つずつ抜ける。生まれる輪ごとに、中心を離れる最初の一歩が小さくなり、速い輪は前の輪に追いついて、大きい一歩の手前で足踏みする。最後の群れでもう一度滴が待ち、そのあとは滴が来ず、残った三つの輪が外の端で詰まって足踏みし、一つずつ抜けて、何も鳴らなくなる。

## 仕組みと聴こえ方

### 言葉

- **間**: 二つの音のあいだ、または二つの鳴り始めのあいだ。音の高さの間は半音を 1 として数え、四分音は .5
- **格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。ふつうの半音の方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ。.5 の付く間をはさんだ二音は、別々の格子に立つ
- **中心**: 二つの格子のちょうど真ん中。どちらの格子からも四分音の半分離れた所（既定値では MIDI 番号で 66.25。66 が F♯4）。四分音より細かくは割らないので、どの楽器もこの高さは出せない。楽譜にも一度も書かれない
- **輪と幅**: 中心の上と下に一声ずつ、中心から同じ距離に立つ二声の組を「輪」と呼ぶ。輪の二声のあいだの間を「幅」と呼ぶ。幅 s の輪は、中心 − s/2 と中心 + s/2 を鳴らす。
  中心が格子の外にあるので、幅はどれも .5 付き（四分音で奇数個）になる。だから輪の二声は、いつも一声ずつ別々の格子に立つ
- **一歩とはしご**: 輪が外へ一回動くことを「一歩」、一歩で一声が動く量を「一歩の大きさ」と呼ぶ。二声が反対向きに同じだけ動くので、幅は一歩の大きさの 2 倍広がる。一つの輪が通る幅の並び（狭い順に 8 つ）を、その輪の「はしご」と呼ぶ
- **前の輪**: ある輪のすぐ外にいて、まだ鳴っている輪。輪は生まれた順に内から外へ並び、この順は変わらない
- **仲間と atom**: 時間の間を数える一粒（atom）は、素数の仲間ごとに一つ。2 の仲間は 16 分（1/4 拍）、3 の仲間は 3 連 8 分（1/3 拍）、5 の仲間は 5 連 16 分（1/5 拍）。一つの輪は、生まれてから消えるまで、一つの仲間の格子の上でだけ動く
- **周期**: 輪が次の一歩を試す間隔。自分の仲間の atom 11 個（2 の仲間で 2¾ 拍、3 の仲間で 3⅔ 拍、5 の仲間で 2⅕ 拍）
- **滴**: 輪が生まれること。滴の時刻は、拍で数えた間を 0 拍目から足していく
- **群れ**: 3 拍の間が続いて近くに並んだ滴のまとまり
- **待ち**: 一歩を試した時に、次の幅が前の輪の幅に届く（同じか、越える）ので、一周期とどまること

### 規則

- **生まれる**: 滴の時刻が来て、幅 0.5 に輪がいなければ、そこに輪が生まれる（二声が同時に）。いれば、空いたあとの、生まれる輪の仲間の格子の最初の目盛りで生まれる
- **広がる**: 輪は生まれてから一周期ごとに、自分のはしごの次の幅へ移ろうとする。次の幅が前の輪の幅より狭ければ、二声が同時に、反対向きに、同じ量だけ動く（グリッサンドなし）。届くなら待ち、一周期後にもう一度試す
- **一歩の順**: 七つの一歩を大きい方から 4、3.5、3、2.5、2、1.5、1 と並べる。1 番目の輪はこの順に、2 番目の輪は 3.5 から始めて 1 のあとに 4、3 番目は 3 から始めて 1、4、3.5 と進む。
  だから後の輪の最初の一歩は、前の輪の最初の一歩より四分音一つ小さい（1 のあとは 4 に戻る）。いちばん大きい一歩（4）は、1 番目の輪では最初、2 番目では最後（7 歩目）、3 番目では 6 歩目と、輪ごとに一つ前の位置へ来る
- **同時に来たら外から**: 同じ瞬間に移ろうとする輪がいくつかあれば、外の輪から先に動く（A と同じ順）。だから、外の輪が空けたばかりの所へ、内の輪がその瞬間に入れる。
  既定値では、同じ瞬間に移ろうとするのは 65 と 76 拍目の 2 回（どちらも 51.8 と 54 拍目に生まれた輪）。65 拍目は二つとも動き、76 拍目は二つとも待つ
- **消える**: いちばん広い幅 35.5 で一周期たつと、二声とも止まる
- 中心は動かず、鳴らない。どの音も、鳴らない一点からの距離としてしか決まらない

### 強さ

- 強さは幅で決まる。中心からの距離を強さに写した: 幅 0.5 で p、幅 35.5 で ppp、そのあいだは幅に比例する（強弱を 0 が無音、1 が ppp、2 が pp、3 が p の数で書くと、3 − 2 ×（幅 − 0.5）÷ 35）
- 一歩のあと、一周期かけて、前の幅の強さからその幅の強さへ線でつなぐ。待っているあいだは、その幅の強さのまま。弱くなるのは外へ動いた時だけで、足踏みしている輪は強さも止まる
- 密度が上がる所でも強さは足さない。どの声も p 以下で、頂点を作らない

### 色

- 輪の二声は弦。上の声はヴァイオリン、下の声はヴィオラ（とチェロ）。中心より上と下で楽器が分かれ、二つの群の境目がそのまま中心になる
- 生まれた輪の二音（66 と 66.5、中心をはさむ四分音一つ）は、一音が起点の格子、もう一音がずれた格子に立つ。固定の音しか出せないハープは、自分の格子の方の一音だけを鳴らす。
  ハープ I（ふつうの調弦、起点の格子）は 66、ハープ II（四分音低く調弦、ずれた格子）は 66.5
- 既定値（Harps が in turn）では、生まれるたびに一台ずつ、ハープ I から交互に鳴らす。二音は中心から同じ距離にあり、どちらか一方を「滴の音」とする理由がないので、順番に替える。どちらの格子も 5 回ずつ鳴り、二台が同時に鳴ることはない。
  Harps を together にすると、前の版と同じく二台が毎回同時に鳴らす（四分音一つの二音を同時に弾く）。聴き比べのために残した
- ハープが鳴るのは生まれる瞬間だけ

### 仮の値をなぜ選んだか

- **一歩の大きさ 1、1.5、2、2.5、3、3.5、4**: 前の版のはしご（A の幅のはしご 0.5、2.5、5.5、9.5、14.5、20.5 を外へ 2 段延ばしたもの）の、隣どうしの差をそのまま一歩のセットにした。1 から 4 まで、四分音一つおきのすべての大きさを一回ずつ持つ。
  .5 の付く一歩（1.5、2.5、3.5）では声が格子を移り、付かない一歩では同じ格子に残る。二声は反対向きに同じだけ動くので、輪の二声の格子はいつも別々のまま
- **いちばん広い幅 35.5**: 一歩の和 17.5 から決まる（0.5 + 2 × 17.5）。下の声のいちばん低い音 48.5 がヴィオラの最低音（48）のすぐ上に来る。上の声のいちばん高い音は 84
- **大きい方から並べる**: 後の輪の最初の一歩が、前の輪の最初の一歩より小さくなる向き。だから生まれた輪は、前の輪がまだ最初の幅にいても、一周期たてば外へ出られる。
  小さい方から並べると逆に、後の輪の最初の一歩がいつも前の輪の最初の幅を越え、生まれた輪は前の輪が二歩出るまで幅 0.5 で待つ。そのあいだ四分音一つの二声（66 と 66.5）が伸び続ける。
  同じ滴で試すと、弦が 66 と 66.5 を同時に鳴らしている長さは、大きい方からで 28.6 拍（全体の 31%）、小さい方からで 35.75 拍（41%）
- **毎回一つずらす**: 手引きの落とし穴「形を移すだけの反復進行」を避ける規則。どの輪も同じ七つの一歩を使うが、順が違うので、はしごのあいだの 6 つの幅が違う。七つの輪で一回りする。
  既定値の 10 の輪のうち、8〜10 番目は 1〜3 番目と同じはしごを、違う仲間（違う速さ）で通る。1 番目の輪（と同じはしごの 8 番目）だけは、一歩が大きい方から小さい方へ順に並ぶ
- **中心 66.25**: A と同じ
- **滴の間のセット 3、3、12 拍と、毎回一つずらす規則**
  - 前の版は、12 拍を 3 回、6 拍を 4 回、3 拍を 3 回の順に並べていて、滴の間が単調に縮んだ。そのため弦の声の数と鳴り始めの数が同じ向きに増え、64〜80 拍目（全体の 6〜7 割）を頂点とする一つの山になっていた（手引きの落とし穴「一方向の偏り」）
  - いまはセットから、毎回一つずらす規則で取り出す（3 3 12 ／ 3 12 3 ／ 12 3 3）。3 拍の間が続く所で滴が群れになり、12 拍が群れを分ける。一巡の和は 18 拍で、4 拍の小節の倍数ではない（一巡の頭は 0、18、36 拍目で、小節の頭に来るのは二巡に一度）
  - 3 拍は、三つの仲間の周期のあいだにある（5 の仲間 2⅕ 拍、2 の仲間 2¾ 拍 < 3 拍 < 3 の仲間 3⅔ 拍）。だから 3 の仲間の輪のすぐあと 3 拍で来た滴は、中心が空くのを待つ。既定値では、ほかの仲間の輪のあとの滴は待たない
  - 12 拍は、どの仲間の輪の寿命（下の「寿命」、17.6〜29⅓ 拍）よりも短い。群れと群れのあいだで輪が全部抜けることはなく、次の群れは、前の群れの輪がまだ外を広がっている所に落ちる
  - 3 を二つ持つのは、3 拍の間が続く所（3 滴の群れ）ができるようにするため
  - **10 滴**: この規則のちょうど一回り（12 拍の間が、一巡の中の三つの位置を一回ずつ通る）。群れは 3 滴、2 滴、2 滴、3 滴で、前と後ろが同じ形。
    滴が待つのは、3 の仲間の輪のすぐあとに同じ群れの滴が続く、最初と最後の群れ。最初は鳴っている輪が 2 つの所、最後は 3 つの所で待つ
- **仲間を 2、3、5 の順に回す**: 輪の速さの違いを、仲間の違いだけにした。同じ atom 11 個を三つの仲間で読むと、周期は 2¾ 拍、3⅔ 拍、2⅕ 拍。5 の仲間の輪（いちばん速い）が 3 の仲間の輪（いちばん遅い）のすぐ後に生まれると、追いついて待つ
- **周期 atom 11 個**: 11 は 2 でも 3 でも 5 でも割り切れない。だから輪の動きは、2 の仲間で 4 回に 1 回、3 の仲間で 3 回に 1 回、5 の仲間で 5 回に 1 回しか拍の上に来ず、一定の拍の刻みの上を歩かない。
  拍の上に生まれた輪が次に拍の上で動くのは 11 拍後で、4 拍の小節とはずれていく。手引きの落とし穴「時間の和が小節にそろう」を避けるための条件。
  この条件を満たす数のうち、11 は、滴の間 3 拍が三つの仲間の周期のあいだに入る、いちばん小さい数。7 だと周期は 1¾、2⅓、1⅖ 拍で、どれも 3 拍より短く、滴が待つ所が出ない（試した: 待った滴 0）。13 だと、3 拍より長い周期が二つになる（3¼ 拍と 4⅓ 拍）
- **寿命**: 待たなければ、輪は生まれてから消えるまで 8 周期（7 回の一歩と、いちばん広い幅での一周期）。2 の仲間で 22 拍、3 の仲間で 29⅓ 拍、5 の仲間で 17.6 拍
- **テンポ 60**: 1 拍が 1 秒。滴の時刻が、そのまま秒で読める

## 聴きどころ

- 0:00 にハープ I の 66 で最初の輪が生まれる。最初の輪は大きい一歩から始まり、2.75 秒ごとに一声 4、3.5、3 … 1 半音と、開く量を小さくしながら外へ広がる。0:19 に端（48.5 と 84）に着き、0:22 に消える。外へ行くほど弱くなる
- 0:03 と 0:06.8 に続けて輪が生まれる（最初の群れ）。ハープは II、I と交互に 66.5、66。0:06 の滴は、0:03 に生まれた遅い輪（3 の仲間、周期 3⅔ 秒）がまだ幅 0.5 にいるので、0:06.8 まで待つ
- 生まれる輪ごとに、中心を離れる最初の一歩が四分音一つずつ小さくなる（一声 4、3.5、3、2.5、2、1.5、1 半音。8 番目の輪で 4 に戻る）。後の輪ほど、中心のそばをゆっくり離れる
- 0:13〜0:31、0:06.8 に生まれた速い輪（5 の仲間）が、前の遅い輪に追いついて 5 回足踏みする。とくに 0:22〜0:29 は同じ幅で 3 回続けて待つ。次の一歩が、順が一回りして来たいちばん大きい一歩（4 半音）で、前の輪に届いてしまうから
- 0:18〜0:21 と 0:33〜0:36 は 2 滴ずつの群れ。どちらも待たずに生まれる。0:18 から 1:17 まで、輪は 3 つか 4 つ（弦 6 声か 8 声）重なったまま（0:21〜0:22 だけ 5 つ）。新しい輪が内に入るたびに、外で輪が抜ける
- 0:48〜0:54 は最後の群れ（3 滴）。0:51 の滴は、0:48 の遅い輪がまだ幅 0.5 にいるので 0:51.8 まで待つ。最初の群れと同じ待ち方だが、外にはすでに 3 つの輪がいる
- 1:05 に、0:51.8 と 0:54 に生まれた二つの輪が同じ瞬間に一歩出る（二つの輪が同時に動くのはここだけ）
- 1:07〜1:18 は外の端で詰まる。0:51.8 と 0:54 の輪は、それぞれ次の一歩が 4 半音で前の輪に届くため、止まったまま（4 回と 3 回の足踏み）。
  外の 0:48 の輪だけが 1:10 と 1:13.7 に一歩ずつ出て、1:17.3 に消える。そのあと二つが続けて外へ出て、1:20.4 と 1:24.25 に消える。1:32 まで何も鳴らない
- 中心 66.25 は一度も鳴らない。いちばん近いのは、生まれる瞬間の 66 と 66.5
- **耳で判断してほしい点**
  - ハープの一音を「中心の音」と聴いてしまわないか。鳴っているのは中心ではなく、中心をはさんで両方の格子でいちばん近い二点の、どちらか一方
  - 弦は、生まれる輪ごとに 66 と 66.5（四分音一つ）を一周期（2.2〜3.7 秒）伸ばす。合わせて 28.6 秒（全体の 31%）。構造のうえで中心にいちばん近い二項として置いたが、うなりやざらつき、つまり四分音の効果として聴こえるかもしれない。いまは外していない。
    ハープは既定値では一台ずつなので、ハープがこの二音を同時に打つことはない。Harps を together にした版（前の版と同じ）と聴き比べてほしい
  - ハープが交互に 66 と 66.5 を鳴らすので、群れの中では、四分音一つ上下する一音が 3 秒ほどおきに聴こえる。揺れとして聴こえないか
  - 別々の輪の声どうしが四分音一つまで近づく所が 3 か所ある（9〜10⅓、54〜55⅓、65〜66⅓ 秒。上の声どうしと下の声どうしが同時に）。規則は届くことだけを止めるので、四分音一つまでは近づける
  - はしごは輪ごとに違うが、七つで一回りする。8〜10 番目の輪は 1〜3 番目と同じ音の並びを、違う速さで通る。同じものの繰り返しに聴こえないか

## 楽器

- ハープ I（ふつうの調弦）、ハープ II（四分音低く調弦）: 生まれる瞬間に一音、p、l.v.（響きを止めない）。既定値では交互に、ハープ I は 66 を 5 回（0、6.8、21、36、51.8 拍目）、ハープ II は 66.5 を 5 回（3、18、33、48、54 拍目）
- 弦: arco、ふつうの弾き方、non vib.（ヴィブラートなし）
  - 輪の上の声は、ヴァイオリン I の 1〜4、ヴァイオリン II の 1〜4（人数は 4、4、4、4 と 4、4、3、3）のうち、生まれた時に空いている、番号のいちばん小さいパート

## つまみ

- **Steps**: 一歩の大きさのセット（半音）。どの輪も各一回ずつ使う。大きい方から並べ、輪ごとに一つ先から始める（毎回一つずらす）。いちばん広い幅は 0.5 + 2 × 和
- **Centre**: 中心は、この音の四分音の半分上（既定値 F♯4 → 66.25）
- **Period**: 周期（自分の仲間の atom の数）。既定値 11。2・3・5 で割り切れる数にすると、その仲間の輪がもっと頻繁に拍の上を歩く
- **Families**: 輪の仲間を、生まれる順に回す（既定値 2 3 5）
- **Drops**: 滴と滴の間のセット（拍）。毎回一つずらす規則で取り出す。最初の滴は 0 拍目（既定値 3 3 12）
- **Count**: 滴（輪）の数（既定値 10）
- **Harps**: in turn（一台ずつ交互、既定値）か together（二台同時）
- **Tempo**: テンポ
