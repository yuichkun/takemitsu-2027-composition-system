## 何をしたか

A の仕組み（間は大きさを変えず、隣どうしで位置だけが入れ替わる）に、音色の決め方を一つ足した。

**各声の音色は、その声の下の間が付ける名前。** 下の間が狭い声は弦で、広い声は金管で鳴る（境目はつまみ Strings up to、仮の値は 3 半音）。

二つの間が入れ替わると、あいだの一声が動く。そのすぐ上の声は、音の高さを変えないまま下の間だけが替わる。だから、動かない音が色だけ変えることがある。弦と金管が同じ音の上で交差する。

## 形（1 分 28 秒）

1. **登り（練習番号 back の前）**: 始めは狭い間が下にある。低い弦の固まり（D2 のあたり）の上に、金管の開いた和音。A と同じ波で固まりが一声ずつ持ち上がり、金管の中を通って上へ出る。最後は金管が下、弦が上
2. **戻り（back から）**: 小節線で仲間を 3 から 5 に替えて、並びを戻す。一歩ごとに、隣の組を一つおきにまとめて入れ替えるので、数声が同時に動く。少し大きく鳴り、最初の和音に戻って消える

- いちばん下（立ち位置）はコントラバスで、最後まで同じ音
- いちばん上も最後まで同じ音。色だけがトランペット → ヴァイオリン → トランペットと替わる

## 聴きどころ

- 同じ音のまま、金管から弦へ（弦から金管へ）受け渡される所
- 低い弦の固まりが、金管の中を抜けて上に出ていく過程
- 戻りで数声が一度に動くときの、一声ずつとの手応えの違い
