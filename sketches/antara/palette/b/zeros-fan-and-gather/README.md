## 何をしたか

前提の三点目（どの項も立っていない切れ目は、欠けではなく、新しいものが定義される場所になる）を、音程の 0 で試す。
0 は「同じ音をもう一度」という間で、欠けに見える。ここではその 0 が、一本の線から和音を作る場所になる。

使った仕組みは「0 が増える」。一本の線が、間のセットから規則で間を一つずつ取り出して進む。間の大きさは変えずに、段ごとにセットへ 0 が一つずつ加わる。
0 が増えるほど線は同じ音を踏み直すようになり（足踏み）、最後の段ではセットが 0 だけになって、線は一つの音にとどまる。

ここでは、その段を時間の順に並べるのではなく、**同時に鳴る 7 声に並べた**。0 を持たない声、0 を 1 つ持つ声、…、0 を 6 つ持つ声。
7 声はみな同じ一本の線を弾き、違うのは 0 の数だけ。0 を取るたびに、その声は同じ線の上で一歩遅れる。
だから 7 声は、一本の線の別々の点を同時に鳴らすことになり、線が自分の点でできた和音になる（一本の線を何人かが少しずつずれて同時に弾く形、ヘテロフォニー）。

後半では 0 の意味が替わる。広がる段の 0 は足踏み（同じ音を打ち直して遅れる）。集まる段の 0 は待つこと（音を打ち直さず、伸ばしたまま先へ進まない）。
先頭の声が待ち、遅れた声が同じ線を歩いて追いつき、最後はセットが 0 だけになる。

## 仕組みと聴こえ方

### 言葉

- **間**: 二つの音のあいだ。半音を 1 とした数で書く（.5 が四分音一つ、マイナスは下向き）。0（同じ音）も間
- **セット**: どの間を、いくつずつ持つか
- **規則**: セットから、次にどの間を取り出すか。ここでは「一巡ごとにずらす」だけを使う。セットを書いた順に回し、一巡するたびに始める所を一つ後ろにずらす
- **立ち位置**: 線の最初の音
- **線と点**: 線は、立ち位置に、規則が取り出した間を順に足した音の列。その一つ一つの音を点と呼び、立ち位置から何歩目かで位置を言う
- **帯**: 線が動いてよい音域。一歩で帯を出てしまうときは、その間を逆向きに取る（符号を返す）
- **格子**: 四分音まで数えると、音の高さの目盛りは、四分音ずれた二つの半音の目盛りになる。これを二つの格子と呼ぶ。.5 の付く間は線をもう一方の格子へ移す
- **atom と仲間**: 時間の間を数える単位。素数の仲間ごとに一つあり、3 の仲間の atom は 3 連 8 分
- **刻み**: 全員が共有する鳴り始めの目盛り。時間の間を一つだけ持つセット（パルス）で、ここでは 3 の仲間の atom 2 つ（3 連の 4 分）。1 小節に 6 刻み、♩ = 60 で 1 刻み約 0.67 秒
- **遅れ**: 先頭の声（0 を持たない声）と比べて、線の上で何歩後ろにいるか
- **段**: このカードでは二つの意味で使う。「0 が増える」の段は、セットの 0 が一つ増えるごとの状態（0 が k 個の段）。このスケッチの段は、下の「四つの段」（ユニゾン、広がる、集まる、0 だけ）。前者は 7 声に、後者は時間の順に並ぶ

### 線

線のセットは {3.5, −1.5, 1, −4, 0.5}（書いた順に意味がある）。立ち位置は G♯4、帯は C4〜F5。
線は G♯4 から、B+4（B4 の四分音上）、A♯4、B4、G4、… と進む。58 歩目の一歩だけが帯の下へ出るので、そこで一度だけ向きを返し、C4〜C♯5 のあいだを動く。

### 声ごとの 0

各声は、「一歩進む」を 5 つ（線の間の数）と、0 を自分の数だけ持つセットから、同じ規則「一巡ごとにずらす」で一つずつ取り出す。
一歩進むなら線の次の点へ、0 なら同じ点にとどまる。セットの中身（間 5 つに、その声の数だけの 0）は、「0 が増える」で 0 がその数まで増えた段と同じ割合になる。

「0 が増える」との違いが一つある。あちらでは 0 以外の間もその段のセットから取り出すので、段ごとに線の形が変わる。
ここでは 0 以外はどれも「同じ線の次の一歩」として取るので、7 声はずっと同じ一本の線の上にいる。違いは 0 がどこに入るかだけになる。

だから、二つの声の縦の間は、線が二つの点のあいだで歩いた間の和になる。
たとえば広がる段の終わりで、ヴァイオリン I は 76 歩目の C5、フルートは 65 歩目の A+4（A4 の四分音上）にいる。そのあいだの縦の間 2.5 は、線が 65 歩目から 76 歩目まで歩いた 11 の間の和。

### 四つの段（1 分 20 秒、20 小節、♩ = 60）

段の始まりは、その段の間を取り出し始める音で数える（前の段の最後の音でもある）。

1. **ユニゾン（1 小節目から）**: 7 声が同じ線を一緒に歩く。線のセットを 2 巡（10 歩）。始めの 11 刻みは、7 声がいつも同じ音
2. **広がる（2 小節目の 5 つ目の刻みから）**: 各声が自分のセットから取り出し始める。0 は同じ音の打ち直しで、そのぶん声は遅れる。7 色のユニゾンが声ごとの足踏みでずれていき、線の別々の点が同時に鳴る和音になる
3. **集まる（13 小節目の 5 つ目の刻みから）**: 先頭の声（ヴァイオリン I）はいる所で止まる。ここでの 0 は待つことで、音をタイで伸ばし、打ち直さない。
   ほかの声は 1 刻みに一歩ずつ線を歩き、先頭の声が通った道を後からたどって、同じ音に一人ずつ着く。着いた声も待つ。
   各声が着くまでの刻みの数は、広がる段でその声が取った 0 の数に等しい（遅れを返すだけ）
4. **0 だけ（19 小節目の 5 つ目の刻みから）**: 最後の声（チェロ）が着いた所から、7 声が一つの音を 4 刻み伸ばし、消える

強弱は下がるだけ。ユニゾンと広がる段は p のまま（クレッシェンドなし）、集まる段で pp へ、0 だけの段で niente へ。着く声にアクセントは付けない。
待つ 0 はタイなので、集まる段では打つ声が 7 から一人ずつ減っていき、最後は誰も打たない。刻みで盛り上げを作らないため。

似て見えるものとの違い: 「一つずつ遅れる」（ideas/lines の a-late-by-one）は時間の間が声ごとに増えて、和音が線に倒れる。こちらは時間の間は全員同じで、音程の 0 が増えて、一本の線が自分の点の和音になる。

### 仮の値の理由

- **線のセット {3.5, −1.5, 1, −4, 0.5}**: .5 の付く間が 3 つ（3.5、1.5、0.5）と付かない間が 2 つ（1、4）。狭い間が 3 つ（0.5、1、1.5）と広い間が 2 つ（3.5、4）。上がる間が 3 つと下がる間が 2 つ。
  和は −0.5（四分音一つ）なので、線は一巡しても四分音一つしか動かず、帯からほとんど逃げない（返るのは 1 回だけ）。
  そのため、線の上で遠い点どうしも音の高さは近く、7 声の和音は狭い間で詰まる（下の「事実」）
- **書いた順**: 規則は書いた順に回すので、順もセットの一部として効く。同じ五つの間を小さい順に並べると、別の線になる
- **帯 C4〜F5**: 7 声が全員同じ帯で同じ線を弾くので、帯は 7 声の共通の音域にした。下の端 C4 は、再生に使う BBC Symphony Orchestra の音で 7 つの楽器がどれも鳴る所の下の端（フルートの音が C4 から。楽器としてのフルートは B3 まで出る）。
  はじめの案は立ち位置 G4、帯 B3〜F5 だった。再生の音の外に出るので、立ち位置と帯の下の端をそろって半音上げた。線の間も、返る一歩も、声どうしの関係も変わらない（線が半音上に移るだけ）。
  上の端 F5 には、仮の値の線は届かない（上で返るのは、Line を変えたときだけ）
- **立ち位置 G♯4**: 線のいちばん低い点は立ち位置の 8 半音下に来る。それが帯の下の端にちょうど届く所に置いた。線は帯をいちばん低い所まで使い、58 歩目で一度だけ返る
- **7 声**: 「0 が増える」の段の数（0 が 0 個から 6 個まで）そのもの
- **広がる段の長さ（Fan 6 巡、66 刻み）**: いちばん遅い声のセット（一歩が 5、0 が 6、合わせて 11）を、ちょうど 6 巡する所で止めた。巡りの切れ目で止めるので、その声の遅れは 0 の数 × 巡の数（6 × 6 = 36 歩）になる。
  この長さのうちに、7 声が全部違う音になる刻みが 16 回現れる（集まる段の始めまで含めると 21 回）
- **集まる段の長さ**: 決めていない。いちばん多く 0 を取った声が追いつくまでで、その長さは取った 0 の数（36 刻み）に等しい
- **時間**: 間を一つだけ持つセット（パルス）にした。時間の関係を全員同じにして、声どうしの違いを音程の 0 だけにするため。
  3 の仲間の atom 2 つなので、拍の頭と重なるのは 3 刻みに一度（2 拍ごと）
- **色**: 遅れの順に、弦と木管を交互にした（ヴァイオリン I、フルート、ヴァイオリン II、オーボエ、ヴィオラ、クラリネット、チェロ）。
  7 声が同じ帯で同じ線を弾くので、音域では分けられない。遅れが隣どうしの声は線の上で近い点にいることが多く、音も近い（測ると、ほかの組より平均で 0.6 半音近い）。隣どうしの色を変えて、聴き分けられるようにした

## 聴きどころ

- 7 色のユニゾンの一本の線が、声ごとの足踏みでずれていき、同じ線の別の点が同時に鳴る和音になること。和音の間は、線がいま歩いた間の和
- 集まる段で、先頭の声が伸ばす音へ、遅れた声が先頭の通った道を後からたどって一人ずつ着き、色が一つの音に集まること。着く順はフルート、ヴァイオリン II、オーボエ、ヴィオラ、クラリネット、チェロ
- 最後に 0 だけになって消えること

## 楽器

全員が同じ帯（C4〜F5）で同じ線を弾く 7 声。

- ヴァイオリン I（16 人）: 0 を持たない先頭の声
- フルート 2（ア・ドゥエ）: 0 を 1 つ
- ヴァイオリン II（14 人）: 0 を 2 つ
- オーボエ 2（ア・ドゥエ）: 0 を 3 つ
- ヴィオラ（12 人）: 0 を 4 つ
- クラリネット 2（ア・ドゥエ）: 0 を 5 つ
- チェロ（10 人）: 0 を 6 つ

木管を 2 本ずつにしたのは、広がる段で休みなく吹き続けるため（二人で息を分けられる）。

## つまみ

- Line: 線のセット（書いた順）
- Standpoint: 立ち位置（線の最初の音）
- Band: 帯。出る一歩は逆向きに取る
- Fan: 広がる段の長さ。いちばん遅い声のセットの巡の数。集まる段の長さはこれから決まる
- Pulse / Family: 刻み（パルスの間を何 atom にするか、どの仲間で数えるか）
- Tempo

## 作曲の段で考える点（いまは狭めない）

- ヴァイオリン I は集まる段の始めから終わりまで、一つの音を 26.7 秒伸ばす（pp から niente へ）。弓の返しや、プルトのあいだの受け渡しを考える。フルートも 19.3 秒伸ばす
- 木管は最初から最後まで休みがない（77 秒）。着くまでは歩みと同音の打ち直し（フルート約 58 秒、オーボエ約 68 秒、クラリネット約 72 秒）、着いてからは伸ばし。2 本で息を分ける書き方を考える
- どの声も線の四分音の点を全部弾く（各声の音の約半分）。木管は替え指、p の同音の打ち直しの中で
- 帯の下の端の C4 と C+4（C4 の四分音上）: フルートとオーボエの低い端で、p の四分音。オーボエは低い音を小さく出しにくい
- 釣り合い: 7 声が同じ帯の同じ強弱（p）で鳴るので、2 本ずつの木管（とくに低い音域のフルートとクラリネット）が、弦のセクション全員（52 人）に隠れやすい。
  色で聴き分けるのがこのスケッチの前提なので、弦の人数や、色ごとの強弱の差を考える
- 弦の足踏み（同じ音の打ち直し）を、弓を返すか、ポルタートにするか
- ユニゾン → 広がり → 一つの音、という形が、盛り上げてユニゾンで打つ型に聴こえないか。強弱は下げ、打つ声は減らし、着く所にアクセントを付けていない。聴いて確かめる
