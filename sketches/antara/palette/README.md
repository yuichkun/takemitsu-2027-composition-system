# antara のパレット

曲のアイデアを、スケッチの単位で幅広く集める場所（2026-09-29 から）。
つまみで変化を出すのではなく、スケッチ自体を分けて、仕組みから違うものを並べる（余湖さん）。

- **A（一つの課題）**: 一つのことだけを、わかりやすく試す。複合的にしない。方法そのものが使えるかを、混じりけなく判断するため
- **B（使ってみた例）**: A の方法を実際の場面で使ってみる。中編成〜大編成で、展開を作りながら。具体的な使い道を、音楽のアイデアとして拾うため

作る人は、先に [`GUIDE.md`](./GUIDE.md)（手引き）を読む。前提は [`docs/antara/premise.md`](../../../docs/antara/premise.md)、音の原則は [`docs/antara/sound.md`](../../../docs/antara/sound.md)。
一覧の元は [`ledger.json`](./ledger.json)（この README は台帳から書き出している）。

いま A 37 本、B 27 本。

## 落とした案

作る前か、作ったあとの見直しで落としたもの。理由つき。

- B・配器「上りの面と下りの面」: 「弦が走る」の仕組みを使う案。余湖さんが「この例はもういい、全然違う方向を試そう」と言った方向なので、今夜は使わない
- B・複合「大きさの違う三つの鐘」: 「仲間ごとに抜けていく」と同じ仕組み（一人ずつ離れるを三群で重ねる）の近い案。三群の違いを明るさ（名前のある対比）で付けているので、仲間（原則）で違いを付けた方を残した
- B・音高「残る間が声を増やす」: 厚みの満ち引きを、案自身が「大きな高まりの一部」と呼んでいて、盛り上げの型に近い。人数を増やす規則も、使う A の外から足した二つ目の仕組み
- B・配器「.5 が決める、どの鍵盤が鳴るか」: 「格子が決める、誰が弾けるか」と同じ A を同じ使い方（格子で楽器を決める）で使う近い案
- B・配器「和音が色を編み直す」: A「交差して入れ替わる色」を 3 色に広げただけに近い。同じ A を使う「床を渡る光」の方が、形として新しい
