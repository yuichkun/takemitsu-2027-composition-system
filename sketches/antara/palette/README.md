# antara のパレット

曲のアイデアを、スケッチの単位で幅広く集める場所（2026-09-29 から）。
つまみで変化を出すのではなく、スケッチ自体を分けて、仕組みから違うものを並べる（余湖さん）。

- **A（一つの課題）**: 一つのことだけを、わかりやすく試す。複合的にしない。方法そのものが使えるかを、混じりけなく判断するため
- **B（使ってみた例）**: A の方法を実際の場面で使ってみる。中編成〜大編成で、展開を作りながら。具体的な使い道を、音楽のアイデアとして拾うため

作る人は、先に [`GUIDE.md`](./GUIDE.md)（手引き）を読む。前提は [`docs/antara/premise.md`](../../../docs/antara/premise.md)、音の原則は [`docs/antara/sound.md`](../../../docs/antara/sound.md)。
一覧の元は [`ledger.json`](./ledger.json)（この README は台帳から書き出している）。

いま A 16 本、B 6 本。

## 共通のコード

- [`common.ts`](./common.ts): 線のスケッチの道具（[`../ideas/lines/common.ts`](../ideas/lines/common.ts)）に、弦の分奏の割り振り、楽器を低い方から配る、同じ楽器の番号、強弱の曲線を足したもの
- [`trade.ts`](./trade.ts): 間が入れ替わる計算（一声ずつの波、数声ずつの歩み）
- 楽譜の確かめ: `vp node src/sketch/check.ts <スケッチのフォルダ>`（プレビューと同じ警告を出す）
