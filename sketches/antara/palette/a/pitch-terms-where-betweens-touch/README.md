# A · 間が触れた所に項が立つ

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

間は、その両端の音（項）より先に鳴れるか。

和音の間を一つずつ、二人で同時に弾く二音（組）として入れる。二音はそろって滑り、滑っているあいだはどちらの音もどの高さにも止まらない。
組の端が、すでに立っている音か、もう一つの組の端に触れた瞬間（同じ高さになった瞬間。高さの間、つまり音程の間が 0 になった瞬間）にだけ、二音は止まって項になる。
立ち位置（和音を測りはじめる最初の一音）は鳴らさない。最初の二つの組が触れた所が、最初の項になる。

前提の一つ目（関係（切れ目）が先にあり、項は後から付く名前である）を、和音の始まり方として試す。

## 仕組みと聴こえ方

- **間**: 二つの音のあいだ。高さのあいだ（音程の間）は半音単位で書き、四分音は .5。鳴り始めどうしの間隔も同じく間と呼び、時間の間と言う
- **項**: 間の両端に立つ音。ここでは、ある高さに止まって伸びている音を項と呼ぶ
- **ふつうの順番**: 和音は、立ち位置（最初の一音。音を測りはじめる所）に間を積んだもの。項が先にあり、そこへ間を足して次の項が決まる。このスケッチはこの順番を逆にする
- **組**: 和音の間一つを、二つの分奏（弦のセクションを人数で分けたパート）が同時に鳴らす二音。時間の間が 0 の二音
- **滑る**: 組の二音は、入った瞬間からもう滑っている（グリッサンド）。二音は同じ時間で同じ距離を滑るので、組の中の間の大きさはずっと同じで、どちらの音もどの高さにも止まらない。
  この状態の組を「項のない間」と呼ぶ。一定なのは間の大きさだけで、項はまだどこにも立っていない
- **触れる**: 組の端が、すでに立っている項か、もう一つの組の端と同じ高さになる（音程の間が 0 になる）こと。
  触れた瞬間にだけ、組の二音は止まり、そのまま最後まで伸びる。ここで二音は項になる
- **最初の項**: 立ち位置は鳴らさない。最初の二つの組が触れた所が、最初の項になる。
  計算の上ではその高さ（つまみの First contact、既定値 68.5。高さはこのカードではどこでも実音の MIDI 番号で、60 が中央の C、.5 は四分音）から和音の間を測るが、鳴る順番の上では、そこには最初の 4.8 秒、何も立っていない
- **二つの腕**: 和音の間を、最初の項から下へ向かう**下の腕** {1, 2.5, 4, 5.5} と、上へ向かう**上の腕** {1.5, 3, 4.5, 6} に分けて持つ。
  どちらの腕も、狭い間ほど最初の項の近くに来る。完成する和音は、下から 55.5、61、65、67.5、68.5、70、73、77.5、83.5 の 9 音
- **ずらし**: 各組は、止まる所から和音の外側へ、自分の間の大きさだけずれた所から入る。下の腕の組は下から、上の腕の組は上から来る。
  だから滑る距離も自分の間の大きさ。組が持っている長さはそれしかないので、外から別の長さを持ち込まない
- **規則**: はじめに、下の腕と上の腕のいちばん狭い組（1 と 1.5）が同時に入り、互いに向かって滑って、最初の項の高さで触れる。
  そのあとは一組ずつ、上の腕、下の腕、と交互に、内から外へ。前の組が触れた瞬間に次の組が入り、いまの和音の上の端（上の腕）か下の端（下の腕）へ向かって滑り、同じ時間で触れる
- **触れた所は同音の二人**: 触れる二音は同じ高さなので、内側の 7 つの項は二人（二つの分奏）で、外側の二つは一人で鳴る。
  一度触れるごとに新しく立つ項は一つだけ。組の近い側の端は、すでに立っている項に重なり、遠い側の端が新しい項になる（最初に触れる所だけは、二組の四音が三つの項になる）
- **触れる時刻**: 組が滑る時間は全部同じ（3 の仲間の atom 12 個。atom は時間の間を数える、素数の仲間ごとの最小の粒で、3 の仲間は 3 連 8 分）。
  だから触れる時刻は、時間の間を一つしか持たないセット（セットは、どの間をいくつずつ持つか。一つしか持たないものがパルス）になる。時間の規則は聴こえず、定義の順番だけが聴こえるようにした
- **強弱**: 各組は niente（無音）から入り、触れる瞬間に pp に届き、あとは pp のまま。niente は、滑りの出発点が項として聴こえないため。最後は全員が pp のまま同時に止まる
- 和音が一定の間隔で一つずつ育つ形は [霜が育つ和音](../pitch-frost-freeze/README.md) に似て見えるが、あちらの課題は次にどの切れ目を選ぶか。
  ここでは和音は先に決まっていて、課題は「間が先、項が後」という定義の順番だけ

### 仮の値をなぜ選んだか

- 二つの腕に 4 つずつ。どちらの腕も、外へ行くほど 1.5（四分音三つ）ずつ広くなる（1, 2.5, 4, 5.5 と 1.5, 3, 4.5, 6）。
  だから新しく滑って来る間は、いつもその側でまだ聴いていない広さになる
- 上の腕は、同じ距離にある下の腕の間より四分音一つ広い。両腕が同じ大きさの間を持つことはなく、和音は最初の項を軸にした鏡にならない
- 同じ距離では片方の腕だけが .5 を持つので、項は二つの格子（四分音の格子をつくる、四分音ずれた二つの半音の格子）に分かれて立つ。
  最初の項と同じ、.5 の付く格子に 5 つ、付かない格子に 4 つ
- 組が滑る距離は自分の間の大きさ（上の「ずらし」）。滑る時間は全部同じにして、触れる時刻をパルスにした
- 最初の接点 68.5: 完成した和音の真ん中（最初の項より 1 上、69.5。上の腕の和 15 と下の腕の和 13 の差の半分）が、弦の音域 36〜103（チェロの下の端からヴァイオリン I の上の端まで）の真ん中 69.5 に来るように。
  最初の項が .5 の格子に落ちたのは、その結果
- 滑る時間: 3 の仲間の atom 12 個 = 4 拍、テンポ 50 で 4.8 秒。滑っている組が、項のない間として聴き取れるだけの長さ。
  12 個でちょうど 1 小節なので、触れる時刻はどれも小節の頭（すべての仲間の格子が重なる所）に落ちる。
  出来事の頭がいつも小節の頭に来る形だが、小節の中には何も起こらない（触れる時刻のほかに、時間の上の出来事がない）ので、拍が割られて聴こえることはないはず
- どの値も、和音や音程の名前では選んでいない

### 原則を広げて読んでいる所（余湖さんに確かめてほしい読み）

- **滑っている二音を「項のない間」と読むこと**: 原則の間は「二つの音のあいだ」。ここでは、両端がどこにも止まっていない二音を、もう間として数えている
- **滑る途中の位置は格子の外を通る**: 組の中の間（1, 1.5, …）と、止まった所（項）は、どれも四分音の格子の上にある。
  けれど滑っているあいだの位置は、四分音より細かい所を連続して通る。滑っている組の端と、立っている和音の端とのあいだの間も、組の間の大きさから 0 へ連続して縮み、四分音の目盛りのあいだを通る。
  原則の「四分音より細かくは使わない」が、止まらずに通り過ぎる位置にも及ぶのかは、原則ではまだ決まっていない。ここでは「止まる所と間の大きさだけが atom で数えられればよい」と読んでいる
- **時間の間の 0**: 組の二音は、時間の間が 0 の二音（原則ではまだ決まっていない。試してよいとされている所）

## 聴きどころ

- 0:00〜0:05: 二つの組（1 と 1.5）が niente から、互いに向かって滑るだけ。下の組は上へ、上の組は下へ。二組のあいだは 2.5 から 0 へ縮む。どの高さにも、何も止まっていない
- 0:05（4.8 秒）: 二組が 68.5 で触れ、三つの音（67.5、68.5、70）が同時に立つ。68.5 は二人の同音。同じ瞬間に、上から 3 の組が niente で滑りはじめる
- そのあと 4.8 秒ごとに、外側から一組が滑って来て、鳴っている和音の端に触れた瞬間に新しい項が一つ立つ。上、下、上、下と交互に、だんだん広い間が来る。
  新しい項は 73（9.6 秒）、65（14.4 秒）、77.5（19.2 秒）、61（24.0 秒）、83.5（28.8 秒）、55.5（33.6 秒）
- どの組も同じ時間で滑るので、広い組ほど速く滑る（いちばん遅い 1 の組で 1 秒に 0.21 半音、いちばん速い 6 の組で 1.25 半音）
- 0:34〜0:43: 完成した 9 音の和音が pp のまま伸び、43.2 秒で全員が同時に止まる
- **耳で判断してほしい点**
  - 滑っているあいだ、間の広さ（狭い・広い）が、高さの名前なしに聴き取れるか
  - 触れた瞬間が「音が生まれる所」として聴こえるか
  - 4.8 秒からあとは、立っている和音の外側を一組だけが滑る。そのとき耳に入るのは、組の中の一定の間だけでなく、組の近い側の端と和音の端とのあいだで縮んでいく間でもある。どちらが前に出て聴こえるか
  - ずらしが自分の間の大きさなので、どの組も、近い側の音は、その組がのちに立てる新しい項の高さから滑りだす。niente の中なので項としては聴こえないはずだが、耳で確かめてほしい
  - 同じ高さに近づく最後の瞬間に、うなりが出る。触れる瞬間の音響の副産物で、狙ったものではない（四分音を揺れとして置いてはいない）
  - 滑りは、色のための滑りではなく「項のない間」という状態そのもの。距離は自分の間、時間は全部同じ。それでも音塊が滑る常套の効果として聴こえてしまうかどうか
  - 滑っている組は、触れるまでずっと、立っている和音の一つひとつの声（pp）より弱い（niente から pp へ上がる途中）。
    そのかわり、いつも和音の外側（上の腕の組は和音より上、下の腕の組は和音より下）にいる。埋もれずに聴こえるか
  - 鳴っている人数（12 人から 52 人）、全体の幅（3.75 から 28）、滑りの速さ（おおむね 0.21 から 1.25）が、そろって増えていく。
    一つひとつの声は pp のままだが、盛り上げの形に聴こえないか
  - 最初の項を含まない方の格子に立つ 4 音（61、65、70、73）は、隣どうしの間が 4、5、3。平均律の音名で言えば、D♭・F・B♭・D♭ という短三和音の形になっている。
    14.4 秒からは 65、70、73 が、あいだに 67.5 と 68.5 を挟んで同時に立つ。値はこの名前のために選んだのでも、避けたのでもない（関係の結果）。和音がこの名前の側に聴こえるかどうか

## つまみ

- Lower arm: 下の腕の間（半音、.5 は四分音）。つまみは値を小さい順に並べるので、腕の中の順番はいつも、狭い間が内側（最初の項の近く）
- Upper arm: 上の腕の間。同じく狭い間が内側
- First contact: 最初の二つの組が触れる高さ。最初の項
- Approach: 組が滑る時間。触れてから次に触れるまでの、ただ一つの時間の間でもある（atom の数）
- Family: その atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- Tempo: テンポ
