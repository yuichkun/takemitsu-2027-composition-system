# A · 間が触れた所に項が立つ

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

間は、その両端の音（項）より先に鳴れるか。

和音の間を一つずつ、二人で同時に弾く二音（組）として入れる。二音はそろって滑り、滑っているあいだはどちらの音もどの高さにも止まらない。
組の端が、すでに立っている音か、もう一つの組の端に触れた瞬間（同じ高さになった瞬間。高さの間、つまり音程の間が 0 になった瞬間）にだけ、二音は止まって項になる。
立ち位置（和音を測りはじめる最初の一音）は鳴らさない。最初の二つの組が触れた所が、最初の項になる。

前提の一つ目（関係（切れ目）が先にあり、項は後から付く名前である）を、和音の始まり方として試す。

## 仕組みと聴こえ方

- **間**: 二つの音のあいだ。高さのあいだ（音程の間）は半音単位で書き、四分音は .5。鳴り始めどうしの間隔も同じく間と呼び、時間の間と言う
- **項**: 間の両端に立つ音。ここでは、ある高さに止まって伸びている音を項と呼ぶ
- **ふつうの順番**: 和音は、立ち位置（最初の一音。音を測りはじめる所）に間を積んだもの。項が先にあり、そこへ間を足して次の項が決まる。このスケッチはこの順番を逆にする
- **組**: 和音の間一つを、二つの分奏（弦のセクションを人数で分けたパート）が同時に鳴らす二音。時間の間が 0 の二音
- **滑る**: 組の二音は、入った瞬間からもう滑っている（グリッサンド）。二音は同じ時間で同じ距離を滑るので、組の中の間の大きさはずっと同じで、どちらの音もどの高さにも止まらない。
  この状態の組を「項のない間」と呼ぶ。一定なのは間の大きさだけで、項はまだどこにも立っていない
- **触れる**: 組の端が、すでに立っている項か、もう一つの組の端と同じ高さになる（音程の間が 0 になる）こと。
  触れた瞬間にだけ、組の二音は止まり、そのまま最後まで伸びる。ここで二音は項になる
- **最初の項**: 立ち位置は鳴らさない。最初の二つの組が触れた所が、最初の項になる。
  計算の上ではその高さ（つまみの First contact、既定値 68.5。高さはこのカードではどこでも実音の MIDI 番号で、60 が中央の C、.5 は四分音）から和音の間を測るが、鳴る順番の上では、そこには最初の 4.8 秒、何も立っていない
- **二つの腕**: 和音の間を、最初の項から下へ向かう**下の腕**（1, 5.5, 2.5, 4）と、上へ向かう**上の腕**（1.5, 6, 3, 4.5）に分けて持つ。
  腕は書いた順に、内から外へ読む。この順番が規則（セットから次にどの間を取り出すか）で、組が入る順番でもある。
  完成する和音は、下から 55.5、59.5、62、67.5、68.5、70、76、79、83.5 の 9 音
- **ずらし**: 各組は、止まる所から和音の外側へ、自分の間の大きさだけずれた所から入る。下の腕の組は下から、上の腕の組は上から来る。
  だから滑る距離も自分の間の大きさ。組が持っている長さはそれしかないので、外から別の長さを持ち込まない。
  滑る時間は全部同じなので、組の間が広いほど速く滑る。組の間の大きさは、滑る速さであり、新しく立つ間の大きさであり、触れたときに和音の幅が増える量でもある
- **規則**: はじめに、下の腕と上の腕の最初の組（1 と 1.5）が同時に入り、互いに向かって滑って、最初の項の高さで触れる。
  そのあとは一組ずつ、上の腕、下の腕、と交互に、腕の書いた順に内から外へ。前の組が触れた瞬間に次の組が入り、いまの和音の上の端（上の腕）か下の端（下の腕）へ向かって滑り、同じ時間で触れる
- **触れた所は同音の二人**: 触れる二音は同じ高さなので、内側の 7 つの項は二人（二つの分奏）で、外側の二つは一人で鳴る。
  一度触れるごとに新しく立つ項は一つだけ。組の近い側の端は、すでに立っている項に重なり、遠い側の端が新しい項になる（最初に触れる所だけは、二組の四音が三つの項になる）
- **触れる時刻**: 組が滑る時間は全部同じ（3 の仲間の atom 12 個。atom は時間の間を数える、素数の仲間ごとの最小の粒で、3 の仲間は 3 連 8 分）。
  だから触れる時刻は、時間の間を一つしか持たないセット（セットは、どの間をいくつずつ持つか。一つしか持たないものがパルス）になる。時間の規則は聴こえず、定義の順番だけが聴こえるようにした
- **強弱**: 各組は niente（無音）から入り、入った高さから四分音一つ分を滑り終えた所（atom の切れ目まで繰り上げる）で pp に届き、あとは触れても pp のまま。
  組の近い側の音は、その組がのちに立てる新しい項の高さから滑りだす（ずらしが自分の間の大きさなので必ずそうなる）。そこから四分音一つ離れるまでは項の強さで鳴らさない、というのが niente の理由。
  そこから先の滑りは、立っている項の一つひとつと同じ pp で鳴るので、項が立つ前に間が聴こえる。最後は全員が pp のまま同時に止まる
- 和音が一定の間隔で一つずつ育つ形は [霜が育つ和音](../pitch-frost-freeze/README.md) に似て見えるが、あちらの課題は次にどの切れ目を選ぶか。
  ここでは和音は先に決まっていて、課題は「間が先、項が後」という定義の順番だけ

### 仮の値をなぜ選んだか

- 二つの腕に 4 つずつ。どちらの腕も、間の大きさは 1.5（四分音三つ）おきに並ぶ（1, 2.5, 4, 5.5 と 1.5, 3, 4.5, 6）。
  上の腕の間は、下の腕の同じ位置の間より四分音一つ広い。だから 8 つの間はどれも違う大きさで、新しく滑って来る間は、いつもまだ聴いていない広さになる
- **順番（規則）**: どちらの腕も、両端から交互に、狭い方から取る。いちばん狭い、いちばん広い、二番目に狭い、二番目に広い（1, 5.5, 2.5, 4 と 1.5, 6, 3, 4.5）。理由は三つ
  - 触れるたびに、和音の外側に項が一つ増え、どの声も最後まで伸びるので、鳴っている人数と和音の幅は、仕組みの上でいつもそろって増える。
    組の大きさ（滑る速さ）を狭い順に並べると、速さも同じ向きにそろって上がり、高さ・厚さ・速さが一方向に揃う（前の版がそうだった）。
    両端から交互に取ると、組が入る順の大きさは 1 と 1.5（同時）、6、5.5、3、2.5、4.5、4 になり、遅い、速い、遅い、中くらい、と向きを持たない
  - 最初の二組は、それぞれの腕のいちばん狭い間のまま。だから最初に触れる所は、二組のあいだが 2.5 から 0 へ縮むだけの、いちばん小さい出来事になる
  - 両腕に同じ規則を使うので、同じ位置では上の腕の間が下の腕の間よりいつも四分音一つ広い。両腕が同じ大きさの間を持つことはなく、和音は最初の項を軸にした鏡にならない。
    同じ位置では片方の腕だけが .5 を持つので、項は二つの格子（四分音の格子をつくる、四分音ずれた二つの半音の格子）に分かれて立つ。最初の項と同じ、.5 の付く格子に 5 つ、付かない格子に 4 つ
- 比べて採らなかった順番: 各腕の中で、隣り合う二つが大きさでも隣にならない順（2.5, 5.5, 1, 4 と 4.5, 1.5, 6, 3）。
  これは最後の三組が 1、3、4 と広がり、最後の 14.4 秒で人数・幅と同じ向きに速くなって終わる
- 組が滑る距離は自分の間の大きさ（上の「ずらし」）。滑る時間は全部同じにして、触れる時刻をパルスにした
- niente から pp までの長さ: 四分音一つ分を滑る時間。四分音は間の atom で、それより小さい差は別の間ではなく同じ間の揺れとして聴かれやすい（音の原則）。
  だから、入った高さ（近い側の音にとっては、のちの新しい項の高さ）から四分音一つ離れるまでを弱くし、そこから先は項と同じ強さにした。
  書ける所に置くため、atom の切れ目まで繰り上げる。組ごとに 0.4〜2.4 秒で、組の間が広いほど短い
- 最初の接点 68.5: 完成した和音の真ん中（最初の項より 1 上、69.5。上の腕の和 15 と下の腕の和 13 の差の半分）が、弦の音域 36〜103（チェロの下の端からヴァイオリン I の上の端まで）の真ん中 69.5 に来るように。
  最初の項が .5 の格子に落ちたのは、その結果
- 滑る時間: 3 の仲間の atom 12 個 = 4 拍、テンポ 50 で 4.8 秒。滑っている組が、項のない間として聴き取れるだけの長さ。
  12 個でちょうど 1 小節なので、触れる時刻はどれも小節の頭（すべての仲間の格子が重なる所）に落ちる。
  出来事の頭がいつも小節の頭に来る形だが、小節の中には何も起こらない（触れる時刻のほかに、時間の上の出来事がない。pp に届く所は強弱の変わり目で、音の頭ではない）ので、拍が割られて聴こえることはないはず
- どの値も、和音や音程の名前では選んでいない

### 原則を広げて読んでいる所（余湖さんに確かめてほしい読み）

- **滑っている二音を「項のない間」と読むこと**: 原則の間は「二つの音のあいだ」。ここでは、両端がどこにも止まっていない二音を、もう間として数えている
- **滑る途中の位置は格子の外を通る**: 組の中の間（1, 1.5, …）と、止まった所（項）は、どれも四分音の格子の上にある。
  けれど滑っているあいだの位置は、四分音より細かい所を連続して通る。滑っている組の端と、立っている和音の端とのあいだの間も、組の間の大きさから 0 へ連続して縮み、四分音の目盛りのあいだを通る。
  原則の「四分音より細かくは使わない」が、止まらずに通り過ぎる位置にも及ぶのかは、原則ではまだ決まっていない。ここでは「止まる所と間の大きさだけが atom で数えられればよい」と読んでいる
- **時間の間の 0**: 組の二音は、時間の間が 0 の二音（原則ではまだ決まっていない。試してよいとされている所）

## 聴きどころ

- 0:00〜0:05: 二つの組（1 と 1.5）が niente から、互いに向かって滑るだけ。下の組は上へ、上の組は下へ。二組のあいだは 2.5 から 0 へ縮む。どの高さにも、何も止まっていない。
  1.5 の組は 1.6 秒、1 の組は 2.4 秒で pp に届く（どちらも、入った高さから四分音一つ滑った所）
- 0:05（4.8 秒）: 二組が 68.5 で触れ、三つの音（67.5、68.5、70）が同時に立つ。68.5 は二人の同音。同じ瞬間に、上から 6 の組が niente で滑りはじめ、0.4 秒で pp に届く
- そのあと 4.8 秒ごとに、外側から一組が滑って来て、鳴っている和音の端に触れた瞬間に新しい項が一つ立つ。上、下、上、下と交互に。
  新しい項は 76（9.6 秒）、62（14.4 秒）、79（19.2 秒）、59.5（24.0 秒）、83.5（28.8 秒）、55.5（33.6 秒）
- どの組も同じ時間で滑るので、広い組ほど速く滑る。入る順の速さ（1 秒あたりの半音）は、最初の二組が 0.21 と 0.31、そのあと 1.25、1.15、0.63、0.52、0.94、0.83。
  上の腕の組と、次に来る下の腕の組は、腕の中の同じ位置なので四分音一つしか違わず、速さはほぼ同じ二つずつで変わる（遅い、速い、遅い、中くらい）
- 4.8 秒からあとは、滑っている組は、入ってから 0.4〜1.2 秒で pp に届き、残りの 3.6〜4.4 秒（滑る時間の 75〜92%）は、立っている項と同じ pp で滑る
- 0:34〜0:43: 完成した 9 音の和音が pp のまま伸び、43.2 秒で全員が同時に止まる
- **耳で判断してほしい点**
  - 滑っているあいだ、間の広さ（狭い・広い）が、高さの名前なしに聴き取れるか
  - 触れた瞬間が「音が生まれる所」として聴こえるか
  - 4.8 秒からあとは、立っている和音の外側を一組だけが滑る。そのとき耳に入るのは、組の中の一定の間だけでなく、組の近い側の端と和音の端とのあいだで縮んでいく間でもある。どちらが前に出て聴こえるか
  - ずらしが自分の間の大きさなので、どの組も、近い側の音は、その組がのちに立てる新しい項の高さから滑りだす。そこから四分音一つ離れるまでは pp より弱いので、項としては聴こえないはずだが、耳で確かめてほしい。
    いちばん遅い 1 の組は、四分音一つ滑るのに 2.4 秒かかる
  - 同じ高さに近づく最後の瞬間に、うなりが出る。触れる瞬間の音響の副産物で、狙ったものではない（四分音を揺れとして置いてはいない）
  - 滑りは、色のための滑りではなく「項のない間」という状態そのもの。距離は自分の間、時間は全部同じ。それでも音塊が滑る常套の効果として聴こえてしまうかどうか
  - 滑っている組（二つの分奏、4〜8 人）は、滑る時間の大半を、立っている和音の一つひとつの声と同じ pp で鳴る。最後の組が滑るあいだ、立っている和音は 14 の分奏（48 人）。
    滑っている組はいつも和音の外側（上の腕の組は和音より上、下の腕の組は和音より下）にいて、動いている。埋もれずに聴こえるか
  - 鳴っている人数（12 人から 52 人）と全体の幅（3.75 から 30、最後は 28）は、仕組みの上でいつもそろって増える。滑りの速さはもうそれに付いていかない
    （4.8〜24 秒は、速さが 1.25 から 0.52 へ下がるあいだに人数と幅が増える）。それでも和音が育つこと自体が、盛り上げの形に聴こえないか
  - 最初の項を含まない方の格子に立つ 4 音（62、70、76、79）は、隣どうしの間が 8、6、3。平均律の音名で言えば D・B♭・E・G で、4 音そろうと半減七の和音（E・G・B♭・D）の音になる。4 音がそろって立つのは 19.2 秒から終わりまで。
    上の三つ（70、76、79）は和音の中でも隣り合っていて、19.2 秒から 28.8 秒までは立っている音のいちばん上に来る。隣どうしの間 6、3 は、音名で言えば減三和音（E・G・B♭）の形。
    出どころは上の腕のセット（1.5, 3, 4.5, 6）。どれも 1.5 の倍数なので、上の腕の項のうち .5 の付かない格子に立つものは、どの順番でも 70 から 3 ずつ離れた位置（70、73、76、79、82）に乗る。
    そこに何個乗るかは順番で決まり、いまの順番（6 のすぐあとに 3）では 3 つ、狭い順だった前の版では 2 つ（70、73）。
    値はこの名前のために選んだのでも、避けたのでもない（関係の結果）。和音がこの名前の側に聴こえるかどうか

- 一つの組の二音は、いつも同じセクションの隣り合う二つの分奏が弾く（声部を、組ごとに、止まる所の低い方から並べて渡している。各セクションに組が二つずつ入る）
- 全員 arco、non vib.（楽譜に書いてある）、niente から pp。音色と強弱をそろえ、間が先に鳴り項が後に立つ順番だけが聴こえるようにした
- 譜表の名前の括弧の中に、その声が属する組（間の大きさと、最初の項より上か下か）と、組の上の音か下の音かを書いた
- 再生の音は BBC SO の弦のふつうの伸ばしで、ヴィブラートがかかる。non vib. は楽譜の指示だけで、プレビューの音には反映されない

## つまみ

- Lower arm: 下の腕の間（半音、.5 は四分音、0.5〜12）。書いた順に、内（最初の項の近く）から外へ読む。
  この順番が規則で、下の腕の組が入る順番、つまり滑る速さの並びにもなる
- Upper arm: 上の腕の間。同じく書いた順に内から外へ
- First contact: 最初の二つの組が触れる高さ。最初の項
- Approach: 組が滑る時間。触れてから次に触れるまでの、ただ一つの時間の間でもある（atom の数）。niente から pp までの長さも、これと組の大きさから決まる
- Family: その atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- Tempo: テンポ
