# A · 同じ音で名前が入れ替わる

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

三本の線が、それぞれ自分のセットで動く。二本が同じ音に着いたとき、楽器は席に残り、線だけが楽器を乗り換える。

線は、起点に、規則が自分のセットから取り出した間を足したもの。これが関係で、どの楽器がその線を吹くかは後から付く名前。
二本の線の縦の間が 0 になった所（同じ音）では、どちらがどちらの線かを区別するものが何もない。そこでだけ名前（楽器）を付け替える。
縦の間が 0 でない交差では、何も替えない。

前提の二点目（名前は立つ位置で変わる）と三点目（どの項も立っていない切れ目は、新しいものが定義される場所になる）を、音色の側で試す。
仕組みは一つだけ: 縦の間が 0 の所で名前を付け替える。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだの幅。半音単位で数え、四分音は .5 と書く。線の中の間は向きを持ち、- は下へ、+ は上へ
- **セット**: どの間を、いくつずつ持つか
- **規則**: セットから、次にどの間を取り出すか。ここでは三本とも同じ規則で、セットを書いた順に読み、一巡するたびに読み始めを一つ後ろへずらす
  （{a b c d} なら a b c d、b c d a、c d a b、d a b c、…）
- **起点**: 線の最初の音
- **線**: 起点に、規則が取り出した間を一つずつ足していった音の列。前の音から歩き続け、起点へは戻らない
- **帯**: 三本の線が動いてよい音域。帯の外へ出る一歩は、同じ大きさで逆向きに取る
- **縦の間**: 同じ時刻に鳴る、二本の線の音のあいだの間。0 なら同じ音
- **出会い**: 二本の線の縦の間が 0 になる鳴り始め
- **交差**: 二本の線の上下が、同じ音を通らずに、次の鳴り始めで逆になる所
- **手触り**: 一本の線を聴いたときの動き方。ここでは線の間の大きさだけで決まる（細かく這う、中くらいに動く、大きく跳ぶ）
- **二つの格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。.5 の付く間は次の音をもう一方の格子へ移し、付かない間は同じ格子に置く
- **atom**: 時間を数えるいちばん小さな一粒。**仲間**（2・3・5）ごとに一つあり、2 の仲間の atom は 16 分音符
- **時間の間**: 二つの鳴り始めの間隔。atom の何個分かで数える

### 規則はひとつ

線は先に、誰が吹くかと関係なく計算する。三本の音の列は、楽器を付け替えても一つも変わらない。

はじめは、クラリネットが狭い線、オーボエが中くらいの線、フルートが広い線を吹く。そのあとの名前の付け方は一つだけ。

- 二本の線が同じ音に着いた鳴り始めの、**次の鳴り始めから**、その二本を吹いていた二つの楽器が線を取り替える。どちらも、相手の線の続きを吹く
- 交差では何も替えない。楽器は線と一緒に交差し、手触りを持ったまま
- 三本が同時に同じ音に着いたら、三つの楽器を一つずつ回す（仮の値では起こらない）

出会いの印（アクセント、強弱の変化、スラーの切れ目）は何も付けない。付け替わったことを知らせるのは、手触りが楽器を移ることだけ。

### そこから出てくること

- 出会いのたびに、二つの楽器の手触りが入れ替わる。ほかの所で手触りが楽器を移ることはない
- 出会いで二本の線が触れて離れる（同じ音に着いて、上下の順を保ったまま離れる）ときは、線を取り替えた楽器の方が、上下を入れ替える。
  それまで上にいた楽器が、次の鳴り始めからは下の線を吹いている。楽器の側から見ると、二つの楽器が同じ音で交差し、交差した瞬間に歩き方を取り替えたように聴こえる
- 出会いで二本の線が通り抜ける（同じ音を通って、上下が逆になる）ときは、楽器は元の側に残り、同じ音で跳ね返ったように聴こえる
- 例: 最初の出会い（8.25 秒）では、フルートが 75 から、オーボエが 72 から、どちらも下りて 69 で重なる。次の鳴り始めで、フルートは 70.5 へ（中くらいの線の一歩）、オーボエは 77.5 へ（広い線の一歩）。
  上にいたフルートが下に、下にいたオーボエが上に入れ替わり、跳ぶのはオーボエになる
- 出会いは、二本が同じ時刻に同じ格子にいるときにしか起こらない。四分音一つずれた二つの音は縦の間 0.5 で、出会いではない

### 仮の値

- 狭い線: セット {-0.5 1.5 -1 0.5}（この順）、起点 64
- 中くらいの線: セット {-3 1.5 -2.5 3.5}（この順）、起点 72
- 広い線: セット {-6 8.5 -6.5 4.5}（この順）、起点 80
- 帯: 60〜86
- 時間: 時間の間を一つだけ持つセット {3}。2 の仲間の atom 3 つ（付点 8 分音符）。三本とも同じ時刻に鳴る。♩ = 60 で 0.75 秒ごと
- 長さ: 各線 80 歩（鳴り始めは 81）。最後の音は、次の小節線まで伸ばす
- 強弱: 三人とも mp のまま変えない

値を選んだ理由（構造から）:

- **三つのセットは同じ形**: どれも 4 つの間を、下・上・下・上の順に持つ。違うのは大きさの組だけで、狭い線は 0.5〜1.5、中くらいの線は 1.5〜3.5、広い線は 4.5〜8.5。
  線の手触りが間の大きさだけで区別されるようにするため。
  どのセットも 4 つのうち 3 つが .5 の付く間で、三本とも同じ割合でもう一方の格子へ移る（どの線も 81 音のうち 30 音がもう一方の格子）。格子の移り方でも線を区別できないようにした
- **和はどれも四分音一つ**（狭い +0.5、中くらい -0.5、広い +0.5）: 一巡しても四分音一つしか進まないので、どの線もゆっくりしか流れず、三本とも同じ帯の中をさまよう。
  だから交差も出会いも、仕組んだものではなく結果として起こる（狭い線は 64 から 74 へ、中くらいの線は 72 から 62 へと、ゆっくり居場所を入れ替える）
- **起点は帯の中に等間隔**（8 ずつ）で、三つとも同じ格子の上: 始めから出会いを仕組んでいない。同じ格子に立っているので、出会いは起こりうる
- **帯の幅 26**: いちばん広い間 8.5 の 2 倍（17）以上あれば、逆向きに取った一歩はいつも帯に入る。そのうえで、三本が同じ場所を共有し続けるだけ狭い。
  帯の置き場所（60〜86）は、三つの楽器がみな出せる 59〜93 の中にあるが、その中のどこに置くかは構造からは決めておらず、仮のまま
- **80 歩**: 出会いが数回、あいだを空けて起こる長さ（7 回、あいだは 5〜13 歩）
- **時間の間を一つだけ**: 時間の側には何も起こらない（パルス）。聴こえる変化を名前の付け替えだけにするため。三本が同時に鳴るので、縦の間が鳴り始めごとに揃って聴ける。
  その間の大きさ（atom 3 つ）とテンポ（♩ = 60）は、構造からは決めておらず、仮のまま

## 聴きどころ

- 細かく這う線、中くらいに動く線、大きく跳ぶ線の、三つの手触りを追う
- 二つの楽器が同じ音に着いた次の瞬間、手触りが楽器を乗り換える。最初は 8.25 秒（3 小節目）: フルートが跳ぶのをやめて中くらいに動き始め、オーボエが跳び始める
- 24 秒（7 小節目）の出会いだけは、二本の線が同じ音 68 を通り抜ける。オーボエは上、フルートは下のまま、手触りだけが入れ替わる（オーボエが這い始め、フルートが中くらいに動き始める）
- 同じ音でない交差では、楽器はそのまま交差して、手触りを保つ
- 耳で判断してほしい所: 入れ替わりが「線が楽器を乗り換えた」と聴こえるか、「楽器が歩き方を変えた」と聴こえるか。後者なら、名前（楽器）の方が関係（線）より先に立って聴こえている。
  音色の入れ替えが、関係の話ではなく配器の手品として聴こえる恐れがある

## 楽器

クラリネット、オーボエ、フルート（各 1 人）。同じ音域を持ち、音色がはっきり違う三つ。どの手触りがどの楽器にあるかを聴き分けるため。
三つともどちらの格子も出せる。ふつうの奏法で、一音ずつタンギングし、各音は次の鳴り始めまで伸ばす。

## つまみ

- **Line 1 / Line 2 / Line 3**: 三本の線のセット。書いた順に読まれる（クラリネット、オーボエ、フルートが最初に吹く線）。
  規則が書いた順に読むので、順を保つために文字で書く（間のセットのつまみは、値を小さい順に並べ直してしまう）
- **Line 1 from / Line 2 from / Line 3 from**: 三本の起点
- **Band**: 帯。いちばん広い間の 2 倍より狭くはできない
- **Steps**: 各線の歩数
- **Time between / Family**: ただ一つの時間の間と、その atom の仲間
- **Tempo**

- 付け替えは 7 回。楽譜の各パートの間の列を、そのパートが加わった出会いで区切ると、区切りの一つ一つが一本の線のセットの間だけでできている。

  曲の中でいちばん長く鳴る一つの縦になる

## 作曲の段で考える点（いまは狭めない）

- **息**: 三人とも 64 秒、休みなく吹き続ける（81 音、休符なし）。どこで息を取るか
- **フルートの低い所**: フルートは 64〜85 を吹き、66 以下が 9 音。低い所は弱く、オーボエとクラリネットに埋もれやすい
- **広い線を吹くとき**: 四分音を含む 8.5 までの跳躍が 0.75 秒ごとに続く。三人とも、跳躍の中で四分音の運指を取る
- **クラリネットの音域の切り替わり**: クラリネットは 60〜85 を行き来し、実音 69 のあたりにある音域の切り替わりを、四分音を含んでまたぐ
- 出会いの数は、二本が同じ時刻に同じ格子にいる割合で決まる。出会いを多くしたいときは、セットの .5 の付く間の数や置き場所を線どうしで揃える手がある
