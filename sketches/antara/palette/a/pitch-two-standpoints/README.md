# A · 戻る人と歩く人

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

一本の間の列を、二人のヴィオラがまったく同じ時に弾く。列は、間のセットから規則が二つずつ取り出した間のまとまり（組）を並べたもの。
一人（戻る人）は組のたびに起点へ戻ってから間を足し、もう一人（歩く人）は戻らずに前の音から足し続ける。二人の違いは立ち位置（間を足し始める音）だけ。
二人のあいだの縦の間（同じ瞬間に鳴っている二人の音のあいだの間）は、歩く人の立ち位置が起点からどれだけ離れたか、そのものになる。

前提の「名前は、立つ位置で変わる」を、音の高さで試す。同じ間の列でも、立ち位置が違えば別の音になり、立ち位置が重なった所でだけ一致する。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだ。半音単位で数え、四分音は .5 と書く。− は下へ
- **起点（立ち位置）**: 間を足し始める音。音の並びは、起点に、規則がセットから取り出した間の列を足したもの
- **セット**: どの間を、いくつずつ持つか。ここでは −5.5、−1、+2.5、+4 の四つ
- **規則（組合せ）**: セットから間を二つずつ取り出して一つの組にする。四つから二つを選ぶ選び方は六つあり、それを辞書順に並べる
  （セットを小さい順に並べ、一つ目の間が小さい組から。一つ目が同じなら二つ目が小さい組から。組の中も小さい順）。
  (−5.5, −1)、(−5.5, +2.5)、(−5.5, +4)、(−1, +2.5)、(−1, +4)、(+2.5, +4)
- **組の和**: 組の二つの間を足したもの。上の順に −6.5、−3、−1.5、+1.5、+3、+6.5
- **頭**: 一つの組は三つの鳴り始めでできている。はじめの一つを頭と呼ぶ。そのあとに、組の間を一つずつ足した音が二つ続く
- **縦の間**: 同じ瞬間に鳴っている二人の音のあいだの間（歩く人の音 − 戻る人の音）
- **二つの格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。縦の間に .5 が付くと、二人は別々の格子に立つ
- **atom**: 時間を数えるいちばん小さな単位。ここでは 3 の仲間（拍を三つに割る系統）の atom、3 連 8 分（1 拍の 3 分の 1）

### 二人の違いは立ち位置だけ

- **戻る人**（ヴィオラ 1）: 頭で必ず起点 63 を弾き、組の間を順に足す（63、63 + 一つ目、63 + 一つ目 + 二つ目）。立ち位置は動かない
- **歩く人**（ヴィオラ 2）: 63 から始める。頭では直前の音をもう一度弾き（動く間は 0）、そこから同じ間を順に足す。立ち位置は組ごとに組の和だけ動く
- 二人はまったく同じ時に鳴り、同じ長さで伸ばす（どの音も次の鳴り始めまで）
- 組の中では、二人は同じ間で動く。だから縦の間は組のあいだ変わらない
- 頭では、戻る人だけが起点へ跳び、歩く人はその場に留まる。だから縦の間は頭でだけ替わる
- 組の中の縦の間は、それより前のすべての組の和を積み重ねたもの。歩く人の立ち位置が起点からどれだけ離れたか、そのもの
- 形: 組合せを一巡（六つの組）、同じ六つの組を逆の順にもう一巡、最後に頭を一つ（締めの頭）。締めの頭で戻る人は起点を、歩く人は直前の音を弾き、1 小節伸ばして消える

### セットの間の和

- **セットの間の和 = −5.5 − 1 + 2.5 + 4 = 0**
- 組合せを一巡すると、どの間もちょうど三回ずつ使われる。だから一巡で歩く人が動く量は、セットの和の三倍になる。和が 0 なので、一巡の終わりでずれは 0 に戻り、二人は同じ音に会う
- 和が 0 でないセットにすると、歩く人は戻ってこない。スケッチはそれを直さない

### ずれの弧

組ごとの縦の間（歩く人の立ち位置 − 起点）は、次のように動く。

- 一巡目: 0、−6.5、−9.5、−11、−9.5、−6.5、そして 0 に戻る
- 二巡目（組の順を逆に）: 0、+6.5、+9.5、+11、+9.5、+6.5、締めの頭で 0

和が 0 の四つの間では、辞書順の一つ目と六つ目、二つ目と五つ目、三つ目と四つ目が、互いに残りの二つを持つ組になる（(−5.5, −1) と (+2.5, +4) のように）。
その二つの組の和は正負が逆で大きさが同じ。だから積み重ねは対称な弧を描く。二巡目は組の順を逆にするので、はじめに和の正の組が来て、同じ弧が上側に出る。

似たものに、平行に重ねた二声がある。違いは、縦の間が頭ごとに替わり、その縦の間そのものが積み重ねの線になっていること。ここがこの課題の芯。

### 仮の値をなぜ選んだか

- **セット −5.5、−1、+2.5、+4**: 和を 0 にした。歩く人が戻ってくることが、終わり方を後から選んだ結果ではなく、セットの性質になる。
  下向きが二つ、上向きが二つ。.5 の付くものが二つ（−5.5、+2.5）、付かないものが二つ（−1、+4）。大きさはどれも違う。
  組の和に .5 が付くのは .5 の付く間を一つだけ含む組で、六つのうち四つ。積み重ねた縦の間は ±6.5、±9.5 の所で .5 が付き、そこで二人は別々の格子に立つ
- **組の大きさ 2**: 頭と、二歩の中身を持つ、いちばん小さな組。中身が二歩あるので、組の中で「二人が同じ形で動く」ことが聴こえる
- **起点 63**: 歩く人のいちばん深い所は起点 − 15（縦の間が −9.5 の組で、さらに −5.5 を足した所）。63 にすると、そこがちょうどヴィオラのいちばん低い音 48 に着く
- **リズム 3、4、4、5 atom**: 鳴り始めの間は、このセットを小さい順に繰り返し（セットはどう書いても小さい順に並ぶ）、組の区切りとは関係なく読み続ける。
  間を一つだけにしない（パルスにしない）ために、大きさの違う間を持つ。
  間を三つ（たとえば 3、4、5）にすると、間の数が一つの組の鳴り始めの数（三つ）と同じになり、リズムと組が噛み合ってしまう。
  組はいつも 12 atom（ちょうど 1 小節）、頭は 13 回すべて小節の頭に来て、どの頭の前にもいちばん長い 5 が来る。頭がリズムで目立ち、頭を音の関係だけで聴くという課題とぶつかる。
  間を四つにすると（4 と 3 は 1 のほかに公約数を持たない）、リズムは組と噛み合わずに回り、組の頭はリズムの中の四つの場所を順に通る。
  4 を二つにしたのは、3 と 5 の真ん中で、平均の間（4 atom）と全体の長さを間三つのときと同じに保つため。組の長さは 11、12、12、13 atom で、組ごとの速さの違いも目立たない
- **テンポ 60**: 鳴り始めの間は 1 拍、1⅓ 拍、1⅔ 拍（1〜1.7 秒）。一つひとつの縦の間が耳に届く速さ

### 強弱

二人とも mp のまま。アクセントもスラーも付けない。頭は、音の関係（戻る人の跳躍と、歩く人の同じ音）だけで分かる。締めの頭の 1 小節で消える。

## 聴きどころ

- 0:00〜0:04、二人が同じ音で動く（63、57.5、56.5）
- 0:04 から、組の頭ごとに（ほぼ 4 秒おき）戻る人だけが 63 へ跳び、歩く人は同じ音をもう一度弾く。二人の縦の間が、頭のところでだけ替わる
- 歩く人はまず下へ離れていく（縦の間 −6.5、−9.5、−11）。いちばん深い所は 0:09 の 48（ヴィオラのいちばん低い音）。そこから弧を描いて戻る
- 0:24、二人がまた 63 で会い、一つの組のあいだ同じ音で動く（63、65.5、69.5）
- 後半、歩く人は上へ離れる（+6.5、+9.5、+11。いちばん高い所は 0:34〜0:36 の 74）。0:48 に、二人は 63 の一つの音に着く
- 組の中の二人の動きは同じ形で、違うのは高さ（立ち位置）だけ
- 耳で判断してほしい所: 組の中では、二人が同じ縦の間のまま平行に動く。平行に重ねた二声としか聴こえないか、頭ごとに替わる縦の間が一本の線として聴こえるか。
  また再生では、二人とも BBC SO の同じ独奏ヴィオラの音で鳴るので、同じ音の所（0:00〜0:04、0:24〜0:28、0:48）は一つの音が太くなったように聴こえるかもしれない

## 楽器

独奏ヴィオラ 2 人。1 が戻る人、2 が歩く人。同じ楽器にして音色を揃え、立ち位置の違いだけが聴こえるようにした。ふつうの弓（arco）

## つまみ

- **Set**: 間のセット（半音、.5 は四分音、− は下へ）。和が 0 なら歩く人は戻ってくる
- **Group size**: 一つの組が取る間の数（組合せの大きさ）。組は頭と、間一つにつき一つの鳴り始め
- **Anchor**: 起点。二人が始める音で、戻る人が頭ごとに戻る音
- **Rhythm**: 鳴り始めの間（atom の数）。小さい順に繰り返し（どう書いても小さい順に並ぶ）、組の区切りとは関係なく読み続ける
- **Family**: リズムを数える atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- **Tempo**
