# A · 強弱という間

- 状態: 試し中（2026-09-29。同じ日の見直しで、端での折り返しをやめた。下の「見直しで変えたこと」）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

強弱そのものを、名前の付いた効果（クレッシェンド、段ごとに強さを替える書き方、突然の弱音）としてではなく、間・セット・規則という同じ仕組みの結果として鳴らせるか。
音の高さは一つの音に、リズムは一小節に一弓の鼓動に固定して、強弱の関係だけを聴く。

前提（[`premise.md`](../../../../../docs/antara/premise.md)）は、この構図を音の高さに閉じた話ではなく「リズムなどにも同じ構図で通る」ものとしている。それを、音程でも時間でもない強弱の軸で確かめる。

**余湖さんに決めてほしいこと: このスケッチは、パレットの三つの軸（音高・律動・配器）のどれにも入らない、強弱という四つ目の軸を持ち込んでいる。**
フォルダ名の頭には仮に `dynamics-` を付けた。強弱を軸の一つとして数えるか（数えるならこの頭でよいか、数えないならどこに置くか）は、余湖さんが決める。

## 仕組みと聴こえ方

言葉の確認から。

- **強弱の目盛り**: 楽譜の約束（`src/score/types.ts`）の強弱は、0 から 8 までの 9 点。0 は niente（無音）、1 が ppp、2 が pp、3 が p、4 が mp、5 が mf、6 が f、7 が ff、8 が fff
- **atom（マーク一つ）**: それ以上は割らない単位。記譜は強弱を最も近いマークに丸めるので、マーク一つより細かい差は書けない。音程の軸の四分音にあたる
- **強弱の間**: 二つの強さのあいだ。マークの何個分かで数え、強くなる向きを +、弱くなる向きを − と書く。0（同じ強さ）も間
- **セット**: どの間を持つか。ここでは +2、−1、−4、+3 の四つ（書いた順）
- **起点と歩き方**: 起点は最初の強さ（立ち位置）。取り出した間を、直前の強さに足していく。起点へは戻らずに歩き続ける
- **端**: 0 と 8 は本当の端として扱う。音程の線はオクターブで折り返せるが、それはオクターブ離れた音が同じ音の別の高さとして聴かれるから。強弱には、それにあたる聴こえがない（niente と fff を同じと聴くことはない）。
  だから目盛りの外へ出る歩きは折り返さない。外へ出る値をつまみで選ぶと、楽譜は書かれず、何小節目で外に出るかが知らされる
- **巡**: セットの四つの間を一回ずつ足し終えるまでの一回り
- **規則**: 決まった順に取り出す。前半の一巡は書いた順（+2、−1、−4、+3）、後半の一巡は逆順（+3、−4、−1、+2）。後半は前半の終わった所から歩き続ける
- **段で移る**: 一小節のあいだ一つの強さを保ち、次の小節線で次の強さへ一気に移る。途中でだんだん変える（ヘアピン）ことはしない。
  だから一つの間が一つの段差として聴こえ、聴こえる段差はどれも、取り出した間そのものになる

ほかの軸は動かさない。

- 音程の軸は、セットが {0}（同じ音）だけの場合。音程の間が一つもないので、四分音の格子はここでは働かない
- 時間の軸は、2 の仲間（atom は 16 分音符）で 16 atom の間を一つだけ持つセット。つまり一小節に一弓の鼓動。音の原則の表の「同音を同じパルスで連打」の行に、強弱の軸を一本足した形になる
- 一弓の長さが一小節にそろうのは、手引きの落とし穴「時間の和が小節にそろう」と同じ形。ただ、一弓の中では何も起きないので、4/4 の拍は聴こえない。聴こえるのは 4.4 秒ごとの鼓動だけで、小節線は強さを書く場所として使っている。
  それでも、一巡（四つの間）がちょうど 4 小節で、起点の mp へ戻る所が 5 小節目と 9 小節目の頭に来るので、4 小節ずつの句として聴こえるかもしれない（推測）。時間の軸を止めたこの A では動かさない

一小節ずつの動き（強弱の数のあとに、記譜で書かれるマークを添えた）。

| 小節 | 取り出した間（そのまま聴こえる段差） | 立っていた強さ | 着いた強さ |
| --- | --- | --- | --- |
| 1 | 起点 | 無音から 1 拍で出る | 4（mp） |
| 2 | +2 | 4（mp） | 6（f） |
| 3 | −1 | 6（f） | 5（mf） |
| 4 | −4 | 5（mf） | 1（ppp） |
| 5 | +3 | 1（ppp） | 4（mp） |
| 6 | +3 | 4（mp） | 7（ff） |
| 7 | −4 | 7（ff） | 3（p） |
| 8 | −1 | 3（p） | 2（pp） |
| 9 | +2 | 2（pp） | 4（mp） |
| 10 | （枠） | 4（mp） | 無音へ |

1 小節目の無音からの出だしと、10 小節目の無音への消えは枠で、仕組みには入らない。

### 仮の値をなぜ選んだか

- **起点 4**: 0〜8 のちょうど真ん中。セットの和が 0 なので、後半の強さの並び（5〜9 小節目）は、前半の並び（1〜5 小節目）を逆から読み、一つずつ「起点の 2 倍」から引いたものになる。
  起点が真ん中（4）だと、これは 8 から引くこと、つまり目盛りを真ん中で上下に裏返すことで、目盛りは目盛りそのものに写る（0 と 8、1 と 7 が入れ替わる）。だから前半が目盛りの中にいれば、後半も必ず中にいる
- **四つの大きさ 1・2・3・4**
  - 全部違う。どの段差がどの間から来たのかを区別できる
  - この軸の atom（マーク一つ）である 1 を含む。いちばん小さい単位を最初から入れておく（音程の仮の値に .5 の付く間を入れるのと同じ理由）
- **和が 0**: 端が本当の端なので、和が 0 でないセットで歩き続けると、いつか端の外に出る。和が 0 であることが、二つの端のあいだで歩き続けられる条件になる。一巡すると必ず起点に戻る
- **向きの分け方**: 1・2・3・4 の和を 0 にするには、和の等しい二組に分けるしかなく、その分け方は {1、4} と {2、3}（どちらも和 5）の一通りだけ。
  どちらの組を弱くなる向きにするかは、全体を上下に裏返すかどうかの違いなので、仮に {1、4} を弱くなる向き（−1、−4）、{2、3} を強くなる向き（+2、+3）にした
- **書いた順 +2、−1、−4、+3**: 四つの間の並べ方 24 通りを、起点 4 から二巡とも実際に歩いて数えた
  - 端の外に出ないもの: 16 通り
  - そのうち、どちらの巡でも 0 にも 8 にも着かないもの: 8 通り。0 に着くと、その小節は無音になり、次の段差は段差ではなく無音からの出だしとして聴こえる。休みが入るので時間の軸まで動く。
    8 は、起点を軸にした裏返しで 0 と対になるので、片方の巡で 8 に着けば、もう片方で 0 に着く。だから鳴っている強さ 1〜7 の中に収めた
  - そのうち、四つの間のどれもが、前半と後半で違う強さから取られるもの: 2 通り（+2 −1 −4 +3 と、その逆順 +3 −4 −1 +2）。
    同じ間が違う立ち位置から取られると、違うマークに着く。前提の「名前は、立つ位置で変わる」を、強弱の上で四つの間すべてについて聴ける形
  - この 2 通りは、前半と後半を入れ替えただけの同じ二巡になる。どちらを前にするかに構造の理由はないので、仮に +2 から始まる方にした
  - 結果（選んだ理由ではない）: 起点以外に立つ 6 つの強さが、1、2、3、5、6、7 に一度ずつ。ppp から ff までのマークすべてに立つ
- **後半は同じ四つの逆順**: 新しい値を足さない。変わるのは読む順（規則）だけ
- **一小節に一弓、♩ = 54**: 一つの強さを 4.4 秒保つ。段差と段差のあいだに、その強さを強さとして聴く時間を置く。10 小節で 0:44
- **音 60（MIDI 番号）**: チェロの音域（36〜84）のちょうど真ん中。開放弦（36、43、50、57）ではない押さえた音

## 聴きどころ

- 音の高さもリズムも変わらないのに、強さだけが小節線ごとに段で替わること（一小節の中では変わらない）
- 聴こえる段差は、どれもセットの四つの間（+2、−1、−4、+3）のどれか。大きさは 1〜4 マークの四種類だけで、それ以外の大きさの段差は一つもない
- 同じ間が、違う強さから取られて、違うマークに着く所。間は同じなのに、着いた所の名前は、立っていた所で変わる
  - −4: 4 小節目（0:13）mf から ppp、7 小節目（0:27）ff から p
  - +3: 5 小節目（0:18）ppp から mp、6 小節目（0:22）mp から ff
  - +2: 2 小節目（0:04）mp から f、9 小節目（0:36）pp から mp
  - −1: 3 小節目（0:09）f から mf、8 小節目（0:31）p から pp
- 5 小節目（0:18）と 9 小節目（0:36）で、どちらの巡も起点の強さ（mp）にちょうど戻ること
- 後半（6 小節目から。楽譜には練習記号 reversed）: 段差の並びが前半の逆順になる。強さの並び 4、7、3、2、4 は、前半の 4、6、5、1、4 を、4 を軸に上下裏返し（8 から引く）、逆から読んだもの
- **耳で判断してほしい点**
  - 同じ間が、目盛りの違う所で同じ大きさの段差として聴こえるか。1 マークの差が聴こえの上でどれだけの大きさになるかは、強さの所によって揃わないかもしれない（推測）。
    揃わなければ、「同じ間」は数の上だけのものになり、この課題はそこで答えが出る
  - マーク一つの段（3 小節目の f から mf、8 小節目の p から pp）が、段として聴こえるか。大きな段差のあとで埋もれないか
  - 後半が前半の裏返しの逆読みであることは、数の上では確か。聴いて分かるかは分からない（推測）
  - 段で替わる強さが、名前の付いた効果（段ごとに強さを替える書き方、4 小節目の mf から ppp や 7 小節目の ff から p のような突然の弱音）として聴こえるか、同じ四つの間が立つ位置を替えて出てくるものとして聴こえるか。
    前者なら、仕組みは正しくても、聴こえる結果は名前の側に落ちている

## 楽器

独奏チェロ 1 本（1 人。再生はチェロのソロの音）。音は一つ（MIDI 60）で、最初から最後まで変えない。arco、ふつうの弾き方、弱音器なし、弓の位置の指定なし。
一小節に一弓で、弓を返す所で次の強さに移る。

チェロにしたのは、無音から弓で音を出せ、弓を返す所で強さを段で替えられ、ppp から ff まで同じ一つの音色の中で出せるから。強弱以外に聴こえが変わる要素を持ち込まないため。

## つまみ

- **Set**: 強弱の間のセット（マーク、− は弱くなる向き）。書いた順がそのまま前半の規則で、後半はその逆順。和が 0 なら、どちらの巡も起点に戻る。整数だけ、−8〜8。
  端は折り返さないので、歩きが 0〜8 の外に出るセットと起点の組は、楽譜を書かずに、何小節目で外に出るかを知らせる
- **Standpoint**: 起点の強さ（0〜8）。仮のセットで外に出ないのは 3、4、5。3 だと 4 小節目が 0（無音の小節）に着き、5 だと 6 小節目が 8（fff）に着く
- **Tempo**: テンポ（一小節に一弓）

Set は、ほかのスケッチのような目盛りのつまみ（間のセットのつまみ）ではなく、文字で書くつまみにした。目盛りのつまみは間を大きさの順に並べ替えてしまい、書いた順（規則）を保てないため。

固定したもの（仕組みの一部）: 目盛り 0〜8 と、その端を折り返さないこと、音の高さ、一小節に一弓、前半は書いた順・後半は逆順の二巡。
強さが 0 に着いた小節は、無音なので休みになる（仮の値では着かない）。

## 事実

仮の値で、書かれた楽譜（`dynamics-a-between.json`）を数えた。

- 長さ 0:44（10 小節、♩ = 54、一小節 4.44 秒、44.44 秒）。`check.ts` は OK、警告 0。1 パート、10 音。`vp check` はエラー 0
- 9 つの段の強さ: 4、6、5、1、4、7、3、2、4。10 小節目は 4 から無音へ
- 聴こえる段差（隣り合う小節の強さの差）: 前半 +2、−1、−4、+3、後半 +3、−4、−1、+2。取り出した間と、8 段のうち 8 段が一致した。折り返しは 0 回。どちらの巡も和は 0
  - 聴こえる段差の大きさは 1、2、3、4 の四種類で、どれもちょうど 2 回
- 同じ間を取った二か所の強さ: +2 は 4 → 6 と 2 → 4、−1 は 6 → 5 と 3 → 2、−4 は 5 → 1 と 7 → 3、+3 は 1 → 4 と 4 → 7。四つの間すべてで、立っていた強さも着いた強さも二度とも違った
- 使われた強さ: 4 が 3 回（1、5、9 小節目）、1、2、3、5、6、7 が 1 回ずつ。0 と 8 は一度も出ない。いちばん低いのは 1（ppp）、いちばん高いのは 7（ff）
- 後半の段差の並びは、前半の段差の並びを逆から読んだものと一致した。強さの並び 9 つは 5 小節目を中心に対称で、i 番目と（8 − i）番目の和がすべて 8
- 音の高さはスコア全体で 1 種類（MIDI 60）。音は 10 で、どれも小節の頭から 4 拍、すき間も重なりも 0
- 強弱以外に変わる要素: 0。音の書き込みは時刻・長さ・音高の三つだけで、奏法、アーティキュレーション、スラー、グリッサンド、トリル、音ごとの強弱の指定は、どれも 0
- 記譜: 強弱記号は小節ごとに一つずつ mp、f、mf、ppp、mp、ff、p、pp、mp。ヘアピンは二つだけ（1 小節目の頭の 1 拍、無音からのクレッシェンドと、10 小節目の無音へのディミヌエンド）
- 再生の計画: チェロのソロの音（Celli Leader）。10 音すべて持続音のサンプル（Long）で、弓ごとに発音し直す。
  発音の強さ（velocity）は 16、94、81、29、68、107、55、42、68、68。連続して流れる強さ（CC1）は、各小節の中で一定の 64、95、79、16、64、111、48、32、64 で、値が変わるのは小節線だけ（1 小節目の頭の 1 拍の 0 から 64 と、10 小節目の 64 から 0 への消えを除く）
- 起点のつまみを 0〜8 で一つずつ試した: 仮のセットで楽譜が書かれるのは 3、4、5。ほかはどれも、外に出る小節を知らせて止まる

## 作曲の段で考える点（いまは狭めない）

- 弓を返す瞬間に、mf から ppp、ff から p（4 マーク下）、ppp から mp、mp から ff（3 マーク上）へ段で移る。返しの瞬間にだけ強さを替え、弓の途中では保つこと
- 4.4 秒の一弓を、ppp でも ff でも同じ音色のまま保つ（弓の配分）
- 目盛りの 1 マークの差が、聴こえの上でどれだけの大きさになるかは、楽器・音域・奏者で揃わない（推測）。数の上では同じ間でも、聴こえの段差は揃わないかもしれない。再生でも、強さは目盛りの数に比例する値で送っている
- 音の高さと鼓動を固定したのは、課題を一つにするため。強弱の軸を音程や時間の軸と同時に動かしたときにどう聴こえるかは、別のスケッチの問い

## 見直しで変えたこと（2026-09-29）

前の版は、目盛りの外に出た強さを、目盛りの幅 8 だけ戻して中に入れていた（9 → 1、−1 → 7）。これは音程のオクターブを強弱に借りた操作で、niente（0）と fff（8）を同じと見なすことになり、聴こえの上でそれに当たるものがない。
しかも書いた順（−1、−4、+2、+3）は端を越えるように並べてあり、8 段のうち 4 段が折り返しだった。聴きどころの中心がその折り返しで、+2 と −4 はそのままの形では一度も聴こえなかった（聴こえたのは −6 と +4）。

今の版では、端を端として扱い、折り返しをやめた。セットの四つの間と起点、テンポ、楽器はそのままで、書いた順だけを +2、−1、−4、+3 に替えた（理由は「仮の値をなぜ選んだか」）。
聴こえる段差がセットの間そのものである段は、8 段のうち 4 段から 8 段になった。
