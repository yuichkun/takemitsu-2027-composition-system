# A · 一つの数え、三つの単位

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

間を、四分音の何個分かという「数え」として持つ。三本の線が同じ起点（最初の音）から、同じ数えの列を、単位だけ替えて読む。単位は四分音 1 個分、2 個分（半音）、3 個分。

前提の一つ目（関係が先にあり、項は後から付く名前である）に沿った課題。数えは関係の側にあって、音の高さという名前は、その数えをどの単位で読むかが決まって初めて付く。一つの数えの列に、三つの単位で同時に名前を付ける。

## 仕組みと聴こえ方

- **間と数え**: 間は二つの音のあいだ。大きさは四分音（間の atom。それ以上は割らない単位）の何個分かで数える。この「何個分か」を、ここでは数えと呼ぶ。上へは +、下へは −
- **単位**: 数えを音の高さの差に直すときの、一目盛りの大きさ。単位 1 は四分音 1 個（数え 1 が 0.5 半音）、単位 2 は四分音 2 個（数え 1 が半音）、単位 3 は四分音 3 個（数え 1 が 1.5 半音）。数え c を単位 u で読むと c × u 個の四分音、つまり c × u ÷ 2 半音になる
- **セット**: どの数えを、いくつずつ持つか。ここでは 6 つの数え +3、−1、+6、−9、+12、−11（書いた順）。6 つの和は 0
- **規則**: セットから、次にどの数えを取り出すか。ここでは書いた順に読み、セットを読み終えるたびに、次は一つ後ろから読み始める（一巡ごとに一つずらす）。取り出しは一度だけで、三本はその同じ数えを読む
- **巡**: セットの 6 つを一回ずつ読み終えるまでの一回り。6 巡で 36 の数えになる
- **起点と歩き方**: 三本とも起点 60（MIDI 番号。C4）から一緒に始める。各線は、読んだ数えに自分の単位を掛けたものを、自分の直前の音に足していく。オクターブで折り返さない
- **部分和**: 始めからその時点までに読んだ数えの合計。三本とも部分和は同じで、線の高さは「起点 + 部分和 × 単位 ÷ 2 半音」。だから三本はいつも同じ向きに動き、動く幅の比はいつも 1 : 2 : 3 になる。同じ形を、三つの大きさで描く
- **縦の間**: 同時に鳴る二本のあいだの間。部分和に二本の単位の差を掛けた数の四分音になる。単位 1 と 2、2 と 3 のあいだは部分和の半分の数の半音、いちばん外の 1 と 3 のあいだは部分和と同じ数の半音。
  だから単位 2 の線はいつも外の二本のちょうど真ん中にいて、下の縦の間と上の縦の間はいつも同じ大きさになる。縦に聴くと、同じ間を二つ重ねた響きが、幅だけを替えながら動く
- **同じ音への戻り**: 部分和が 0 の所では縦の間が全部 0 になり、三本は同じ音（起点）に立つ。一巡で読む 6 つの数えの和は、どこから読み始めてもセットの和 0 なので、巡の終わりごとに三本は起点に戻る。並べて作ったのではなく、和が 0 であることから出てくる。この書いた順では、巡の途中で部分和が 0 になることはない。二本だけが同じ音になることもない（縦の間はどれも部分和に比例するので、二本が揃う所では三本とも揃う）
- **上下**: 三本の上下は部分和の正負だけで決まる。正なら単位 3 がいちばん上、負ならいちばん下。部分和が一歩で正から負へ（または逆へ）跳ぶ所では、三本が同じ瞬間に互いを跳び越えて上下が入れ替わる
- **格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。起点 60 が乗る方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ
  - 単位 2 の線は、どの数えを読んでも半音の整数しか足さないので、起点の格子から一度も出ない。**これは選んだことではなく、単位 2 が四分音の偶数個であることの結果。** 単位を決めるときに格子のことは考えていない
  - 単位 1 と単位 3 の線は、数えが奇数のとき（四分音の奇数個を足すとき）に格子を移る。二本はいつも同じ瞬間に移るので、いつも同じ格子にいる（二本の縦の間に .5 は付かない。「.5 が付く」は、半音で数えた間に四分音一つ分の端数があること。二本が別々の格子にいるとき付く）
  - 部分和が奇数の所では、単位 1 と 3 がずれた格子、単位 2 が起点の格子にいて、二つの格子が同時に鳴る
- **時間**: 時間の間も足し算で組む。atom は仲間（素数 2・3・5 の系統）ごとに一つあり、時間の間はその atom の何個分かで数える。ここでは 3 の仲間（3 連 8 分）の atom 4 個 = 1⅓ 拍を、時間のセットが持つただ一つの間にした。三本は同じ瞬間に次の音へ移り、どの音も次の鳴り始めまで切れ目なく伸ばす。テンポ 60 で一巡 8 秒
- **強弱**: 三本とも最初から最後まで p。アクセントも、同じ音への戻りの印も付けない。最後の同じ音（48 拍目）だけを 4 拍伸ばし、niente（音が無くなるところ）まで消える

### 単位を 1・2・3 にした理由: 時間の仲間との並行

- 時間の軸では、間は atom の何個分かという数えで、どの仲間の atom で読むかによって長さが変わる。同じ数え 4 が、2 の仲間では 1 拍、3 の仲間では 1⅓ 拍、5 の仲間では ⅘ 拍になる。数えは同じで、単位だけが違う
- このスケッチは、その構図を音程の軸に置いた。時間の軸には atom が三つ（仲間ごとに一つ）あるが、音程の軸の atom は四分音一つだけなので、単位はその整数倍として作る。1・2・3 は、atom そのものを含めた、いちばん小さい三つの倍数
- 格子の重なり方も並行している。時間では、2 の仲間と 3 の仲間の格子は拍ごとに重なる（2 の atom 4 個 = 3 の atom 3 個）。ここでは、単位 2 の線と単位 3 の線が立ちうる高さは、起点から 3 半音ごとに重なる（単位 2 の 3 目盛り = 単位 3 の 2 目盛り = 四分音 6 個）。単位 1 の線は、どの四分音にも立てる

### 仮の値をなぜ選んだか

- 数えのセット: 6 つの大きさ（1、3、6、9、11、12）が全部違い、上向き 3（+3、+6、+12）・下向き 3（−1、−9、−11）、奇数 4（3、1、9、11）・偶数 2（6、12）
  - 和が 0 なので、一巡ごとに三本が起点で同じ音に戻る
  - 大きさが全部違うので、形の中の一歩一歩が区別できる
  - 奇数と偶数が混ざるので、単位 1 と 3 の線には、格子を移る歩み（6 歩のうち 4 歩）と移らない歩み（2 歩）の両方が出る
  - どの単位で読んでも一歩が 2・5・7 半音にならない数えだけを使った（手引きの決まり: 2・5・7 を仮の値に置かない）。最初の案 {−9 −4 −2 +3 +5 +7} は、単位 2 で読むと −2・+5・+7 半音の歩みになるので替えた。この条件で上の性質（6 つ、大きさが全部違う、上下 3 ずつ、奇数 4・偶数 2、和 0）を満たす組のうち、いちばん大きい数えがいちばん小さくなるもの（その中で大きさの合計もいちばん小さいもの）が 1、3、6、9、11、12。上向きと下向きへの分け方は二通りあり、最初の案の −9 と +3 が残る方を取った
- 書いた順（+3 −1 +6 −9 +12 −11）: 上向きと下向きを一歩ずつ交互にし、上向きも下向きもそれぞれ狭い順に並べた。上と下を組にしたので部分和は 0 の近くを行き来し、どの巡でも部分和の幅はちょうど 12（起点から −12〜+12 の中）に収まる。値の順（−11 −9 −1 3 6 12）で読むと、最初の巡で部分和が −21 まで下がり、単位 3 の線は起点の 31.5 半音下（28.5）へ行ってチェロの音域を出る。また、この順ではどの巡の途中でも部分和が 0 にならないので、三本が揃うのは巡の終わりだけになる
- 巡の数 6: 読み始めのずれが一周する数（セットの個数）。6 つの巡の形はすべて違う
- 起点 60: チェロの音域（36〜84）の真ん中。部分和が −12〜+12 で上下対称なので、いちばん大きく動く単位 3 の線（42〜78）も上下に同じだけ（6 半音）余白が残る
- 時間の間は一つだけにして、時間の規則が聴こえないようにした。聴こえる規則は音程の側だけ

## 聴きどころ

- 三本が同じ音（60）から出て、いつも同じ向きに、1 : 2 : 3 の大きさで動くこと。最初の一歩で、単位 1 は 1.5 半音、単位 2 は 3 半音、単位 3 は 4.5 半音上がる
- 8 秒ごと（0:08、0:16、0:24、0:32、0:40、0:48）に、三本が一つの音に戻ること。戻る音はいつも同じ 60。戻る一歩の前、三本は 1〜12 半音に開いている（外の二本の間が、巡の順に 11、3、1、6、9、12）
- 縦に聴くと、真ん中の線がいつも外の二本のちょうど真ん中にいること（下の間と上の間が同じ）。部分和が変わるたびに、その同じ間の大きさだけが替わる（0〜6 半音）
- 三本の上下が、一歩で入れ替わること（12 か所）。0:32〜0:40 の巡は三本とも起点より上で開き（単位 3 が 78 まで）、0:40〜0:48 の巡は三本とも下で開く（単位 3 が 42 まで）
- 真ん中の単位 2 の線は起点の格子から一度も出ず、上下の二本は同じ瞬間に格子を移ること
- **耳で判断してほしい点**
  - 三つの大きさの同じ形として聴こえるか、それとも三本の別の線に聴こえるか
  - 8 秒ごとの同じ音が、区切り（終止のような着地）として立ちすぎないか。楽譜には強弱もアクセントも付けていない。
    ただし再生では、三本とも BBC SO の同じ独奏チェロの音（同じ録音）で鳴るので、同じ音の所では三つの同じ波が重なって、一つの音が太く、大きくなったように聴こえうる。これは再生の音源による上乗せで、仕組みからは来ない。生の三人なら、同じ音でも三人の音は揃いきらない
  - 単位 2 の線は半音の整数だけで歩き、巡ごとに一回 12 半音跳ぶ。単位を選ぶときに名前は使っていないが、半音だけの線として名前が先に立って聴こえるか

## 楽器

独奏チェロ 3 本。Vc 1 が単位 1、Vc 2 が単位 2、Vc 3 が単位 3。arco、ふつうの弾き方。

同じ楽器にして音色を揃え、動きの大きさの比だけが聴こえるようにした。三本とも同じ音から始め、同じ音に戻る。

## つまみ

- Counts: 数えのセット（四分音の個数、整数、− は下向き）。書いた順がそのまま規則の順になるので、並べた順に意味がある。三本とも同じ数えを読む
- Units: 三つの単位（四分音の個数、1 以上の整数）。楽譜の上から Vc 1、2、3 の順
- Standpoint: 起点。三本がここから一緒に始める。オクターブで折り返さないので、チェロの音域（36〜84）を出る線があるとスケッチはエラーで止まる
- Passes: 巡の数。同じ音は巡の数より一つ多い（始めと、各巡の終わり。和が 0 のとき）
- Time between: 時間のセットが持つ一つの間（atom の数）
- Family: その atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- Tempo: テンポ

Counts は、ほかのスケッチのような目盛りのつまみ（間のセットのつまみ）ではなく、文字で書くつまみにした。目盛りのつまみは間を大きさの順に並べ替えてしまい、書いた順（規則）を保てないため。

## 事実

- 0:52（13 小節、♩ = 60）。`check.ts` は OK、警告 0。3 パート、111 音（各線 37 音）。`vp check` はエラー 0
- 鳴り始めは 37 か所（0 拍目から 1⅓ 拍おきに 48 拍目まで。すべて 3 連 8 分の格子の上）。三本はどの鳴り始めでも同時に動き、どの音も次の鳴り始めまで伸びる（すき間も重なりも 0）。最後の音だけ 4 拍
- 読んだ数え（巡ごと）: +3 −1 +6 −9 +12 −11 ｜ −1 +6 −9 +12 −11 +3 ｜ +6 −9 +12 −11 +3 −1 ｜ −9 +12 −11 +3 −1 +6 ｜ +12 −11 +3 −1 +6 −9 ｜ −11 +3 −1 +6 −9 +12
- 比: 36 歩すべてで、単位 j の線の一歩 = 数え × 単位 j ÷ 2（1 : 2 : 3、ずれ 0）。三本が同じ向きに動いたのは 36 歩のうち 36。どの鳴り始めでも、高さ = 60 + 部分和 × 単位 ÷ 2（37 か所のうち 37）
- 同じ音（三本）: 37 か所のうち 7。0、6、12、…、36 番目の鳴り始め（0:00、0:08、…、0:48）で、音はいつも 60。二本だけが同じ音になる所は 0
- 部分和: 37 か所で 21 通りの値（−12〜+12 のうち、±7 と ±10 以外）。各巡の部分和の幅はどれも 12（巡 1: −1〜+11、巡 2: −4〜+8、巡 3: −3〜+9、巡 4: −9〜+3、巡 5: 0〜+12、巡 6: −12〜0）
- 音域: 単位 1 が 54〜66、単位 2 が 48〜72、単位 3 が 42〜78（どれもチェロの 36〜84 の中）。どの線も 21 の違う高さに立つ
- 一歩の大きさ（半音）
  - 単位 1: −5.5、−4.5、−0.5、+1.5、+3、+6（平均 3.5）
  - 単位 2: −11、−9、−1、+3、+6、+12（平均 7）
  - 単位 3: −16.5、−13.5、−1.5、+4.5、+9、+18（平均 10.5）。36 歩のうち 18 歩が 12 半音以上
  - 2・5・7 半音の一歩は、どの線にもない
- 格子: 格子を移る歩みは、単位 1 が 24、単位 3 が 24（同じ 24 か所）、単位 2 が 0。ずれた格子にいる鳴り始めは、単位 1 と 3 が 18、単位 2 が 0。二つの格子が同時に鳴っているのは 37 か所のうち 18（部分和が奇数の所）
- 縦の間
  - 単位 1 と 2、単位 2 と 3: .5 付きが 37 のうち 18、最大 6 半音
  - 単位 1 と 3（いちばん外の二本）: .5 付きが 0、最大 12 半音
- 上下: 部分和が正（単位 3 がいちばん上）の鳴り始めが 15、負（いちばん下）が 15、0（同じ音）が 7。三本が同じ音を通らずに一歩で上下を入れ替える所が 12
- 強弱: 三本とも p のまま。最後の音だけ、48 拍目から 52 拍目へ niente まで減衰。アクセント、奏法の指定、スラー、グリッサンドは 0
- 再生: 三本とも BBC SO の Celli Leader（独奏チェロの音）、持続音のサンプル（Long）、同じ強さ。四分音の高さは、50 セント上げた別の音源で鳴らす（近い音での代用なし）

## 作曲の段で考える点（いまは狭めない）

- 単位 3 の線の大きな跳び（最大 18 半音、12 半音以上が 36 歩のうち 18 歩）を、1⅓ 秒ごとに、p のまま。着く高さの半分（18 か所）が四分音の高さで、いちばん低いのは 43.5
- 単位 1 の線は、四分音一つ（−0.5）を含む細かい歩みで、18 か所が四分音の高さ
- 三本の同じ音 60 の音程の揃え。三本は違う幅の跳びで 60 に着く（単位 3 は最大 18 半音の跳びで着く）
- 三本が一歩で互いを跳び越えて上下を入れ替える所（12 か所）の譜読みと、同じ楽器どうしの交差の聴こえ方
- 2・5・7 を外した結果、いちばん大きい数えが 12 になり、単位 3 の跳びが大きくなった。跳びを小さくするなら、数えのセットや単位（つまみ）で試せる
