# A · 両端から切る

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

和音を、立ち位置に間を積んだものとしてではなく、一つの広い間を切っていったものとして持つ。
二声の枠を、規則が取り出した間で、下の端から・上の端からと交互に切る。切るたびに一声が増え、切り取った間はセットの大きさ、残りはセットにない大きさになる。
残りがセットのどの間より狭くなったら和音は満ちる。そのあと、切れ目が開いた順に閉じていき、枠だけが残る。

前提の三つ目（どの項も立っていない切れ目は、欠けではなく、新しいものが定義される場所になる）と一つ目（関係が先にあり、項は後から付く名前である）を、音の高さで試す。

## 仕組みと聴こえ方

- **間**: 二つの音のあいだ。半音単位で書き、四分音は .5
- **枠**: 最初に鳴る二声と、そのあいだの一つの広い間。二声は最初から最後まで同じ高さで伸び続ける。仮の値では MIDI 番号 50 と 72.5 で、幅 22.5
- **切るセット**: 枠を切るのに使う間のセット。仮の値は {1.5, 2.5, 3, 4}
- **規則**: 切るセットから、次にどの間を取り出すか。仮の値は「決まった順に回す」で、狭い順に 1.5、2.5、3、4、1.5、…
- **いちばん広い間**: いま鳴っている和音の、隣どうしの間のうち、いちばん広いもの（同じ広さが二つあれば低い方）。まだどの項も立っていない、いちばん大きい切れ目
- **切る**: 規則が次の間 c を取り出す。和音のいちばん広い間（下の音 a、上の音 b）の中に、新しい一声が入る。
  入る所は、下の端から測って a + c か、上の端から測って b − c。どちらの端から測るかは一回ごとに替わる（1 回目は下の端、2 回目は上の端、…）。
  測りはじめる端が、その一回の**立ち位置**になる。ほかの声は動かない。和音のどの声も、入ったあと一度も高さを変えない
- **残り**: 切られたいちばん広い間は、c と b − a − c の二つに分かれる。c はセットの間。b − a − c を「残り」と呼ぶ。
  残りは、セットが持っていない大きさの間になりうる。それは欠けではなく、切ったことで新しく定義された間
- **満ちる**: 取り出した c が、いちばん広い間と同じか、それより広ければ、もう切れない。そこで和音は満ちる（その c は使わない）
- **閉じる**: 満ちた和音をしばらく伸ばしたあと、切った声が、入った順に一つずつ抜けていく。一声が抜けると、その声の上と下の間が一つにつながる（二つの間の和になる）。最後に枠の二声だけが残る
- **格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。ふつうの半音の方を「起点の格子」、四分音ずれた方を「ずれた格子」と呼ぶ。
  .5 の付く間で測ると、新しい声は測りはじめた端と反対の格子に立ち、.5 の付かない間なら同じ格子に立つ
- 両端から交互に切るので、声は枠の外側から真ん中へ向かって埋まる。最後に真ん中に残る間は、それまでの切り方のすべて（セット、取り出す順、枠の幅）から決まる
- 片側からだけ切ると、はじめのうちは下の端に間を積むふつうの和音の作り方と同じになる（つまみ「Measured from」を below only にすると比べられる）
- 声は一度も動かない。和音が変わるのは、間が切れることと、切れ目が閉じることだけ

### 仮の値をなぜ選んだか

- 枠の幅 22.5: .5 付きなので、枠の二声は別々の格子に立つ（50 は起点の格子、72.5 はずれた格子）。
  下の端 50 はチェロの音域、上の端 72.5 はヴァイオリンの音域の中で、切った声が全部、弦の分奏に収まる幅
- 切るセット {1.5, 2.5, 3, 4}: 4 つの大きさが全部違い、.5 付きが二つ（1.5 と 2.5）、付かないものが二つ（3 と 4）。
  だから切った声の半分はずれた格子へ、半分は同じ格子へ移る
- セットの和は 11。はじめの 8 回の切り（セットを二巡）は、どれも真ん中の残りを切る（残りがずっといちばん広いまま）。
  二巡で切り取る合計は 22 で、枠の 22.5 から引くと 0.5 が真ん中に残る
- 枠の幅と真ん中の余りの関係: 22.5 は、.5 付きの幅のうち、セットの二巡（22）がまるごと真ん中に入る、いちばん狭い幅。
  22 以下の幅では、8 回目の 4 が真ん中を切れず、切りは 7 回で止まる（比べて確かめた）。だから両端から来た切りは、四分音一つ（0.5。音程の間のいちばん小さい粒）を残して真ん中で出会う。
  幅は「.5 付き」「弦の音域に収まる」「二巡がまるごと真ん中に入る」の三つで決め、余りの 0.5 はその幅とセットの和の差として決まる。
  **この四分音一つは、四分音の響きやうなりを聴かせるために置いたものではない。** 両端からの切りが出会う所の幅で、セットにない大きさの間として残る
- 「いちばん広い間を切る」は、まだ誰も立っていないいちばん大きい切れ目へ向かう、という規則。響きの名前は使っていない
- 両端から交互に切るのは、片側からだけ切ると、立ち位置に間を積むふつうの和音と同じになってしまうから。交互にすると、最後に定義される間が真ん中に残る
- 時間の間は一つだけ: 3 の仲間（時間の間を数える素数の仲間 2・3・5 の一つ）の atom（その仲間の最小の粒。3 の仲間は 3 連 8 分）6 個、つまり 2 拍。
  時間の間を一つしか持たないセット（パルス）なので、時間の規則は聴こえない。耳の関心を「どこが切れたか」だけに絞った。テンポ 60 で 2 秒ごとに一声が入り、新しい声と残りの広さが耳に落ち着く
- 満ちた和音は時間の間二つぶん（4 拍）伸ばしてから閉じはじめる。最後の声が抜けたあと、枠の二声は次の小節線から一小節だけ二声で伸び、最後の一小節で消える
- 強弱: どの声も pp。入る声だけ p で入り、1 拍かけて pp に落ちる（どこに入ったかを聴き取れるように）。抜ける声は 1 拍かけて無音へ消える。弦の音色を揃え、強弱も平らにして、増えたり減ったりするのは声の数だけにした

## 聴きどころ

- 0:00、枠の二声（50 と 72.5）だけ。広い一つの間
- 0:02 から 2 秒ごとに一声が入る。下の端から、上の端から、下から、上から、と交互に枠が埋まる。
  入るたびに、真ん中の残りが狭くなる: 21 → 18.5 → 15.5 → 11.5 → 10 → 7.5 → 4.5 → 0.5
- 0:16、両端から来た切りが真ん中で出会い、四分音一つ（59 と 59.5）だけが残る
- 0:18 と 0:20、残っているいちばん広い間（どちらも 4）が、もう一度ずつ切られる（61 と 67.5）。0:20 で和音は 12 声で満ちる
- 0:20〜0:24、満ちた和音がそのまま鳴る
- 0:24 から 2 秒ごとに、入った順に声が抜けていく（51.5、70、54.5、66、56、63.5、59、59.5、61、67.5）。0:43 に最後の声が消え、枠の二声だけになる。0:48〜0:52 で消える
- **閉じ方は、開き方の逆回しではない。** 声が入った順に抜けるので、一つにつながる間（4.5、5、6、4、9、6.5、9.5、11、17.5、22.5）は、切ったときの間とは別の大きさになる。
  下の端のすぐ上がまず開いて、どんどん広がる（4.5 → 6 → 9 → 9.5 → 11 → 17.5）。上の端の下には、0:26 から 0:42 まで 67.5 と 72.5 の間 5 が残る。真ん中の四分音は 0:36 まで残る
- **耳で判断してほしい点**: 真ん中に残る四分音一つ（59 と 59.5）が、うなりとして聴こえるか、両端が出会った所として聴こえるか。
  構造の余りとして残したもので、効果として置いたものではない。うなりに聴こえたとき、どうするかは余湖さんが決める（いまは狭めていない）
- **もう一つの判断点**: 声が一つずつ増えていくので、「積み上げていく」型に聴こえるかもしれない。強弱は平らで、増えるのは声の数だけにしてある

## つまみ

- Bottom: 枠の下の端（既定値は MIDI 番号 50。つまみでは D3 と表示される）
- Span: 枠の幅（半音、.5 は四分音）。上の端は下の端にこれを足した所
- Cut set: 切るセット（半音、.5 は四分音）。つまみはセットを定規の上の点として持つので、いつも狭い順に並ぶ。
  極端な値（狭い間ばかりのセットと広い枠など）で声が増えすぎ、弦の分奏のどれかの一部が一人になるときは、そこでも切るのをやめる（どの分奏も二人以上に保つ）。仮の値ではこの止まり方は起きない
- Rule: in order（狭い順に何度も回す）か shift each time（一巡ごとに一つ後ろから始める）
- Measured from: below and above in turn（下の端と上の端から交互に）か below only（いつも下の端から。比べるため）
- Close: 満ちたあと閉じるか。オフにすると、満ちた和音がそのまま伸びて消える
- Time between: 切りと切りの時間の間、抜けと抜けの時間の間（atom の数。一つだけ）
- Family: その atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- Tempo: テンポ

## 作曲の段で考える点（いまは狭めない）

- 12 部の分奏のうち 6 声が、ずれた格子の音（四分音）を pp で 23 秒伸ばす。入る瞬間に音程の手がかりになるのは、すでに鳴っている和音だけ
- 真ん中の 59 と 59.5 を、隣どうしのヴィオラの分奏が pp で 20 秒保つ（聴きどころの「耳で判断してほしい点」も）
- チェロの 3 部が 50、51.5、54.5 と、低い所で狭く寄る。51.5 は 3 人の分奏で、四分音を pp で保つ
- 抜け方: 弓を返さずに 1 秒で消える。枠の二声は 52 秒の保続なので、分奏の中で弓を替える所をずらす必要がある
