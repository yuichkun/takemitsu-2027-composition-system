# A · 鳴らない起点

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

時間の起点を鳴らさない。起点は立ち位置で、線が時間の間（二つの鳴り始めの間隔）を足し始める所。
三つの仲間（時間の間を数える一粒の種類。2・3・5 の三つ）に一本ずつの線が、同じ間の組（規則がセットから一度に取り出す間の並び）を、
その鳴らない一点から、時間の進む向き（起点より後）へも、さかのぼる向き（起点より前）へも足す。
起点に近づくほど三つの鳴り始めは寄り合っていくが、寄り合うはずの一点だけは誰も鳴らさない。その点が中心として聴こえるか。

**これは原則の一つの読みで、決まっていない。** 原則では、時間の間は最初の鳴り始め（起点）から時間の進む向きへ足していく。
このスケッチは起点を真ん中に置き、同じ間を過去の向きにも足している。「立ち位置から足す」をこう読んでよいかは、余湖さんに確かめてほしい。

## 仕組みと聴こえ方

言葉の確認から。

- **時間の間**: 二つの鳴り始めの間隔。仲間ごとの **atom**（それ以上割らない一粒）の何個分かで数える
- **仲間**: 2・3・5 の三つ。atom は、5 の仲間が 5 連 16 分（1 拍の 1/5）、2 の仲間が 16 分（1/4）、3 の仲間が 3 連 8 分（1/3）
- **格子**: ある仲間の atom の目盛り。一つの線はいつも自分の仲間の格子の上にいる。拍は、三つの格子が重なる所
- **起点**: 線が間を足し始める所（立ち位置）。ここでは拍の上に置き、そこには何も鳴らさない
- **セット**: どの間を、いくつずつ持つか。**規則**: セットから、次にどの間を取り出すか
- **組**: 規則がセットから一度に取り出す間の並び。**番目**は、起点から数えて何番目の鳴り始めか
- **打ち**: ウッドブロックの一打ち。一つの鳴り始め
- **抜け**: 起点をはさむ、何も鳴らない所。起点の直前の打ちから直後の打ちまで

仕組み。

- 三つの線（仲間ごとに一本）が一つの起点を共有する。起点は拍、つまり三つの格子が重なる所に置く。だから、そこから atom を足した鳴り始めは、どの線でも自分の格子から外れない
- 起点ごとに、規則が組を一つ取り出す。三つの線は同じ組を、起点の後ろへ足し、同じ組を起点の前へも足す（前へ足すのは、起点より前に置くこと）。
  前の半分は、起点に近づきながら組を逆の順に聴くことになる。起点をはさんで鏡になる
- 起点そのものには、どの線も何も置かない

聴こえ方。同じ個数の atom でも、仲間ごとに長さが違う（0.2 拍、0.25 拍、1/3 拍）。
だから同じ番目の三つの鳴り始めは、起点からの距離がいつも 12 : 15 : 20 の比になり、起点から遠いほど開き、近いほど寄り合う。
寄り切るはずの一点、三つの線どうしの時間の間が 0 になるはずの所だけが鳴らない。

仮の値と、その理由。

- **セット {1 2 3}**（atom）。規則は **毎回一つずらす**: 起点ごとにセットの読み始めを一つ後ろへずらし、[1 2 3]、[2 3 1]、[3 1 2]、また [1 2 3] と回る
  - 1 を含むので、最初の組では起点にいちばん近い三つが、三つの格子の、起点の隣の最初の目盛りに来る。格子が許すいちばん近い寄り合い
  - 三つとも大きさが違うので、ずらすたびに起点に触れる間が替わり、真ん中の抜けの幅が 1 : 2 : 3 で回る（0.4、0.8、1.2 拍）。規則が、ほかの仕組みを足さずに抜けの幅として聴こえる
  - 合計 6 atom は、3 の仲間でちょうど 2 拍。3 の仲間のいちばん外の鳴り始めが拍に落ち、隣の起点の組と一つを共有する。組どうしが途切れずにつながり、三つの線がそろって止まるのは起点の所だけになる
- **起点の間隔 4 拍**: 起点の片側に足す 6 atom が、3 の仲間で占める長さ（2 拍）の 2 倍。前後の組がちょうど接し、重ならない。起点は各小節の 3 拍目に来る（最初の起点の前に、片側の 2 拍がちょうど入る）
- **起点の数 12**: 組が三通りなので、それを 4 回聴く。最後の起点は近づくだけで離れない。曲は鳴らない起点で終わる
- **木の高さ**: atom の小さい仲間ほど高い木。同じ番目の三つは、近づくときは低・中・高、離れるときは高・中・低の順に鳴り、鏡が音の高さでも聴こえる（番目どうしが混ざる組もある。事実を参照）
- **強弱は p で一定、アクセントなし**: 何も盛り上げない。中心が寄り合いだけで決まるかを聴くため
- **テンポ 60**: いちばん詰まる所（最初の組のいちばん近い三つ）は 50 ms と 83 ms の間隔で、一つの打ちににじむかもしれない。
  ずらした組では 100・167 ms、150・250 ms と開くので、にじむ場合と分かれて聴こえる場合の両方が一つの中にある

## 聴きどころ

- 各小節の中ほどで、低・中・高の三つの木が順に寄り合っていき、寄り切るはずの一点が抜けたまま、今度は高・中・低と離れていく。抜けた一点が中心として聴こえるか
- そのすぐ隣の、鳴っている拍より、鳴っていない拍の方が中心に聴こえるか
- 回ごとに抜けの幅が変わる（0.4、0.8、1.2 拍）とき、中心の立ち方がどう変わるか
- 最初の回では、抜け（0.4 拍）より長い無音（0.5 拍）が外側の小節線のまわりにある。長さではなく寄り合いで中心が決まるかが、ここで聴ける
- 最後は、鳴らない起点で終わる（最後の打ちから 0.6 拍後）

## 楽器

ウッドブロック 3（高 = 5 の仲間、中 = 2 の仲間、低 = 3 の仲間）。一本の線を一つの木に。音の高さを持たない乾いた音で、時間の間だけが聴こえるようにした

## つまみ

- **Set**: 起点から両向きに足す間のセット（atom）
- **Rule**: 起点ごとの組の取り出し方。毎回一つずらす（shift each time）と、決まった順（in order: 毎回同じ組で、抜けの幅は変わらない）
- **Origins every**: 起点どうしの間隔（拍）。起点はいつも拍の上
- **Origins**: 起点の数。最後の起点は近づくだけ
- **Tempo**

どれかの線が起点に届く設定にしても、起点には何も置かない（仕組みの一部として固定）。

## 事実

仮の値で、書かれた楽譜を数えた。

- 長さ 0:48（12 小節、♩ = 60）。`check.ts` は OK で警告 0。`vp check` はエラー 0
- 鳴る打ち 196（高 69、中 69、低 58）。書いたのは 207 で、3 の仲間のいちばん外の打ち 11 か所を隣の起点の組と共有して一つにした（1 小節目の頭を除く、各小節線）
- 12 の起点に置かれた打ち: 0
- 鏡: 最後以外の 11 の起点で、各線の起点の前と後の距離が完全に一致（ずれ 0）
- 比: どの起点のどの番目でも、高・中・低の起点からの距離が 12 : 15 : 20（ずれ 0）
- 格子から外れた打ち: 0。打ちの長さはすべて自分の仲間の atom 一つ、一つの線の中の重なり 0
- 抜け: 0.4 → 0.8 → 1.2 拍の順に回る（11 回。最後の起点は後ろがない）
- 起点以外でいちばん長い無音: 0.5 拍（15 か所、どれも小節線の前後）。ほかの無音はすべてこれより短い（0.05〜0.33 拍）
- いちばん近い三つの広がり: 0.13 拍（最初の組）、0.27 拍、0.4 拍
- 起点から外へ聴こえる順（起点の後ろ側。前側はこの逆）:
  - [1 2 3]: 高 中 低 ｜ 高 中 低 ｜ 高 中 低。番目ごとに三つずつきれいにまとまる
  - [2 3 1]: 高 中 低 ｜ 高 高 中 中 低 低。外の二つの番目は 1 atom しか違わないので、混ざる
  - [3 1 2]: 高 中 高 （中と低が同時） 高 低 中 低
  - いちばん内側の三つは、どの組でも高・中・低の順（離れるとき）
- 線をまたいだ同時（線どうしの時間の間が 0。狙ったものではなく結果）: 7 回。すべて [3 1 2] の組の起点の 1 拍前と 1 拍後で、中と低
- 一つの線の中で聴くと、抜けはその線の最初の間の 2 倍（2、4、6 atom）
- 最後の打ちは、最後の起点（12 小節目の 3 拍目）の 0.6 拍前（高）。その鳴り始めから楽譜の終わりまで 2.6 拍、何も鳴らない
