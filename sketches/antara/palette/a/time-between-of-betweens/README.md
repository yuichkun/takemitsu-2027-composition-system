## 一つの課題

時間の間（二つの鳴り始めの間隔）の並びそのものを、一本の線として作る。
音程の線は「起点の音に、規則がセットから取り出した間を足したもの」。同じ形を一段上に当てて、
最初の間（起点の間）に、規則が差のセットから取り出した差（隣り合う二つの間の、間。「間と間の間」）を足していく。
差が 0 の所では同じ間が続き、そこにだけパルスが結果として生じる。パルスは書かない。拍も書かない。
前提の一つ目（関係が先にあり、項は後から付く名前）を、時間の間どうしの関係に当てたもの: 差が先にあり、一つ一つの間はその後に決まる。

**これは原則の一つの読みで、決まっていない。** 原則では、時間の線は起点に、セットから取り出した間を足したもの。
このスケッチは間を直接セットから取らず、差のセットから取る。
これを「原則の形（起点 + 規則が取り出したもの）を一段上に当てた」と言い直してよいかは、余湖さんに確かめてほしい。

## 仕組みと聴こえ方

言葉の確認から。

- **時間の間**（このカードでは単に**間**）: 二つの鳴り始めの間隔。仲間ごとの **atom**（それ以上割らない一粒）の何個分かで数える
- **仲間**: 2・3・5 の三つ。ここでは 5 の仲間だけを使う。atom は 5 連 16 分（1 拍の 1/5）
- **格子**: ある仲間の atom の目盛り。**拍**は、三つの仲間の格子が重なる所で、5 の仲間では 5 atom ごと
- **差**: 隣り合う二つの間の、間。次の間が前の間より何 atom 長いか（短ければ負）。「間と間の間」
- **差のセット**: どの差を、いくつずつ持つか
- **規則**: セットから、次にどの差を取り出すか
- **組**: 規則が一度に取り出す差の並び。ここでは 3 個ずつ
- **辞書順**: 組を、先頭の差から順に比べて小さい順に並べること（辞書の見出しと同じ並べ方）
- **対**: 辞書順に並べた組の、両端から一つずつ取った二つの組（1 番目と最後、2 番目と最後から 2 番目、…）
- **起点の間**: 最初の間。差を足し始める立ち位置
- **境界**: 間のいちばん短い所と、いちばん長い所
- **折り返し**: 差を足すと境界の外に出るとき、代わりにその差を引くこと
- **パルス**: 同じ間が続く所。原則の言葉では、時間のセットが間を一つしか持たない場合。同じ間が n 回続くと、等しい間隔の n + 1 打になる
- **打ち**: ハープの一回の撥弦。一つの鳴り始め

仕組み。

- 差のセット {−3 −1 0 0 +1 +3}（atom）から、3 個ずつの組を取り出す。組はすべての選び方で、組の中は小さい順。
  0 が二つあるので同じになる選び方が出るが、それは一つにまとめる。14 組
- 14 組を辞書順に並べ、両端から一つずつ取って 7 つの対にする。3 個はセットの半分で、対のもう一方は、セットから一方の組を除いた残りの三つになる。
  だから、どの対もセットをちょうど一度使い、対の差の和は 0
- 規則は、対を外側から順に読む。対の中でどちらの組を先に読むかは、一つ目の対は前の端から、二つ目の対は後ろの端から、と対ごとに入れ替える。
  14 組、42 の差を一度通したら終わる
  - (−3 −1 0)(0 1 3) ‖ (0 0 3)(−3 −1 1) ‖ (−3 −1 3)(0 0 1) ‖ (−1 1 3)(−3 0 0) ‖ (−3 0 1)(−1 0 3) ‖ (−1 0 1)(−3 0 3) ‖ (−3 1 3)(−1 0 0)
- 起点の間は 8 atom。次の間は、前の間に次の差を足したもの。境界 1〜15 atom から出るときは、その差を引く（折り返し）
- 鳴り始めは、0 から間を足していく（音程の線と同じ足し算）。43 の打ちがあり、どの打ちも次の打ちまで響く。最後の打ちは自分の間だけ響いて終わる
- 仮の値で出る間の並び（縦線は組の切れ目、二重線は対の切れ目。聴こえるようには書いていない）:
  8 ‖ 5 4 4 | 4 5 8 ‖ 8 8 11 | 8 7 8 ‖ 5 4 7 | 7 7 8 ‖ 7 8 11 | 8 8 8 ‖ 5 5 6 | 5 5 8 ‖ 7 7 8 | 5 5 8 ‖ 5 6 9 | 8 8 8

聴こえ方。一つの音の打ち方の速さが、atom 一つずつ詰まったりほどけたりし、ときどき 3 つ跳ぶ。
差が 0 の所だけ、同じ間隔の打ちが 3 打か 4 打そろってパルスが聴こえ、次の差で消える。
速さはたいてい起点の間（8 atom）より速い側にいて、対の終わりごとに起点へ戻る（43 の間のうち、8 より短いものが 23、8 が 17、8 より長いものは 3 つだけ）。
どの対も差の和が 0 なので、全体としては速くも遅くもならない。
前の端から読み始める対は、起点の下へ下りて（速くなって）から戻る（7 つ目だけは、下りたあと 9 まで上ってから戻る）。後ろの端から読み始める対のうち、2 つ目と 4 つ目は起点の上へ上って（遅くなって）から戻り、
6 つ目は上らない（和が 0 の組 (−1 0 1) から始まるので）。はじめの 4 対では、下りる対と上る対が交互に来る。

仮の値と、その理由。

- **差のセット {−3 −1 0 0 +1 +3}**
  - 符号を裏返しても同じセットで、合計は 0。セットそのものは速くも遅くもならない。流れの形は、規則の並びから結果として出る
  - 0 が二つ: 0 が二つ続く所で同じ間が三つ続き、4 打のパルスになる。0 が一つの所は 3 打。パルスの長さが二通りになる
  - ±1: atom 一つ。いちばん小さい時間の変化
  - ±3: ±1 と 0 だけが続く所で間が動くのは、この読み方では 1 atom まで。
    対の並べ方や組の中の順を変えても 2 atom まで（どの対にも ±3 があり、一つの対に +1 と −1 は一つずつしかないので、±3 をはさまずに続くのは隣り合う二つの対にまたがる所まで）。
    3 はそれより一つ先で、跳びが小さな歩みの連なりと同じ大きさにならない
- **3 個ずつの組**: セットの半分。対のもう一方がセットの残りの三つになり、どの対もセットを一度ずつ使う。すべての組を一度通すと終わるので、終わりが規則から決まる
- **両端から対にして読む**: 辞書順は組を先頭の差で並べるので、そのまま読むと −3 を含む 7 組（和が −4〜+1）がすべて先に、含まない 7 組（和が −1〜+4）が後に来る。
  線は後半でほぼ倍遅くなり（時間の前半に 30 打、後半に 13 打）、終わりへ向かうリタルダンドという既知の形になる。後半には 2 秒を超える間が 9 つ並び、そこのパルスはまとまりにくい。
  両端から対にすると、どの対も和が 0 で、線は一方へ流れない
- **対ごとに読み始める端を入れ替える**: 前の端の 7 組はどれも −3 を含み、組の中は小さい順なので、先に下りる。
  いつも前の端から読むと、どの対も起点の下へ下りてから戻るので、起点が届く範囲のほぼ上の端になる。
  しかも前の端の組は辞書順の後ほど下り方が浅いので、対ごとの平均の間が 5.0・5.3・6.3・5.3・5.7・6.7・7.3 atom と後ろほど伸び、終わりへ遅くなる形が小さく残る（比べるための数）。
  入れ替えると、後ろの端の組は −3 を含まない（和が −1〜+4）ので、そこから読み始める対は、先に起点の近く（1 atom 下まで）か上を通る。
  下りる一方にならず、起点は届く範囲の中（下へ 4 atom、上へ 3 atom）に来る。
  対ごとの平均の間は、後ろほど伸びる並びではなくなる。ただ終わりの 3 対は、いつも前の端から読む場合と同じ 5.7・6.7・7.3 atom で、少しずつ伸びる（事実を参照）
- **起点の間 8**: 境界 1 と 15 のまん中。どちらへも同じだけ（7 atom）歩ける
- **境界 1 と 15**: 1 は atom そのもの、格子の上でいちばん短い間。15 は 5 の仲間で 3 拍、格子の重なる所。
  この読み方では線は 4〜11 atom の中にいて、境界には届かない（折り返しは起きない）
- **5 の仲間**: 三つの仲間のうち atom がいちばん細かい。1 atom の差が、いちばん小さな時間の差になる
- **音の高さ一つ（MIDI 57）**: 音の高さはこの課題に関係しないので、一つに固定する。
  境界の長い端（15 atom = 2.7 秒）まで響きが残り、短い端（1 atom = 0.18 秒）でも打ちが分かれて聴こえる所として、ハープの中低音にした（響きの長さは見込み。聴いて確かめる）。
  仮の値で鳴る間は 4〜11 atom（0.73〜2.0 秒）で、その内側
- **♩ = 66**: atom は 0.18 秒。鳴る間は 0.73 秒から 2.0 秒で、全体は 53.5 秒、A の長さ（30 秒〜1 分 15 秒）に収まる
- **強弱 p で一定、アクセントなし**: パルスや組の頭を強めない。パルスが差 0 だけから聴こえるかを聴くため

## 聴きどころ

- 打ち方の速さが、atom 一つずつ詰まったりほどけたりし、ときどき 3 つ跳ぶ
- 同じ間隔の打ちがそろう所（9 か所）。パルスは「間と間の間が 0」の所にだけあり、次の差で消える。
  パルスの間隔は初めから終わりまで 0.73〜1.45 秒（4〜8 atom）で、曲のどこでも同じ条件で試せる
- 拍ちょうど（5 atom、0.91 秒間隔）のパルスは 3 か所（32・35・42 秒目から）、どれも 3 打。
  書かれた拍より 1〜2 atom 遅れた所に並ぶ。拍が聴こえるなら、それは書かれた拍とずれた拍
- パルスが、そのまま別の速さのパルスへ移る所は 1 か所: 28〜32 秒目の 8 atom（1.45 秒間隔）の 4 打の最後の打ちから、5 atom（0.91 秒間隔）の 3 打へ
- 起点の間（8 atom、1.45 秒）が、対の終わりごとに戻ってくる。43 の間のうち 17 が 8 atom で、時間の 46% が 8 atom の間。パルスのうち 3 か所も 8 atom（5.5・27.6・49.1 秒目から。最後のものは線の終わり）。
  起点の速さが「帰ってくる速さ」として聴こえるか。
  そして、8 7 8（2 か所、11〜13 番目と 19〜21 番目の間）のように差が 0 でない所まで、8 atom のパルスに聴こえてしまわないか（そう聴こえるなら、課題が起点の戻りに紛れる）
- はじめの 4 対では、下りる対と上る対が交互に来て、対ごとの平均の間が 5.0・8.3・6.3・8.3 atom と振れる。あとの 3 対は 5.7・6.7・7.3 と振れが小さく、少しずつ伸びる。
  速い所と遅い所の交互が、区切りとして聴こえるか
- 終わりへ向けて遅くなる型に聴こえないか。全体では遅くならない（時間の前半と後半で、打ちは 22 と 21）。
  ただ、最後の対は 5 6 9 と伸びてから起点の 8 の 3 打で終わり、時間を 8 つに分けた最後の区間だけ打ちが 4（ほかは 5〜7）。終わりで起点に落ち着く形に聴こえないか

## 楽器

ハープ 1 台、一つの音（MIDI 57、ヘ音記号の段）、ふつうの撥弦。一本の線を一本の弦に。
音の高さと音色を一つにして、時間の間の並びだけが聴こえるようにした

## つまみ

- **Differences**: 差のセット（atom。負の差も 0 も書ける。同じ差を二度書けば二つ持つ）
- **Start**: 起点の間（atom）
- **Bounds**: 境界。いちばん短い間と、いちばん長い間（atom）
- **Group size**: 一つの組の差の数。どの大きさでも、すべての組を一度ずつ、辞書順の両端から対にして読んで終わる。
  仮の値（6 個のセットから 3 個）では、対はセットを一度ずつ使う
- **Order in a group**: 組の中の差の順。ascending（小さい順）か descending（大きい順）。組どうしの順は変わらない
- **Family**: atom の仲間
- **Pitch**: ハープの一つの音（ハープは起点の格子だけなので、半音の刻み）
- **Tempo**

対の読み方（辞書順の両端から対にし、読み始める端を対ごとに入れ替える）は仕組みの一部として固定。
折り返し（境界を出る差は引く）も固定。引いても境界を出るとき（境界の幅が差より狭いとき）は、境界で止める。

## 作曲の段で考える点（いまは狭めない）

- 読み: 15 小節ずっと 5 連 16 分の上で、長い音がタイで拍や小節をまたぐ（タイ 49、5 連の括弧 34）。拍を割らない足し算の線を、拍で書いた楽譜で数えることになる
- 起点が対の終わりごとに戻る: どの対もセットを一度ずつ使い、和が 0 なので、6 つの差ごとに間は必ず起点に戻り、43 の間のうち 17 が起点の 8 atom になる。
  起点の速さが帰ってくる所として聴こえるなら、それは規則の結果で、置いたものではない。ただ、このスケッチではそれが終わりまで消えない。セットを曲の中で変えていく段で、起点に戻る周期をどう扱うか
- 読み始める端を対ごとに入れ替えるのは、線が一方へ偏らないための約束。速い対と遅い対の交互が区切りとして聴こえすぎるなら、ほかの入れ替え方もありうる
- 境界での折り返しは、音程の線を音域にオクターブで戻すのと同じ種類の約束で、仕組みの外から足したもの。この読み方では一度も起きない（線は 4〜11 atom の中）。境界が効くのは、ほかのつまみの値のとき
- 5 atom のパルスが「拍」に聴こえても、それは差が 0 の所に生じた結果で、置いたものではない。しかも書かれた拍から 1〜2 atom ずれている
