# A · 仲間を替える待ち

- 状態: 試し中（2026-09-29。同じ日の見直しで、鳴らし方と組の取り出しの順を変えた）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 見直しで変えたこと

最初の版は、ウッドブロックの乾いた短い打ちで線を鳴らしていた。そこでは、組の中の間（鳴り始めと鳴り始めのあいだ）も、打ちのあとはすぐ無音だった。
待ち（下で定義する休み）は、定義から一拍より短い。次の拍までの残りなので、どのつまみでも 0 以上 1 拍未満になる。
最初の版では待ちが 0〜0.8 拍（平均 0.37 拍）で、組の中の間（0.2〜1.67 拍、平均 0.78 拍）より短いことが多く、30 のうち 16 は自分の組の二つの間のどちらよりも短かった。
無音の続く中に、少し長いか短い無音がもう一つ入るだけなので、待ちは休みではなく、小さなためらいとして聴こえるおそれがあった。

変えたのは二つ。

- **間を鳴らしきる**: 組の中の音は、次の鳴り始めまで（組の最後の音は組の終わりまで）続く。だから線の中の無音は待ちだけになる。
  待ちの長さは前と同じく一拍未満のまま。休みかどうかは、長さではなく、鳴っているか鳴っていないかで分かれるようにした。楽器は、ウッドブロックから、音を持続できる木管 3 本に替えた
- **組の取り出しの順**: 辞書の順のままだと、10 組のひとまわりごとに、和の小さい組から大きい組へ並ぶ（どのひとまわりでも、前半 5 組の和の平均 4.6 atom、後半 7.4 atom）。
  音を鳴らしきると、音の長さがひとまわりごとに伸びていき（計算では、前半の音の平均 0.57〜0.63 拍、後半 0.91〜1.02 拍）、3 回くり返す減速として聴こえる（パレットの手引きの「一方向の偏り」）。
  辞書の順の並びの中を、3 つずつ先へ進みながら取るようにした（理由は下の「仮の値と、その理由」）

変えても残っている疑い（見直しの疑いのうち、解けたのは「待ちがほかの無音に紛れる」所だけ）。

- 待ちは今も一拍未満（0.2〜0.8 拍）。0 でない休み 21 のうち 11 は、前後の二つの音のどちらよりも短い。1 atom の休み 8 つ（0.2〜0.33 秒）は、休みではなく音の切れ目（息継ぎ）として聴こえるかもしれない
- 頭は全部拍に立ち、無音は必ず拍の上で明ける。鳴り続ける線に小さな穴があき、穴のあとの入りが拍を示すので、「拍の格子に小さな穴」と聴こえうる。
  これはこの仕組みそのもので、未決の問い「仲間を替える所が拍として目立ちすぎないか」を試すために変えていない（下の「聴こえ方のおそれ」）
- 再生では、音を離したあとのサンプルの余韻が、短い休みにかかる。0.2 秒の休みがどれだけ無音に聴こえるかは、書き出した音では確かめていない

## 一つの課題

休みを「仲間を替えるための待ち」として持つ。
一本の線が、組（規則がセットから一度に取り出す、時間の間の並び）ごとに、時間を数える粒の種類（仲間）を替える。
替えてよいのは拍の上だけなので、組が拍の途中で終われば、線は次の拍まで待つしかない。その待ちが休みで、線の中の無音はこれだけになる。
休みの長さは誰も選ばない。組の間の和と、その組が立っていた仲間だけから決まる（言葉はすぐ下で定義する）。

前提の三点目「どの項も立っていない切れ目は、欠けではなく、新しいものが定義される場所になる」を、時間で読んだもの。
待ちはどのセットからも取り出されない時間で、組と仲間の関係が、そこで新しい長さを定義する。
二点目の「その名前は、立つ位置で変わる」も入っている。同じ数の組が、どの仲間に立つかで違う待ちを持つ。

**休み（鳴らない時間）の扱いは、音の原則（[`sound.md`](../../../../../docs/antara/sound.md)）でまだ決まっていない。これはその一つの案で、決まったことではない。**
ほかの案には、ある大きさの間を鳴らさずに過ごす読み（[鳴らない間](../time-unsounded-betweens/README.md)）と、音の終わりから次の鳴り始めまでを間にする読みがある。

もう一つ、原則の未決の問い「仲間を替える所が拍として目立ちすぎないか」を、いちばん露わな形で聴く。ここでは頭（組の最初の音の鳴り始め）が全部拍に立ち、仲間の替わり目は全部頭になる。

## 仕組みと聴こえ方

言葉の確認から。

- **時間の間**: 二つの鳴り始めの間隔。仲間ごとの **atom**（それ以上割らない時間の一粒）の何個分かで数える
- **仲間**: atom の種類。2・3・5 の三つ。atom は、2 の仲間が 16 分（1 拍の 1/4）、3 の仲間が 3 連 8 分（1/3）、5 の仲間が 5 連 16 分（1/5）。
  一拍に入る atom の数は、2 の仲間で 4、3 の仲間で 3、5 の仲間で 5
- **格子**: ある仲間の atom の目盛り。二つの仲間の格子が重なるのは、どの組み合わせでも拍の上だけ
- **原則の約束**: 一本の線は、ある区間のあいだ一つの仲間の格子の上で足していく。仲間を替えてよいのは、格子の重なる所（拍）だけ
- **セット**: どの間を、いくつずつ持つか。**規則**: セットから、次にどの間を取り出すか
- **組**: 規則が一度に取り出す間の並び。**和**: 組の間の合計（atom）。**ひとまわり**: 規則が組を全部一度ずつ取り出すまで（ここでは 10 組）
- **音**: 一つの鳴り始めから、その間の長さだけ続く一つの持続音
- **頭**: 組の最初の音の鳴り始め。**組の終わり**: 頭に組の間を全部足した所。組の最後の音はそこで止まる
- **待ち**: 組の終わりから次の頭までの時間。元の仲間の atom で数える。これがこのスケッチの **休み**
- **N 拍目**: 始まりから N 拍たった所。最初の頭が 0 拍目。♩ = 60 なので、N 拍目は N 秒目でもある。
  小節の中の位置は「小節の 1 拍目」のように書く（小節線の上が小節の 1 拍目。たとえば 5 拍目は 2 小節目の小節の 2 拍目）

仕組み。

- 規則は、セット {1 2 3 4 5}（atom）から二つずつ選ぶ組合せ 10 組を辞書の順に並べ、(1 2)(1 3)(1 4)(1 5)(2 3)(2 4)(2 5)(3 4)(3 5)(4 5)、
  その中を 3 つずつ先へ進みながら取り出す（歩幅 3。並びの終わりを越えたら頭へ回り込む）: (1 2)(1 5)(2 5)(4 5)(1 4)(2 4)(3 5)(1 3)(2 3)(3 4)。和は 3 6 7 9 5 6 8 4 5 7。10 組でひとまわりし、また最初から
- 組ごとに仲間を替える: 2 → 3 → 5 → 2 …
- 組は頭から始まり、間を一つずつ足す。間の一つずつに音が一つあり、音はその間の長さだけ鳴る（次の鳴り始めまで）。
  二つの間の組は 2 音で、頭から組の終わりまで切れ目なく鳴る。一つめの間は鳴り始めの間隔として、二つめの間は組の最後の音の長さとして聴こえる
- 組の終わりから次の拍までが待ち。待ちの atom 数は、和に足すと一拍の atom 数の倍数になる、いちばん小さい数（0 以上）。
  式にすると (一拍の atom 数 − 和を一拍の atom 数で割った余り) を一拍の atom 数で割った余り
- 待ちのあいだは誰も鳴らない。線の中の無音は待ちだけ
- 待ちが明けた拍が、次の組の頭。だから頭はいつも拍の上で、どの頭も仲間の替わり目になる
- 和が一拍の atom 数で割り切れると、待ちは 0。組の最後の音が止まる拍で、次の組の頭が鳴り始める。無音はなく、楽器（色）だけが替わる
- 強さは p で一定、アクセントなし。一音ずつタンギングで区切る（スラーなし）
- 30 組目の待ちが明けた所（58 拍目）で線は終わり、楽譜は次の小節線（60 拍目）で終わる

同じ組が、仲間ごとに違う待ちを持つ。10 組 × 3 つの仲間の、待ち（元の仲間の atom）と、その組の頭の時刻（何組目か）:

- 待ちは組の中身では決まらず、和と仲間だけで決まる。(1 4) と (2 3) は並びが違っても和が同じ 5 なので、どの仲間でも同じ待ちになる（2 の仲間で 3、3 の仲間で 1、5 の仲間で 0）

  「待たない組」「長く待つ組」という名前は、組だけでは付かない。どの仲間に立つかで付く

仮の値と、その理由。

- **セット {1 2 3 4 5}**（atom）: いちばん小さい五つの整数で、全部違う大きさ。二つずつの組合せが 10 組になる
- **組の大きさ 2**: 組ごとに 2 音で、組の中に二つの間が聴こえる（一つめは鳴り始めの間隔、二つめは組の最後の音の長さで、そのあとに休みか次の色が来る）。
  和は 3〜9 で、各仲間の一拍の atom 数で割り切れる和（2 の仲間: 4 と 8。3 の仲間: 3、6、9。5 の仲間: 5）と、割り切れない和の両方がある。
  だから待ち 0 も、各仲間でありうる待ちの長さ全部（2 の仲間 0〜3、3 の仲間 0〜2、5 の仲間 0〜4 atom）も現れる
- **歩幅 3 で取り出す**: 辞書の順の 10 組の中を、決まった数（歩幅）ずつ先へ進みながら取る。歩幅が 10 と共通の約数を持たなければ（1、3、7、9）、ひとまわりで 10 組をちょうど一度ずつ通る。
  1 は辞書の順そのもの、9 はその逆の順で、どちらもひとまわりの中で和が一方向に動く（1 なら前半 5 組の和の平均 4.6 atom、後半 7.4 atom。9 なら逆）。
  残る 3 と 7 は互いに逆向きの同じ歩き方で、小さい方の 3 を取った。歩幅 3 では、前半・後半とも和の平均が 6.0 atom になる
- **組の数 30**: 組が 10 でひとまわりし、仲間が 3 でひとまわりする。10 と 3 は互いに素なので、30 組でどの組もどの仲間に一度ずつ当たり、(組, 仲間) の 30 通りを全部一度ずつ通る。
  歩幅 3 で取っても、組の並びは 10 組の並べ替えなので同じ。31 組目からは同じ並びに戻る
- **仲間の順 2 → 3 → 5**: 30 組でどの組もどの仲間に一度ずつ当たるのは、順によらない。だから 30 の待ちの内訳（上の表）は、どの順でも同じ。
  順が変えるのは、どの待ちがどの位置に来るかだけ。2 3 5 は数の小さい順に置いただけで、ほかの理由はない
- **音は間の長さだけ鳴らしきる**: 組の中の間を音で埋めて、無音が待ちだけになるように。
  休みと間の違いが、長さ（休みは 0〜0.8 拍、間は 0.2〜1.67 拍で重なる）ではなく、鳴っているかどうかになる
- **仲間ごとに楽器を分ける**（フルート = 5、オーボエ = 2、クラリネット = 3）: 待ち 0 の所には無音がないので、仲間が替わったことは色でしか分からない。
  どの仲間をどの楽器に当てるかに構造の理由はない（仮）。楽譜の上から atom の小さい順に置いた（木の版と同じ並べ方）
- **一つの音の高さ（MIDI 76）**: 音の高さはこの課題に関わらないので動かさない。三本の音域（[`catalog.ts`](../../../../../src/instruments/catalog.ts) で、フルート 59〜98、オーボエ 58〜93、クラリネット 50〜94）の重なり 59〜93 の真ん中。
  音程の軸では、セットが {0}（同じ音）だけの場合にあたる。音程の間が一つもないので、四分音の格子はここでは働かない。時間の間は atom の整数で数えるので、.5 はない
- **♩ = 60**: atom は 5 の仲間 200 ms、2 の仲間 250 ms、3 の仲間 333 ms。いちばん短い休みといちばん短い音がどちらも 0.2 秒（5 の仲間の 1 atom）で、30 組が 1 分に収まる
- **p で一定、アクセントなし**: 拍が立つなら、それは頭の位置（休みのあとの入り）と色の替わりから来たものだけになる

似た仕組みとの違い。

- [着いた拍で仲間が替わる](../time-change-where-it-lands/README.md) と因果が逆。あちらは、足し算が拍に着いたことが仲間の替わりを起こす。待ちはなく、結果として決まるのはどの仲間にどれだけ留まるか。
  こちらは、組ごとに必ず仲間を替えることが、拍までの待ちを生む。結果として決まるのは休みの長さ
- 曲のアイデアの「同じ並びを三つの仲間で」（[`../../../combos/woods/`](../../../combos/woods/README.md)）は、同じ並びを小節線で仲間ごとに運ぶ。ここでは組は替わり続け、待ちが主題になる

聴こえ方のおそれ。

- 頭が全部拍に立ち、休みは必ず拍の上で明けるので、休みのあとの入りが拍を示す。拍子のように聴こえうる。それが試したいこと（未決の問いそのもの）で、避けない
- 休みは長くない。どのつまみでも一拍未満（次の拍までの残りだから）。ここでは 0 でない休み 21 が 0.2〜0.8 拍（平均 0.50 拍）で、音（0.2〜1.67 拍、平均 0.78 拍）より短いことが多い。
  21 のうち 11 は、前後の二つの音のどちらよりも短い。いちばん短い 1 atom の休み（0.2〜0.33 秒、21 のうち 8）は、休みというより音の切れ目として聴こえるかもしれない。ここで確かめる
- 待ち 0 の 8 か所には無音がなく、色だけが替わる。長さ 0 の休みとして聴こえるか、ただの受け渡しとして聴こえるか

## 聴きどころ

- 線の中の無音は待ちだけ。最後の一つを除いて、無音は拍の上で明け、楽器が替わって次の組が入る
- 同じ組 (1 4)（和 5）: 0:08 の 3 の仲間（クラリネット）では 1 atom（0.33 秒、0:09.67〜0:10）待つ。
  0:27 の 5 の仲間（フルート）では待ちがなく、0:28 にフルートが止まる所でオーボエが入る。0:47 の 2 の仲間（オーボエ）では 3 atom（0.75 秒、0:48.25〜0:49）待つ
- 待ち 0 の 8 か所（0:03、0:14、0:17、0:20、0:27、0:28、0:51、0:54）: 前の楽器の音が止まる拍で、次の楽器が鳴り始める
- いちばん長い休み（5 の仲間の 4 atom、0.8 秒）: 0:11.2〜0:12 と 0:21.2〜0:22
- いちばん短い休み（5 の仲間の 1 atom、0.2 秒）: 0:33.8〜0:34 と 0:46.8〜0:47
- 休みなしでいちばん長く続く所: 0:24〜0:29.5（クラリネット → フルート → オーボエ。待ち 0 が二つ続く）
- 30 の頭が全部拍の上に来る。拍がどれくらい立つか。頭が続けて拍に来る所（0:00・0:01、0:16・0:17、0:19・0:20、0:27・0:28、0:33・0:34、0:39・0:40、0:53・0:54）が、拍がいちばん立ちうる所。
  ここに「仲間を替える所が拍として目立ちすぎないか」の答えがある
- 終わり: 最後の音は 0:57.4 で止まる。最後の待ち（3 atom、0.6 秒）のあとに頭は来ないので、その待ちは待ちとしては聴こえず、1:00 の終わりまで無音が続く

## 楽器

フルート、オーボエ、クラリネット 各 1。三本とも同じ一つの音の高さ（MIDI 76）。一本の線を、仲間ごとに三つの楽器で（フルート = 5 の仲間、オーボエ = 2 の仲間、クラリネット = 3 の仲間）。
一音ずつタンギングで区切れて、音を次の鳴り始めまで持続できる楽器にした。組の中は切れ目なく鳴り、待ちだけが無音になる。一度に鳴るのはいつも一本だけ

## つまみ

- **Set**: 組を取り出すセット（atom）
- **Group size**: 組の間の数。組合せを全部、辞書の順に並べ、その中を歩幅ずつ先へ進みながら取る（ひとまわりで一度ずつ）。組は間の一つずつに一音で、音はその間の長さだけ鳴る
- **Family order**: 仲間の順（2 3 5、2 5 3、3 2 5、3 5 2、5 2 3、5 3 2）。一組ずつ次へ進み、最後の次は最初に戻る
- **Groups**: 組の数。最後の組の待ちが明けた所で線は終わり、楽譜は次の小節線で終わる
- **Tempo**

組ごとに仲間を替える、替えるのは拍の上だけ、待ちは次の拍まで、音は間の長さだけ鳴らしきる、は仕組みの一部として固定。
取り出しの歩幅も固定で、組の数から決まる（組の数と共通の約数を持たない、1 と「組の数 − 1」を除いたいちばん小さい歩幅。そういう歩幅がなければ 1）。
音の高さも固定（三本の音域の重なりの真ん中）。

## 事実

仮の値で、書かれた楽譜（`time-wait-to-change.json`）を数えた。

- 長さ 1:00（15 小節、♩ = 60）。線の終わり（30 組目の待ちが明ける所）は 58 拍目で、そこから 2 拍の無音で終わる。最後の音が止まるのは 57.4 拍目。
  `check.ts` は OK で警告 0（3 パート、60 音）。`vp check` はエラー 0

## 作曲の段で考える点（いまは狭めない）

- 三人で一本の線を受け渡す。各奏者は自分の仲間の格子だけを吹くが、ほかの二人の組のあいだ（と待ち）を数えて、拍の上で入る
- 待ち 0 の 8 か所は、前の奏者が音を止める拍で次の奏者が入る。継ぎ目なく受け渡すこと
- 組は拍をまたいで同じ連符のまま続く（たとえばクラリネットの (4 5) は 3 連 8 分 9 つで 3 拍、フルートの (4 5) は 5 連 16 分 9 つで 1.8 拍）
- 同じ音の高さで、音色の違いだけで仲間を聴き分ける。三本の p の揃え方
- 1 atom の音（フルートで 0.2 秒）を p でタンギングすること
