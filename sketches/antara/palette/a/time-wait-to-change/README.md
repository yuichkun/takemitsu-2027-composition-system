# A · 仲間を替える待ち

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

休みを「仲間を替えるための待ち」として持つ。
一本の線が、組（規則がセットから一度に取り出す、時間の間の並び）ごとに、時間を数える粒の種類（仲間）を替える。
替えてよいのは拍の上だけなので、組が拍の途中で終われば、線は次の拍まで待つしかない。その待ちが休みになる。
休みの長さは誰も選ばない。組の間の和と、その組が立っていた仲間だけから決まる（言葉はすぐ下で定義する）。

前提の三点目「どの項も立っていない切れ目は、欠けではなく、新しいものが定義される場所になる」を、時間で読んだもの。
待ちはどのセットからも取り出されない時間の間で、組と仲間の関係が、そこで新しい間を定義する。
二点目の「その名前は、立つ位置で変わる」も入っている。同じ数の組が、どの仲間に立つかで違う待ちを持つ。

**休み（鳴らない時間）の扱いは、音の原則（[`sound.md`](../../../../../docs/antara/sound.md)）でまだ決まっていない。これはその一つの案で、決まったことではない。**
ほかの案には、ある大きさの間を鳴らさずに過ごす読み（[鳴らない間](../time-unsounded-betweens/README.md)）と、音の終わりから次の鳴り始めまでを間にする読みがある。

もう一つ、原則の未決の問い「仲間を替える所が拍として目立ちすぎないか」を、いちばん露わな形で聴く。ここでは頭（組の最初の打ち）が全部拍に立ち、仲間の替わり目は全部頭になる。

## 仕組みと聴こえ方

言葉の確認から。

- **時間の間**: 二つの鳴り始めの間隔。仲間ごとの **atom**（それ以上割らない時間の一粒）の何個分かで数える
- **仲間**: atom の種類。2・3・5 の三つ。atom は、2 の仲間が 16 分（1 拍の 1/4）、3 の仲間が 3 連 8 分（1/3）、5 の仲間が 5 連 16 分（1/5）。
  一拍に入る atom の数は、2 の仲間で 4、3 の仲間で 3、5 の仲間で 5
- **格子**: ある仲間の atom の目盛り。二つの仲間の格子が重なるのは、どの組み合わせでも拍の上だけ
- **原則の約束**: 一本の線は、ある区間のあいだ一つの仲間の格子の上で足していく。仲間を替えてよいのは、格子の重なる所（拍）だけ
- **セット**: どの間を、いくつずつ持つか。**規則**: セットから、次にどの間を取り出すか
- **組**: 規則が一度に取り出す間の並び。**和**: 組の間の合計（atom）
- **打ち**: ウッドブロックの一打ち。一つの鳴り始め
- **頭**: 組の最初の打ち。**組の終わり**: 組の最後の打ち（頭に組の間を全部足した所）
- **待ち**: 組の終わりから次の頭までの時間の間。元の仲間の atom で数える。これがこのスケッチの **休み**
- **N 拍目**: 始まりから N 拍たった所。最初の頭が 0 拍目。♩ = 60 なので、N 拍目は N 秒目でもある。
  小節の中の位置は「小節の 1 拍目」のように書く（小節線の上が小節の 1 拍目。たとえば 5 拍目は 2 小節目の小節の 2 拍目）

仕組み。

- 規則は、セット {1 2 3 4 5}（atom）から二つずつ選ぶ組合せを全部、辞書の順に取り出す:
  (1 2)(1 3)(1 4)(1 5)(2 3)(2 4)(2 5)(3 4)(3 5)(4 5)。和は 3 4 5 6 5 6 7 7 8 9。10 組で一巡し、また最初から
- 組ごとに仲間を替える: 2 → 3 → 5 → 2 …
- 組は頭から始まり、間を一つずつ足して打ちを置く。頭と、間の一つずつのあとに打ちが来るので、二つの間の組は 3 打。最後の打ちが組の終わり
- 組の終わりから次の拍までが待ち。待ちの atom 数は、和に足すと一拍の atom 数の倍数になる、いちばん小さい数（0 以上）。
  式にすると (一拍の atom 数 − 和を一拍の atom 数で割った余り) を一拍の atom 数で割った余り
- 待ちが明けた拍が、次の組の頭。だから頭はいつも拍の上で、どの頭も仲間の替わり目になる
- 和が一拍の atom 数で割り切れると、待ちは 0。組の終わりの打ちが拍の上に来て、次の頭も同じ拍に来る。
  古い仲間の木と新しい仲間の木が、同時に鳴る（時間の間の 0。原則では未決で、試してよいもの）
- 打ちの長さは、その仲間の atom 一つ。だから楽譜の休符は、待ちより atom 一つ短い（待ちが 1 atom なら休符はない）。強さは p で一定、アクセントなし
- 30 組目の待ちが明けた所（58 拍目）で線は終わり、楽譜は次の小節線（60 拍目）で終わる

同じ組が、仲間ごとに違う待ちを持つ。10 組 × 3 つの仲間の、待ち（元の仲間の atom）と、その組の頭の時刻:

| 組 | 和 | 2 の仲間（一拍 4 atom） | 3 の仲間（一拍 3 atom） | 5 の仲間（一拍 5 atom） |
| --- | --- | --- | --- | --- |
| (1 2) | 3 | 1（0:00） | 0（0:20） | 2（0:39） |
| (1 3) | 4 | 0（0:40） | 2（0:01） | 1（0:21） |
| (1 4) | 5 | 3（0:22） | 1（0:41） | 0（0:03） |
| (1 5) | 6 | 2（0:04） | 0（0:24） | 4（0:43） |
| (2 3) | 5 | 3（0:45） | 1（0:06） | 0（0:26） |
| (2 4) | 6 | 2（0:27） | 0（0:47） | 4（0:08） |
| (2 5) | 7 | 1（0:10） | 2（0:29） | 3（0:49） |
| (3 4) | 7 | 1（0:51） | 2（0:12） | 3（0:32） |
| (3 5) | 8 | 0（0:34） | 1（0:53） | 2（0:15） |
| (4 5) | 9 | 3（0:17） | 0（0:36） | 1（0:56） |

- 待ちは組の中身では決まらず、和と仲間だけで決まる。(1 4) と (2 3) は並びが違っても和が同じ 5 なので、どの仲間でも同じ待ちになる（2 の仲間で 3、3 の仲間で 1、5 の仲間で 0）
- 同じ和 5 が、5 の仲間では一拍ちょうどで待ちがなく、2 の仲間では一拍と 1 atom（次の拍まで 3 atom）、3 の仲間では一拍と 2 atom（次の拍まで 1 atom）になる。
  「待たない組」「長く待つ組」という名前は、組だけでは付かない。どの仲間に立つかで付く

仮の値と、その理由。

- **セット {1 2 3 4 5}**（atom）: いちばん小さい五つの整数で、全部違う大きさ。二つずつの組合せが 10 組になる
- **組の大きさ 2**: 組ごとに 3 打で、組の中に二つの間が聴こえる。和は 3〜9 で、各仲間の一拍の atom 数で割り切れる和（2 の仲間: 4 と 8。3 の仲間: 3、6、9。5 の仲間: 5）と、割り切れない和の両方がある。
  だから待ち 0 も、各仲間でありうる待ちの長さ全部（2 の仲間 0〜3、3 の仲間 0〜2、5 の仲間 0〜4 atom）も現れる
- **組の数 30**: 組が 10 で一巡し、仲間が 3 で一巡する。10 と 3 は互いに素なので、30 組でどの組もどの仲間に一度ずつ当たり、(組, 仲間) の 30 通りを全部一度ずつ通る。31 組目からは同じ並びに戻る
- **仲間の順 2 → 3 → 5**: 30 組でどの組もどの仲間に一度ずつ当たるのは、順によらない。だから 30 の待ちの内訳（上の表）は、どの順でも同じ。
  順が変えるのは、どの待ちがどの位置に来るかだけ。2 3 5 は数の小さい順に置いただけで、ほかの理由はない
- **一打は atom 一つの長さ**（楽譜に書く長さ）: 組の中の打ちが重ならず、待ちが楽譜の上で「最後の打ちのあとの休符」として見えるように。
  ウッドブロックの音はもともとすぐ消えるので、書く長さで聴こえ方は変わらない。耳には、待ちは最後の打ちから次の頭までの空きとして届く
- **仲間ごとに木を分ける**（高 = 5、中 = 2、低 = 3）: 待ち 0 のときにも、仲間が替わったことが色で分かるように。
  atom の小さい仲間ほど高い木（[鳴らない起点](../time-unsounded-origin/README.md)と同じ色の約束）
- **♩ = 60**: atom は 5 の仲間 200 ms、2 の仲間 250 ms、3 の仲間 333 ms。いちばん短い待ち（1 atom）と待ち 0（同時）が、別のものとして聴き分けられる所に置いた
- **p で一定、アクセントなし**: 拍が立つなら、それは頭の位置と色の替わりから来たものだけになる

似た仕組みとの違い。

- [着いた拍で仲間が替わる](../time-change-where-it-lands/README.md) と因果が逆。あちらは、足し算が拍に着いたことが仲間の替わりを起こす。待ちはなく、結果として決まるのはどの仲間にどれだけ留まるか。
  こちらは、組ごとに必ず仲間を替えることが、拍までの待ちを生む。結果として決まるのは休みの長さ
- 曲のアイデアの「同じ並びを三つの仲間で」（[`../../../combos/woods/`](../../../combos/woods/README.md)）は、同じ並びを小節線で仲間ごとに運ぶ。ここでは組は替わり続け、待ちが主題になる

聴こえ方のおそれ。

- 頭が全部拍に立つので、拍子のように聴こえうる。それが試したいこと（未決の問いそのもの）で、避けない
- 待ちは長くない。0〜0.8 拍（平均 0.37 拍）で、組の中の間（0.2〜1.67 拍、平均 0.78 拍）より短いことが多い。0 でない待ちの長さは、どれも組の中の間の長さとしても出てくる。
  だから待ちは、長さではなく、そのあとで色が替わることで待ちと分かる。休みとして聴こえるかは、ここで確かめる
- 待ち 0 の 8 か所では、二つの木が拍の上で同時に鳴る。強さは同じでも、その拍はほかの頭より厚い

## 聴きどころ

- 組の終わりから次の頭までの待ちが、組の数の和と仲間だけで決まっていること。待ちのあとで、木の色が替わる
- 同じ組 (1 4)（和 5）: 0:03 の 5 の仲間では待ちなしで、0:04 に次の頭が組の終わりと重なる。0:22 の 2 の仲間では 3 atom（0.75 秒）待つ。0:41 の 3 の仲間では 1 atom（0.33 秒）待つ
- 待ち 0 の 8 か所（0:04、0:21、0:26、0:27、0:36、0:39、0:41、0:49）: 古い色の最後の打ちと、新しい色の頭が同時に鳴る
- いちばん長い待ち（5 の仲間の 4 atom、0.8 秒）: 0:09.2〜0:10 と 0:44.2〜0:45
- 30 の頭が全部拍の上に来る。拍がどれくらい立つか。頭が拍に続けて来る所（0:20〜0:22、0:39〜0:41 は三つ続く）が、拍がいちばん立ちうる所。
  ここに「仲間を替える所が拍として目立ちすぎないか」の答えがある
- 終わり: 最後の打ちは 0:57.8。最後の待ち（1 atom）のあとに頭は来ないので、その待ちは待ちとしては聴こえず、1:00 の終わりまで無音が続く

## 楽器

ウッドブロック 3（高 = 5 の仲間、中 = 2 の仲間、低 = 3 の仲間）。一本の線を、仲間ごとに三つの木で。
乾いた短い音で、待ちの長さと色の替わりだけが聴こえるようにした

## つまみ

- **Set**: 組を取り出すセット（atom）
- **Group size**: 組の間の数。組合せを全部、辞書の順に回す。組は頭と、間の一つずつのあとで鳴る
- **Family order**: 仲間の順（2 3 5、2 5 3、3 2 5、3 5 2、5 2 3、5 3 2）。一組ずつ次へ進み、最後の次は最初に戻る
- **Groups**: 組の数。最後の組の待ちが明けた所で線は終わり、楽譜は次の小節線で終わる
- **Tempo**

組ごとに仲間を替える、替えるのは拍の上だけ、待ちは次の拍まで、規則は組合せの辞書の順、は仕組みの一部として固定。

## 事実

仮の値で、書かれた楽譜（`time-wait-to-change.json`）を数えた。

- 長さ 1:00（15 小節、♩ = 60）。線の終わり（30 組目の待ちが明ける所）は 58 拍目で、そこから 2 拍の無音で終わる。最後の打ちは 57.8 拍目。
  `check.ts` は OK で警告 0（3 パート、90 音）。`vp check` はエラー 0
- 打ち 90（高 30、中 30、低 30）。強弱は p（3）の一点だけ。アクセント・音高・奏法の指定は 0。打ちの長さはすべて自分の仲間の atom 一つ。
  どの打ちも自分の仲間の格子の上（外れ 0）。一つの木の中での重なり 0
- 組 30。どれも同じ色の 3 打で、組ごとに色が替わる。組の中の間を楽譜から読み直すと、10 組の辞書の順を 3 回まわっていて、10 組のどれも三つの仲間に一度ずつ当たる
- 頭 30 のすべてが拍の上（100%）
- 待ち（元の仲間の atom、組の順に）: 1 2 0 2 1 4 1 2 2 3 0 1 3 0 0 2 2 3 0 0 2 0 1 4 3 0 3 1 1 1。
  30 のすべてが「和に足すと一拍の atom 数の倍数になる、いちばん小さい数」と一致
- 待ち 0 は 8（2 の仲間 2、3 の仲間 4、5 の仲間 2）
- 仲間ごとの待ちの長さ（atom: 回数）: 2 の仲間 0: 2、1: 3、2: 2、3: 3。3 の仲間 0: 4、1: 3、2: 3。5 の仲間 0〜4 が 2 ずつ。どの仲間でも、ありうる長さが全部出る
- 待ちの長さ（秒: 回数）: 0: 8、0.2: 2、0.25: 3、0.33: 3、0.4: 2、0.5: 2、0.6: 2、0.67: 3、0.75: 3、0.8: 2
- 待ちの合計 11 拍（58 拍の 19%）。2 の仲間 16 atom = 4 拍、3 の仲間 9 atom = 3 拍、5 の仲間 20 atom = 4 拍
- 組と待ちを合わせた長さ（頭から次の頭まで。30 組目だけは線の終わりの 58 拍目まで）: 1 拍が 7、2 拍が 18、3 拍が 5。仲間ごとの合計は 2 の仲間 19 拍、3 の仲間 23 拍、5 の仲間 16 拍
- 同時に鳴る打ち（時間の間 0）: 8 か所。どれも待ち 0 の所で、拍の上（4、21、26、27、36、39、41、49 拍目）。木の組は、高と中 2、高と低 4、中と低 2
- 鳴る拍は、0〜57 拍目の 58 のうち 33。頭 30 と、組の中の打ちがちょうど拍に来た 3（13、18、54 拍目。頭から 1 拍ちょうどの間 = 3 の仲間の 3 atom、2 の仲間の 4 atom）。
  鳴らない拍 25。鳴らない拍が二つ続くのは 2 か所（30・31 拍目、37・38 拍目）で、三つ続く所はない
- 頭が続けて拍に来る所: 0・1、3・4、20・21・22、26・27、39・40・41 拍目
- 頭の小節の中の位置: 小節の 1 拍目 10、2 拍目 8、3 拍目 5、4 拍目 7
- 待ちと組の中の間: 組の中の間 60 は 0.2〜1.67 拍（平均 0.78 拍）、待ち 30 は 0〜0.8 拍（平均 0.37 拍）。
  待ちが自分の組の二つの間のどちらよりも短いのは 30 のうち 16。0 でない待ちの長さ 9 通りは、どれも組の中の間の長さとしても出てくる
- 打ちのあとのいちばん長い無音は 1.33 拍で、組の中（3 の仲間の 5 atom の間）。待ちでできる無音はいちばん長くて 0.6 拍（5 の仲間の 4 atom の待ち）
- 楽譜: 高（5 の仲間）は 5 連の括弧 18、低（3 の仲間）は 3 連の括弧 23、中（2 の仲間）はふつうの 16 分。休符 152（高 53、中 51、低 48）、タイ 0

## 作曲の段で考える点（いまは狭めない）

- 一人で三つの木を打つなら、組ごとに（1〜3 拍ごとに、30 回）16 分、3 連、5 連が替わる。替わり目は全部拍の上だが、小節線の上は 30 のうち 10
- 待ち 0 の 8 か所は、二つの木を同時に打つ（二本のばち）
- 組は拍をまたいで同じ連符のまま続く（たとえば 5 の仲間の (4 5) は 5 連 16 分 9 つで 1.8 拍、3 の仲間の (4 5) は 3 連 8 分 9 つで 3 拍）
- 三人で分けるなら、各パートは自分の仲間の格子だけを打つが、ほかの二つの仲間の組のあいだの休みを数えることになる
