# A · 立ち位置が後ろへ下がる

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

一本の線の立ち位置（間を足す元の音）を、直前の音ではなく d 個前の音にする。
セットも規則も、そこから取り出される間の流れも変えず、d だけを 1 → 2 → 3 と替える。
一人が吹く一本の線が、耳の中で d 本の線（糸）にほどけるか。そのとき隣り合う音のあいだに聴こえる間は、セットの間ではなく、二本の糸の切れ目そのものになる。

前提の二点目「名前は、立つ位置で変わる」と三点目「どの項も立っていない切れ目は、新しいものが定義される場所になる」を、一本の旋律の中で試す。

## 仕組みと聴こえ方

### 言葉

- **音の高さ**: MIDI の番号で書く（60 が C4、1 が半音、.5 は四分音上）
- **間**: 二つの音のあいだ。半音単位で数え、四分音は .5 と書く。− は下へ
- **セット**: どの間を、いくつずつ持つか。ここでは −4.5、+1、+3、+2.5、−2 の五つ。**書いた順に意味がある**（次の「規則」がこの順で読む）
- **規則（ずらし読み）**: セットを書いた順に読み、一巡ごとに読み始めを一つ後ろへずらす。
  一巡目は −4.5 +1 +3 +2.5 −2、二巡目は +1 +3 +2.5 −2 −4.5、三巡目は +3 +2.5 −2 −4.5 +1、…（五巡で元に戻る）
- **流れ**: 規則が取り出した間を、取り出した順に一列に並べたもの。スケッチ全体で一本だけで、途中で頭から読み直さない
- **立ち位置**: 間を足す元の音。ふつうは直前の音（線が「歩く」）
- **深さ d**: 立ち位置が何個前の音か。d = 1 はふつうの歩き
- **糸**: 深さ d の区間で、d 個おきに並ぶ音の列（1 番目、1 + d 番目、1 + 2d 番目、…）。深さ d の区間には d 本の糸がある。d = 1 なら糸は一本で、線そのもの
- **糸の間**: 一本の糸の中で続く二つの音のあいだの間。仕組みの上で足しているのはこれ
- **聴こえる間**: 実際に続けて鳴る二つの音（線の中の隣どうし）のあいだの間。d が 2 以上なら、これは別々の糸の音どうしのあいだになる
- **二つの格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。.5 の付く間は線をもう一方の格子へ移し、付かない間は同じ格子に置く
- **atom と仲間**: 時間を数えるいちばん小さな単位。ここでは 2 の仲間の atom（16 分音符）
- **パルス**: 時間の間を一つしか持たないセット。ここでは 2 atom（8 分音符）だけ

### 仕組み

- 三つの区間。深さ d = 1 を 20 音、d = 2 を 40 音、d = 3 を 60 音。全部で 120 音
- 深さ d の区間のはじめの d 音は、立ち位置として置く。1 番目は、前の区間の最後の音（最初の区間は 62）。k 番目は、1 番目に 8.5 ×（k − 1）を足した音（糸の間隔）
- それから先は、どの音も「d 個前の音 + 流れの次の間」。d = 2 なら 3 番目は 1 番目 + 次の間、4 番目は 2 番目 + その次の間、…
- 流れは区間が替わっても止めず、読み直さない。d が替わっても、流れの続きから取り出す
- オクターブで折り返さない。音域の端で跳ね返さない。音がクラリネットの音域（50〜94）の外へ出たら、スケッチは止まる（エラー）
- すると、深さ d の区間では、どの糸も「自分の直前の音 + 流れの間」で歩いている。糸は同じ流れを d 本で交互に分け合う
- 各糸は、どの深さでも 20 音（d = 2 の区間は 20 × 2 = 40 音、d = 3 は 20 × 3 = 60 音）

各区間のはじめ（仮の値）:

```
d = 1  62 57.5 58.5 61.5 64 62 63 66 68.5 66.5 62 …          （聴こえる間: −4.5 +1 +3 +2.5 −2 +1 +3 …）
d = 2  59 67.5 62 65.5 57.5 66.5 60.5 69 56 70 …             （聴こえる間: 0 +8.5 −5.5 +3.5 −8 +9 −6 +8.5 −13 +14 …）
         下の糸: 59 62 57.5 60.5 56 …    上の糸: 67.5 65.5 66.5 69 70 …
d = 3  68.5 77 85.5 71 75 81 74 77.5 79 …                    （聴こえる間: 0 +8.5 +8.5 −14.5 +4 +6 −7 +3.5 +1.5 …）
         下の糸: 68.5 71 74 …    真ん中の糸: 77 75 77.5 …    上の糸: 85.5 81 79 …
```

d = 2 の最初の 0 は、前の区間の最後の音 59 を、新しい区間の 1 番目としてもう一度吹く所（d = 3 のはじめの 68.5 も同じ）。

### 聴こえ方

- d = 1: 聴こえる間は、セットの間そのもの（19 のうち 19）
- d = 2: 糸の間はすべてセットの間。けれど聴こえる間は、下の糸から上の糸へ、上の糸から下の糸へ渡る間で、二本の糸の歩いた量の差に、糸の間隔が足されたもの。
  セットと同じ大きさになるのは 39 のうち 1 つだけで、残りは 0.5 から 18 までの、セットにない 22 種類の大きさ。上・下が一音ごとに交互に来る（39 のうち 39）
- d = 3: 聴こえる間は、上・上・下の繰り返し（下の糸 → 真ん中 → 上 → 下）。セットと同じ大きさは 59 のうち 4 つ、セットにない大きさは 0.5 から 19 までの 25 種類
- 格子: 糸はセットどおりに格子を移る（.5 付きの間は五つのうち二つ）。聴こえる線の格子の移りは、その差として結果的に決まる。
  聴こえる間のうち .5 が付くのは、d = 1 で 19 のうち 8、d = 2 で 39 のうち 21、d = 3 で 59 のうち 32
- 一つの糸の中の時間の間は、d 倍になる。d = 1 は 0.45 秒ごと、d = 2 の各糸は 0.91 秒ごと、d = 3 の各糸は 1.36 秒ごとに次の音が来る

同じセット、同じ規則、同じ流れ、同じ一人の奏者で、違うのは立ち位置の深さだけ。項の関係（何を足したか）は同じなのに、立つ位置で聴こえる旋律が別のものになり、
隣り合う音のあいだには、誰もセットに入れていない大きさの間が立つ。

似たものに、一本の旋律に二声・三声を隠す書き方がある。ここでは糸を奏者や音色で分けず、パートにも区切りの印を付けない。糸が分かれて聴こえるとしたら、それは立ち位置を下げた結果で、聴く側に生じる。

### 仮の値をなぜ選んだか

- **セット −4.5 +1 +3 +2.5 −2**
  - 五つの大きさ（1、2、2.5、3、4.5）はどれも違う。.5 の付くものが二つ（−4.5、+2.5）、付かないものが三つ。下向き二つ、上向き三つ
  - 和が 0。ずらし読みの一巡はいつもセット全部なので、d = 1 の歩きは 5 音ごとに起点 62 に戻る（1、6、11、16 音目）。糸も自分の始まりから遠くへは流れない（ずれの最大 8.5）ので、一本の独奏の音域に収まる
  - 五つという数は 2 とも 3 とも公約数を持たない。だから d = 2 でも d = 3 でも、糸は流れの中の違う位置を順に通り、どの糸もセットの五つの間を全部受け取る（数えて、どの糸も五つとも 2 回以上。事実の表）
- **書いた順**: 五つの巡回の順（読み始めを除いて並べ方が違うもの）24 通りを全部、同じ仕組みで歩かせて数えた。
  この順は、糸の上下が逆になる鳴り始め（下の糸が上の糸と同じか上に出た所）がいちばん少ない（2。次に少ない順で 3、多いもので 46）。糸のずれの最大は 8.5 で、糸の間隔と同じ
- **糸の間隔 8.5**
  - .5 が付くので、隣り合う糸は反対の格子から始まる
  - 糸が一歩ずつ動くあいだに隣の二本が近づける量は、いちばん大きな上り（3）といちばん大きな下り（4.5）を足した 7.5。8.5 はそれより広いので、始まってすぐに交差することはない
  - ほかを仮の値のままで間隔だけ替えて数えると、上下が逆になる鳴り始めは、7.5 で 6、8 で 5、8.5 で 2、9 で 2、9.5 で 0（音域は 56〜90 に広がる）。
    8.5 は、これを 2 まで減らすいちばん狭い間隔（四分音の格子の上で）。間隔を広げるほど、聴こえる間も全体の音域も広がる
- **各糸 20 音**: どの深さでも、糸一本あたり同じ数（19）の糸の間を聴くため
- **起点 62**: 結果の音域 56〜87 が、クラリネットの音域 50〜94 の中に、下に 6、上に 7 の余りを残して収まる高さ
- **時間はパルス（8 分音符、♩ = 66）**: 時間の間を一つにして、時間の規則を聴こえなくした。聴こえる違いは音の高さの関係だけになる。
  ♩ = 66 の 8 分は、120 音を 1 分ほど（A の長さ）に収める値で、糸に割れて聴こえるように選んだ値ではない。割れ方は速さで変わりうる（作曲の段で考える点）
- **深さ 1 → 2 → 3**: 一つの仕組みの三つの深さ。d = 1 を最初に置き、糸がふつうに歩くとどう聴こえるかを先に聴かせる

### 強弱と奏法

mp のまま。アクセント、スラー、奏法の指定はなし（ふつうのタンギング）。区間の替わり目にも何の印も付けない。深さが替わったことが聴こえるとしたら、線そのものから。
線の中では、替わり目の同じ音の吹き直し（聴こえる間 0。このスケッチでここの 2 か所だけ）と、立ち位置を 8.5 ずつ積む上への跳びが、替わり目に来る。
120 音目を 2 拍伸ばし、そのあいだに消える。

## 聴きどころ

- 0:00〜0:09、ふつうの歩き（d = 1）。聴こえる間はセットの間だけ。5 音ごとに 62 に戻る
- 0:09 から立ち位置が二つ前になる。直前の 59 をもう一度吹き、8.5 上へ跳んで、線の音が低い糸（56〜65）と高い糸（64.5〜76）の二本に分かれる。上・下が一音ごとに交互に来る
- 0:27 から三本。直前の 68.5 をもう一度吹き、8.5、8.5 と上がって、下の糸（65〜74）、真ん中（71.5〜79.5）、上（78〜87）。上・上・下の繰り返し
- 割れて聴こえるか、大きく跳ぶ一本の線に聴こえるか
- 二本、三本に割れたとき、それぞれの糸がセットの間だけで歩いていること（最初の 20 音と同じ間。ただし、流れを分け合うので間の並びは違い、糸の中の音はゆっくりになる）
- 隣り合う音の跳びは 8.5、13.5、14.5 のような、セットにない大きさばかりになること
- 0:53〜0:54、下の糸（72）が真ん中の糸（71.5）の四分音上に出る。二つの糸の上下が入れ替わる、ただ一つの所
- d が替わる所（0:09、0:27）には、強弱や奏法の印を何も付けていない。線の中で替わり目に来るのは、同じ音の吹き直しと 8.5 ずつの上への跳びだけ。それでも切れ目として聴こえるか、聴こえるなら何で聴こえるか

## 楽器

独奏クラリネット 1 本（音域 50〜94）。三つの糸を一人の中に収め、糸の分かれ方が配器ではなく聴く側に生じるようにした。四分音はどちらの格子も出せる

## つまみ

- **Set**: 間のセット（半音、.5 は四分音、− は下へ）。書いた順に意味がある（ずらし読みがこの順で読む）
- **Depths**: 深さを区間ごとに「1 | 2 | 3」のように書く。立ち位置が何個前の音か
- **Strand gap**: 区間のはじめに置く d 個の立ち位置の間隔（半音）。.5 を付けると隣の糸は反対の格子から始まる
- **Standpoint**: 最初の音。二つ目からの区間は、前の区間の最後の音から始まる
- **Onsets per strand**: 一つの区間で糸一本が吹く音の数。深さ d の区間は、その d 倍の音
- **Time between**: 時間の間（atom の数）。ただ一つなのでパルスになる
- **Family**: atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- **Tempo**

流れを一本にして区間の替わり目で読み直さないこと、区間を前の区間の最後の音から始めること、折り返さないことは、仕組みの一部として固定。

## 作曲の段で考える点（いまは狭めない）

- 四分音を含む大きな跳躍が 0.455 秒ごとに続く。12 以上の跳躍は d = 2 で 39 のうち 14、d = 3 で 59 のうち 17。最大 19。.5 の付く 5 以上の跳躍は d = 2 で 16、d = 3 で 23
- 跳躍がレジスターの切り替わり（B♭ 管なら実音 69 から上がクラリオンの音域。68.5 までを下として数えた）をまたぐ所: d = 2 で 39 のうち 22、d = 3 で 59 のうち 15。d = 2 では、下の糸（56〜65）はすべて切り替わりの下、上の糸（64.5〜76）はその上下にまたがる
- d = 3 の上の糸は 78〜87 で、高い音域の四分音が続く（60 音のうち 23 音が 78 以上、6 音が 84 以上）
- 0:00 から 0:56 まで休みがない。息継ぎの場所
- 区間の境目の同じ音の吹き直し（2 か所）。タンギングで吹き直すか、つなぐか
- 最後の交差は四分音の差（72 と 71.5）。糸として聴こえるか、ここで糸が絡まって聴こえるか
- 糸に割れて聴こえるかは、速さと跳躍の大きさで変わりうる。Tempo と Time between で確かめられる
