# A · 蓄えが尽きる所で終わる

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

セットは「どの間を、いくつずつ持つか」。その「いくつ」を、取り出すと減っていく蓄えとして使う。規則はいつも、残りがいちばん多い間を取り出す。
線の始まり（いちばん多い間しか取れない所）、間の種類が一つずつ増える所、終わり（全部の蓄えがそろって 0 になる所）が、音が鳴る前に個数だけから決まっているかを試す。
終わりはフェードでも締めくくりの一音でもなく、取り出す間がなくなった所。

前提の一つ目（関係が先にあり、項は後から付く名前である）に沿った課題。線の形の始まり・曲がり目・終わりと最後の音の高さが、関係の側（セットの個数）で先に決まっていて、音の高さ（項）はそれに後から付く。

**原則の読み（余湖さんに確かめてほしい）**: 音の原則では、セットは「どの間を、いくつずつ持つか」で、規則はそこから次の間を取り出す。
ここでは、取り出すたびにその間がセットから一つ減る、と読んだ。セットが曲の中で変わるその変わり方を、取り出すこと自体に持たせた形。
また、線の終わりを「セットが空になった所」と読んだ。どちらも原則にはまだ書かれていない読み。

## 仕組みと聴こえ方

- **間**: 二つの音のあいだ。半音単位で書き、四分音は .5。ここでは向きも持たせ、上向きを +、下向きを − で書く
- **起点**: 最初の音。線はここから、取り出した間を一つずつ足していく。オクターブで折り返さない（折り返すと足した間が変わるため）
- **セットと蓄え**: セットは 5 種類の間を持つ。持っている個数を、その間の「蓄え」と呼ぶ。間を一つ取り出すと、その間の蓄えが一つ減る

  | 間 | はじめの蓄え |
  | --- | --- |
  | −1.5（下へ 1.5 半音） | 11 |
  | +2.5（上へ 2.5 半音） | 8 |
  | −3（下へ 3 半音） | 7 |
  | +4（上へ 4 半音） | 3 |
  | −5.5（下へ 5.5 半音） | 1 |

  合わせて 30 個。だから線は 30 歩で、音は起点を入れて 31

- **規則**: 残りの蓄えがいちばん多い間を取り出す
- **一巡**: いちばん多い蓄えを持つ間を、それぞれ一つずつ取り出す一回り。いちばん多いのが一種類だけなら一巡は 1 歩、二つ以上の間が同じ数で並んでいれば、並んだ数だけの歩になる。
  一巡が終わると、並んでいた間はどれも一つずつ減って、また同じ数で並ぶ。だから一巡の中のどの一歩も「残りがいちばん多い間」を取っている。規則は一つだけ
- **一巡の中の順**: 取り出しに加わった順（はじめの蓄えが多い順。上の表の順）を輪にして回る。
  一巡ごとに、取り出し始める間を、前の巡の始めの間の次へ一つずらす。
  ずらさないと、同じ数で並んでいるあいだ一巡はいつも同じ並びになり、線は同じ形を一巡の和ずつ移すだけになる（音の原則で余湖さんが退けた、形を移すだけのセリー）。
  ずらすと、一巡の中の並びが巡ごとに替わる
- **格子**: 四分音の格子は、四分音ずれた二つの半音の格子でできている。ここでは、ふつうの半音の方を「半音の格子」、四分音ずれた方を「ずれた格子」と呼ぶ。.5 の付く間を足すと、線はもう一方の格子へ移る

### 形が個数から決まる

- **始まり**: はじめは −1.5 だけがいちばん多い（11）。次に多い +2.5（8）の数まで減るまでの 3 歩、取り出せるのは −1.5 だけ。
  セットは間を一つだけ持つ場合と同じに振る舞い、規則は聴こえない
- **加わる所**: いちばん多い蓄えが次の間の数まで減ると、その間が同じ数で並び、取り出しに加わる。
  はじめの蓄えの差（11−8=3、8−7=1、7−3=4、3−1=2）が、そのまま各区間の長さになる。一種類だけの 3 歩、二種類で 1 巡、三種類で 4 巡、四種類で 2 巡、そして五種類で 1 巡
- **終わり**: 全部の蓄えが 1 になったあと、最後の一巡で全部が同時に 0 になり、線はそこで終わる。蓄えが 1 個しかない −5.5 は、この最後の一巡の中で一度だけ鳴る
- **最後の音**: 起点 + Σ（はじめの蓄え × 間）。ここでは Σ = −16.5 + 20 − 21 + 12 − 5.5 = −11 で、最後の音は起点の 11 半音下。
  取り出す順によらず、セットだけで鳴る前に決まっている。順番が決めるのは、そこまでの道筋（どこまで下がり、どこまで上がるか）だけ
- **一巡の和**: 一巡の中では並んだ間が一つずつ出るので、一巡の和は順によらず個数だけで決まる。
  一種類のときは −1.5、二種類 +1、三種類 −2、四種類 +2、五種類 −3.5。新しい間が加わるたびに、巡ごとの向きが下・上・下・上・下と入れ替わる。
  線は三種類の区間で巡ごとに 2 半音ずつ下がり、+4 が加わった所から巡ごとに 2 半音ずつ上がり、最後の一巡で 3.5 半音下がって終わる
- **時間**: 時間の間も足し算で組む。atom（素数 2・3・5 の仲間ごとにある、時間の間を数える最小の粒）の何個分かで数える。
  ここでは 3 の仲間（3 連 8 分）の atom 3 個 = 1 拍を、時間のセットが持つただ一つの間にした（パルス）。時間の側の規則は聴こえない。耳に入る変化は、取り出される間だけ
- 各音は次の鳴り始めまで切れ目なく伸ばす。最後の音には次の鳴り始めがないので、時間の間 3 つ分（3 拍）伸ばしてから、そのまま切る。この 3 は仕組みからは決まらない仮の値
- **強弱**: 最初から最後まで p。終わりにもフェードやアクセントを付けない

### 仮の値をなぜ選んだか

- 5 種類で、はじめの蓄え 11、8、7、3、1 を全部違えた。どの間も、自分だけの時点で取り出しに加わる
- 隣どうしの蓄えの差は 3、1、4、2 で、1 から 4 が一度ずつ。だから区間の長さ（一種類 3 歩、二種類 1 巡、三種類 4 巡、四種類 2 巡）がそろわず、種類の増え方に規則的な刻みができない
- いちばん少ない間は 1 個。最後の一巡の中で一度だけ鳴るので、初めて鳴ることがそのまま終わりの一巡のしるしになる
- 蓄えが少ない間ほど広くした（1.5、2.5、3、4、5.5）。いちばん多い間がいちばん狭いので、始まりは細かく歩く。いちばん少ない間がいちばん広いので、終わりの一巡に一度だけいちばん大きな跳びが来る
- 向きは蓄えの多い順に −、+、−、+、−。新しく加わる間が、直前に加わった間と反対向きに引く。
  しかも新しく加わる間の幅（2.5、3、4、5.5）は、それまでの一巡の和の幅（1.5、1、2、2）より大きい。その結果、上に書いたとおり、加わるたびに巡ごとの向きが入れ替わる
- .5 が付くのは −1.5、+2.5、−5.5 の三つ、付かないのは −3、+4 の二つ。多くの一歩で格子を移り、全部ではない（30 歩のうち 20 歩）
- 起点 76.5（MIDI 番号）: この取り出し方では、線は起点（いちばん高い所）から 14 半音下の 62.5 までを動く。その真ん中 69.5 が、ヴィオラの音域 48〜91 の真ん中に来るようにした。
  起点がずれた格子に立つのは、その結果
- パルス 1 拍、♩ = 44: 一歩 1.36 秒。四分音を含む一歩一歩の大きさを聴き分けられる遅さで、30 歩と最後の 3 拍で 45 秒（A の長さの中）

## 聴きどころ

- 0〜4 秒: 始めの 3 歩は下へ 1.5 だけ。規則はまだ聴こえない
- 5.5 秒（4 歩目）に上へ 2.5 が初めて出る。8.2 秒（6 歩目）に下へ 3 が初めて出る
- 8〜23 秒: 三種類の 4 巡（12 歩）。一巡の中の並びは巡ごとにずれ、線は巡ごとに 2 半音ずつ下がる。21.8 秒（16 歩目）にいちばん低い 62.5
- 24.5 秒（18 歩目）に上へ 4 が初めて出る。ここから線は巡ごとに上がる
- 39.5 秒（29 歩目）に一度だけ下へ 5.5（いちばん大きな跳び）。次の一歩（40.9 秒）が最後の音 65.5 で、3 拍伸ばして 45 秒で切れる
- **耳で判断してほしい点**
  - 終わりが、弱くなるのでも止めの音でもなく、「もう取り出すものがない所」として聴こえるか。聴く人は蓄えの残りを知らない。手がかりは、最後の一巡で一度だけ出るいちばん大きな跳びと、そこまでに種類が一つずつ増えてきたこと
  - 巡ごとに 2 半音ずつ下がって上がる流れ（巡の終わりの音: 73、71、69、67、65、67、69）。一巡の中の並びはずらしてあるので同じ形は続かないが、一巡の和は順によらないので、巡の終わりの音はどんな並べ方でもこの並びになる。
    これが形を移す進行として聴こえないか
  - 最後の音を 3 拍伸ばすことが、締めくくりの一音に聴こえないか
  - 最後の二歩（29〜30 歩目）は −5.5 −1.5 で、72.5 から 65.5 へ二歩で 7 半音下がってから伸ばしに入る。二歩の幅が 7 になるのは 30 歩の中でここだけ。
    狙った値ではなく、最後の一巡の順（この値では Ties のどちらでも同じ）の結果だが、止めの形に聴こえないか
  - 巡の長さは 1、1、1、2、3、3、3、3、4、4、5 歩と伸びていく。前の巡をそのまま残して一つずつ足していく反復（加算の型）に聴こえないか。
    既定では巡ごとに始めの間をずらすので、前の巡の並びはそのまま残らない。after the last drawn では、新しい間が前の巡の −1.5 の手前に差し込まれるだけ（+2.5 −1.5 → +2.5 −3 −1.5 → +2.5 −3 +4 −1.5 → +2.5 −3 +4 −5.5 −1.5）で、この型に近い
  - つまみ Ties を「after the last drawn」にすると、一巡はいつも直前に取った間の次から始まる。三種類の区間は +2.5 −3 −1.5 の同じ 3 歩が 4 回、2 半音ずつ下へ移されて続く。比べられるように残した

## 楽器

独奏ヴィオラ 1（arco、non vib.、p で一定）。音色も強弱もリズムも変えず、取り出される間の種類と、それが尽きる所だけが聴こえるようにした。

再生は BBC SO の独奏ヴィオラ（Viola Leader）の、ふつうの伸ばし（Long）。四分音の高さは、50 セント上げた別の音源で鳴らす。
non vib. は楽譜の指示だけで、再生の音にはヴィブラートがかかる。

## つまみ

- Set: 蓄え。各間を、持つ個数だけ書く（半音、.5 は四分音、− は下向き）。目盛りの上では大きさの順に並ぶが、取り出しに加わる順は蓄えの数から決まるので、並びは使わない。
  蓄えが同じ数の間どうしは、狭い方が先（同じ幅なら下向きが先）
- Ties: 一巡の中の順。shift each round（既定）は一巡ごとに始めの間を一つずらす。after the last drawn は、直前に取った間の次から始める
- Standpoint: 起点。オクターブで折り返さないので、線がヴィオラの音域（48〜91）を出るとスケッチはエラーで止まる
- Pulse: 時間のセットが持つ一つの間（atom の数）。最後の音はこの 3 つ分
- Family: その atom の仲間（2: 16 分、3: 3 連 8 分、5: 5 連 16 分）
- Tempo: テンポ
