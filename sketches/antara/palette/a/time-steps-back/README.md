# A · 時間を戻る一歩

- 状態: 試し中（2026-09-29）。パレットの見方は [`../../README.md`](../../README.md)
- 作るもの: [`sketch.ts`](./sketch.ts)

## 一つの課題

時間の間に向きを持たせてよいか。音程の間には上と下の向きがあるのに、時間の間はこれまで前へ進む向き（正）だけと読んできた。
ここでは時間のセットにも負の間を入れ、音程の線とまったく同じ足し算で一本の線を歩く。
すると、足した順（歩く人の順）と聴こえる順（時間の順）が別のものになり、同じ点に二度立つことも起きる。それがどう聴こえるかを、それだけ試す。

**これは原則の一つの読みで、決まっていない。** 原則では、時間の間は最初の鳴り始めから前へ足していく。
このスケッチは「足す」を、前へだけでなく後ろへも足せるものと読んでいる。[「鳴らない起点」](../time-unsounded-origin/README.md)が起点から後ろへ足したのと同じく、この読みでよいかは余湖さんに確かめてほしい。
退けられたら、このスケッチは値を変えずに落とす。

## 仕組みと聴こえ方

言葉の確認から。

- **時間の間**: 二つの鳴り始めの間隔。仲間ごとの **atom**（それ以上割らない一粒）の何個分かで数える
- **仲間**: 2・3・5 の三つ。ここでは 3 の仲間だけを使う。atom は 3 連 8 分（1 拍の 1/3）
- **向き**: 間の符号。正の間は前へ（後の時間へ）、負の間は後ろへ（前の時間へ）一歩を置く
- **セット**: どの間を、いくつずつ持つか。**規則**: セットから、次にどの間を取り出すか
- **組**: 規則が一度に取り出す間の並び。**辞書順**: 組を、先頭の間から順に比べて小さい順に並べること（辞書の見出しと同じ並べ方）
- **周**: 規則がすべての組を一度ずつ取り出し終えるまで
- **起点**: 線が間を足し始める所（立ち位置）
- **項**: 線の上の一つの点。起点と、足すたびにできる点
- **歩く**: 項を一つずつ足していくこと。歩く人は、いま立っている項に次の間を足して、次の項に立つ
- **打ち**: ウッドブロックの一打ち

仕組み。

- セット {−3 −1 2 4 5}（atom）から、規則が 2 つずつの組を、すべての選び方を辞書順に取り出す。組の中は小さい順。一周は 10 組:
  (−3 −1)(−3 2)(−3 4)(−3 5)(−1 2)(−1 4)(−1 5)(2 4)(2 5)(4 5)。組の和は −4 −1 1 2 1 3 4 6 7 9 で、一周で +28 atom 進む
- 起点を 0 として、音程の線と同じに歩く。次の項は、いまの項に次の間を足した所。負の間なら、次の項はいまの項より前に置かれる
- 6 周歩く。項は起点を入れて 121。**歩き終えてから**、全部の項を時間の順に並べ直して鳴らす（歩くことは時間の中で進まない）
- 各項は一打ち、長さ 1 atom。どの木で打つかは、その項に着いた一歩の向きだけで決まる。高い木 = 進んで着いた項、低い木 = 戻って着いた項、中の木 = 起点（どの一歩でも着いていない項）
- 二つの項が同じ点に来たら（同じ点に二度立ったら）: 着いた向きが違えば高と低を同時に打ち、同じなら一打ちにまとめる
- 起点は、いちばん前の項（起点の 8 atom 前）が入る最初の拍に置く。1 小節目の 4 拍目の頭

一周目を例に。歩いた順は

```
0 −3 −4 −7 −5 −8 −4 −7 −2 −3 −1 −2 +2 +1 +6 +8 +12 +14 +19 +23 +28
```

聴こえる順は −8 −7 −5 −4 −3 −2 −1 0 +1 +2 +6 +8 … になる。歩く人が最初に足した項（−3）は 5 番目に聴こえ、起点は 8 番目の鳴り始め。
最初に聴こえるのは起点ではなく、起点の 8 atom 前の低い木。

聴こえ方。戻る一歩は、歩く人にとっては「いま立っている項の後ろへ下がる」ことだが、聴く人には、その項より**先に**鳴る音になる。
−1 の一歩で着いた項は、下がる前に立っていた項のすぐ前（あいだに何も挟まず 1 atom 前）に聴こえ、−3 の一歩で着いた項は、あいだに一つか二つの鳴り始めを挟んで 3 atom 前に聴こえる。
足した順と聴こえる順は、項の関係（足し算）は同じなのに、立つ位置（歩く人か、時間の中の聴く人か）で違う名前になる。前提の二点目「名前は立つ位置で変わる」を、時間の順に当てたもの。

規則は同じ組を同じ順に回すので、歩いた形は周ごとに 28 atom ずれるだけで同じになる。だから聴こえるのも、28 atom（9⅓ 拍）の一つの**型**（同じ形で繰り返し聴こえるひとまとまり）の繰り返し。
一文字を 1 atom として書くと、型はこう（低 = 低い木、高 = 高い木、両 = 高と低を同時に、・ = 打たない）:

```
低低・高両低両高高低高・・・高・高・・・高・高・・・・高
```

前の 11 文字（11 atom のうち 10 に鳴り始め。空くのは一つだけ）が、戻る一歩を含む組のもつれで、**結び目**と呼ぶ。
後ろの 17 文字は、高い木だけが 4 2 4 2 5 atom の間で前へ進む所で、**ほどけ**と呼ぶ。
歩く人が一周を終えて立つ所（28 の倍数）は、次の結び目の 9 文字目（高）。次の周はそこから後ろへ下がって結び目を作るので、周の切れ目は、聴こえる所では結び目の中に埋もれる。
最初の型だけは、9 文字目が中の木（起点）。

仮の値と、その理由。

- **セット {−3 −1 2 4 5}**
  - 戻る幅が二つ（1, 3）、進む幅が三つ（2, 4, 5）。和は +7 で、線は大きく見れば前へ流れ、局所でだけ戻る
  - 戻る幅は、進む幅のどれの裏返しでもない（1 と 3 に対して 2, 4, 5）。だから一つの組の中で「行って戻る」だけで同じ点に戻ることはなく、同じ点に二度立つには三つ以上の間の関係が要る（歩き直して数えて、最短で 3 つ）。
    たとえば {−2 −1 1 3 4} なら、(−1 1) の組が二歩で元の点へ戻る
  - 五つとも大きさが違い、どれも一つずつ持つ。組合せの規則で、どの間も一周に 4 回ずつ取り出される
- **2 つずつの組、辞書順、組の中は小さい順**: 負の間を含む 7 組が辞書順でいつも先に来て、正の間だけの 3 組が後に来る。これが結び目とほどけの対比になる
- **3 の仲間**: 一周の流れ 28 atom は 9⅓ 拍で、拍の整数倍にならない。型は周ごとに小節の中の別の場所に来る（3 周の 28 拍 = 7 小節で同じ場所に戻る）
- **6 周**: 型を 6 回聴く。A の長さ（1 分前後）に収まる
- **木の高さ**: 一歩の向きだけを名指す。高 = 進んだ、低 = 戻った、中 = 起点の一打だけ。どの間の大きさで着いたかは木では分けない
- **強弱 p で一定、アクセントなし**: 何も強めない。順と間だけが聴こえるように
- **テンポ 60**: atom は 1/3 秒。1 atom の先取りも、二つの打ちとして分かれて聴こえる間隔

## 聴きどころ

- 低い木（戻った一歩）が、それが下がる前に立っていた項より先に鳴る。歩く人の「戻った」一歩が、聴く人には次の音の「先取り」に聴こえるか
- 高と低が同時に鳴る所（型ごとに 2 か所、全部で 12）。同じ点に、進んで着いた項と戻って着いた項が二度立った所
- 最初に鳴るのは起点の中の木ではなく、その 8 atom 前の低い木。起点は最初に聴こえる音ではない（8 番目の鳴り始め、曲の頭から 3 拍後）
- 結び目（戻る一歩を含む組、11 atom = 3⅔ 拍）のもつれと、ほどけ（高い木だけが前へ進む、17 atom = 5⅔ 拍）の対比。周の切れ目が結び目の中に埋もれて聴こえないこと
- 同じ型が 6 回来て、小節の中の別の場所に来ること。型として聴こえてしまうか

## 楽器

ウッドブロック 3（高 = 進んで着いた項、低 = 戻って着いた項、中 = 起点の一打だけ）。
音の高さを持たない乾いた音で、時間の順と間だけが聴こえるようにした。奏者は一人でも三人でもよい（作曲の段で）

## つまみ

- **Set**: 向きのある時間の間のセット（atom、−6〜6）。負の間は一歩戻る。0 を入れると、その一歩はどちらへも動かず前の項と同じ点に立ち、起点と同じ中の木で打つ
- **Rule**: 組の取り出し方。combinations（Group size の数ずつの組をすべて辞書順に）、shift each time（セット全体を、読み始めを一つずつずらして）、in order（セット全体を、毎回同じ順で）
- **Group size**: combinations のときの、一つの組の間の数
- **Order in group**: combinations のときの組の中の順。ascending（小さい順）か descending（大きい順）。組どうしの辞書順は変わらない
- **Family**: atom の仲間
- **Cycles**: 周の数（combinations はすべての組を一度ずつ、shift each time はすべての読み始めを一度ずつ、in order はセットを一度）
- **Tempo**

歩ききってから時間の順に並べること、向きで木を選ぶこと、同じ向きで同じ点に二度立ったら一打ちにまとめることは、仕組みの一部として固定。

## 事実

仮の値で、書かれた楽譜（`time-steps-back.json`）を数えた。項の足した順は楽譜に書かれないので、同じ仕組みで歩き直して楽譜と突き合わせた。

- 長さ 1:00（15 小節、♩ = 60）。`check.ts` は OK で警告 0（3 パート、104 音）。`vp check` はエラー 0
- 項 121（起点 + 120）。戻る一歩で着いた項 48（−1 と −3 で 24 ずつ）、進む一歩で着いた項 72
- いちばん前の項は起点の 8 atom 前、最後の項は +168 atom（6 周 × 28）。最初の打ち（低）は曲の頭から 1/3 拍後、起点は 3 拍後（1 小節目の 4 拍目の頭。楽譜の数えの目盛り tick（1 拍 = 60）で 180）、最後の打ちは 59 拍後（15 小節目の 4 拍目の頭）。最後の打ちが終わってから楽譜の終わりまで 2/3 拍
- 起点に戻る項はない（0 の点に立つのは起点だけ）。起点は 8 番目の鳴り始め
- 同じ点に二度立った所 29（三度は 0）。その内訳:
  - 進んで着いた項と戻って着いた項 12 → 高と低を同時に打つ
  - 戻って着いた項どうし 12、進んで着いた項どうし 5 → 一打ちにまとめた。歩く人は二度立ったが、聴く人には一度
  - 二度目に立つまでに足した間の数: 3 が 6 回、4 が 12 回、5 が 5 回、8 が 6 回
- 打ち 104（高 67、中 1、低 36）。鳴り始め 92（高だけ 55、低だけ 24、高と低の同時 12、中 1）
- 聴こえる間（全部の項を時間の順に並べた隣どうし）: 0 が 29、1 が 53、2 が 18、4 が 13、5 が 7。
  セットにない 0 が 29 回聴こえ、セットにある 3 は一度も聴こえる間にならない
- 足した順と聴こえる順が逆になる項の組（入れ替わり）: 183（全 7260 組の 2.5%）。うち 70 は、別の周の項どうし。
  入れ替わる二つは、足した順で最大 11 項、時間で最大 8 atom 離れている。足した順で隣の二つの項が聴こえる順でも隣になるのは、120 のうち 44
- 戻る一歩で着いた項は、下がる前の項の −1 なら 1 atom 前（あいだに鳴り始め 0、24 回）、−3 なら 3 atom 前（あいだに 1 つが 18 回、2 つが 6 回）に聴こえる
- 低の鳴り始め 36 の、次の鳴り始めまで: 1 atom が 30、2 atom が 6。高い木が同時か 2 atom 以内に来るのは 30。
  残りの 6（どの結び目も最初の低）は、低がもう一つ続き、高は 3 atom 後
- 聴こえる型は 28 atom ごとに 6 回、同じ（違うのは、最初の型で起点が中の木であることだけ）。最後の型のあとに高が 2 打ち（+163、+168）
- 結び目の始まり: 0.3 秒、9.7 秒、19.0 秒、28.3 秒、37.7 秒、47.0 秒。小節の中では、1 拍目の 1/3 拍後、2 拍目の 2/3 拍後、4 拍目の頭、の三つを順に回る
- いちばん長い無音（鳴り始めの間）は 5 atom = 1⅔ 拍
- どの打ちも 3 の仲間の格子の上（tick が 20 の倍数）。長さはすべて 1 atom、同じ木の中の重なり 0。強弱は p の一点だけ、アクセントも技法の指定もない
- ほかのつまみで（比べるための数。その値を保存した組（プリセット）は作っていない）: Order in group を descending にすると、鳴り始め 86、高と低の同時 17、起点の点に高い木が一度戻ってくる。
  Rule を shift each time にすると 19 小節で、高と低の同時 11。in order にすると 5 小節で、同じ点に二度立つことはない

## 作曲の段で考える点（いまは狭めない）

- 読みの確認: 時間の間の負の値は、原則の「前へ足す」を広げる読み。これでよいかは余湖さんに確かめる
- 規則が組を同じ順で回すので、聴こえるものは 28 atom の型の 6 回の繰り返しになる。足した順は型の中の並び替えとしてしか聴こえない。型として聴こえてしまうかは聴いて確かめる
- 同じ向きで同じ点に二度立った 17 項は、一打ちにまとめたので聴こえない。二度立ったことを聴こえるものにするかは、ここでは決めない
- 一人で三つの木を打つなら、結び目では 1/3 拍ごとの打ちが高と低を行き来し、高と低の同時打ちが二か所ある（二本のばちで足りる）。テンポを上げると結び目の打ち分けが詰まる
- 楽譜: ずっと 3 連 8 分の上で、型の頭が拍の上の別の場所に来る。拍で書いた楽譜で、拍と揃わない型を読むことになる
