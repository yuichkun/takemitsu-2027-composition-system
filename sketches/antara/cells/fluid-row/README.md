## 問い

リズムの列は、体がつかまれる型（踊りの型）になる。その上で、音の場所だけが動いていく。

## 編成と意図

チェロのピッツィカート。弾いた低い線は踊りの下のベースのように聴こえるので、場所の移り変わりが、足もとの和声が動いていく感じとして聴こえる。

## つまみ

Pitch（Set、Rule、Group size、Order in a group、Standpoint、Anchor、Range）、Time（Family、Rhythm row）、Form。どれも仮の値で、余湖さんが動かしたら橙の点が消える。
