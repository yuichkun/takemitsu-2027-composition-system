## 問い

音の形は同じまま、時間だけが伸び縮みする。同じ節が、違う息で何度も言い直される。

## 編成と意図

オーボエ。オーケストラの中の歌う声、話す声。同じ節がパターンの繰り返しではなく、呼び声の言い直しとして聴こえる。

## つまみ

Pitch（Row、Standpoint、Anchor、Range）、Time（Family、Rhythm set、Rule、Group size、Order in a group）、Sound（Slur the pitch groups）、Form。どれも仮の値で、余湖さんが動かしたら橙の点が消える。

## 保存した組（札）

- **Call**: 5 −2 −3（A–D–C の 3 音で一周）を、1 2 2 3 4 から 3 個ずつの時間で
- **Shift each time**: 時間を 3 2 1 2 で毎回ひとつずらす
- **Long first**: 時間の組の中を長い順に
- **In triplets**: 3 の仲間で
