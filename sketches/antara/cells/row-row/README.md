## 問い

音程の列とリズムの列を、それぞれ決まった順に回す。長さが違えば、音と長さがずれながら重なり、両方が一周してやっと揃う（アイソリズムのカラーとタレアが、この原則の一つの場合として出てくる）。長さが同じなら固まる。

## 編成と意図

ファゴット。音域全体でスラーもタンギングも自然に出る一本の線なので、音程の組をスラーで、時間の組をアクセントで同時に示せる。二つの区切りがずれていく様子が一本の中で聴こえる。

## つまみ

Pitch（Row、Standpoint、Anchor、Range）、Time（Family、Rhythm row）、Sound（Slur the pitch groups、Accent the rhythm heads）、Form。どれも仮の値で、余湖さんが動かしたら橙の点が消える。
