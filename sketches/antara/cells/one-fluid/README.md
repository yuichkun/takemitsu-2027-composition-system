## 問い

音の高さを消して、時間の関係だけを聴く。組の長さが変わっていくので、拍子は書かずに結果として生じて動く。それが体でどう感じられるか。

## 編成と意図

ウッドブロックが全部の音。乾いた短い音なので、間の長さが正確に聴こえる。大太鼓（pp）が組の頭だけに重なる。強拍に聴こえる所を記号ではなく楽器の重ねで示すと、どこが「1」かが体で分かる（つまみで外せる）。
