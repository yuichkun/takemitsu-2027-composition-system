## 問い

音程の列を同じパルスで回すと、同じ形が戻ってくる。起点に戻ればオスティナート、続けて歩けばゼクエンツ。色と場所が一緒に固まる（普通のセリーと同じロックイン）のが、どう聴こえるか。

## 編成と意図

フルート。平らで澄んだ音で、パルスの上の形そのものが聴こえる。四分音の間もすべて出せる。列の頭にアクセントを置き、ロックインが聴こえるようにした（つまみで外せる）。

## つまみ

Pitch（Row、Standpoint、Anchor、Range）、Time（Family、Pulse）、Sound（Accent the row's start）、Form。どれも仮の値で、余湖さんが動かしたら橙の点が消える。
