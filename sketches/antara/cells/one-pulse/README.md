## 問い

セットが間を一つしか持たないとき、規則は聴こえなくなる。同じ音の連打（間 0）と、同じ間を踏み続ける線（全音、5 度、短 3 度）は、どう聴こえるか。

## 編成と意図

マリンバ。2 本のマレットで連打が自然に弾け、一打ずつがはっきり立つ。規則が聴こえない所では、線の命は立ち上がりと一つの間だけになる。マリンバは音が固定なので、このスケッチの間は半音単位。

## つまみ

Pitch（Between、Standpoint、Anchor、Range）、Time（Family、Pulse）、Form（Bars、Tempo）。どれも仮の値で、余湖さんが動かしたら橙の点が消える。

## 保存した組（札）

- **Same note**: 同じ音の連打（8 分）
- **Whole tones**: 全音ずつ上がり、音域の上で折り返す
- **Fifths**: 5 度ずつ回る
- **Minor thirds**: 短 3 度ずつ（減 7 の輪）
- **Trill**: 起点に戻りながら全音を往復（16 分）
- **Same note in triplets**: 同じ音を 3 連で
- **Same note in fives**: 同じ音を 5 連で
