# 同じ音でリズムの列 — 間が一つ × 一定の規則

- 状態: 試し中（2026-09-28）
- 地図の場所: 音程 = 間が一つ（同じ音）、時間 = 一定の規則（リズムの列）（[`../../README.md`](../../README.md)）
- 作るもの: [`sketch.ts`](./sketch.ts)。値はプレビュー右のつまみで動かせる（`values.json` に残る）

## 問い

音の高さを動かさず、リズムの列だけを回す。列の合計が拍と揃えば組の頭は拍に留まり、揃わなければ拍の上を移っていく。それがどう聴こえるか。

## 編成と意図

ティンパニ。一つの太鼓、一つの音。一打の重さだけで、組の頭が拍のように感じられる。

## つまみ

Pitch（Drum）、Time（Family、Rhythm row）、Form。どれも仮の値で、余湖さんが動かしたら橙の点が消える。

## 保存した組（札）

- **3 3 2**: 合計 8（2 拍）なので頭は拍に揃い続ける
- **3 2 (drifts)**: 合計 5 なので頭が拍の上を移る。揃うのは 5 拍に一度
- **2 2 3**: 合計 7
- **Row in triplets**: 3 の仲間で 2 1（1 拍）
- **Row in fives**: 5 の仲間で 3 2（1 拍）
- **Row that moves**: 3 3 2 | 3 2 | 2 2 3 | 3 3 2 と列が替わる
