## 問い

「音程セットを変えながら連打」。同じ音の連打から、間が一つずつ入ってきて、最後に 4 度・5 度がそろう。パルスは変えない。どこで調性感が生じ始めるか。

## 編成と意図

ヴァイオリン I の spiccato が線。一打ずつがはっきりしているので、連打が生きたまま続き、新しい間が入った瞬間がすぐ聴こえる。四分音も含めてどの間も出せる。チェロが起点の音を 2 オクターブ下で pp で保つ。立つ位置が聴こえるので、新しい間がそれに対してどう聴こえるか（調性感が生じるか）を判断できる（つまみで外せる）。
