- 状態: 試し中（2026-09-28）

## 問い

間の数（atom の何個分か）はそのままで、atom だけを替える（16 分、3 連 8 分、5 連 16 分）。仲間を替えるのは小節線（どの仲間の格子も重なる所）。並びは、仲間を替えるだけで拡大・縮小される。

## 編成と意図

ウッドブロック 3 つ。2 の仲間は高い木、3 は中、5 は低い木。仲間が替わるのが木の音の違いとして聴こえ、時間の粒と音色が一緒に動く。
