# percussion — BBC SO の打楽器で何ができるか

- 状態: テスト（作品に使う段階ではない。音楽の中身は仮のもの）
- 余湖さんの注文（2026-09-28）: 打楽器を特殊効果的に使う例を、BBC SO の打楽器でなるべく広く

| スケッチ | 中身 |
| --- | --- |
| inventory | BBC SO で鳴らせる打楽器の音を全部、名前付きで 1 つずつ（太鼓、金属、木、鍵盤打楽器・ハープ）。聴き比べの見本 |
| haze | 大太鼓のソフトなロールの上に、弓で弾くタムタムとシンバル、タムタムのスウェル、トライアングルのロール、弓で弾くクロタルが現れては消える |
| clockwork | ウッドブロック 3 種、カスタネット、ギロ、カウベル、アンヴィル、サイドスティック、シロフォンの 1 小節の型が、行ごとにずれていく |
| metal | 印の所へ向けて、シンバルのロール・タムタムのスウェル・タンバリン・鈴がクレッシェンドし、合わせシンバル・タムタム・チューブラーベルで打つ（止めるか鳴らすか） |
| drums | 大太鼓とテナードラムの歩みに、ティンパニ（ホットロッド）・軍隊太鼓・スネア（リムショット）・テナードラムが入れ替わって先導し、句の終わりにスネアのロールからティンパニの一撃 |

## BBC SO にない打楽器

サンダーシート、ラチェット、シェーカー、テンプルブロック、トムトム、ムチ、ブレーキドラムは BBC SO にない
（[`../../docs/research/bbcso.md`](../../docs/research/bbcso.md) §9）。鳴らすには `samples/<楽器 id>/` に音声ファイルを置く
（[`../../samples/README.md`](../../samples/README.md)）。ラチェットは楽器表にあるので、サンプルを置けばすぐ鳴る。
ほかは楽器表に足す（1 行）。

## 分かったこと

- BBC SO のティンパニは鍵より 1 オクターヴ低く鳴っていた。これまでのティンパニは全部 1 オクターヴ低く、低い音は鳴っていなかった。直した
- 大太鼓のソフトなロールとハードスティックは Bass Drum 2 のパッチにある。使えるようにした（奏法 `roll+soft`、`hard-sticks`）
