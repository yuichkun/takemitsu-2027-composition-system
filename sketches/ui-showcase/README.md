# UI showcase — つまみの部品を見せるスケッチ

- 状態: 部品の見本（作品に使う提案ではない。音楽の中身は部品を動かすための仮のもの）
- ダブルクリックは使わない。部品の一部を押したときのメニュー（右クリックでも同じ）に操作をまとめる
- 部品の定義: [`../../src/sketch/knobs.ts`](../../src/sketch/knobs.ts)、描画: [`../../src/preview/knobs/controls.ts`](../../src/preview/knobs/controls.ts)

## 部品と、どのスケッチで触れるか

| 部品 | 操作 | 使いどころの例 | 見本 |
| --- | --- | --- | --- |
| number | 横にドラッグ、↑↓（Shift ×10）、クリックで入力 | テンポ、小節数 | 全部 |
| pitch | 同上。音名で出る（↑↓ は四分音）。C4、E+4、E↑4 と打てる | 基音 | spectrum |
| range | 下限と上限の 2 つ | 強弱の幅、音価の幅 | grid |
| pitch-range | 最低音と最高音 | 音域 | cloud |
| choice | 短いものは並んだボタン、長いものはメニュー | 奏法、順序 | spectrum |
| toggle | スイッチ | 四分音の有無 | spectrum、grid |
| text | 文字の欄 | 自由な数列 | string-16ths |
| curve | フリーハンドで描く（0–1）。右クリックで、その高さで平らに・なめらかに・時間を逆に・上下を逆に・最初の形に戻す | 密度・音域・強弱の時間変化 | cloud |
| envelope | 折れ線の点を動かす、空いた所をクリックで追加、点を右クリックで削除 | 強弱の包絡 | spectrum |
| pitch-set | 12 か 24 に分けた円の点を押す。集合と音程ベクトルが出る | 音階、音程集合 | cloud |
| partials | 倍音の番号を押す。四分音に丸めた音名が出て、重ねるとずれ（セント）が出る | スペクトル和音 | spectrum |
| weights | 棒をなぞって高さを塗る | 楽器・奏法の出やすさ | cloud、grid |
| steps | マスを押す、なぞって塗る | リズムの型 | grid |
| proportions | 区切りを横にドラッグ（合計は変わらない） | 形式の比率 | spectrum、grid |
| xy | 点をドラッグ | 2 つの軸を同時に | cloud |
| seed | ‹ › で隣の種、⚄ で新しい種 | 乱数の振り直し | cloud、grid |
| markers | 帯の空いた所をクリックで印を足す、ドラッグで動かす、印をクリック（右クリックでも）でメニュー（消す）。単位に吸着 | 区切り、出来事の位置 | harmony |
| lanes | 区間をクリック（右クリックでも）でメニュー: 選択肢を選ぶ、クリックした所で二つに切る、区間を消す。境目はドラッグで動かす。隣が同じ選択肢でもまとめない（弾き直しになる） | 奏法の移り変わり | harmony |
| vector-set | 音程ベクトルの 6 つの数を入れる（空欄は問わない）→ 合う集合（基本形）から選ぶ | 音程の中身から集合を探す | harmony |
| between-set | 定規の空いた所をクリックで間を足す、点をドラッグ（か ← →）で動かす、点をクリックでメニュー。Next は一手違いのセット（押すと鳴る、↻ で別の候補）、Tried は試したセット。⚄ で定規全体から新しいセット、⇄ で向きを逆に、+ / − で全部を一歩広く／狭く。文字を押すと打ち込める。起点のつまみを指すと、間一つ・二つで届く所を時計に出す（印は起点からの間、音名は重ねたときだけ） | 音程や時間の間のセットを耳で探す | antara/ideas/running |
| lattice | 格子の点を押す。横と縦がそれぞれ決まった音程（見本は 5 度 × 長 3 度）。中心は輪 | 和音、音の近さ | harmony |
| heatmap | 右で濃さを選び、マスを塗る。行は上から高い音域、横は時間 | 音域 × 時間の密度 | field |

## 見本の中身

- **cloud**: 6 人の短い音の雲。密度と音域を線で描き、音高クラス・楽器の出やすさ・音の長さと強さ（xy）・種で変える
- **spectrum**: 基音の倍音列から選んだ部分音を、低い順に空いている奏者へ割り当てた和音。入る・保つ・抜ける の比率、入る順、強弱の包絡、四分音の有無
- **grid**: 4 つの打楽器の 1 小節の型を、A（そのまま）B（行ごとに回る）C（音が抜ける）の 3 部分で繰り返す
- **harmony**: 弦 5 部の 2 つの和音を、印のところで交互に替える。A は格子の上で、B は音程ベクトルから選ぶ。音域に均等に広げ、低い順に割り振る。奏法は帯で変わる
- **field**: オクターブ × 小節で塗った濃さに従って、短い音を散らす（ハープ、マリンバ、ヴィブラフォン、弦のピッツィカート）
