操作

Space 再生 / 一時停止
Enter Home 先頭へ戻る
← → 前 / 次の小節へ
P ページ / パノラマを切り替える
F 全画面で譜面だけにする（Esc で戻る）
⌘= ⌘− 拡大 / 縮小（ピンチ、⌘ + ホイールでも）
⌘0 高さに合わせる（全部の段が見える）
⌘B 左の一覧をたたむ / ひらく
M ミキサーをたたむ / ひらく
? この一覧
譜面をクリック そこへ再生位置を移す
再生位置の線をドラッグ 再生位置を動かす
上の帯をクリック 曲のその位置へ移す（帯の濃い所はレンダ済み）
フェーダーをダブルクリック 0 dB に戻す
S を Alt+クリック そのパートだけをソロ

楽譜を保存すると、変わったところだけを裏でレンダし直す。再生位置の近くから先に作る。
