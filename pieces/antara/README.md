## 編成

決定 [`0024`](../../docs/decisions/0024-antara-orchestra.md)。楽器の一覧は [`ensemble.ts`](./ensemble.ts)（総譜の並び順）。

| 楽器 | 人数 |
| --- | --- |
| フルート | 3（3 番はピッコロ持ち替え） |
| オーボエ | 3（3 番はイングリッシュ・ホルン持ち替え） |
| クラリネット | B♭ 2、バス・クラリネット 1（3 番はバス専任） |
| ファゴット | 3（3 番はコントラファゴット持ち替え） |
| ホルン・トランペット・トロンボーン・テューバ | 4・3・3（3 番はバス・トロンボーン）・1 |
| ティンパニ | 1 |
| 打楽器 1 | クロタル、グロッケンシュピール、吊りシンバル、シェーカー |
| 打楽器 2 | ヴィブラフォン、タムタム、サンダーシート |
| 打楽器 3 | マリンバ、チューブラー・ベル、バスドラム、ウッドブロック 3（高・中・低）、ラチェット |
| ハープ | 2（2 番は全弦を四分音低く調弦） |
| 鍵盤 | ピアノ、チェレスタ |
| 弦 | 16・14・12・10・8 |

- 総譜は実音で書く。ハープ 2 も実音（四分音の臨時記号）で書く
- 弦のセクションは、音楽が求める分け方のパートで書く（独奏 s、残り r、半分 a b、四分の一 q1〜q4、全員 t）。楽譜に出すのは弾いているパートだけで、セクションのどれも弾いていなければ全員のパートを一段出す
- 確かめ（`check.ts`）: ハープ 1、ピアノ、チェレスタ、鍵盤打楽器に四分音が来たら警告。ハープ 2 は逆に、四分音ずれていない音が来たら警告（パートの `tuning: -0.5`。楽譜には何も出ない）
- BBC SO にないもの: シェーカー、サンダーシート、ラチェット。音符を書くと、サンプルを置くまで「音がない」と警告が出る（`samples/<楽器>/`、決定 0012）
