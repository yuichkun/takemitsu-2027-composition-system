# antara

- 状態: 書き始め（2026-09-29）。セクションは prologue、opening、rhythm、series、running、climax、two-grids、ending。スケッチをラフに決めて、どんどん曲に入れていく段（細かいことはあとで）
- 前提: [`../../docs/antara/premise.md`](../../docs/antara/premise.md)。音の原則: [`../../docs/antara/sound.md`](../../docs/antara/sound.md)
- 組み方: セクションはそれぞれ別のコード（パレットのスケッチと同じ書き方）で自由に作り、一番上（[`sketch.ts`](./sketch.ts)）の操作でつなぐ
  （[`../../src/sketch/join.ts`](../../src/sketch/join.ts)、決定 [`0023`](../../docs/decisions/0023-join-sections-from-outside.md)）。試しは [`../four-ideas/`](../four-ideas/README.md)
- セクションはスケッチそのもの（決定 [`0026`](../../docs/decisions/0026-sections-are-sketches.md)）。ここのフォルダの `sketch.ts` はどのスケッチかを言うだけで、コードも値もスケッチのもの。
  スケッチで詰めると、曲のそのセクションも変わる。つなぎ方はここの一番上で決める

## セクション

順番とつなぎ方は一番上（[`sketch.ts`](./sketch.ts)）のつまみで変えられる。

- **Order**（Sections）: セクションのフォルダの名前を、来る順に空白で区切って並べる。書かなかったセクションは鳴らない
- **Join 1, 2, …**: つなぎ目ごとに同じつまみ（How: end to end ／ rest ／ at once ／ by players、Lead、Spread、Order、The others、Rest）。
  Join 1 はいつも 1 番目と 2 番目のあいだ（順番を変えても、つなぎ目の値は位置についたまま）。つまみの中身は [`../../docs/architecture.md`](../../docs/architecture.md) の「セクションをつなぐ」
- [`rest`](./rest/sketch.ts) は全休止のためのセクション（How = rest のときに置く）。Order には書かない

| 順 | フォルダ | スケッチ（仕組みと構成はそのカード） | 長さ | つなぎ方 |
| --- | --- | --- | --- | --- |
| 1 | [`prologue`](./prologue/sketch.ts) | [`prologue`](../../sketches/antara/ideas/prologue/README.md): プロローグ。two-grids のガラスの和音（その最初の和音）が、ヴァイオリン I の高音から 5 連 16 分ずつ上から下へ入り、コントラバスの G1 まで数秒でそろう。そろってすぐ、全員が pp のままふっと止まり、全休止のフェルマータ（ホールの残響だけ）。そこから冒頭の地鳴りが始まる | ♩ = 52、3 小節 | 0 拍目から |
| 2 | [`opening`](./opening/sketch.ts) | [`opening`](../../sketches/antara/ideas/opening/README.md): 冒頭。長い地鳴り（E1 から波打つコントラバス、ロール、タムタム、あとから低い管）にチェレスタの一つの音。その間が 5 連 16 分で一巡ごとに 1 拍へ近づくあいだに、オーケストラが間の中に引き込まれる（打ちのあとに残響、前に無から膨らむ立ち上がり、ハープ 1・2（最初の音程）、ピアノ、ヴィブラフォン、ヴィオラのピッツィカート、低い金管と木管）。間が 1 拍に定まる所がこの曲で最初のパルスで、そこへ地鳴りも引き込まれ、最後は全員で一拍に一つの波を作る | ♩ = 60、38 小節 | Join 1: end to end（4 小節目から）。プロローグのフェルマータのあと |
| 3 | [`rhythm`](./rhythm/sketch.ts) | [`rhythm`](../../sketches/antara/ideas/rhythm/README.md): 律動。冒頭のパルスを、系ごとの三つの合唱（16 分・3 連 8 分・5 連 16 分。打つたびに合唱の中の楽器が替わる）が受け取る。拍を割り、一巡が拍にそろわない間を得てずれ、組み合わせの規則になる。系が出会う所でだけそろい、そこでウッドブロック（三つの出会いではホルンとトロンボーンの短い和音）。最後に中の合唱の全員が次の拍（♩ = 90）を打って手渡す | ♩ = 60、28 小節 | Join 2: end to end（42 小節目から） |
| 4 | [`series`](./series/sketch.ts) | [`series`](../../sketches/antara/ideas/series/README.md): 音程のセリー。管が間の組から旋律を歌う（声ごとに読む順と系が違い、句の終わりの出会いで同じ音にそろう）。組は {0.5 2} から running の {−1.5 2 5} へ一手ずつ、起点は F♯4 から D4 へ下りる。出会いで金管のコラールと、ハープ・鍵盤・打楽器の一打。下でマリンバとピッツィカートが刻む。最後の出会い（ff）を断ち切り、チェロだけが running の速さ・組・起点で走り出す | ♩ = 90、36 小節 | Join 3: end to end（70 小節目から） |
| 5 | [`running`](./running/sketch.ts) | [`running-orchestra`](../../sketches/antara/ideas/running-orchestra/README.md): 弦 4 部のカノンが 3 連系 → 16 分系 → 5 連系と速くなる。管が組の頭を、金管が頭の重なりを、固定の音の楽器が出せる刻みを重ね、最後の頭を全員で | ♩ = 120、25 小節 | Join 4: end to end（106 小節目から）。series のチェロの走り出しから続く |
| 6 | [`climax`](./climax/sketch.ts) | [`climax`](../../sketches/antara/ideas/climax/README.md): クライマックス。巨大な鐘（管の 32 音の和音。ピアノ・チェレスタ・打楽器が一緒に打つ。ハープ2台は固定ペダルの上下グリッサンド）が 6.5 秒おきに鳴り、低い弦が起点をトレモロで保ち、上の弦が鐘の音の中を走り続ける。鐘は二つ（半音の音と四分音ずれた音）に割れて交互に打ち、打つ位置が近づいてそろった一打でビブラスラップ、断絶。タムタムと下りてくる木管の余韻が残る | ♩ = 120、26 小節 | Join 5: end to end（131 小節目から） |
| 7 | [`two-grids`](./two-grids/sketch.ts) | [`two-grids-orchestra`](../../sketches/antara/ideas/two-grids-orchestra/README.md): ガラスの和音。弦 30 のプルトが一つの和音を保ち、半音の音と四分音ずれた音のあいだをグリッサンドで行き来する。反射はハープ・チェレスタ・ピアノ・クロタル。28 拍目から、チェレスタが冒頭の F♯5 を 1 拍に一つ打ちはじめる（定点。終わりへ続く） | ♩ = 52、14 小節 | Join 6: end to end（157 小節目から）。クライマックスの余韻のあと |
| 8 | [`ending`](./ending/sketch.ts) | [`ending`](../../sketches/antara/ideas/ending/README.md): 終わり。独奏ヴァイオリンと独奏チェロが F♯4（冒頭の音）から四分音ずつ分かれ、同じ間の組を上下逆に読んで離れていく（別々の系で、そろわずに。折り返さず、ときどき留まる）。後ろのヴァイオリン II とヴィオラは独奏がこれから着く音を弱く保ち、着いたら手放す。チェロは開放の C へ半分ずつ近づいて先に消え、そこで冒頭の地鳴り（E1）がかすかに戻る。ヴァイオリンはひとり通常奏法で F♯7 に着き、四分音上へ滑って消える。two-grids から続くチェレスタの F♯5 は、ヴァイオリンが F♯7 に着いたあと、滑りはじめる前の拍で止む | ♩ = 52、19 小節 | Join 7: end to end（171 小節目から） |

曲全体: 10:28、189 小節、100 パート（弦は、分けたパートと全員のパートが両方出る）。running の弦4部は、それぞれ4群が連続したフレーズを受け渡す。仕組みと比較用の全員版は [running-orchestra のカード](../../sketches/antara/ideas/running-orchestra/README.md)。

チェレスタの F♯5 は曲を通る一本の糸になっている: 冒頭で地鳴りのあとに一つ鳴り、間が縮んで最初のパルスになる → 律動の最初の 2 小節で消える →
two-grids の 28 拍目から 1 拍に一つで戻る（定点）→ 終わりでヴァイオリンが F♯7 に着いたあと止む。

決定 [`0024`](../../docs/decisions/0024-antara-orchestra.md)、[`0025`](../../docs/decisions/0025-antara-parts-and-staves.md)。楽器の一覧は [`ensemble.ts`](./ensemble.ts)（総譜の並び順）。

| 打楽器 1 | クロタル、グロッケンシュピール、吊りシンバル、シェーカー |
| 打楽器 2 | ヴィブラフォン、タムタム、サンダーシート |
| 打楽器 3 | マリンバ、チューブラー・ベル、バスドラム、ウッドブロック 3（高・中・低）、ラチェット、ビブラスラップ（クライマックスの最後の一打のために足した） |

| 弦 | 16・14・12・10・8 |

- 持ち替えはない。一人が複数の楽器を持つのは打楽器だけ
- 総譜は実音で書く。ハープ 2 も実音（四分音の臨時記号）で書く。Sibelius でも移調譜にしない（Transposing Score を切ったまま）
- 1 人 1 段。管も金管も二人で一段にまとめない（楽譜の JSON の `pairs: false`）。空の楽譜で 52 段
- 弦のセクションは、音楽が求める分け方のパートで書く: 全員（`vn1t`）、首席（`vn1s`）、残り（`vn1r`）、2 つから 1 プルト（2 人）ずつまでの分け方（`vn1-8-3` = 8 つに分けた上から 3 つ目）。
  楽譜に出すのは弾いているパートだけで、セクションのどれも弾いていなければ全員のパートを一段出す。分けたパートの段の名前（Vln. I 5–6）と「div. a N」「unis.」は書き出しが付ける
- 確かめ（`check.ts`）: ハープ 1、ピアノ、チェレスタ、鍵盤打楽器に四分音が来たら警告。ハープ 2 は逆に、四分音ずれていない音が来たら警告（パートの `tuning: -0.5`。楽譜には何も出ない）
- BBC SO にないもの: シェーカー、サンダーシート、ラチェット。音符を書くと、サンプルを置くまで「音がない」と警告が出る（`samples/<楽器>/`、決定 0012）

## 冒頭のページに書くこと

楽譜の前に付けるページ（演奏上の注意）にまとめる。システムでは扱わない。

- ハープ 2 は全弦を四分音低く調弦する。パート譜の書き方（弾く音で書くか、実音で書くか）もここで決める
- 打楽器の割り振りと、必要な楽器の一覧
- 四分音の記号の読み方
- （書きながら足す）

## Sibelius での仕上げで隠す所

- 全体を選んで Layout > Hide Empty Staves: 休んでいる段、打楽器の使っていない楽器、弦の全員の段とディヴィジの段の入れ替わりが、段落ごとに消える
- ハープ・ピアノ・チェレスタ・マリンバで、大譜表の片方だけが消えていないか見て出し直す
- 最初のページは全楽器の段を出し（最初の段落だけ Show Empty Staves）、ディヴィジの段は隠したままにする
