## 編成

決定 [`0024`](../../docs/decisions/0024-antara-orchestra.md)、[`0025`](../../docs/decisions/0025-antara-parts-and-staves.md)。楽器の一覧は [`ensemble.ts`](./ensemble.ts)（総譜の並び順）。

| 楽器 | 人数 |
| --- | --- |
| フルート | フルート 2、ピッコロ 1（専任） |
| オーボエ | オーボエ 2、イングリッシュ・ホルン 1（専任） |
| クラリネット | B♭ 2、バス・クラリネット 1（専任） |
| ファゴット | ファゴット 2、コントラファゴット 1（専任） |
| ホルン・トランペット・トロンボーン・テューバ | 4・3・3（3 番はバス・トロンボーン）・1 |
| ティンパニ | 1 |
| 打楽器 1 | クロタル、グロッケンシュピール、吊りシンバル、シェーカー |
| 打楽器 2 | ヴィブラフォン、タムタム、サンダーシート |
| 打楽器 3 | マリンバ、チューブラー・ベル、バスドラム、ウッドブロック 3（高・中・低）、ラチェット |
| ハープ | 2（2 番は全弦を四分音低く調弦） |
| 鍵盤 | ピアノ、チェレスタ |
| 弦 | 16・14・12・10・8 |

- 持ち替えはない。一人が複数の楽器を持つのは打楽器だけ
- 総譜は実音で書く。ハープ 2 も実音（四分音の臨時記号）で書く。Sibelius でも移調譜にしない（Transposing Score を切ったまま）
- 1 人 1 段。管も金管も二人で一段にまとめない（楽譜の JSON の `pairs: false`）。空の楽譜で 52 段
- 弦のセクションは、音楽が求める分け方のパートで書く: 全員（`vn1t`）、首席（`vn1s`）、残り（`vn1r`）、2 つから 1 プルト（2 人）ずつまでの分け方（`vn1-8-3` = 8 つに分けた上から 3 つ目）。
  楽譜に出すのは弾いているパートだけで、セクションのどれも弾いていなければ全員のパートを一段出す。分けたパートの段の名前（Vln. I 5–6）と「div. a N」「unis.」は書き出しが付ける
- 確かめ（`check.ts`）: ハープ 1、ピアノ、チェレスタ、鍵盤打楽器に四分音が来たら警告。ハープ 2 は逆に、四分音ずれていない音が来たら警告（パートの `tuning: -0.5`。楽譜には何も出ない）
- BBC SO にないもの: シェーカー、サンダーシート、ラチェット。音符を書くと、サンプルを置くまで「音がない」と警告が出る（`samples/<楽器>/`、決定 0012）

## 冒頭のページに書くこと

楽譜の前に付けるページ（演奏上の注意）にまとめる。システムでは扱わない。

- ハープ 2 は全弦を四分音低く調弦する。パート譜の書き方（弾く音で書くか、実音で書くか）もここで決める
- 打楽器の割り振りと、必要な楽器の一覧
- 四分音の記号の読み方
- （書きながら足す）

## Sibelius での仕上げで隠す所

- 全体を選んで Layout > Hide Empty Staves: 休んでいる段、打楽器の使っていない楽器、弦の全員の段とディヴィジの段の入れ替わりが、段落ごとに消える
- ハープ・ピアノ・チェレスタ・マリンバで、大譜表の片方だけが消えていないか見て出し直す
- 最初のページは全楽器の段を出し（最初の段落だけ Show Empty Staves）、ディヴィジの段は隠したままにする
