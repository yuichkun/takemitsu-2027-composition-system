## 考え方

**セクションより先に、境目を作る。** ふつうはセクションを作ってから並べるので、つなぎ目が継ぎ目に聴こえる。
前提では関係（切れ目）が先にあり、内と外はそれをどちら側から見るかで付く名前だった。
だからこの曲では、一番上の [`sketch.ts`](./sketch.ts) が先にセクションの境目を決める。一つの境目は、奏者ごとに次のセクションへ移るタイミングを持つ。
各セクションは二つの境目のあいだを書くだけで、奏者が順に移っていく境目では、そのあいだオーケストラの一部はもう次のセクションにいる。
境目で線は、一巡して中心音に戻った音を次のセクションに引き継ぎ、次のセクションがそれを自分の最初の音として鳴らす。続くのは音程の間や最後の音で、変わるのは規則と中心音。

**筋は、線が揃っていくこと。** どの線も同じ間のセット {−4.5 −3 +0.5 +1.5 +5.5}（和が 0）を自分の順で進み、一巡ごとに自分の中心音へ戻る。
中心音は四つの音域の群ごとに一つで、四つで中心音の和音（B♭2・B3・C♯5・C6、下から 13・14・11 半音）になる。
同じセットを違う順で読む線は、一巡ごとに同じ音に着く。着く音はセットの和だけ動くので、**この曲の筋は、セットの和がどう変わるかで決まる**。

**弾ける楽器と、弾けない楽器。** ハープ・ピアノ・チェレスタ・鍵盤打楽器（固定音高の楽器）は、鍵盤にある半音の音しか出せない。
中心音が半音の音にあるあいだは、これらの楽器が中心音を鳴らし、中心音が四分音ずれた音へ動くと黙る。
誰も弾けない対称の軸（二つの音のちょうど真ん中）のまわりでは、鏡像のペアのどちらか一方が必ず半音の音にあるので、固定音高の楽器はペアの片方だけを鳴らせる。

## つなぎ目

| 境目 | 移り方 | 続くもの／変わるもの |
| --- | --- | --- |
| 冒頭 → 独奏の線 | 次の音が生まれた時に、前の木管が動き出す | 伸ばしていた音がそのまま一歩目になる |
| 独奏の線 → 揃っていく | 高い群から低い群へ順に。各線は、一巡して中心音に戻った所で移る | 戻った音を次のセクションが鳴らす |
| 揃っていく → ダンス | 全員が 67 小節の頭で揃う | 音の長さはそのまま、テンポと拍子の表記が変わる |
| ダンス → 中心音が動く | 中心音の移動は全員同時。弦だけ最初の二小節は踊り続け、木管が先に長い音に移る | 中心音の位置が変わる |
| 中心音が動く → 頂点 | 中心音の最後の二つの位置が、ペアの最初の二音として同時に鳴る | 対称の軸が決まる |
| 全休止 | 一小節、全員が休む | ペアの上下が入れ替わる |
| 頂点 → 終わり | 重なる（最初のペアは ff が消えていく中から入る。テンポは次の小節線で ♩=54 に） | 軸が曲の中心になる |

- 0:04–0:35 二本のグリッサンドがすれ違う所に音が生まれ、木管が受け取る（四回）
- 0:40–2:10 同じ音程の並びが、四つの違う中心音の上で、それぞれ別の「中心」に聴こえるか
- 2:48–4:24 線が一本ずつ共通の周期に入り、戻りが重なり、弦が中心音を伸ばし始め、ハープが部分的に揃った所を鳴らす。4:24 で全部が揃う

## 作曲の段で考える点（いまは狭めていない）

- 中心音の和音（B♭2・B3・C♯5・C6）は、固定音高の楽器が弾ける半音の音で、群どうしの音域が少しだけ重なる幅、という理由で選んだ。広げた半音の集まりの響きになる。中心に聴こえるかは耳で
- ダンスの 48 小節は、句ごとに群を替えても、毎小節同じ中心音に戻る。長すぎるか
- 中心音が動く所の金管の和音は、動かない周期のあいだ長く伸ばす（最長で 20 秒ほど）。息の配り方
- 最後の独奏ヴァイオリンの高い音（96.5）は長く伸ばす。フラジオレットで書くか
- クラリネットは低い線が長く続く所でヘ音記号になる（スコアは C の記譜）。パート譜は Sibelius がト音記号にする
- ティンパニの四分音はペダルで取る前提
