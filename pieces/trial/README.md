## 考え方

**つなぎ目は、切れ目から作る。** ふつうはセクションを作ってから並べるので、つなぎ目が継ぎ目になる。
前提では切れ目が先にあり、内と外はその切れ目をどちら側から見るかで付く名前だった。
だからこの曲では、一番上（[`sketch.ts`](./sketch.ts)）が先に切れ目を決める。一つの切れ目は、奏者ごとに「いつ向こう側へ渡るか」を持つ。
セクションは二つの切れ目のあいだを書くだけで、切れ目が一人ずつ渡る波なら、そのあいだオーケストラの一部はもう向こう側にいる。
切れ目で線は、向こう側に着く音（到着）を手渡す。向こう側のセクションがその音を自分の最初の音として鳴らす。続くのは関係（間、最後の音）で、変わるのは規則と立ち位置。

**筋は「出会い」。** どの線も同じ間のセット {−4.5 −3 +0.5 +1.5 +5.5}（和が 0）を、自分の順で歩き、一巡ごとに自分の立ち位置へ戻る。
立ち位置は四つの音域の群ごとに一つで、四つで家の和音（B♭2・B3・C♯5・C6、間 13・14・11）になる。
同じセットを違う順で読む線は、一巡ごとに同じ所に着く。着く所はセットの和だけ動くので、**この曲の物語はセットの和の物語**になる。

**名前を付けられる楽器。** ハープ・ピアノ・チェレスタ・鍵盤打楽器は起点の格子にしか立てない。家がそこにあるあいだは鐘が家を鳴らし、
もう一方の格子へ動くと黙る。誰も弾けない軸のまわりでは、どの鏡の対も片足ずつ二つの格子に立つので、鐘は半分だけ名前を付けられる。

## 作曲の段で考える点（いまは狭めていない）

- 家の和音（B♭2・B3・C♯5・C6）は、鐘が鳴らせる整数の間で、群どうしが少しだけ重なる幅、という理由で選んだ。広げた半音の集まりの響きになる。「家」に聴こえるかは耳で
- ダンスの 48 小節は、句ごとに群を替えても同じ家に毎小節戻る。長すぎるか
- 家が動く所の金管の和音は、動かない周期のあいだ長く保つ（最長で 20 秒ほど）。息の配り方
- 最後の独奏ヴァイオリンの高い音（96.5）は長く保つ。倍音で書くか
- クラリネットは低い線が長く続く所でヘ音記号になる（スコアは C の記譜）。パート譜は Sibelius がト音記号にする
- ティンパニの四分音はペダルで取る前提
