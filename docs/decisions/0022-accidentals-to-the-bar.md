# 0022. 臨時記号は、小節の終わりまで効くふつうの規則に戻す

- 状態: 採用
- 関係する論点: 記譜の射影
- 差し替える決定: [0021](./0021-full-score-layout.md) の「臨時記号」の項

## 背景

[0021](./0021-full-score-layout.md) では、臨時記号を「その音符にだけ効く（変化のない音にもナチュラルを書く）」にした。四分音があると、何も付いていない音がナチュラルか、前の四分音がまだ効いているのかで迷うため。
余湖さんは、仕上がりを見て変える可能性があると言っていた。

Sibelius の実機テスト（[`../research/score-layout/import-test.md`](../research/score-layout/import-test.md)）で分かったこと:

- Sibelius は MusicXML の `<accidental>` の指定を読まず、自分の規則（小節の終わりまで効く）で付け直す。書き出しで付けたナチュラルは Sibelius では消える
- 臨時記号を全部の音符に付けるプラグイン（Add Accidentals to All Notes）はあるが、同じ小節で繰り返す四分音には付けず、四分音に警告を出す。Sibelius だけでは「その音符にだけ効く」を仕上げられない

## 決定

小節の終わりまで効く、ふつうの規則に戻す（余湖さん、2026-09-29）。書き出しの既定を `Score.accidentals: "bar"` にする。

## 理由

- 余湖さん: 常に表示するのは対応が面倒そうで、紙面のスペースもかなり占める
- Sibelius がもともとこの規則で付けるので、プレビューと Sibelius の見た目がそろう

## 結果と副作用

- 四分音のあとの変化のない音の読み違いは、演奏上の注意（臨時記号は小節の終わりまで効く）と、Sibelius での注意の臨時記号で補う
- `Score.accidentals: "note"` は、見比べる用に書き出しに残す
