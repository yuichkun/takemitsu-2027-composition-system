# 0012. 音源は BBC Symphony Orchestra Professional を主にし、足りない音は余湖さんが用意するサンプルで補う

- 状態: 採用
- 関係する論点: Q1 / Q8 / Q9

## 背景

余湖さんが BBC Symphony Orchestra Professional（Spitfire、Splice の Rent-to-Own）を入手し、このマシンに入れた。
これをオーケストラ再生の主力にする。

BBC SO には、この曲で使いうる楽器と奏法のすべてが揃っているわけではない
（[`../research/bbcso.md`](../research/bbcso.md) §8）。欠けた音をどう鳴らすかを決める必要があった。

## 選択肢

| 案 | 中身 | 効いてくること |
| --- | --- | --- |
| A. 近い奏法で代用して警告 | BBC SO の中で近いものを鳴らす | 追加の仕組みが要らない。聴こえ方を誤解しうる |
| B. 鳴らさず警告 | 譜面にだけ出す | 誤解はないが、全体像が聴けない |
| C. Kontakt を併用 | Komplete の音源を楽器・奏法単位で差し込む | 音源の幅が広がる。状態の作成に GUI が要り、実装が重くなる |
| D. 余湖さんが個別にサンプルを用意する | 欠けた音（例: ラチェット）をネットで探してフォルダに置く。ホストは素のサンプル再生で鳴らす | 必要な音だけを確実に足せる。音の選定は人がする |

## 決定

- 主力は BBC SO Professional。マイクは **Mix 1（Full Mix）のみ**、リバーブは足さない
- **欠けた音は D を基本にする。** 所定のフォルダにサンプルを置くと、その楽器・奏法の再生に使われる。
  同じ音に複数のファイルがあれば、発音ごとに無作為に選ぶ（実質1つずつの想定）
- 楽器単位の代用（BBC SO の別楽器）と Kontakt の併用は、欠けている楽器の一覧を見てから決める。
  どちらも差し込める作りにしておく

## 理由

- 余湖さんが「音は自分で探してくる」と決めた（2026-09-27）。必要な音は少数なので、1つずつ確実に足せる方式が合う
- サンプル再生はホストの外の音源を必要としないので、状態の作成も GUI も要らない
- Kontakt の併用は実装が複雑になるなら避けたい、という条件つき（余湖さん）

## 結果と副作用

- 余湖さんに「音を探してフォルダに置く」作業が発生する。これは余湖さん自身の選択
- サンプルには強弱の層がない。強弱は音量で近似する
- Splice のログインが切れると BBC SO は無音になる。ホストはこれを検出してエラーにする
