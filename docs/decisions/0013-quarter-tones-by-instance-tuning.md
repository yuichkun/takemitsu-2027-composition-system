# 0013. 四分音は、チューニングを変えた音源インスタンスで鳴らす

- 状態: 採用
- 関係する論点: Q1 / Q12
- 差し替える決定: [0010](./0010-pitch-bend-quarter-tones.md)

## 背景

四分音はノートごとのピッチベンドで鳴らすと決めていた（[0010](./0010-pitch-bend-quarter-tones.md)）。
主力の音源が BBC SO に決まり（[0012](./0012-bbcso-with-user-samples.md)）、実測したところ、
**BBC SO はピッチベンドを完全に無視する**ことが分かった。
一方で、状態に書く Global Tune は正確に効く（+0.5 半音で +49.8 セント）
（[`../research/bbcso.md`](../research/bbcso.md) §4）。

あわせて余湖さんから、**この曲では四分音より細かい音高は使わない**と約束があった（2026-09-27）。

## 選択肢

| 案 | 中身 | 効いてくること |
| --- | --- | --- |
| A. ピッチベンド | ノートごとにベンドを置く | BBC SO では鳴らない |
| B. インスタンスごとのチューニング | 「ずらしなし」と「+50 セント」の2つのインスタンスを楽器ごとに用意し、音符を振り分ける | 確実。インスタンスとメモリが増える |
| C. 演奏中に Global Tune を書き換える | 1インスタンスでチューニングを都度変える | インスタンスは増えない。重なった音が一緒に動いてしまい、和音やレガートで破綻する |

## 決定

B を採る。

- 半音単位の音高は鍵盤で出す。四分音の上げは「+50 セントに調律したインスタンス」の半音下の鍵で出す
- 1楽器（1パート）あたりのインスタンスは最大2つ。四分音を使わないパートは1つ
- 音高の表現は四分音の格子に限る（半音の半分の刻み）。四分音より細かい値は受け付けない

## 理由

- BBC SO で実際に鳴る唯一の方式
- 四分音以外を使わないので、インスタンスの種類が2つで閉じる。実装が単純で、再生が速い
- 余湖さんが「実装が楽で確実な方法でよい、再生がサクッと鳴るのがありがたい」と決めた

## 結果と副作用

- ピッチベンドに頼らないので、[0010](./0010-pitch-bend-quarter-tones.md) の副作用
  （MIDI チャンネルの枯渇、ベンドを表現に使えない）は消える
- グリッサンドはピッチベンドで作れない。BBC SO のレガート（ポルタメント）か、サンプルで補う
- 同じ楽器の「ずらしなし」と「+50 セント」は別インスタンスなので、レガートが両者をまたぐとつながらない
- 他の音源（Kontakt、サンプル）を併用するときも、同じ「インスタンスごとの調律」の考え方で揃える
