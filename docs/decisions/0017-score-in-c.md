# 0017. 総譜は実音（in C）で書く

- 状態: 採用
- 関係する論点: Q12

## 背景

記譜の射影（楽譜の JSON → MusicXML）で、移調楽器を移調して書くか、実音で書くかを決める必要があった。
Sibelius へ渡す MusicXML の形が変わる。

## 選択肢

| 案 | 中身 | 効いてくること |
| --- | --- | --- |
| A. 実音 | すべて実音で書く。ピッコロ、コントラバス、グロッケンなどのオクターヴ記譜だけは慣例どおり | 四分音と組み合わせても臨時記号が素直。以前の取り込みテストで、Sibelius が移調の指定を音高に適用してずれた経路を通らない |
| B. 移調 | B♭ クラリネット、F のホルンなどを移調して書く | 演奏者の慣れた形。取り込みでの移調の扱いを確かめ直す必要がある |

## 決定

A を採る。

## 理由

- 余湖さんが実音でよいと決めた（2026-09-27）
- パート譜の提出は求められておらず、演奏用の楽譜は主催者が作る（[`../competition.md`](../competition.md)）
- 四分音の臨時記号が移調の計算を経ずに済む

## 結果と副作用

- MusicXML に `<transpose>` を書かない。オクターヴ記譜の楽器は、書かれた音高そのものを出す
- 総譜の冒頭に「Score in C」の注記が要る。浄書の段階で入れる
