# 0015. ディヴィジを記譜と再生の両方で一級に扱う

- 状態: 採用
- 関係する論点: Q9

## 背景

この曲は、リゲティのように弦を大量にディヴィジで書く可能性がある（余湖さん、2026-09-27）。
もちろん規定の編成（[`../competition.md`](../competition.md)）の範囲内で。

BBC SO の弦はセクションの人数が固定で、単独の奏者はリーダーのパッチしかない。
「Vn1 を 8 つに分ける」「このパートは 2 人」を、そのまま鳴らす手段はない。

## 決定

- 楽譜の JSON では、**パートが奏者数を持つ。** 1つのセクション（例: Violins 1）を複数のパートに分けられ、
  各パートが「このセクションの何人か」を持つ
- 記譜では、分けたパートを独立した譜表（または1譜表に複数声部）として書き、`div.` と人数を記す
- 再生では、人数からパッチと音量を選んで近似する。初期の規則:
  - 1 人 → リーダーのパッチ
  - 2〜3 人 → リーダーのパッチ（同じ奏者の音が重なるのを避けるため、ラウンドロビンの位置をずらす）
  - 4 人以上 → セクションのパッチを、人数の比で音量を下げて鳴らす
- 同じセクションを分けたパートの人数の合計が、編成の人数を超えないことを検査する

## 理由

- 大量のディヴィジを書く可能性があるなら、後付けではなく最初からモデルに入れておく必要がある
- 再生の近似は規則として一箇所に置けば、聴きながら調整できる

## 結果と副作用

- 再生は近似であり、少人数のディヴィジの響きは実演と違う。とくに 2〜3 人は同じ奏者の録音を重ねるだけ
- パートの数だけ音源のインスタンスが増える。四分音で倍になりうる（[0013](./0013-quarter-tones-by-instance-tuning.md)）
