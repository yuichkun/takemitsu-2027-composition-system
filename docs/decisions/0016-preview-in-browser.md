# 0016. プレビューは vp dev のブラウザ画面にする

- 状態: 採用
- 関係する論点: Q4 / Q5

## 背景

楽譜の JSON（[0014](./0014-score-json-contract.md)）を、譜面で見て BBC SO で聴くための画面が要る。
作曲用の UI は持たない。

## 選択肢

| 案 | 中身 | 効いてくること |
| --- | --- | --- |
| A. vp dev のブラウザ画面 | 開発サーバがファイル監視とレンダの起動を持ち、ブラウザは表示と再生だけ | すぐ立ち上がる。アプリとしての起動はできない |
| B. Electron | Web UI をデスクトップアプリに包む | アプリとして起動できる。包む作業が要る |

## 決定

A を採る。譜面の描画は Verovio で、Sibelius に渡すのと同じ MusicXML を描く。

## 理由

- 余湖さんが vp dev でよいと決めた
- A からあとで B に包むこともできる（[`../proposal.md` 4.3節](../proposal.md#43-アプリケーションの形態--選択肢)）
- MusicXML をそのまま描くので、プレビューが「MusicXML に何が乗っているか」の検査を兼ねる

## 結果と副作用

- Verovio の描画は Sibelius の描画と別物。内容が乗っているかの確認にはなるが、見た目の保証にはならない
