# 0024. antara の編成

- 状態: 採用
- 関係する論点: Q9（編成をどう決めるか）

## 背景

本番の antara を書き始める前に、編成を決める（余湖さん、2026-09-29）。上限は応募要項（[`../competition.md`](../competition.md)）。
Claude が余湖さんの希望を要項と BBC SO の楽器に照らして案を出し（Artifact「antara の編成案」）、余湖さんが決めた。

## 決定

楽器の一覧の正本は [`../../pieces/antara/ensemble.ts`](../../pieces/antara/ensemble.ts)。

- フルート 3（3 番ピッコロ持ち替え）、オーボエ 3（3 番イングリッシュ・ホルン持ち替え）、クラリネット B♭ 2 とバス・クラリネット 1、ファゴット 3（3 番コントラファゴット持ち替え）
- ホルン 4、トランペット 3、トロンボーン 3（3 番バス・トロンボーン）、テューバ 1
- ティンパニ 1 人、打楽器 3 人
  - 1: クロタル、グロッケンシュピール、吊りシンバル、シェーカー
  - 2: ヴィブラフォン、タムタム、サンダーシート
  - 3: マリンバ、チューブラー・ベル、バスドラム、ウッドブロック 3、ラチェット
- ハープ 2。**2 番は全弦を四分音低く調弦する**
- ピアノ、チェレスタ（鍵盤 2 人）
- 弦 16・14・12・10・8

使わないもの（検討して外した）: E♭ クラリネット、アルト・フルート、その他の管楽器の 1 枠、四分音低く調律したピアノ（鍵盤の奏者が足りない）。
打楽器の割り振りは、書きながら変わってよい（余湖さん「多少変更あるかも」）。

## 理由

- ハープ 2 の調弦: 固定音高の楽器でも、半音の音（ハープ 1、ピアノ、チェレスタ、鍵盤打楽器）と、四分音ずれた音（ハープ 2）の両方を鳴らせる。
  ガラスの和音で試した「着いた格子の楽器が鳴らす」がオーケストラの中でできる。余湖さん「この曲のアイコニックな楽器になりそう」。
  ペダルは弦を短くして半音ずつ上げる仕組みで、上がる幅は弦の長さの比で決まるので、全弦を低く張ってもペダルの働きは変わらない
- クラリネット: E♭ は使わない（余湖さん）。3 番をバス専任にすると、クラリネットの持ち替えはなくなる
- 打楽器: 音高のある打楽器は音域と音色で分け、弓で弾ける金属（クロタル、ヴィブラフォン、タムタム、吊りシンバル）を入れた。
  音高のない打楽器は時間の軸を鳴らすもの（ウッドブロック 3 つ、シェーカー、ラチェット）と、大きな雑音（サンダーシート、タムタム、バスドラム）

## 結果と副作用

- 音の原則（[`../antara/sound.md`](../antara/sound.md)）の「調律を四分音ずらした楽器も使わない」を、ハープ 2 だけの例外に書き換えた
- ハープ 2 の調弦のような準備は、楽譜の冒頭のページ（演奏上の注意）にまとめる。システムでは扱わず、総譜は実音で書く（余湖さん）。
  確かめのためだけに、パートに `tuning`（半音いくつずらしたか）を持たせ、ハープ 2 に四分音ずれていない音が来たら警告する
- 本選では 4 曲を同じオーケストラで続けて演奏するので、ハープ 2 は antara の前後で張り直すか、もう一台が要る。演奏上の注意に書く
- BBC SO にないシェーカー、サンダーシート、ラチェットは、音符を書く前にサンプルを用意する（決定 0012 の経路）。目録（`src/instruments/catalog.ts`）にはシェーカーとサンダーシートを足した
- フルート 3・オーボエ 3・ファゴット 3 の持ち替えの時間が足りるかの確かめは、まだない（同時に鳴ることだけを警告する）
