# 決定記録

**1つの決定につき1ファイル。** なぜそう決めたかを残す場所。

これがあるおかげで、仕様（`docs/*.md`）から経緯を追い出せる。
仕様は「今の正解」だけを書き、「なぜ」はここが持つ。

## ファイル名

`NNNN-slug.md`（例: `0001-document-rules.md`）。番号は連番で、欠番を作らない。

## 状態

| 状態 | 意味 |
| --- | --- |
| `提案` | Claude または誰かの案。まだ合意していない |
| `採用` | 合意して、これで進める |
| `棄却` | 検討して採らなかった。理由を残す価値があるもの |
| `差し替え済み` | 別の決定に置き換わった。新しい番号へのリンクを持つ |

**合意前の案を `提案` として置いてよい。** 口頭で流れて消えるより残したほうがいい。

## 運用の約束

- **本文は書いたら変えない。** 覆すときは新しい決定記録を書き、
  古い方の状態を `差し替え済み` にして新しい番号へのリンクだけを足す。
- 決定に至らなかった論点は、ここではなく [`../open-questions.md`](../open-questions.md) に置く。

## 書式

```markdown
# NNNN. タイトル

- 状態: 提案 / 採用 / 棄却 / 差し替え済み
- 関係する論点: Q1 など

## 背景

何が問題で、なぜ決める必要があったか。

## 選択肢

検討した案と、それぞれの効いてくること。

## 決定

何をどう決めたか。

## 理由

なぜその案を選んだか。

## 結果と副作用

決めたことで何が起きるか。引き受けた不利益も書く。
```
