### やったこと

- 掃除: 手作りの取り込みテスト（`verification/`）、動作確認の取れていない ManuScript プラグイン（`sibelius-plugins/` と Sibelius 側のコピー）、
  Sibelius テストの生の記録（`artifacts/sibelius-*`）を消した。結論は調査ノートに残してある
- BBC SO の全 467 パッチを走査し、在庫表（`src/libraries/bbcso/inventory.json`）にした
- 楽譜の JSON の型、記譜の射影（MusicXML）、演奏の射影とレンダ、プレビュー画面（`vp dev`）を作った。構成は [`../architecture.md`](../architecture.md)
- `examples/showcase.json`（四分音、3連・5連、niente のヘアピン、奏法、ディヴィジ、小太鼓、ピアノ2段）で、譜面と音の両方を確かめた

### 観測したこと

- 速い走査では、音高のある楽器に「範囲内で鳴らない鍵」が 400 余り出た。1鍵ずつ鳴らし直すと全部鳴った。立ち上がりの遅い音が前の音の残響に埋もれた誤検出
- クロタルは走査でずれが大きく見えたが、鍵 = 実音で他と同じだった（非調和な倍音のせい）
- レンダ済みの四分音: フルート A+4 は +5 セント、ヴァイオリン C+5 は +16 セント（残りはサンプル自体の揺らぎ）
- showcase 全体（8 レーン、12.5 秒）のレンダは約 34 秒。大半は音源の読み込み待ち。2 回目以降はキャッシュで即座に鳴る
- Verovio は `svgHtml5` のとき id を `data-id` に書き、`getElementsAtTime` の前に `renderToMIDI` が要る
