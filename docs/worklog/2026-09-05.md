## 観測したこと

### ★取り込みで落ちるものが、文献でかなり確定していた

手元の Sibelius 24.3.1 に同梱の Reference（1.9 Opening MusicXML Files）を `pdftotext` で読んだ。

- 内蔵 converter は **MusicXML 3.0 ベース**。将来版のファイルは開けるが新機能は取り込まれない
- **`<technical>` と `<ornaments>` は取り込まれない**（トリル・モルデント・ターンは例外）。
  ハーモニクス記号・Bartók ピツィカート・弓の上下・ゲシュトップト・トレモロがここに落ちる
- **`<symbol>` は取り込まれない**。SMuFL 記号を名前で送る経路は閉じている
- **譜表タイプの変更は取り込まれない**。打楽器の譜線数変更や有音高⇄無音高の切替が効かない
- 二次連桁、heavy 系小節線、微分音の調号（`<key-step>` / `<key-alter>`）、譜表をまたぐ和音も落ちる
- 四分音の可否は文献上不明。Codex が Sibelius 7 時代の「非対応」の一次報告を見つけた（原典未確認）

### ★ManuScript が四分音の音符を作れる

同梱の ManuScript Language Guide で確認した。`SetInterpreterOption(SupportHalfSemitonePitchValues)` を有効にすると
`Bar.AddNote` 等が浮動小数の音高（0.5 = 四分音）を受け付ける。`Note.Pitch` と `Note.Accidental` は read only なので
既存の音符は書き換えられず、消して作り直す形になる。符頭（`NoteStyle`）・アーティキュレーション（`HarmonicArtic` /
`PlusArtic` 等）・トレモロ（`SingleTremolos`）・線・テキスト・記号・楽器変更は作れる。

→ 取り込みで落ちるものは「Sibelius が確実に読む要素にマーカーとして埋め、取り込み後にプラグインで置き換える」
経路が文献上成立する。四分音が MusicXML 直接で通らなくても作品は止まらない。
