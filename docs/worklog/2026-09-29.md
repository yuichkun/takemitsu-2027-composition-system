## 曲のアイデア 3: 縦の線と横の線（8 本）

余湖さんの注文:
- 「縦の線が横の線になる（逆でもいい）」。A（時間）: 8〜10 の楽器が同時に鳴る状態から、それぞれが順番に鳴るのが聴き取れる状態へ。
  B（音程）: 上行する旋律から、完全な同音の反復へ
- 原則を最大限に生かす。パラメーターでバリエーションを出すのではなく、スケッチ自体を分けて、実装方法から変えた A/B の複数パターン
- 作る前に、やることを Claude の言葉で言語化する → Artifact「縦の線と横の線」。余湖さん: バッチリ、進めて

見方（Claude の読み、余湖さんが了承）: 縦の線は時間の間が 0 の並び、横の線は音程の間が 0 の並び。A は時間の間を 0 から開き、B は音程の間を 0 へ閉じる

やったこと（[`../../sketches/antara/ideas/lines/`](../../sketches/antara/ideas/lines/README.md)、共通のコード `common.ts`）:
- A: 一つずつ遅れる（間が atom 一つずつ違うパルス）、時間の間が 0 から開く（0 ばかりのセットが atom ずつ開く）、
  仲間がほどける（拍ごとに鳴る声が一人ずつ間を atom 一つ動かす）、一人ずつ離れる（和音から一人ずつ抜けて後ろに並ぶ）
- B: 間が四分音ずつ縮む、0 が増える、天井で止まる、同じ音を受け渡す
- 和音の音は、その格子を出せる楽器に配る（固定の音の楽器は起点の格子、四分音低く調弦したハープとピアノはずれた格子）
- ブリーフィング: Artifact「縦の線と横の線」を、作ったものと聴きどころに書き直した

確かめたこと:
- 8 本とも楽譜が書き出せ、プレビューで最後まで鳴り、警告なし（0 が増える のクラリネットが BBC SO の音の上を越えたので、音域を E6 までにした）
- 仕組みどおりに動く: 一つずつ遅れる の崩れ方は 0 → 1.8 → 3.6 → 5.4 → 7.2 拍、時間の間が 0 から開く は別々に鳴る所が 1 → 3 → 4 → 7 → 10、
  一人ずつ離れる は和音にいる人が 10 → 1、天井で止まる はチェロが最初に入って最後に着く

計画から変えたこと: 同じ音を受け渡す のヴァイオリンを倍音から flautando に（その音域に BBC SO の倍音の音がない）。天井で止まる からコントラバスを外した（天井の音に届かない）

次の一手: 余湖さんが聴いて、続けたいものを選ぶ。「時間の間の 0」を原則に入れるかも聞いている

試しながら足した操作（どのセクションにも効くもの）:
- 同じパートなら、前の声部は次の声部が入るまで鳴らし続ける（はじめは替わった時刻で止め、次が自分の入りまで待つので空白ができた）
- まだ入っていない次の声部は、替わった時刻へ最初の音を伸ばして入る。そのときは次の声部自身の「無音から入る」強弱を使わない（一度 niente まで落ちていた）
- 前の強さで入る（adopt）
- テンポの替わりを一つの置き方の中で持つ（はじめは二つに分けていて、伸ばしている音が弾き直しになった）
- 値を読むのは替わる直前（終わった瞬間に替わると、何も鳴っていない瞬間を読んで値が渡らなかった）

足りないこと・決めていないこと:
- 音を群をまたいで受け渡すとき（breaths ではヴィオラが持っていた 56.5 と 59 を、glass ではチェロが持つ）、群ごとに替えると、順番しだいで短く抜ける（高い群からだと 2.7 拍）。
  いまは順番のつまみで避けた。「誰かが同じ音を引き継ぐまで鳴らし続ける」操作はない（弦の人数とぶつかりうる）
- 前の出力から値を入れると、次のセクションが前提にしていた音域を外れることがある。rings のペアは、一番上でオクターブを動かして弾ける所に入れた。
  All at once で一度、ヴァイオリン独奏が音域の下に出て、ハープが録音の下に出た（直した）。セクションが「受け取れる値の範囲」を言えると良い
- 両側で区切りの候補に寄せるので、次の線が次の組の頭を待つ短い隙間（120 で 0.5〜1 秒）ができる。組の途中から入ってよいかは、つまみにしていない
- 地図にはセクションが並ぶだけで、つなぎ目ごとに何が続き何が何秒に替わったか（境目の表）は、まだ見せていない
- Carry が入れた値は、そのセクションのつまみの欄では分からない（そのセクションのつまみを動かしても効かない）
- セクションの中のテンポの変化は扱っていない（最初のテンポだけを使い、警告を出す）
