## 観測したこと

### ★四分音は `<accidental>` だけが運ぶ。`<alter>` は半音に切り捨てられる

quarter-sharp は `<alter>0</alter>`、three-quarters-sharp は `<alter>1</alter>`。`0.5` は一度も出ない。
Sibelius にとって四分音は「音高」ではなく「臨時記号」として MusicXML に載る。
取り込みテストの第一候補はこの方言そのもの（alter 切り捨て + accidental）になる。

### 移調楽器でも四分音の臨時記号は追従する

Clarinet in B♭ の `<pitch>` は記譜音で出て（実音 C↑ → written D↑）、`<transpose>` が別に付く。
四分音の臨時記号は移調後の音に正しく付いていた。MusicXML の `<pitch>` は記譜音、`<transpose>` を足すと実音。

### 書き出しで意味が失われるもの

- Symbols（矢印つき臨時記号、Bartók pizz.）は `<other-direction print-object="no">` の不可視テキストになる
- niente ヘアピンの `niente` 属性、羽根連桁の `fan` 属性は出ない
- l.v. タイは始点だけの `<tie>` / `<tied>` になる（3.0 に `let-ring` はない）
- ○（Harmonic/Open）は `<technical><open-string/></technical>` として出る。取り込みで `<technical>` が
  読まれないなら落ちるはずだが、自分の書き出しと対称な例外があるかは次のテストで見る

### 楽器変更と 8va の方言

- 持ち替え: パートに `<score-instrument>` を2つ持ち、音符ごとの `<instrument id>` で切り替え、
  `<transpose>` を変え、`<print>` の `<part-name-display>` で名前を変える
- 8va: `<octave-shift type="down">` の下の `<pitch>` は鳴る高さ（C6）で書かれる

### 匿名性

- 書き出した MusicXML の `<encoder>` に Sibelius のユーザ名（実名）が入る
- PDF の Info には Author が入らなかった

### Sibelius の更新で変わること

Avid のリリースノート PDF（2024.10〜2026.8）を取得して読んだ。MusicXML の取り込みに触れているのは 2024.10 だけで、
楽器名の解釈の改善と、警告ダイアログで取り込みが止まらなくなることが実利。四分音・technical・ornaments・symbol・
譜表タイプの扱いはどの版にも記述がない。浄書側では譜表またぎの臨時記号（2026.6）・タイ（2026.8）・連桁（2026.2）、
2音トレモロの音価表示（2026.2）、線の継続テキスト（2026.8）が効く。詳細は調査ノート1章。
