# antara ―「あいだ」と切れ目についての考察

- 元: 余湖さんの Notion の同名ページ（雑記の下。最終更新 2026-09-27）。2026-09-28 に本文と参考文献をそのまま写した
- 曲名はこの語から取る（[`README.md`](./README.md)）

> このノートは、インドネシア語・マレー語で「あいだ」を意味する語 antara を手がかりに、「あいだ」とは何かを、言語の歴史、数学、東南アジアの歴史の三つの方向から考えたものです。余湖雄一さんの作品コンセプトを練る過程で、2026年9月に書かれました。
>
> 語形の前に付いている \* は、文献には残っておらず、言語どうしの比較から理論的に復元された形（再建形）であることを示します。

## 1. 同じ語がどう分かれ、どう一つになったか

印欧祖語（インド・ヨーロッパ祖語）は、英語、ドイツ語、ラテン語、ギリシャ語、サンスクリット語など、ヨーロッパから南アジアに広がる多くの言語の共通の祖先として、比較言語学によって再建された言語です。

出発点は、印欧祖語で「中に」を意味する \*h₁én です。これに、二つを対比させる接尾辞が付いて、次の二つの語ができました。

- \*h₁entér「あいだに、内に」→ ラテン語の inter、サンスクリット語の antár
- \*h₁énteros「内側にあるもの」→ ラテン語の interior、ギリシャ語の énteron（はらわた）

これとは別に、\*h₂énteros「もう一方の、二番目の」という語がありました。英語の other、ドイツ語の ander、ゴート語の anþar（序数の「二番目」）、リトアニア語の antras（二番目）がその子孫です。語頭の部分がどこから来たのかについては諸説あります。

共通の接尾辞 \*-teros は、「二つのうちのどちら」を意味する \*kʷóteros にも使われていて、英語の whether はその子孫です。つまり、どの語も「二つのうちの片側」を名指す形をしています。「内側」は外に対する内であり、「もう一方」は一方に対するもう一方です。

h₁ と h₂ は「喉音」と呼ばれる、印欧祖語にあったと考えられている子音で、正確な音はわかっていません。ヨーロッパの言語では、この二つの違いが後に続く母音の違い（e と a）として残ったので、interior と other は別々の語のままでした。ところが、サンスクリット語やペルシャ語などを含むインド・イラン語派では、祖語の e・o・a が a に合流し、喉音も一つの音にまとまりました。その結果、「内側のもの」と「もう一方のもの」はまったく同じ \*Hántaras になり、サンスクリット語の ántara は、一語で「内側」と「別の、異なる」の両方を意味するようになりました。英語が今も interior と other に分けているものを、サンスクリット語は同じ一つの音で持っているわけです。

ちなみに英語の other も、古英語では「二番目」の意味で序数として使われていました。紛らわしいので、その役目はのちにラテン語由来の second に譲られましたが、スウェーデン語では今も「二番目」を andra と言います。

## 2. サンスクリット語・パーリ語での意味の広がり

パーリ語は、サンスクリット語に近い古代インドの言語の一つです。パーリ語の辞書は、antara の基本の意味を「内側」と「あいだ」としています。そこから、内側という関係の二つの側を対比することで「隔たりがある」「異なる」という意味が生まれ、さらに名詞の「違い」へと発展した、と説明しています。内側、あいだ、違い、他者は、別々の意味というより、「二つに分けて片側を名指す」という一つの働きを、違う角度から呼んだものと言えます。

## 3. 東南アジアでの読まれ方

この語は、サンスクリット語から古ジャワ語（中世ジャワの文語）に入りました。Nusantara という語の最古の記録は1255年の碑文で、nusa（島）と antara を組み合わせたこの語は、文字どおりには「外の島々」を意味します。この合成語の antara には、「間隔」のほかに「他の、別の」という意味が当てられています。一方、1275年に使われた同じ意味の語 Dvipantara は「あいだの島々」と説明され、Nusantara の antara を「向かい側の」と訳す人もいます。同じ語で同じ島々を指しているのに、「外」「あいだ」「向かい側」と読みが割れます。どこに立って見るかで、名前が変わるのです。そして現代のインドネシア語とマレー語では、antara は「A と B のあいだ」の形で使う前置詞になっています。

## 4. 有理数のあいだ

有理数とは、分数で書ける数のことです。どの二つの分数のあいだにも、必ず別の分数があります。たとえば $\frac{1}{3}$ と $\frac{1}{2}$ のあいだには $\frac{5}{12}$（二つの平均）があり、$\frac{1}{3}$ と $\frac{5}{12}$ のあいだには $\frac{3}{8}$ がある、というふうに無限に続きます。だから「0 のすぐ次の分数」は存在しません。どんな正の分数 $\frac{a}{b}$ を挙げても、$\frac{a}{2b}$ がさらにそのあいだに入るからです。

それほど密に並んでいるのに、分数の列には隙間があります。2乗すると2に近くなる分数を順に並べてみます。

- $\frac{3}{2}$ → 2乗は $\frac{9}{4}$（2より $\frac{1}{4}$ 大きい）
- $\frac{7}{5}$ → 2乗は $\frac{49}{25}$（2より $\frac{1}{25}$ 小さい）
- $\frac{17}{12}$ → 2乗は $\frac{289}{144}$（2より $\frac{1}{144}$ 大きい）
- $\frac{41}{29}$ → 2乗は $\frac{1681}{841}$（2より $\frac{1}{841}$ 小さい）
- $\frac{99}{70}$ → 2乗は $\frac{9801}{4900}$（2より $\frac{1}{4900}$ 大きい）

2乗は2の上と下を交互に行き来し、ずれは $\frac{1}{4}$、$\frac{1}{25}$、$\frac{1}{144}$ とどこまでも小さくなります。それでも、2乗がちょうど2になる分数はありません。$\frac{p}{q}$ の2乗が2なら $p^2 = 2q^2$ ですが、素因数2の個数は、左辺では必ず偶数、右辺では必ず奇数になるので、等しくなりえないからです。

そこで分数全体を二組に分けます。一方は「負の数と、2乗が2より小さい分数」（$\frac{7}{5}$、$\frac{41}{29}$ など）、もう一方は「2乗が2より大きい正の分数」（$\frac{3}{2}$、$\frac{17}{12}$、$\frac{99}{70}$ など）です。小さい側には最大の分数がなく、大きい側には最小の分数がありません。どこまで近づけても、境目にはどの分数も立っていないのです。

1872年、ドイツの数学者リヒャルト・デデキントは、このようにどの有理数によっても生じない切れ目があるとき、その切れ目によって完全に定まる新しい数を「創る」と書きました。それが $\sqrt{2}$ です。$\sqrt{2}$ は隙間の中で見つかったものではありません。二つに分ける切れ目そのものを、一つの数として数えたものです。この考え方は「デデキント切断」と呼ばれ、実数の標準的な定義の一つになっています。

比べると、$\frac{1}{2}$ で分けた場合は、境目にちゃんと $\frac{1}{2}$ が立っています。切れ目には、項が立っているものと、立っていないものがあるわけです。

## 5. 二つを重ねると見えてくるもの

antara では、分けることが先にあり、内側・外・他者・違いは、その切れ目を立つ位置から呼び分けた名前でした。デデキントの $\sqrt{2}$ でも、切れ目が先にあり、数はその切れ目として定義されます。スイスの言語学者フェルディナン・ド・ソシュールは、違いは通常、そのあいだで違いが成り立つ二つの項を前提とするが、言語の中には項をもたない違いしかない、と述べました。これも同じ向きの考え方です。

インドネシア語の antara を A と B なしで置くことは、「どの項も立っていない切れ目」をそのまま名指すことになります。有理数の世界では、それは欠けた場所でした。デデキントは、そこを新しいものが定義される場所に変えました。

## 6. マラッカ海峡：余湖さんの体験と歴史

余湖さんは2026年7月をインドネシアのジャカルタで過ごしたあと、初めてマレーシアのクアラルンプールへ渡りました。機上からスマトラ島をはじめとする島々を越えていく眺めは、それまでの飛行機の体験とは違って強く印象に残り、そのとき Nusantara という言葉が頭をよぎったといいます。マレーシアに着いてから歴史を学ぶうちに、あの海峡がマラッカ海峡と呼ばれていること、この地域が外から侵略を受けてきた歴史、そしてマラッカ王国の時代には今のインドネシアの一部も同じ国だったことを知りました。以下は、その体験と、歴史として確かめられることとの重なりです。

ジャカルタからクアラルンプールへの飛行は、ジャワ島から、スマトラ島とマラッカ海峡を越えてマレー半島へ向かうルートです。Nusantara は、ジャワの中心から見て「外」の島々を指した言葉でした。マジャパヒト王国の宰相ガジャ・マダが14世紀に立てた誓い（1334年とも1336年とも言われる）には、征服すべき地として、スマトラのパレンバンやハル、マレー半島のパハン、今のシンガポールにあたるトゥマシクが並んでいます。その言葉が余湖さんの頭をよぎったのは、ちょうどその言葉が生まれた視点から出発して、その言葉が「外」と呼んだ場所の上を横切っているときでした。

マラッカ海峡は、時代によって「内側」にも「あいだ」にもなってきた海です。15世紀のマラッカ王国は、マレー半島の大部分に加えてスマトラ島中東部の沿岸も領土とし、インドと中国を結ぶ航路の要としてこの海峡を押さえていました。この時代に、古典マレー語は海域東南アジアの共通語になっています。当時の海峡は、国を二つに分ける線ではなく、国の真ん中を通る道でした。

その後、マラッカは1511年にポルトガル、1641年にオランダ、1824年にイギリスの支配下に入り、1942年には日本に占領されました。1824年の英蘭条約は、マレー世界を海峡に沿って二つに分け、スマトラをオランダ側、マレー半島とシンガポールをイギリス側としました。この条約は、マレー世界の社会への影響を考慮せずに勢力圏だけを定めたもので、海峡の中に厳密な境界線を引いたわけでもありませんでした。それでも、のちにインドネシアとマレーシアの国境の土台になります。ライデン大学の講演の要旨は、この分割について、はじめは外から押しつけられ、文化の営みとはほとんど無関係だったのに、のちには内側から支持され守られるようになった、と述べています。外から引かれた線が、内側の線になったのです。

どこに立つかで、同じ海が「内側」にも「あいだ」にもなる。これは1節と3節で見た antara の構造そのものです。

さらに言えば、この切れ目は $\sqrt{2}$ の切れ目に似ています。1824年の線は、それ以前から立っていた境界の上に引かれたものではありませんでした。どの既存の境目によっても生じない切れ目です。それでも一度引かれると、その切れ目が新しいものを定義し始めました。線の両側は別々の国家になり、同じマレー語から二つの標準語が育ちました。それ以前はマレー語と呼ばれていた言語が、1928年にインドネシアの側で「インドネシア語」と名づけられます。二つの標準語はおおむね通じ合いますが、綴り、文法、発音、語彙には違いがあります。同じ言語が、立つ側によって別の名前で呼ばれるようになったわけです。そして antara という語は、その切れ目の両側で、今も「あいだ」を意味しています。もちろん国境は数ではないので、これはあくまで構造の類比です。

もう一点、余湖さんの経歴から合理的に言えることがあります。余湖さんは日本語のほかに、英語（EF SET C2）と中国語（HSK6級）を高い水準で身につけ、韓国語も話します。同じ字や語が言語によって別の意味になる経験（日本語の「手紙」が、中国語の「手纸」ではトイレットペーパーになるような）は、余湖さんにとって日常です。1節の「同じ語が分かれ、立つ場所で意味が変わる」という話は、余湖さんにとって外から借りてきた知識ではありません。

## 7. コンセプトの核

> あいだとは、二つのものの間にある第三のものではない。二つに分ける切れ目そのものであり、内・外・他・違いは、その切れ目を立つ位置から呼んだ名前である。マラッカ海峡が、ある時代には国の真ん中を通る道であり、ある時代には二つの国を分ける線であったように。そして、どの項も立っていない切れ目は、欠けではなく、新しいものがそこで定義される場所になる。
