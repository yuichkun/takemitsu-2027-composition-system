# antara

応募作の曲名は **antara**（余湖さん、2026-09-28）。インドネシア語・マレー語で「あいだ」。

この曲の構想を置く場所。システムの仕様は `docs/` の上の階、曲のコードは（できたら）`pieces/antara/` に置く。

| ファイル | 中身 |
| --- | --- |
| [`concept.md`](./concept.md) | コンセプト。antara という語、デデキント切断、マラッカ海峡から「あいだ」を考えたもの。余湖さんの Notion から写した |
| [`interval-series.md`](./interval-series.md) | 音の組み方。音程のセリー。調性感は音程の関係の中に結果として生じる、という方針と、その整理 |

## コンセプトの核

> あいだとは、二つのものの間にある第三のものではない。二つに分ける切れ目そのものであり、内・外・他・違いは、その切れ目を立つ位置から呼んだ名前である。マラッカ海峡が、ある時代には国の真ん中を通る道であり、ある時代には二つの国を分ける線であったように。そして、どの項も立っていない切れ目は、欠けではなく、新しいものがそこで定義される場所になる。

## 音の組み方の方針

調性感とは、音程の関係性の中に「結果として」生じるものである。音程のセットを並べて旋律と和音を作り、同じ構図をリズムなどにも埋め込む。
詳しくは [`interval-series.md`](./interval-series.md)。
