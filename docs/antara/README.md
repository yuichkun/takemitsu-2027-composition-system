## コンセプトの核

> あいだとは、二つのものの間にある第三のものではない。二つに分ける切れ目そのものであり、内・外・他・違いは、その切れ目を立つ位置から呼んだ名前である。マラッカ海峡が、ある時代には国の真ん中を通る道であり、ある時代には二つの国を分ける線であったように。そして、どの項も立っていない切れ目は、欠けではなく、新しいものがそこで定義される場所になる。

## antara で挑むこと

調性感とは、音程の関係性の中に「結果として」生じるものである。調性を避けも戻りもせず、関係の結果として現れ、また消えていくものとして扱う。
