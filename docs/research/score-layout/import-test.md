# 実機テスト — Sibelius 24.3.1 はフルスコアの体裁をどう取り込むか

実施: 2026-09-29、Codex（computer use）が Sibelius 24.3.1 build 3317（Ultimate、英語 UI）で。
テスト用のファイルと手順は [`../../../verification/sibelius-layout/`](../../../verification/sibelius-layout/README.md)。
Codex の報告の原文は [`import-test-report.md`](./import-test-report.md)（画像と再書き出しの MusicXML は `verification/sibelius-layout/results/`、git の外）。

確度の記号はすべて `[実測]`。取り込みダイアログは既定のまま（ページと五線の大きさ・レイアウトを MusicXML から、楽器は Sibelius が選ぶ、名前は MusicXML から）。
House style の欄は「Podium」と出て選べなかった（結果には影響していないと見ている）。

## 結果と、書き出しへの反映

| 問い | 結果 | 書き出し |
| --- | --- | --- |
| オクターヴ記譜の楽器（ピッコロ、グロッケン、クロタル、シロフォン、チェレスタ、コントラファゴット、コントラバス） | `<transpose>` のオクターヴがあれば、書いた位置も鳴る高さも正しい（ピッコロは C5 に書かれ C6 で鳴る）。無いと 1 オクターヴ下に書かれる | オクターヴの `<transpose>` を書く（済み） |
| バスクラリネット | 実音のヘ音記号（移調なし）は「Bass Clarinet in Bb」になり、Transposing Score で長 9 度上のト音記号に正しく移る。1 オクターヴ上のト音記号＋移調では、歌の「Bass」として読まれた | 実音のヘ音記号で書く（済み） |
| 楽器の種類 | `<score-instrument>`（Sibelius の楽器名と標準の音色名）があれば、クラリネットは in B♭ / in E♭、ホルンは in F、トランペットは in B♭ として読まれる。無いと in A、in D、in A に化ける | 書く（済み） |
| 楽器の複製 | オクターヴ記譜の楽器と 1 線の打楽器は「Piccolo (MusicXML)」のような複製の楽器になる。表示と鳴る高さは正しい | そのまま（見た目に影響なし） |
| 括弧と小節線 | `<part-group>` は効かない。括弧を書いても書かなくても同じで、Sibelius が家族ごとの太い括弧を自分で付ける（木管・金管・弦）。細い括弧は付かない。ティンパニは一人で括弧、ほかの打楽器は括弧なし。小節線は家族の中でつながり、家族のあいだで切れる | プレビューのために書き続ける。細い括弧とティンパニの括弧は Sibelius での仕上げ |
| ハープとピアノ | 波括弧、上下の段、下の段の音部記号の替わり、段のあいだの強弱は、そのまま入る | そのまま |
| ハープのペダル図 | `<harp-pedals>` は入らない | 書かない。要るなら Sibelius で |
| 段の名前 | 最初の段は正式名、二段目からは略称になる。`<part-name-display>` の ♭ は音楽記号で出る（文字の ♭ も読めた） | そのまま（済み） |
| 調号 | 空の `<key/>` だけが「調号なし」になり、Transposing Score でも B♭ クラリネットに調号が付かない。`<fifths>0</fifths>` と `<key>` なしは、移調表示で ♯2 つが付く | 空の `<key/>` を書く |
| 二人で一段 | 「a 2」、和音、二声（符尾の向き、「1.」は上・「2.」は下）、一人だけのときの隠した休符、3 連符と 5 連符の同居が、全部そのまま入る。「a 2」「1.」は Technique のテキストになる | そのまま |
| 二声の休符 | 二人とも休む所で、二声それぞれの休符が上下に二つ出る | 二人とも休む所では下の声の休符を隠す |
| 奏者の番号と奏法の文字 | 同じ音符に付くと、「1.senza vib.」のように接して読める | 並べ方を考える |
| ディヴィジ | 分かれたパートの段は別の楽器として入り、名前もそのまま。二段にした弦楽器は、ピアノとして読まれた | 弦を二段の楽器にしない（今も使っていない） |
| 打楽器 | 奏者ごとの段、名前、1 線譜は入る。ただし B4 に書いた音が線の上（間一つほど上）に出る | 線に乗る高さを、次の実機テストで確かめる |
| 用紙 | A2 縦 420 × 594 mm、五線 6 mm、余白 30 mm が、そのまま Document Setup に入る（名前は Custom） | そのまま（済み） |
| 段の改めと空の段を隠す | `<print new-system="yes"/>` の所で段が改まり、Hide Empty Staves で、狙いどおり「二人一段」と「一人一段」の段が入れ替わる | 場面ごとに切り替える書き方も使える（今は曲全体で決める） |
| 臨時記号 | `<accidental>` の指定（毎回のナチュラル、括弧の注意記号、繰り返す四分音の記号）は読まれず、Sibelius が自分の規則で付け直す。プラグイン「Add Accidentals to All Notes」（Note Input > Plug-ins > Accidentals）は変化のない音にナチュラルを付けるが、同じ小節で繰り返す四分音には付けず、四分音に「Q」の警告を出す | 小節の終わりまで効く、ふつうの規則に戻す（[`../../decisions/0022-accidentals-to-the-bar.md`](../../decisions/0022-accidentals-to-the-bar.md)） |

## Sibelius での仕上げ（この結果で決まった手順）

1. File > Open。ダイアログは既定のまま（全部オン）
2. **細い括弧**: 同じ楽器の段（フルート、クラリネット、ホルン、トランペット、トロンボーン、Violin I と II、ディヴィジの段）を選び、Notations > Bracket or Brace > Sub-bracket
3. **打楽器の括弧**: ティンパニの括弧を下へ延ばして、打楽器の段まで一つにする（括弧の端をドラッグ）
4. **空の段を隠す**: 全体を選んで Layout > Hide Empty Staves。ハープと鍵盤の片手だけが消えていないか見る
5. **テンポと練習番号**: Appearance > System Objects > System Object Positions で、ヴァイオリン I（と金管）の上にも出す
6. **小節番号**: Engraving Rules > Bar numbers
7. 表紙・編成表・演奏上の注意は別に作る

## まだ確かめていないこと

- 1 線の打楽器の譜表で、どの高さ（E4、G4、B4 …）が線に乗るか
- 空の `<key/>` を、プレビュー（Verovio）が問題なく描くか（こちらで確かめる）
