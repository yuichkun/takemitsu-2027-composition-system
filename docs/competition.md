[`research/takemitsu-award-2027.md`](./research/takemitsu-award-2027.md)。

| 項目 | 条件 |
| --- | --- |

## 作品の条件

- 本選演奏会時に**未発表**のオーケストラ作品
  - 「未発表」の定義（英語版原文）: 本選演奏会より前に、出版・公開演奏・商業録音された譜面は対象外
  - つまり **2027年5月30日まで**、出版も公開初演も商業録音もできない
- **コンチェルトを除く**
- **一人の指揮者で指揮が可能**であること
- 演奏時間 **10分以上20分未満**
- 応募は**1人1曲**のみ
- **1人の作曲家によるもの**に限る（共作不可）

## 楽器編成の上限

| 楽器 | 上限 |
| --- | --- |
| フルート | 3（ピッコロ、アルト・フルート 持ち替え可） |
| オーボエ | 3（イングリッシュ・ホルン 持ち替え可） |
| クラリネット | 3（E♭クラリネット、バス・クラリネット 持ち替え可） |
| ファゴット | 3（コントラファゴット 持ち替え可） |
| ホルン | 4 |
| トランペット | 3 |
| トロンボーン | 3 |
| チューバ | 1 |
| その他の管楽器 | 1（上記以外の種類の管楽器を1つ追加可） |
| ハープ | 2 |
| キーボード | **2奏者**（ピアノ［2台可］、チェレスタ、シンセサイザー可） |
| 打楽器 | **4奏者**（ティンパニを含む） |
| ヴァイオリン | 30 |
| ヴィオラ | 12 |
| チェロ | 10 |
| コントラバス | 8 |

**打楽器とキーボードは楽器の数ではなく奏者の数が上限。**
4人で持ち替えて回せる配置に収まっている必要がある。

その他:

- 特殊な管楽器・打楽器は**変更を求められることがある**
- **楽器を損傷させる恐れのある奏法は不可**

## 電子音の扱い

- **リアルタイムの電気的増幅・変調は不可**
- **テープ・CD等の再生（フィクスト・メディア）の併用は不可**
- シンセサイザーは可。ただし条件つき:
  - 原則として**日本で調達が容易な機種**に限る。希望機種がある場合は事前に事務局へ問い合わせ
  - **音色データは応募者が用意**する
  - ソフトウェア・シンセサイザーも可。ただし「通常のキーボードと同様に**鍵盤奏者がキーボードで演奏**すること」。
    コンピュータ・ソフトウェア・インターフェイスはすべて応募者が用意する

## 提出物

- **製本されたスコアのコピー2部**（製本されていないものは無効）
- **応募申込書**（PDFに直接入力可。印刷して同封）
  - ダウンロード: https://www.operacity.jp/concert/award/entry/download01.php
  - 記入項目: 応募年度（2027/2028/2029/2030 から選択）・氏名・生年月日・性別・国籍・
    住所・連絡先（TEL/FAX/E-MAIL）・別連絡先・略歴・**応募作品名**・**演奏時間**・
    **楽器編成**・備考・日付・署名
  - 注記:「上記連絡先で事務局からの連絡が取れない場合、失格になることがあります」

**パート譜は不要。** 本選ノミネート作の演奏用楽譜は主催者が作成する。
音源・CDの提出要求はない。参加料は無料。**応募スコアは返却されない。**

### 匿名審査

- **楽譜には作品タイトルのみを記し、作曲者名などは記入しない**

### 記譜に使用できる言語

- 通常の音楽用語・記号のほかは、**英語・フランス語・ドイツ語・イタリア語のいずれか**
- **日本語の奏法指示・演奏注記は書けない**

### 提出後

- **変更・訂正・加筆には一切応じられない**
- 例外として、演奏上の問題が生じる場合、審査員または指揮者から変更を要請することがある

## 選考の仕組み

- **審査員は各年度1名のみ。** 合議制ではない
- **譜面審査もその審査員本人が行う。** 予備審査委員会は存在しない
  - 公式（英）: "The judge will screen the submitted scores and select a certain number of works to be performed."
- 譜面審査を通過した作品を本選演奏会で上演し、その場で受賞作を決める
- 指揮者・演奏者の選択は主催者に任される

- 本選と並行するワークショップ等への参加要請があれば、**報酬の有無にかかわらず参加必須**
- 本選使用の演奏用楽譜は東京オペラシティ文化財団が所有・保管・管理する
