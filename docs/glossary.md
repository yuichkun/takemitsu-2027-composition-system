# 用語

同じものを別の名前で呼ばないための統一表。

## このシステムの概念

| 用語 | 意味 |
| --- | --- |
| **素材** (material) | 音高輪郭・リズム・出自を持つ、楽器に非依存の音楽的な種。柱1から来る |
| **ジェスチャー** (gesture) | 素材にダイナミクス包絡と奏法が分離不能に結びついた1単位。データモデルのプリミティブ |
| **配器** (orchestration) | ジェスチャーを楽器・レジスター・重複・ディヴィジへ割り当てる層 |
| **スコア** (score) | 完全に具体化された状態。2つの射影の入力 |
| **射影** (projection) | スコアから MusicXML または MIDI を生成する変換 |
| **演奏マップ** (performance map) | 記譜的意味を、音源ライブラリ固有の演奏実現（キースイッチ・CC）へ翻訳する対応表 |
| **出自** (provenance) | あるジェスチャーが、どの素材からどの変形を経て生じたかの記録 |
| **変形** (transformation) | ジェスチャーに適用する操作。移高・反行・間引き・再配器など |
| **時間設計** | 作品全体のドラマの曲線。生成の前に人間が引く |
| **規定リンター** | 応募規定への適合を機械的に検査する仕組み |

## 4本の柱

| 用語 | 意味 |
| --- | --- |
| **柱1 / 即興** | 時間芸術におけるドラマの構成能力、情緒の表現能力。技術以前の源泉 |
| **柱2 / エクリチュール** | 具象化の手技。同時に、鳴った音を裁く**評価器** |
| **柱3 / アルゴリズミック** | 計算機による創作。量のコストが消え、プログラムを書くコストが生じる |
| **柱4 / AI協業** | 柱3のコストを AI が消す層。メタプログラミング |

## 賞まわり

| 用語 | 意味 |
| --- | --- |
| **譜面審査** | 応募スコアから本選進出作を選ぶ選考。**審査員本人が行う**。予備審査委員会はない |
| **本選** | 選ばれた4作品をオーケストラが実演し、その場で受賞作を決める公開審査 |
| **ファイナリスト** | 譜面審査を通過した4名。発表は12月上旬 |
| **必着** | 消印有効ではなく、現物が期日時刻までに到着していること |

## 記譜・演奏の用語

| 用語 | 意味 |
| --- | --- |
| **キースイッチ** | 音源ライブラリで奏法を切り替えるための、演奏音域外のノート |
| **CC** | MIDI コントロールチェンジ。CC1 / CC11 でダイナミクスや表情を送ることが多い |
| **ステム** | 楽器・グループごとに分けて書き出したオーディオ |
| **浄書** | 譜面を読みやすく整える作業。このプロジェクトでは Sibelius が担当し、作曲行為は含まない |

## 書き方の約束

- 数値には単位と、それが**実測なのか目標なのか仮置きなのか**を書く
- 図は Mermaid で書く
- 断定できないことは断定しない。`[推測]` と書くか、`open-questions.md` に置く
- **このリポジトリは公開されうる。** 特定のマシンにしか存在しないパスを書かない
